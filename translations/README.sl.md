## Ročna namestitev za začetnike

<details>
<summary><b>Nameščate prvič? Odprite kratka navodila</b></summary>

### 1. Razširite arhiv ZIP

Prenesite `weig-qb-webui.zip` in ga razširite. Arhiv že vsebuje naslednjo strukturo map:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

**Celotna mapa `weig-qb-webui`** je korenska mapa spletnega vmesnika. Ne kopirajte samo map `public` ali `private`.

### 2. Izberite trajno mesto

Celotno mapo premaknite na mesto, kjer je ne boste po pomoti izbrisali, na primer:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

To pot nato vnesete v nastavitve programa qBittorrent.

### 3. Omogočite alternativni WebUI v qBittorrentu

Odprite **Orodja → Možnosti → Spletni vmesnik**. Imena možnosti se lahko nekoliko razlikujejo glede na jezik qBittorrenta.

1. Označite **Uporabi alternativni spletni vmesnik** (*Use alternative WebUI*).
2. Poiščite polje **Mesto datotek** (*Files location*).
3. Vnesite pot do mape `weig-qb-webui`.

Primer za Windows:

```text
D:\weig-qb-webui
```

Primer za Linux:

```text
/opt/weig-qb-webui
```

4. Kliknite **OK**, da shranite spremembe.
5. Znova naložite stran qBittorrenta. Če se še vedno prikaže stari vmesnik, za prisilno osvežitev pritisnite `Ctrl + F5`.

> **Kako preveriti pot?** V izbrani mapi morajo biti neposredno vidne mape `public`, `private` in datoteka `VERSION`. Če morate najprej odpreti še eno mapo `weig-qb-webui`, ste izbrali napačno raven.

> **Uporabljate Docker?** qBittorrent deluje **znotraj vsebnika**. V nastavitve zato vnesite pot, ki je dostopna v vsebniku, in ne poti, ki obstaja samo na gostiteljskem sistemu. Razlaga sledi spodaj.

</details>

## Namestitev z enim ukazom

Namestitveni skript za Linux in NAS se vedno prenese s spodnjega stalnega naslova Dev Pages. **Naslov skripta ne določa namestitvenega kanala:** brez `-dev` se namesti zadnja preverjena stabilna izdaja iz GitHub Releases, z `-dev` pa razvojna različica, določena z natančnim Git SHA. Skript ostane v trenutni mapi za poznejšo posodobitev ali povrnitev prejšnje namestitve.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Prikaži mesto skripta in privzeto namestitveno mapo</b></summary>

Preneseni skript se shrani sem:

```text
./install.sh
```

Privzeta namestitvena mapa WebUI:

```text
~/.local/share/weig-qb-webui
```

Pri zagonu kot uporabnik `root` je to običajno:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Namestitev v Dockerju, več vsebnikov in pravilne poti</b></summary>

#### Gostitelj in vsebnik

Če uporabljate Docker na VPS, strežniku Linux, napravi Synology, QNAP ali drugem NAS-u:

- **Gostitelj (host)** je sistem Linux ali NAS, na katerem deluje Docker. Običajno se nanj povežete prek SSH.
- **Vsebnik (container)** je ločeno okolje, v katerem deluje qBittorrent. Vidi le mape, ki so vanj priklopljene.

Predpostavimo, da je konfiguracijska mapa priklopljena tako:

```text
Gostitelj: /root/qbittorrent/config
   ↓ priklopljeno kot
V vsebniku: /config
```

V Docker Compose je tak priklop lahko videti tako:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Pot **levo od dvopičja** pripada **gostitelju**, pot **desno** pa označuje mesto **v vsebniku**.

Če je WeiG na gostitelju nameščen tukaj:

```text
Gostitelj: /root/qbittorrent/config/weig-qb-webui
```

v polje **Files location** v qBittorrentu vnesite:

```text
/config/weig-qb-webui
```

**Ne vnesite `/root/qbittorrent/config/weig-qb-webui`**. To je pot na gostitelju, ki je vsebnik običajno ne vidi neposredno.

#### Primer 1: Imate samo en vsebnik qBittorrent

Zaženite:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Namestitveni skript bo poskusil poiskati delujoči vsebnik qBittorrent, priklop `/config` in ustrezno mapo na gostitelju. Če lahko varno prepozna konfiguracijo, samodejno nastavi qBittorrent.

#### Primer 2: Ne poznate imena vsebnika

Prikažite razpoložljive vsebnike:

```sh
sh install.sh --list-containers
```

Ali jih preverite neposredno z Dockerjem:

```sh
docker ps
```

Če se vsebnik na primer imenuje:

```text
qbittorrent
```

ga izrecno izberite:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Primer 3: Uporabljate več vsebnikov qBittorrent

Na primer glavnega in preizkusnega:

```text
qbittorrent
qbittorrent-test
```

Najprej prikažite seznam:

```sh
sh install.sh --list-containers
```

Namestitev v glavni vsebnik:

```sh
sh install.sh --container=qbittorrent -configure
```

Namestitev v preizkusni vsebnik:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Če skript najde več vsebnikov, **ne bo naključno izbral nobenega**.

#### Primer 4: Poznate mapo `/config` na gostitelju

Na primer:

```text
/root/qbittorrent/config
```

Lahko jo podate neposredno:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Na napravi Synology je pot lahko taka:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Na drugem NAS-u pa na primer:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

To so le primeri. Uporabite dejansko pot do konfiguracije qBittorrenta na svojem gostitelju.

#### Primer 5: Izberite namestitveno mapo WebUI

Če ste vsebnik že izbrali, lahko določite tudi mesto WebUI znotraj njega:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Namestitveni skript iz Dockerjevega priklopa `/config` ugotovi ustrezno pot na gostitelju.

#### Primer 6: Posodobite več namestitev hkrati

Če upravljate več primerkov qBittorrenta, lahko parameter `-o` večkrat ponovite. Paket se prenese in preveri le enkrat; noben cilj se ne zamenja, dokler niso pripravljeni vsi. Za vsak cilj se neodvisno hranijo **zadnje tri varnostne kopije** v `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Pri več ciljih ne uporabljajte `-configure`. Vsak primerek naj ohrani že nastavljeno pot do alternativnega WebUI. Vse možnosti prikaže ukaz `sh install.sh -help`.

#### Preverjanje poti po namestitvi

Po uspešni namestitvi je izpis lahko podoben temu:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

- `Host install path`: dejansko mesto datotek na gostitelju.
- `qBittorrent Root Folder`: pot **znotraj vsebnika**, ki jo vnesete v polje *Files location* v qBittorrentu.

Z možnostjo `-configure` skript omogoči alternativni WebUI in nastavi pot, če lahko varno ugotovi konfiguracijo qBittorrenta. Sicer sledite zgornjim navodilom za ročno namestitev.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Prikaži namestitveno mapo</b></summary>

```text
C:\Users\<uporabnisko_ime>\AppData\Local\weig-qb-webui
```

</details>

## Pogosti parametri

Osnovni parametri imajo v Linuxu in Windowsih enaka imena; PowerShell pri njihovih imenih ne razlikuje med velikimi in malimi črkami.

| Namen | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Namesti najnovejšo stabilno izdajo (`main`) | Privzeto, brez parametrov | Privzeto, brez parametrov |
| Namesti določeno stabilno izdajo | `-version 1.2.0` | `-version 1.2.0` |
| Namesti razvojno različico | `-dev` | `-dev` |
| Izberi namestitveno mapo | `-o /path` (v Linuxu je mogoče ponoviti) | `-o D:\path` ali `-output D:\path` |
| Določi konfiguracijsko datoteko qBittorrenta | — | `-qbconfig D:\path\qBittorrent.ini` |
| Samodejno nastavi qBittorrent | `-configure` | `-configure` |
| Povrni prejšnjo namestitev | `-rollback` | `-rollback` |
| Odstrani tudi varnostne kopije | `-uninstall -purge` | `-uninstall -purge` |
| Prikaži celotno pomoč | `-help` | `-help` |
| Izberi vsebnik Docker | `--container=NAME` | — |
| Prikaži seznam vsebnikov | `--list-containers` | — |
| Mapa `/config` na gostitelju | `--config-root=/path` | — |

<details>
<summary><b>Razlaga parametrov (razširi)</b></summary>

- Brez `-dev` se uporabi stabilni kanal `main`, z `-dev` pa razvojna različica, določena z natančnim Git SHA.
- Črka `o` v `-o` pomeni **output**. V Linuxu lahko parameter ponovite in z enim prenosom posodobite več obstoječih namestitev.
- Varnostne kopije, ki jih upravlja skript, so v `~/.config/weig-qb-webui/backups/`; za vsak cilj se hranijo **največ zadnje tri varnostne kopije**.
- `-configure` omogoči *Use alternative WebUI* in nastavi *Files location*, vendar samo za en cilj.
- `-rollback` povrne zadnjo varnostno kopijo, ki jo je skript ustvaril za izbrani cilj. S ponavljanjem `-o` lahko povrnete več izrecno določenih ciljev.
- `-uninstall -purge` odstrani varnostne kopije in podatke za povrnitev **samo trenutne namestitve**; druge namestitve ostanejo nedotaknjene.
- Če želite kopije ohraniti za poznejši `-rollback`, izpustite `-purge`.
- S parametrom `-version` namestite določeno izdajo z GitHub Releases, na primer `1.2.0`. Če je ni, namestitev spodleti in **ne preklopi samodejno** na latest ali dev.
- Pri več vsebnikih uporabite `--list-containers` in izberite `--container=NAME` ali pa navedite gostiteljsko mapo za `/config` z `--config-root=/path`.

### Izbira različice in namestitvene mape

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Povrnitev prejšnje namestitve

Linux:

```sh
sh install.sh -rollback
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Odstranitev z enim ukazom

<details>
<summary><b>Popolna odstranitev v Linuxu / NAS-u, Dockerju in Windows PowerShellu</b></summary>

Praviloma priporočamo **odstranitev WebUI brez ohranitve varnostnih kopij namestitvenega skripta**. Spodnji ukazi odstranijo vmesnik, izklopijo alternativni WebUI za izbrani cilj, izbrišejo varnostne kopije in podatke za povrnitev ter na koncu odstranijo preneseni namestitveni skript iz trenutne mape.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Če uporabljate mapo po meri, dodajte `-o /pot/do/weig-qb-webui`.

### Docker

En vsebnik s samodejnim zaznavanjem:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Več vsebnikov:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Pri uporabi `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Za mapo po meri dodajte `-o D:\weig-qb-webui`.

Parameter `-purge` odstrani le varnostne kopije namestitve, ki jo trenutno odstranjujete. Drugi primerki ostanejo nedotaknjeni. Če skupna mapa s stanjem postane povsem prazna, se odstrani še `~/.config/weig-qb-webui` v Linuxu (za `root`: `/root/.config/weig-qb-webui`) ali `%APPDATA%\weig-qb-webui` v Windowsih.

Če želite varnostne kopije ohraniti za poznejši `-rollback`, odstranite brez `-purge`.

</details>
