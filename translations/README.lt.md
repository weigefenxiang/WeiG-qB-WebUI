## Kelių egzempliorių šoninė juosta

Keli nepriklausomi qBittorrent egzemplioriai gali naudoti tą patį paruoštą WeiG aplanką **tik skaitymui**. Prijunkite pagrindinio kompiuterio aplanką prie kiekvieno Docker konteinerio atskirai, pavyzdžiui, `/root/weig-qb-webui:/weig-qb-webui:ro`, ir kiekviename qBittorrent egzemplioriuje nurodykite `/weig-qb-webui` kaip Alternative WebUI šakninį katalogą. Kiekvieno egzemplioriaus torrentai, nustatymai ir prisijungimai lieka atskiri.

Šoninės juostos skiltyje **Instances** galite registruoti egzempliorius, tarp jų persijungti pilnai atveriant kitą puslapį ir juos pervadinti (dešiniuoju pelės mygtuku arba eilutės meniu). Dabartinį egzempliorių nustato tikrasis URL, ne išsaugotas pavadinimo priesagas. Automatinio tikrinimo intervalas nustatomas **Settings → WeiG WebUI → Interface**: numatytoji reikšmė yra `30 min`; tikrinimą galima išjungti arba pasirinkti nuo 5 iki 1440 minučių.

**Būsenos įrodymai sąmoningai vertinami atsargiai:** patvirtintas to paties šaltinio WebAPI atsakymas rodo, kad qB veikia internete. Kryžminio šaltinio `no-cors` atsakymas be prisijungimo duomenų tik patvirtina HTTP adreso pasiekiamumą, net jei atsakymas yra 403/404. Kito šaltinio Cookie/SID neskaitomi, slaptažodžiai ir sesijos neperduodami, CORS neapeinamas ir serverio tarpininkas nenaudojamas. Ankstesnio sėkmingo patikrinimo laikas yra **istorinis įrodymas**, o ne dabartinės būsenos patvirtinimas. Naršyklėje adresas `127.0.0.1` reiškia patį įrenginį, kuriame veikia naršyklė, o ne nutolusį VPS.

## Diegimas pradedantiesiems

<details>
<summary><b>Diegiate pirmą kartą? Atverkite šį trumpą vadovą</b></summary>

### 1. Išskleiskite ZIP archyvą

Atsisiųskite `weig-qb-webui.zip` ir išskleiskite jį. Archyve jau yra standartinis aplankas:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Visas **`weig-qb-webui`** aplankas yra WebUI šakninis katalogas. Nekopijuokite vien `public` arba `private` aplanko.

### 2. Perkelkite į nuolatinę vietą

Pavyzdžiui:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Šį kelią vėliau turėsite nurodyti qBittorrent.

### 3. Įjunkite qBittorrent programoje

Atverkite qBittorrent:

**Tools → Options... → WebUI**

Tai tikslūs dabartinės angliškos qBittorrent sąsajos meniu pavadinimai. Toliau:

1. Įjunkite **Use alternative WebUI**.
2. Raskite lauką **Files location:**.
3. Įveskite `weig-qb-webui` aplanko kelią.

„Windows“ pavyzdys:

```text
D:\weig-qb-webui
```

„Linux“ pavyzdys:

```text
/opt/weig-qb-webui
```

4. Spustelėkite **OK**, kad išsaugotumėte.
5. Atnaujinkite qBittorrent WebUI puslapį. Jei naršyklės podėlyje liko sena sąsaja, vieną kartą pabandykite `Ctrl + F5`.

> **Kelio patikra:** nurodytame kataloge tiesiogiai turi būti `public`, `private`, `VERSION` ir kiti WebUI failai.

> **Docker naudotojams:** qBittorrent veikia konteineryje, todėl paprastai reikia nurodyti konteineryje matomą kelią, o ne pagrindinio kompiuterio kelią.

</details>

## Diegimas viena komanda

„Linux“ / NAS diegimo scenarijus visada atsisiunčiamas iš toliau nurodyto pastovaus Dev Pages adreso. **Scenarijaus URL nenustato diegimo kanalo:** be `-dev` diegiama naujausia patikrinta stabili GitHub Release versija; `-dev` pasirenka dabartinę kuriamą versiją pagal tikslų Git SHA. Atsisiųstas scenarijus lieka dabartiniame kataloge vėlesniam naujinimui ar grįžimui į ankstesnę versiją.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Rodyti scenarijaus adresą ir numatytąjį diegimo katalogą</b></summary>

```text
./install.sh
```

Numatytoji WebUI diegimo vieta:

```text
~/.local/share/weig-qb-webui
```

Vykdant kaip `root`, paprastai:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, keli konteineriai ir kelių paaiškinimas</b></summary>

#### Pagrindinis kompiuteris ir konteineris

- **Pagrindinis kompiuteris:** Linux / NAS įrenginys, kuriame veikia Docker.
- **Konteineris:** izoliuota aplinka, kurioje veikia qBittorrent.

Pavyzdžiui:

```text
Хост:       /root/qbittorrent/config
   ↓ смонтировано как
Контейнер:  /config
```

Docker Compose pavyzdys:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Jei WebUI pagrindiniame kompiuteryje yra čia:

```text
/root/qbittorrent/config/weig-qb-webui
```

qBittorrent lauke **Files location:** turite nurodyti:

```text
/config/weig-qb-webui
```

#### Vienas qBittorrent konteineris

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Diegiklis mėgins automatiškai aptikti konteinerį ir jo `/config` prijungtą katalogą.

#### Konteinerių paieška

Pirmiausia peržiūrėkite aptiktų qBittorrent konteinerių sąrašą:

```sh
sh install.sh --list-containers
```

Arba naudokite Docker tiesiogiai:

```sh
docker ps
```

Pavyzdžiui, konteineris gali vadintis:

```text
qbittorrent
```

Tuomet pasirinkite jį aiškiai:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Kai yra keli qBittorrent konteineriai

Pavyzdžiui, pagrindinis ir bandomasis egzemplioriai:

```text
qbittorrent
qbittorrent-test
```

Pirmiausia parodykite jų sąrašą:

```sh
sh install.sh --list-containers
```

Pagrindiniam egzemplioriui:

```sh
sh install.sh --container=qbittorrent -configure
```

Bandomajam egzemplioriui:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Jei aptikti keli konteineriai, diegiklis nepasirinks vieno atsitiktinai.

#### Pagrindinio kompiuterio aplanko, prijungto kaip `/config`, nurodymas

Jei qBittorrent konfigūracijos aplankas pagrindiniame kompiuteryje yra čia:

```text
/root/qbittorrent/config
```

Galite jį nurodyti tiesiogiai:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

„Synology“ pavyzdys:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Kitos NAS sistemos pavyzdys:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Pakeiskite pavyzdinius kelius tikruoju pagrindinio kompiuterio keliu, kuris qBittorrent prijungtas kaip `/config`.

#### WebUI diegimo aplanko pasirinkimas

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Kelių WebUI diegimų naujinimas vienu atsisiuntimu

„Linux“ / NAS sistemoje galite pakartoti parametrą `-o`, kad vienu atsisiuntimu atnaujintumėte kelis esamus diegimus. Šiuo režimu nenaudokite kartu `-configure`, `--container` ir `--config-root`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Kelių patikra po diegimo

Diegiklis parodo kelią pagrindiniame kompiuteryje ir qBittorrent matomą kelią:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent nustatyme **Files location** naudokite antrąjį kelią — esantį konteineryje. Jei `-configure` pavyksta, diegiklis jį nustato automatiškai.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Rodyti diegimo katalogą</b></summary>

```text
C:\Users\<имя-пользователя>\AppData\Local\weig-qb-webui
```

</details>

## Dažniausi parametrai
PowerShell parametrų pavadinimuose neskiriamos didžiosios ir mažosios raidės.

| Paskirtis | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Naujausia stabili versija | Numatytasis | Numatytasis |
| Konkreti Release versija | `-version 1.2.0` | `-version 1.2.0` |
| Kuriama versija | `-dev` | `-dev` |
| Diegimo aplankas | `-o /path` (galima kartoti) | `-o D:\path` arba `-output D:\path` |
| qBittorrent konfigūracijos failas | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automatinis qBittorrent konfigūravimas | `-configure` | `-configure` |
| Grįžti prie ankstesnės versijos | `-rollback` | `-rollback` |
| Visiškas pašalinimas (be atsarginių kopijų) | `-uninstall -purge` | `-uninstall -purge` |
| Pagalba | `-help` | `-help` |
| Docker konteinerio pasirinkimas | `--container=NAME` | — |
| Docker konteinerių sąrašas | `--list-containers` | — |
| Pagrindinio kompiuterio aplankas, prijungtas kaip Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Pastabos (spustelėkite, kad išskleistumėte)</b></summary>

- Jei prašomos versijos nėra, diegimas nutraukiamas ir automatiškai neperjungiama į latest arba dev.
- `-dev` negalima naudoti kartu su `-version`.

### Konkreti versija ir diegimo aplankas

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Grįžimas prie ankstesnės versijos

Grąžinimas:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Pašalinimas viena komanda

<details>
<summary><b>Visiškas pašalinimas Linux / NAS, Docker ir Windows PowerShell aplinkoje</b></summary>

Rekomenduojama komanda atlieka **visišką pašalinimą, neišsaugant diegiklio atsarginių kopijų**: pašalina WebUI, išjungia atitinkamą alternatyvios WebUI sąsajos nustatymą, ištrina šio diegimo atsargines kopijas ir grąžinimo būseną, tada pašalina atsisiųstą diegimo scenarijų iš dabartinio katalogo.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Jei naudojate pasirinktą diegimo katalogą, pridėkite `-o /path/to/weig-qb-webui`.

### Docker

Vienas konteineris / automatinis aptikimas:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Keli konteineriai:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Naudojant `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Pasirinktam diegimo katalogui pridėkite `-o D:\weig-qb-webui`.

`-purge` ištrina tik dabartinio diegimo atsargines kopijas ir neliečia kitų diegimų. Jei bendras būsenos katalogas ištuštėja, Linux sistemoje taip pat pašalinamas `~/.config/weig-qb-webui` (root naudotojui: `/root/.config/weig-qb-webui`), o Windows sistemoje — `%APPDATA%\weig-qb-webui`.

Jei norite išsaugoti atsargines kopijas vėlesniam `-rollback`, tiesiog nenaudokite `-purge`.

</details>
