## Több qBittorrent-példány az oldalsávon

Több egymástól független qBittorrent-példány használhatja ugyanazt az előkészített WeiG-mappát **csak olvasható** megosztásként. A gazdagépen lévő mappát minden Docker-konténerbe külön csatold, például `/root/weig-qb-webui:/weig-qb-webui:ro` alakban, majd mindegyik példányban a `/weig-qb-webui` helyet add meg az Alternative WebUI gyökérkönyvtáraként. A torrent-adatbázis, a beállítások és a bejelentkezés példányonként elkülönülnek.

Az oldalsáv **Instances** részében példányokat adhatsz hozzá, teljes oldalnavigációval válthatsz közöttük, és átnevezheted őket (jobb kattintással vagy a sor menüjéből). Az aktuális példányt a tényleges URL azonosítja, nem a névben tárolt utótag. Az automatikus ellenőrzés időköze a **Settings → WeiG WebUI → Interface** alatt állítható: alapértelmezésben `30 min`, kikapcsolható, illetve 5 és 1440 perc közé állítható.

**Az állapotjelzés szándékosan óvatos:** az azonos eredetről hitelesített WebAPI-válasz azt igazolja, hogy a qB online. A hitelesítő adatok nélküli, más eredetű `no-cors` HTTP-válasz csak a cím elérhetőségét jelzi, akár 403/404 esetén is. Nincs eredetek közötti Cookie/SID-olvasás, jelszó- vagy munkamenet-továbbítás, CORS-megkerülés vagy szerveroldali átjáró. A korábbi sikeres ellenőrzés mentett időpontja **történeti adat**, nem a jelenlegi online állapot bizonyítéka. A böngészőben szereplő `127.0.0.1` a böngészőt futtató eszközt jelenti, nem egy távoli VPS-t.

## Telepítés kezdőknek

<details>
<summary><b>Először telepíted? Nyisd meg ezt a rövid útmutatót</b></summary>

### 1. A ZIP kibontása

Töltsd le és bontsd ki a `weig-qb-webui.zip` fájlt. Az archívum már tartalmazza a szokásos mappát:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

A teljes **`weig-qb-webui`** mappa a WebUI gyökérkönyvtára. Ne csak a `public` vagy `private` mappát másold át.

### 2. Áthelyezés végleges helyre

Például:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Ezt az elérési utat kell majd megadnod a qBittorrentben.

### 3. Engedélyezés a qBittorrentben

Nyisd meg a qBittorrentet:

**Tools → Options... → WebUI**

Ezek a menüpontok a qBittorrent jelenlegi angol felületének pontos nevei. Ezután:

1. Kapcsold be a **Use alternative WebUI** lehetőséget.
2. Keresd meg a **Files location:** mezőt.
3. Add meg a `weig-qb-webui` mappa elérési útját.

Windows-példa:

```text
D:\weig-qb-webui
```

Linux-példa:

```text
/opt/weig-qb-webui
```

4. A mentéshez kattints az **OK** gombra.
5. Frissítsd a qBittorrent WebUI oldalát. Ha a böngésző gyorsítótárából még a régi felület látszik, egyszer próbáld meg a `Ctrl + F5` kombinációt.

> **Az útvonal ellenőrzése:** a megadott mappában közvetlenül látszania kell a `public`, `private`, `VERSION` és a többi WebUI-fájlnak.

> **Docker esetén:** a qBittorrent konténerben fut, ezért általában a konténerből látható útvonalat kell megadni, nem a gazdagép elérési útját.

</details>

## Telepítés egyetlen paranccsal

A Linux/NAS telepítőszkriptet mindig az alábbi állandó Dev Pages-címről töltöd le. **A szkript URL-je nem határozza meg a telepítési csatornát:** `-dev` nélkül a legújabb ellenőrzött stabil GitHub Release települ; a `-dev` az aktuális fejlesztői változatot választja a pontos Git SHA alapján. A letöltött szkript a jelenlegi mappában marad későbbi frissítéshez vagy visszaállításhoz.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>A szkript címének és az alapértelmezett telepítési mappának a megjelenítése</b></summary>

```text
./install.sh
```

A WebUI alapértelmezett telepítési helye:

```text
~/.local/share/weig-qb-webui
```

`root` felhasználóval futtatva ez általában:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, több konténer és az elérési utak magyarázata</b></summary>

#### Gazdagép és konténer

- **Gazdagép:** az a Linux/NAS gép, amelyen a Docker fut.
- **Konténer:** a qBittorrentet futtató elkülönített környezet.

Például:

```text
Хост:       /root/qbittorrent/config
   ↓ смонтировано как
Контейнер:  /config
```

Docker Compose-példa:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Ha a WebUI a gazdagépen itt található:

```text
/root/qbittorrent/config/weig-qb-webui
```

akkor a qBittorrent **Files location:** mezőjébe ezt kell beírnod:

```text
/config/weig-qb-webui
```

#### Egyetlen qBittorrent-konténer

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

A telepítő megpróbálja automatikusan felismerni a konténert és a `/config` csatolását.

#### A konténerek megkeresése

Először listázd a felismert qBittorrent-konténereket:

```sh
sh install.sh --list-containers
```

Vagy használd közvetlenül a Dockert:

```sh
docker ps
```

Például a konténer neve lehet:

```text
qbittorrent
```

Ezután válaszd ki kifejezetten:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Több qBittorrent-konténer esetén

Például egy éles és egy tesztpéldány:

```text
qbittorrent
qbittorrent-test
```

Először listázd őket:

```sh
sh install.sh --list-containers
```

Az éles példányhoz:

```sh
sh install.sh --container=qbittorrent -configure
```

A tesztpéldányhoz:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Több konténer esetén a telepítő nem választ önkényesen egyet.

#### A `/config` helyre csatolt gazdagépmappa megadása

Ha a qBittorrent konfigurációs mappája a gazdagépen itt van:

```text
/root/qbittorrent/config
```

Közvetlenül is megadhatod:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology-példa:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Más NAS-eszköz példája:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

A példaútvonalakat cseréld le a qBittorrent `/config` helyére ténylegesen csatolt gazdagépelérési útra.

#### A WebUI telepítési mappájának kiválasztása

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Több WebUI-telepítés frissítése egyetlen letöltéssel

Linuxon és NAS-on a `-o` kapcsolót többször megadva egyetlen letöltéssel több meglévő telepítés frissíthető. Ebben a módban ne használd együtt a `-configure`, `--container` és `--config-root` kapcsolókat.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Az útvonalak ellenőrzése telepítés után

A telepítő megjeleníti a gazdagépen lévő és a qBittorrentből látható elérési utat:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

A qBittorrent **Files location** beállításában a második, konténeren belüli útvonalat használd. Ha a `-configure` sikeresen lefut, a telepítő ezt automatikusan beállítja.

</details>

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

## Gyakori kapcsolók
A PowerShell-paraméterek nevében a kis- és nagybetűk nem számítanak.

| Cél | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Legújabb stabil kiadás | Alapértelmezés | Alapértelmezés |
| Konkrét Release-kiadás | `-version 1.2.0` | `-version 1.2.0` |
| Fejlesztői változat | `-dev` | `-dev` |
| Egyéni telepítési mappa | `-o /path` (ismételhető) | `-o D:\path` vagy `-output D:\path` |
| Egyéni qBittorrent-konfigurációs fájl | — | `-qbconfig D:\path\qBittorrent.ini` |
| qBittorrent automatikus beállítása | `-configure` | `-configure` |
| Korábbi telepítés visszaállítása | `-rollback` | `-rollback` |
| Teljes eltávolítás (telepítőmentések nélkül) | `-uninstall -purge` | `-uninstall -purge` |
| Teljes súgó | `-help` | `-help` |
| Docker-konténer kiválasztása | `--container=NAME` | — |
| Docker-konténerek listázása | `--list-containers` | — |
| A Docker `/config` helyére csatolt gazdagépmappa | `--config-root=/path` | — |

<summary><b>Megjegyzések (kattints a kibontáshoz)</b></summary>

## Eltávolítás egyetlen paranccsal

<details>
<summary><b>Teljes eltávolítás Linux / NAS, Docker és Windows PowerShell alatt</b></summary>

Az ajánlott eljárás **a telepítő biztonsági mentéseinek megőrzése nélkül** teljesen eltávolítja a WebUI-t: kikapcsolja a megfelelő alternatív WebUI-beállítást, törli az adott cél mentéseit és visszaállítási állapotát, majd eltávolítja a jelenlegi könyvtárból a letöltött telepítőszkriptet.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Egyéni telepítési mappához add meg a `-o /path/to/weig-qb-webui` kapcsolót.

### Docker

Egy konténer / automatikus felismerés:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Több konténer:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

A `--config-root` használatával:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Egyéni telepítési mappához add meg a `-o D:\weig-qb-webui` kapcsolót.

A `-purge` csak az aktuális cél mentéseit törli, más telepítéseket nem érint. Ha a közös állapotmappa kiürül, Linuxon a `~/.config/weig-qb-webui` (root esetén: `/root/.config/weig-qb-webui`), Windowson pedig a `%APPDATA%\weig-qb-webui` is eltávolításra kerül.

A mentések későbbi `-rollback` általi visszaállításához hagyd el a `-purge` kapcsolót.

</details>
