## Ručna instalacija za početnike

<details>
<summary><b>Prvi put instalirate? Otvorite kratko uputstvo</b></summary>

### 1. Raspakujte ZIP arhivu

Preuzmite `weig-qb-webui.zip` i raspakujte arhivu. Ona već sadrži sledeću strukturu direktorijuma:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

**Cela fascikla `weig-qb-webui`** predstavlja osnovni direktorijum veb-interfejsa. Nemojte kopirati samo `public` ili `private`.

### 2. Izaberite stalnu lokaciju

Premestite celu fasciklu na mesto gde je nećete slučajno obrisati, na primer:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Zatim unesite putanju do te fascikle u podešavanjima qBittorrenta.

### 3. Uključite alternativni WebUI interfejs u qBittorrentu

Otvorite **Alati → Opcije → WebUI** u qBittorrentu. Nazivi opcija mogu da se razlikuju u zavisnosti od izabranog jezika.

1. Označite **Koristi alternativni veb-interfejs** (*Use alternative WebUI*).
2. Pronađite polje **Lokacija datoteka** (*Files location*).
3. Unesite putanju do fascikle `weig-qb-webui`.

Primjer za Windows:

```text
D:\weig-qb-webui
```

Primjer za Linux:

```text
/opt/weig-qb-webui
```

4. Kliknite na **OK** da sačuvate izmene.
5. Ponovo učitajte stranicu qBittorrenta. Ako se i dalje prikazuje stari interfejs, pritisnite `Ctrl + F5` da je osvežite bez keša.

> **Kako proveriti putanju?** U izabranoj fascikli moraju direktno da se nalaze `public`, `private` i `VERSION`. Ako prvo morate da otvorite još jednu fasciklu `weig-qb-webui`, izabrali ste pogrešan nivo direktorijuma.

> **Koristite Docker?** qBittorrent radi **unutar kontejnera**. Zato u podešavanjima navedite putanju koja je dostupna kontejneru, a ne samo putanju na host računaru. Objašnjenje sledi u nastavku.

</details>

## Instalacija jednom komandom

Instalaciona skripta za Linux i NAS uvek se preuzima sa stalne adrese Dev Pages navedene ispod. **Adresa skripte ne određuje kanal instalacije:** bez `-dev` instalira se poslednja proverena stabilna verzija sa GitHub Releases, a sa `-dev` razvojna verzija vezana za tačan Git SHA. Skripta ostaje u trenutnoj fascikli radi kasnijeg ažuriranja ili vraćanja prethodne verzije.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Prikaži lokaciju skripte i podrazumevanu instalacionu fasciklu</b></summary>

Preuzeta skripta sprema se ovde:

```text
./install.sh
```

Podrazumevana instalaciona fascikla za WebUI:

```text
~/.local/share/weig-qb-webui
```

Kada se pokreće kao korisnik `root`, to je obično:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Instalacija u Dockeru, više kontejnera i ispravni putanje</b></summary>

#### Host i kontejner

Ako koristite Docker na VPS-u, Linux serveru, Synologyju, QNAP-u ili drugom NAS uređaju:

- **Host** je Linux ili NAS sistem na kom radi Docker. Obično mu pristupate preko SSH-a.
- **Kontejner (container)** je izdvojeno okruženje u kom radi qBittorrent. Vidi samo fascikle koje su u njega mapirane.

Pretpostavimo da je konfiguracijska fascikla povezana ovako:

```text
Domaćin: /root/qbittorrent/config
   ↓ povezano kao
Unutar spremnika: /config
```

U Docker Compose konfiguraciji to može izgledati ovako:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Putanja **levo od dvotačke** pripada **hostu**, a putanja **desno** označava lokaciju **unutar kontejnera**.

Ako je WeiG instaliran na hostu ovde:

```text
Domaćin: /root/qbittorrent/config/weig-qb-webui
```

u polje **Files location** u qBittorrentu unesite:

```text
/config/weig-qb-webui
```

**Nemojte unositi `/root/qbittorrent/config/weig-qb-webui`**. To je putanja na hostu koju kontejner obično ne može direktno da vidi.

#### Slučaj 1: Imate samo jedan qBittorrent kontejner

Pokrenite:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Instalaciona skripta će pokušati da pronađe aktivni qBittorrent kontejner, mapiranje `/config` i odgovarajuću fasciklu na hostu. Ako može pouzdano da prepozna konfiguraciju, automatski će podesiti qBittorrent.

#### Slučaj 2: Ne znate naziv kontejnera

Prikažite dostupne kontejnere:

```sh
sh install.sh --list-containers
```

Ili ih proverite direktno u Dockeru:

```sh
docker ps
```

Ako se kontejner, na primer, zove:

```text
qbittorrent
```

izričito ga izaberite:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Slučaj 3: Koristite više qBittorrent kontejnera

Na primer, jedan glavni i jedan testni:

```text
qbittorrent
qbittorrent-test
```

Najpre prikažite popis:

```sh
sh install.sh --list-containers
```

Instalacija u glavni kontejner:

```sh
sh install.sh --container=qbittorrent -configure
```

Instalacija u testni kontejner:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ako instalaciona skripta pronađe više kontejnera, **neće nasumično izabrati nijedan**.

#### Slučaj 4: Znate lokaciju fascikle `/config` na hostu

Na primer:

```text
/root/qbittorrent/config
```

Možete je direktno navesti:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Na Synologyju put može izgledati ovako:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Na drugom NAS uređaju, na primer:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Ovo su samo primjeri. Koristite stvarni put do konfiguracije qBittorrenta na svojem hostu.

#### Slučaj 5: Izaberite instalacionu fasciklu za WebUI

Ako ste već izabrali kontejner, možete zadati i lokaciju WebUI-ja unutar njega:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Instalaciona skripta prema Docker povezivanju `/config` pronalazi odgovarajući put na hostu.

#### Slučaj 6: Ažurirajte više instalacija odjednom

Ako upravljate većim brojem qBittorrent instanci, možete da ponovite parametar `-o`. Paket se preuzima i proverava samo jednom; nijedna instalacija se ne zamenjuje dok svi ciljevi nisu pripremljeni. Za svaki cilj zasebno se čuvaju **tri poslednje rezervne kopije** u `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Za više ciljeva nemojte koristiti `-configure`. Svaka instanca zadržava ranije podešenu putanju do alternativnog WebUI-ja. Sve opcije možete videti komandom `sh install.sh -help`.

#### Provera putanja posle instalacije

Nakon uspešne instalacije može se prikazati nešto poput ovoga:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

- `Host install path`: stvarna lokacija datoteka na hostu.
- `qBittorrent Root Folder`: put **unutar kontejnera** koji unosite u polje *Files location* u qBittorrentu.

Ako skriptu pokrenete uz `-configure`, ona uključuje alternativni WebUI i podešava put ako može sigurno otkriti konfiguraciju qBittorrenta. U protivnom slijedite gornje uputstva za ručnu instalaciju.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Prikaži instalacionu fasciklu</b></summary>

```text
C:\Users\<korisnicko_ime>\AppData\Local\weig-qb-webui
```

</details>

## Uobičajeni parametri

Osnovni parametri se isto zovu na Linuxu i Windowsu; PowerShell ne razlikuje velika i mala slova u njihovim nazivima.

| Namjena | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Instaliraj najnoviju stabilnu verziju (`main`) | Podrazumijevano, bez parametara | Podrazumijevano, bez parametara |
| Instaliraj određenu stabilnu verziju | `-version 1.2.0` | `-version 1.2.0` |
| Instaliraj razvojnu verziju | `-dev` | `-dev` |
| Izaberi instalacionu fasciklu | `-o /path` (na Linuxu se može ponoviti) | `-o D:\path` ili `-output D:\path` |
| Navedi konfiguracijsku datoteku qBittorrenta | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automatski postavi qBittorrent | `-configure` | `-configure` |
| Vrati prethodnu instalaciju | `-rollback` | `-rollback` |
| Deinstaliraj i ukloni rezervne kopije | `-uninstall -purge` | `-uninstall -purge` |
| Prikaži potpunu pomoć | `-help` | `-help` |
| Izaberi Docker kontejner | `--container=NAME` | — |
| Prikaži popis kontejnera | `--list-containers` | — |
| Mapa `/config` na hostu | `--config-root=/path` | — |

<details>
<summary><b>Objašnjenje parametara (proširi)</b></summary>

- Bez `-dev` koristi se stabilni kanal `main`; s `-dev` razvojna verzija određena tačnim Git SHA identifikatorom.
- Slovo `o` u `-o` znači **output**. Na Linuxu se parametar može ponavljati kako biste jednim preuzimanjem ažurirali više postojećih instalacija.
- Rezervne kopije kojima upravlja instalaciona skripta nalaze se u `~/.config/weig-qb-webui/backups/`; za svako se odredište čuvaju **najviše tri najnovije rezervne kopije**.
- `-configure` uključuje *Use alternative WebUI* i podešava *Files location*, ali samo za jedno odredište.
- `-rollback` vraća poslednju rezervnu kopiju koju je za izabrano odredište napravila instalaciona skripta. Ponavljanjem `-o` možete vratiti više izričito navedenih odredišta.
- `-uninstall -purge` uklanja rezervne kopije i stanje za povratak **samo trenutne instalacije**; ostale instalacije ostaju netaknute.
- Ako želite sačuvati kopije za kasniji `-rollback`, izostavite `-purge`.
- Parametrom `-version` instalirate određeno izdanje s GitHub Releases, na primer `1.2.0`. Ako ne postoji, instalacija završava pogreškom i **ne prelazi automatski** na latest ili dev.
- Za više kontejnera pokrenite `--list-containers` i izaberite `--container=NAME`; alternativno navedite fasciklu hosta za `/config` preko `--config-root=/path`.

### Izbor verzije i instalacione fascikle

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Vraćanje prethodne instalacije

Linux:

```sh
sh install.sh -rollback
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Deinstalacija jednom komandom

<details>
<summary><b>Potpuna deinstalacija na Linuxu / NAS-u, u Dockeru i Windows PowerShellu</b></summary>

Preporučujemo **uklanjanje WebUI-ja bez čuvanja rezervnih kopija instalacione skripte**. Sledeće komande uklanjaju interfejs, isključuju alternativni WebUI za izabrani cilj, brišu njegove rezervne kopije i stanje za povratak i na kraju uklanjaju preuzetu instalacionu skriptu iz trenutne fascikle.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Ako koristite prilagođenu fasciklu, dodajte `-o /put/do/weig-qb-webui`.

### Docker

Jedan kontejner s automatskim otkrivanjem:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Više kontejnera:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Kada koristite `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Za prilagođenu fasciklu dodajte `-o D:\weig-qb-webui`.

Parametar `-purge` uklanja samo rezervne kopije instalacije koju upravo deinstalirate. Ostale instance ostaju netaknute. Ako zajednička fascikla sa stanjem postane potpuno prazna, uklanja se i `~/.config/weig-qb-webui` na Linuxu (za `root`: `/root/.config/weig-qb-webui`) ili `%APPDATA%\weig-qb-webui` na Windowsima.

Ako želite zadržati rezervne kopije za kasniji `-rollback`, deinstalirajte bez `-purge`.

</details>
