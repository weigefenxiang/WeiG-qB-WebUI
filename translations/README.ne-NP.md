## धेरै इन्स्टेन्सका लागि साइडबार

धेरै स्वतन्त्र qBittorrent इन्स्टेन्सले तयार पारिएको एउटै WeiG फोल्डरलाई **पढ्न मात्र मिल्ने** रूपमा साझा गर्न सक्छन्। होस्टको फोल्डर प्रत्येक Docker कन्टेनरमा छुट्टाछुट्टै माउन्ट गर्नुहोस्, उदाहरणका लागि `/root/weig-qb-webui:/weig-qb-webui:ro`, र प्रत्येक qBittorrent इन्स्टेन्समा `/weig-qb-webui` लाई Alternative WebUI को मूल निर्देशिका बनाउनुहोस्। प्रत्येक इन्स्टेन्सका टोरेंट, सेटिङ र लगइन अलग रहन्छन्।

साइडबारको **Instances** खण्डबाट इन्स्टेन्स थप्न, पूरा नयाँ पृष्ठ खोलेर तिनका बीचमा जान र नाम बदल्न सकिन्छ (दायाँ क्लिक वा पङ्क्तिको मेनुबाट)। हालको इन्स्टेन्स वास्तविक URL बाट छुट्याइन्छ, सुरक्षित राखिएको नामको अन्तिम भागबाट होइन। स्वतः जाँचको अन्तराल **Settings → WeiG WebUI → Interface** मा मिलाउन सकिन्छ; पूर्वनिर्धारित `30 min` हो, यसलाई बन्द गर्न वा 5 देखि 1440 मिनेटसम्म राख्न सकिन्छ।

**स्थिति देखाउने प्रमाण सावधानीपूर्वक बुझ्नुपर्छ:** एउटै ओरिजिनबाट प्रमाणित WebAPI प्रतिक्रिया आएमा qB अनलाइन रहेको पुष्टि हुन्छ। अर्को ओरिजिनबाट प्रमाणीकरण जानकारीबिनाको `no-cors` प्रतिक्रियाले HTTP ठेगानामा पहुँच भएको मात्र देखाउँछ, प्रतिक्रिया 403/404 भए पनि। अर्को ओरिजिनको Cookie/SID पढिँदैन, पासवर्ड वा सेसन पठाइँदैन, CORS छलिँदैन र सर्भर प्रोक्सी प्रयोग हुँदैन। पहिले सफल जाँच भएको सुरक्षित समय **ऐतिहासिक प्रमाण** हो, अहिले अनलाइन रहेको पुष्टि होइन। ब्राउजरमा `127.0.0.1` ले ब्राउजर चल्ने उपकरणलाई जनाउँछ, टाढाको VPS लाई होइन।

## नयाँ प्रयोगकर्ताका लागि स्थापना

<details>
<summary><b>पहिलो पटक स्थापना गर्दै हुनुहुन्छ? यो छोटो मार्गदर्शन खोल्नुहोस्</b></summary>

### 1. ZIP फाइल निकाल्नुहोस्

`weig-qb-webui.zip` डाउनलोड गरी अनजिप गर्नुहोस्। सङ्ग्रहमा मानक फोल्डर पहिल्यै छ:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

पूरै **`weig-qb-webui`** फोल्डर नै WebUI को मूल निर्देशिका हो। `public` वा `private` मात्र प्रतिलिपि नगर्नुहोस्।

### 2. स्थायी ठाउँमा सार्नुहोस्

उदाहरणका लागि:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

यो बाटो पछि qBittorrent मा प्रविष्ट गर्नुपर्नेछ।

### 3. qBittorrent मा सक्रिय गर्नुहोस्

qBittorrent खोल्नुहोस्:

**Tools → Options... → WebUI**

यी हालको अङ्ग्रेजी qBittorrent इन्टरफेसमा प्रयोग भएका ठ्याक्कै मेनु नाम हुन्। त्यसपछि:

1. **Use alternative WebUI** सक्रिय गर्नुहोस्।
2. **Files location:** क्षेत्र फेला पार्नुहोस्।
3. `weig-qb-webui` फोल्डरको बाटो प्रविष्ट गर्नुहोस्।

Windows को उदाहरण:

```text
D:\weig-qb-webui
```

Linux को उदाहरण:

```text
/opt/weig-qb-webui
```

4. सुरक्षित गर्न **OK** थिच्नुहोस्।
5. qBittorrent WebUI पृष्ठ पुनः लोड गर्नुहोस्। ब्राउजरको क्यासमा पुरानो पृष्ठ बाँकी छ भने एक पटक `Ctrl + F5` प्रयोग गर्नुहोस्।

> **बाटो जाँच:** दिइएको फोल्डरमा `public`, `private`, `VERSION` र अन्य WebUI फाइलहरू सिधै हुनुपर्छ।

> **Docker प्रयोगकर्ताका लागि:** qBittorrent कन्टेनरभित्र चल्छ, त्यसैले सामान्यतया होस्टको बाटो होइन, कन्टेनरबाट देखिने बाटो प्रविष्ट गर्नुपर्छ।

</details>

## एउटा कमान्डबाट स्थापना

Linux/NAS स्थापना स्क्रिप्ट सधैँ तलको निश्चित Dev Pages ठेगानाबाट डाउनलोड हुन्छ। **स्क्रिप्टको URL ले स्थापना गर्ने च्यानल छान्दैन:** `-dev` बिना नवीनतम प्रमाणित स्थिर GitHub Release स्थापना हुन्छ; `-dev` ले ठ्याक्कै Git SHA अनुसार हालको विकास संस्करण छान्छ। डाउनलोड गरिएको स्क्रिप्ट पछिको अद्यावधिक वा पुरानो संस्करणमा फर्कन हालको फोल्डरमै रहन्छ।

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>स्क्रिप्टको ठेगाना र पूर्वनिर्धारित स्थापना फोल्डर देखाउनुहोस्</b></summary>

```text
./install.sh
```

पूर्वनिर्धारित रूपमा WebUI यहाँ स्थापना हुन्छ:

```text
~/.local/share/weig-qb-webui
```

`root` को रूपमा चलाउँदा सामान्यतया यहाँ:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, धेरै कन्टेनर र बाटोहरूको व्याख्या</b></summary>

#### होस्ट र कन्टेनर

- **होस्ट:** Docker चलिरहेको Linux/NAS कम्प्युटर।
- **कन्टेनर:** qBittorrent चल्ने छुट्टै वातावरण।

उदाहरणका लागि:

```text
Хост:       /root/qbittorrent/config
   ↓ यसरी माउन्ट
कन्टेनर:  /config
```

Docker Compose को उदाहरण:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

यदि WebUI होस्टमा यहाँ छ भने:

```text
/root/qbittorrent/config/weig-qb-webui
```

qBittorrent को **Files location:** क्षेत्रमा यो राख्नुहोस्:

```text
/config/weig-qb-webui
```

#### एउटा qBittorrent कन्टेनर

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

स्थापकले कन्टेनर र त्यसको `/config` माउन्ट स्वतः पहिचान गर्ने प्रयास गर्छ।

#### कन्टेनर फेला पार्नुहोस्

पहिले पहिचान गरिएका qBittorrent कन्टेनरहरूको सूची हेर्नुहोस्:

```sh
sh install.sh --list-containers
```

वा Docker सिधै प्रयोग गर्नुहोस्:

```sh
docker ps
```

उदाहरणका लागि, कन्टेनरको नाम यस्तो हुन सक्छ:

```text
qbittorrent
```

त्यसपछि त्यसलाई स्पष्ट रूपमा छान्नुहोस्:

```sh
sh install.sh --container=qbittorrent -configure
```

#### धेरै qBittorrent कन्टेनर हुँदा

उदाहरणका लागि, एउटा मुख्य र एउटा परीक्षण इन्स्टेन्स:

```text
qbittorrent
qbittorrent-test
```

पहिले तिनको सूची निकाल्नुहोस्:

```sh
sh install.sh --list-containers
```

मुख्य इन्स्टेन्सका लागि:

```sh
sh install.sh --container=qbittorrent -configure
```

परीक्षण इन्स्टेन्सका लागि:

```sh
sh install.sh --container=qbittorrent-test -configure
```

धेरै कन्टेनर भएमा स्थापकले कुनै एउटा मनलाग्दी छान्दैन।

#### `/config` को रूपमा माउन्ट गरिएको होस्ट फोल्डर उल्लेख गर्नुहोस्

यदि qBittorrent को कन्फिगरेसन फोल्डर होस्टमा यहाँ छ भने:

```text
/root/qbittorrent/config
```

तपाईं त्यसलाई सिधै दिन सक्नुहुन्छ:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology को उदाहरण:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

अर्को NAS को उदाहरण:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

उदाहरणका बाटाहरूलाई qBittorrent मा `/config` का रूपमा माउन्ट गरिएको होस्टको वास्तविक बाटोसँग बदल्नुहोस्।

#### WebUI स्थापना फोल्डर छान्नुहोस्

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### एउटै डाउनलोडबाट धेरै WebUI स्थापना अद्यावधिक गर्नुहोस्

Linux/NAS मा `-o` विकल्प दोहोर्याएर एउटै डाउनलोडपछि धेरै विद्यमान स्थापना अद्यावधिक गर्न सकिन्छ। यस मोडमा `-configure`, `--container` र `--config-root` एकसाथ प्रयोग नगर्नुहोस्।

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### स्थापनापछि बाटाहरू जाँच्नुहोस्

स्थापकले होस्टको बाटो र qBittorrent लाई देखिने बाटो देखाउँछ:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent को **Files location** मा दोस्रो अर्थात् कन्टेनरभित्रको बाटो प्रयोग गर्नुहोस्। `-configure` सफल भएमा स्थापकले त्यसलाई स्वतः मिलाउँछ।

</details>

PowerShell मा प्यारामिटरका नामले ठूला र साना अक्षर छुट्याउँदैनन्।

| उद्देश्य | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| नवीनतम स्थिर रिलीज | पूर्वनिर्धारित | पूर्वनिर्धारित |
| निश्चित Release संस्करण | `-version 1.2.0` | `-version 1.2.0` |
| विकास संस्करण | `-dev` | `-dev` |
| स्थापना फोल्डर | `-o /path` (दोहोर्याउन मिल्छ) | `-o D:\path` वा `-output D:\path` |
| qBittorrent कन्फिगरेसन फाइल | — | `-qbconfig D:\path\qBittorrent.ini` |
| qBittorrent स्वतः कन्फिगर गर्नुहोस् | `-configure` | `-configure` |
| अघिल्लो स्थापना फर्काउनुहोस् | `-rollback` | `-rollback` |
| पूर्ण रूपमा हटाउनुहोस् (ब्याकअप नराखी) | `-uninstall -purge` | `-uninstall -purge` |
| पूर्ण मद्दत | `-help` | `-help` |

| Docker `/config` मा माउन्ट गरिएको होस्ट फोल्डर | `--config-root=/path` | — |

## एउटा कमान्डबाट हटाउनुहोस्

<details>
<summary><b>Linux / NAS, Docker र Windows PowerShell मा पूर्ण रूपमा हटाउने</b></summary>

सिफारिस गरिएको कमान्डले **स्थापकका ब्याकअप नराखी पूर्ण हटाउने** काम गर्छ: WebUI हटाउँछ, सम्बन्धित वैकल्पिक WebUI सेटिङ निष्क्रिय बनाउँछ, यस लक्ष्यका ब्याकअप र फिर्ता गर्ने अवस्था मेटाउँछ, अनि हालको फोल्डरबाट डाउनलोड गरिएको स्थापना स्क्रिप्ट हटाउँछ।

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

आफूले छानेको स्थापना फोल्डरका लागि `-o /path/to/weig-qb-webui` थप्नुहोस्।

### Docker

एउटा कन्टेनर / स्वतः पहिचान:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

धेरै कन्टेनर:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` प्रयोग गर्दा:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

आफ्नो फोल्डरका लागि `-o D:\weig-qb-webui` थप्नुहोस्।

`-purge` ले हालको लक्ष्यका ब्याकअप मात्र हटाउँछ, अन्य स्थापनालाई असर गर्दैन। साझा अवस्था फोल्डर खाली भएमा Linux मा `~/.config/weig-qb-webui` (root का लागि: `/root/.config/weig-qb-webui`) वा Windows मा `%APPDATA%\weig-qb-webui` पनि हटाइन्छ।

पछि `-rollback` गर्न ब्याकअप राख्न चाहनुहुन्छ भने `-purge` प्रयोग नगर्नुहोस्।

</details>
