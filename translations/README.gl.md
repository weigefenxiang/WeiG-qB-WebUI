## Barra lateral con varias instancias

Varias instancias independentes de qBittorrent poden compartir o mesmo cartafol WeiG preparado **en modo de só lectura**. Monta o cartafol da máquina anfitrioa en cada contedor Docker, por exemplo `/root/weig-qb-webui:/weig-qb-webui:ro`, e configura `/weig-qb-webui` como raíz do Alternative WebUI en cada instancia. Cada unha mantén separados os seus torrentes, axustes e datos de acceso.

A sección **Instances** da barra lateral permite rexistrar instancias, alternar entre elas mediante navegación de páxina completa e cambiarlles o nome (con clic dereito ou o menú da fila). A marca da instancia actual depende do URL real, non dun sufixo gardado. O intervalo de comprobación automática atópase en **Settings → WeiG WebUI → Interface**, cun valor predeterminado de `30 min`; pódese desactivar ou escoller entre 5 e 1440 minutos.

**A información de dispoñibilidade é deliberadamente prudente:** un WebAPI verificado na mesma orixe indica que qB está en liña. Unha resposta entre orixes a unha petición `no-cors` sen credenciais só proba que o enderezo HTTP é accesible, mesmo se devolve 403/404. Non hai lectura entre orixes de Cookie/SID, transferencia de contrasinais ou sesións, evasión de CORS nin pasarela de servidor. A hora dunha comprobación anterior é **evidencia histórica**, non confirmación do estado actual. O enderezo `127.0.0.1` no navegador refírese ao dispositivo que executa ese navegador e non a un VPS remoto.

## Instalación para principiantes

<details>
<summary><b>É a túa primeira instalación? Abre esta guía rápida</b></summary>

### 1. Extrae o arquivo ZIP

Descarga `weig-qb-webui.zip` e extráeo. O arquivo xa contén o cartafol habitual:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Todo o cartafol **`weig-qb-webui`** constitúe a raíz de WebUI. Non copies unicamente `public` ou `private`.

### 2. Móveo a un lugar permanente

Por exemplo:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Este é o camiño que despois introducirás en qBittorrent.

### 3. Actívao en qBittorrent

Abre qBittorrent:

**Tools → Options... → WebUI**

Estes son os nomes exactos da interface actual de qBittorrent en inglés. Despois:

1. Activa **Use alternative WebUI**.
2. Localiza o campo **Files location:**.
3. Introduce o camiño ao cartafol `weig-qb-webui`.

Exemplo para Windows:

```text
D:\weig-qb-webui
```

Exemplo para Linux:

```text
/opt/weig-qb-webui
```

4. Preme **OK** para gardar.
5. Actualiza a páxina de qBittorrent WebUI. Se segue aparecendo a interface antiga gardada na caché, proba unha vez `Ctrl + F5`.

> **Como comprobar o camiño:** dentro do directorio indicado deben aparecer directamente `public`, `private`, `VERSION` e os demais ficheiros.

> **Para Docker:** qBittorrent execútase dentro dun contedor; normalmente debes indicar un camiño visible desde ese contedor, non directamente o camiño da máquina anfitrioa.

</details>

## Instalación cun só comando

O instalador para Linux/NAS descárgase sempre do enderezo fixo de Dev Pages que aparece abaixo. **O URL do script non determina a canle de instalación:** sen `-dev` instala a última versión estable verificada de GitHub Release; con `-dev` escolles a versión de desenvolvemento actual identificada polo seu Git SHA exacto. O script descargado permanece no directorio actual para actualizacións ou reversións posteriores.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Amosar o enderezo do script e o directorio de instalación predeterminado</b></summary>

```text
./install.sh
```

Por defecto, WebUI instálase en:

```text
~/.local/share/weig-qb-webui
```

Ao executalo como `root`, normalmente en:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, varios contedores e explicación dos camiños</b></summary>

#### Máquina anfitrioa e contedor

- **Anfitrioa:** a máquina Linux/NAS na que se executa Docker.
- **Contedor:** o contorno illado no que se executa qBittorrent.

Por exemplo:

```text
Хост:       /root/qbittorrent/config
   ↓ montado como
Contedor:  /config
```

Exemplo de Docker Compose:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Se WebUI está instalado neste camiño da máquina anfitrioa:

```text
/root/qbittorrent/config/weig-qb-webui
```

no campo de qBittorrent **Files location:** debes indicar:

```text
/config/weig-qb-webui
```

#### Un único contedor de qBittorrent

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

O instalador intentará detectar o contedor e a súa montaxe `/config` automaticamente.

#### Localizar os contedores

Primeiro, consulta a lista de contedores de qBittorrent detectados:

```sh
sh install.sh --list-containers
```

Ou utiliza Docker directamente:

```sh
docker ps
```

Por exemplo, o contedor pode chamarse:

```text
qbittorrent
```

Entón selecciónao explicitamente:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Cando hai varios contedores de qBittorrent

Por exemplo, unha instancia principal e outra de probas:

```text
qbittorrent
qbittorrent-test
```

Primeiro, obten a súa lista:

```sh
sh install.sh --list-containers
```

Para a instancia principal:

```sh
sh install.sh --container=qbittorrent -configure
```

Para a instancia de probas:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Se hai varios contedores, o instalador non escollerá un deles ao chou.

#### Indicar o cartafol da anfitrioa montado como `/config`

Se o cartafol de configuración de qBittorrent na máquina anfitrioa está aquí:

```text
/root/qbittorrent/config
```

Podes indicalo directamente:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Exemplo para Synology:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Exemplo para outro NAS:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Substitúe estes exemplos polo camiño real da anfitrioa montado como `/config` en qBittorrent.

#### Indicar o cartafol de WebUI

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Actualizar varias instalacións de WebUI cunha única descarga

En Linux/NAS podes repetir a opción `-o` para actualizar varias instalacións existentes cunha soa descarga. Neste modo non utilices ao mesmo tempo `-configure`, `--container` nin `--config-root`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Comprobar os camiños tras a instalación

O instalador amosa o camiño da máquina anfitrioa e o que pode ver qBittorrent:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

No axuste **Files location** de qBittorrent debes usar o segundo camiño, o que está dentro do contedor. Se `-configure` se realiza correctamente, o instalador configúrao automaticamente.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Amosar o cartafol de instalación</b></summary>

```text
C:\Users\<nome-de-usuario>\AppData\Local\weig-qb-webui
```

</details>

## Opcións habituais
Os nomes dos parámetros de PowerShell non distinguen entre maiúsculas e minúsculas.

| Finalidade | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Última versión estable | Predeterminado | Predeterminado |
| Versión concreta de Release | `-version 1.2.0` | `-version 1.2.0` |
| Versión de desenvolvemento | `-dev` | `-dev` |
| Directorio de instalación | `-o /path` (repetible) | `-o D:\path` ou `-output D:\path` |
| Ficheiro de configuración de qBittorrent | — | `-qbconfig D:\path\qBittorrent.ini` |
| Configurar qBittorrent automaticamente | `-configure` | `-configure` |
| Recuperar unha instalación anterior | `-rollback` | `-rollback` |
| Desinstalación completa (sen copias de seguridade) | `-uninstall -purge` | `-uninstall -purge` |
| Axuda completa | `-help` | `-help` |
| Escoller un contedor Docker | `--container=NAME` | — |
| Enumerar contedores Docker | `--list-containers` | — |
| Cartafol da anfitrioa montado como Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Notas (preme para despregar)</b></summary>

- Se a versión solicitada non existe, a instalación falla e nunca cambia automaticamente a latest ou dev.
- `-dev` non se pode combinar con `-version`.

### Versión e directorio de instalación específicos

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Reversión

Reverter:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Desinstalación cun só comando

<details>
<summary><b>Desinstalación completa para Linux / NAS, Docker e Windows PowerShell</b></summary>

O comando recomendado realiza unha **desinstalación completa sen conservar as copias de seguridade do instalador**: elimina WebUI, desactiva a configuración do WebUI alternativo correspondente, borra as copias de seguridade e o estado de reversión desa instalación e, finalmente, elimina o script descargado do directorio actual.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Para un directorio de instalación personalizado, engade `-o /path/to/weig-qb-webui`.

### Docker

Un contedor / detección automática:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Varios contedores:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Ao utilizar `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Para un directorio personalizado, engade `-o D:\weig-qb-webui`.

`-purge` só elimina as copias de seguridade da instalación actual; non modifica as doutras instalacións. Se o cartafol de estado compartido queda baleiro, tamén se elimina `~/.config/weig-qb-webui` en Linux (para root: `/root/.config/weig-qb-webui`) ou `%APPDATA%\weig-qb-webui` en Windows.

Para conservar as copias de seguridade para unha reversión posterior con `-rollback`, basta con omitir `-purge`.

</details>
