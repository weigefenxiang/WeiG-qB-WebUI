## Suonu panelis vairuokom instancēm

Vairuokys navatkareigys qBittorrent instancis var lītuot tū pošu sagatavotū WeiG mapi **tikai laseišonai**. Pīmontējit saimnīkdatora mapi kotrā Docker konteinerī, pīmāram, `/root/weig-qb-webui:/weig-qb-webui:ro`, tod kotrys qBittorrent instancis Alternative WebUI saknis mapi nūruodit kai `/weig-qb-webui`. Kotra instance sagloboj sovu torrent datu bāzi, īstatiejumus i pīsaslēgšonu.

Suonu paneļa **Instances** sadaļā var pīvīnuot instancis, puorsaslēgtīs uz cytas instancis pylnu lopu i mainēt nūsaukumu (ar lobū pelis pogu voi rindys izvēlni). Pīmāram, tagadējū instanci var nūsaukt `524 (current)`; tagadējis instancis atzeime sekoj īstajai URL adresei, na vysam nūsaukumā saglobuotam papyldynojumam. Automatiska puorbaudes intervāls ir **Settings → WeiG WebUI → Interface**; nūklusiejuma vērteiba ir `30 min`, tū var izslēgt voi izavielēt 5–1440 minūtys.

**Savīnuojuma statusa pīruodiejumi tīšām ir pīsardzeigi:** apstyprynuota tuos pošys izcelsmis WebAPI atbiļde nūzeimoj, ka qB ir tīšsaistē; bez pīsaslēgšonu duotu cytys izcelsmis `no-cors` atbiļde nūruoda tikai tū, ka HTTP adresi var sasnēgt, pat ja tei atgrīž 403/404. Natīk laseitys cytas izcelsmis Cookie/SID, puorsyuteitys paroles voi seanss, apeiti CORS voi lītuota servera starpnīceiba. Agruokuos qB puorbaudes laiks ir **vēsturisks pīruodiejums**, na tagadējis pīsaslēguma apstyprynojums. Puorlūka `127.0.0.1` nūzeimoj īreici, kurā darbojīs puorlūks, na attuolu VPS.

## Īstateišona jaunim lītuotuojim

<details>
<summary><b>Īstateijit pyrmū reizi? Atverit itū eisu ceļvedi</b></summary>

### 1. Izpakōt ZIP

Lejupīluodējit `weig-qb-webui.zip` i izpakōjit. Arhivā jau ir standarta mape:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Vysa **`weig-qb-webui` mape** ir WebUI saknis mape. Nakuopiejit tikai `public` voi `private`.

### 2. Puorvītuot uz pasteiveigu vītu

Nūlīcit vysu `weig-qb-webui` mapi taidā pasteiveigā vītā, kur tū vēluok nagadēsīs najausi izdzēst, pīmāram:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Itū mapis ceļu vajadzēs nūruodeit qBittorrent.

### 3. Īslēgt qBittorrent

Atverit qBittorrent:

**Tools → Options... → WebUI**

Tī ir tagadējis qBittorrent angļu saskarnis nūsaukumi. Tod:

1. Īslēdzit **Use alternative WebUI**.
2. Atrūnit lauku **Files location:**.
3. Īrokstit ceļu uz `weig-qb-webui` mapi.

Windows pīmārs:

```text
D:\weig-qb-webui
```

Parosts Linux pīmārs:

```text
/opt/weig-qb-webui
```

4. Nūspīdīsit **OK**, lai saglobuot.
5. Atsvaidzynojit qBittorrent WebUI lopu. Ja puorlūks vēļ ruoda vacū lopu nu keša, vīnu reizi pamēginējit `Ctrl + F5`.

> **Kai zynuot, voi ceļš ir pareizs?** Nūruodeitajā mapē tīši juobyun `public`, `private`, `VERSION` i cytim WebUI failim. Ja itūs failus var īraudzēt tikai īejūt vēļ vīnā `weig-qb-webui` mapē, ceļš ir par vīnu leimini nūbeidiejīs.

> **Docker lītuotuojim:** qBittorrent struodoj konteinerī, tamdēļ saimnīkdatora ceļu parosti navar īroksteit tīši. Apsavērit zamuok **Docker** ceļvedi par saimnīkdatora i konteinera ceļu atškireibom.

</details>

## Īstateišona ar vīnu komandu

Linux/NAS īstateituojs ar vīnu komandu vysod tīk lejupīluodāts nu zamuok nūruodeituos namainīguos Dev Pages URL adresis. **Skripta URL naizavielej īstateišonys kanalu:** bez `-dev` tīk īstateits pādejais apstyprynuots stabilais GitHub Release; `-dev` lītojit tikai tod, ja apzyneigi gribit tagadējū izstruodis versiju ar konkretu Git SHA. Lejupīluodātais skripts palīk tagadējā mapē vēluokom atjaunuošonom voi atgrīšonai.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Paruodeit skripta vītu i WebUI nūklusiejuma īstateišonys mapi</b></summary>

```text
./install.sh
```

WebUI pēc nūklusiejuma tīk īstateits šeit:

```text
~/.local/share/weig-qb-webui
```

Pīmāram, darbojūtīs kai `root`, parosti:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker īstateišona ar vīnu komandu / vairuoki konteineri / ceļu ceļvedis (īteicams īsuociejim)</b></summary>

#### Pyrma saprūtit «saimnīkdators» i «konteiners»

Ja qBittorrent darbojīs Docker vidē uz VPS, Linux servera, Synology, QNAP voi cyta NAS:

- **Saimnīkdators**: eistuo Linux/NAS īreice, kurā darbojīs Docker, tū redzit pēc SSH pīsaslēgšonys.
- **Konteiners**: atseviška vide, kū Docker izveidoj qBittorrent darbeibai. qBittorrent redz konteinera ceļus, bet na kotru saimnīkdatora ceļu.

Pīmāram, qBittorrent konteineram var byut šaida ceļu atbiļsteiba:

```text
Host:      /root/qbittorrent/config
   ↓ mapped to
Container: /config
```

Parosts Docker Compose īroksts izaver šaidi:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Nu dūbultpunkta pa kreisi `/root/qbittorrent/config` ir **saimnīkdatora ceļš**, bet pa labi `/config` ir **konteinera ceļš**.

Ja WeiG qB WebUI faktiski ir īstateits šeit:

```text
Host: /root/qbittorrent/config/weig-qb-webui
```

tod qBittorrent laukā **Files location:** vajag nūruodeit:

```text
/config/weig-qb-webui
```

**qBittorrent nanūruodit `/root/qbittorrent/config/weig-qb-webui`**, jū konteiners parosti tysā veidā naredz saimnīkdatora ceļu.

#### 1. gadiejums: darbojīs vīns qBittorrent konteiners

Lītojit parostū īstateišonys komandu:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Īstateituojs raudzēs atrast darbojūšū qBittorrent konteineri, juo `/config` pīvīnuojumu, īstateit WebUI atbiļstūšajā saimnīkdatora vītā i automatiski sakonfigurēt qBittorrent.

#### 2. gadiejums: pyrma atrūnit qBittorrent konteinera nūsaukumu

Ja nazynojit konteinera nūsaukumu:

```sh
sh install.sh --list-containers
```

Var lītuot ari Docker komandu tīši:

```sh
docker ps
```

Ja qBittorrent konteinera nūsaukums ir:

```text
qbittorrent
```

izavielējit tū konkretai:

```sh
sh install.sh --container=qbittorrent -configure
```

#### 3. gadiejums: vairuoki qBittorrent konteineri

Pīmāram:

```text
qbittorrent
qbittorrent-test
```

Pyrma paruodit sarokstu:

```sh
sh install.sh --list-containers
```

Īstateit golvonajam `qbittorrent` konteineram:

```sh
sh install.sh --container=qbittorrent -configure
```

Īstateit izmēginojumys konteineram:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ja ir vairuoki qBittorrent konteineri, īstateituojs pats klusi naizavielēsīs vīnu nu tim.

#### 4. gadiejums: jau zynojit saimnīkdatora mapi, kas pīvīnuota kai `/config`

Pīmāram:

```text
/root/qbittorrent/config
```

Nūruodit tū tīši:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology ceļš var izavērt šaidi:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Cyta NAS ceļš var byut, pīmāram:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Itī ir tikai pīmāri. **Aizstojit tūs ar eistū saimnīkdatora ceļu, kas qBittorrent konteinerī pīvīnuots kai `/config`.**

#### 5. gadiejums: izavielēt WebUI īstateišonys ceļu

Pēc konteinera izavieliešonys varat nūruodeit ari tū WebUI ceļu, kū konteiners redz:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Īstateituojs puorveidoj konteinera ceļu `/config/...` par atbiļstūšū saimnīkdatora īstateišonys ceļu.

#### 6. gadiejums: atjaunuot vairuokys WebUI mapis ar vīnu lejupīluodi

Vairuokom qBittorrent instancēm atkārtojīt `-o`. Pakotne tīk lejupīluodāta i puorbaudeita vīnu reizi, vysys mapis tīk sagatavuotys pyrms versijas puormainis, i kotrai mapē palīk sovys pādejuos treis rezervis kopijys zem `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Daudzim mērkim napīvienojit `-configure`; kotra qBittorrent instance sagloboj jau īstateitū Alternative WebUI saknis mapi. Lai apsavērt tagadējū komandu sintaksi, izpyldit `sh install.sh -help`.

#### Kū vajadzātu redzēt pēc īstateišonys?

Veiksmeiga īstateišona paruoda apmāram šaidys vērteibys:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Nūzeime:

- `Host install path`: vīta, kur faili fiziski atrodās uz saimnīkdatora;
- `qBittorrent Root Folder`: **konteinera ceļš, kū qBittorrent juolītoj laukā Files location**.

Ja `-configure` veiksmeigi atrūn qBittorrent konfiguraceju, īstateituojs īslēdz **Use alternative WebUI** i automatiski nūruoda ceļu. Cytaidi sekojit rūkys īstateišonys sūlim sadaļā **Īstateišona jaunim lītuotuojim → Īslēgt qBittorrent** augšuok.

</details>

## Bīžuok lītuotās izavielis
Linux i Windows, cik īspiejams, lītoj vīnus i tūs pošus publiskūs izavieļu nūsaukumus. Dokumentacejā lītuoti mozie burti; PowerShell parametru nūsaukumi naatškir lelūs i mozūs burtus.

| Nūlūks | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Stabilais main | Pēc nūklusiejuma, bez izavielis | Pēc nūklusiejuma, bez izavielis |
| Konkrets laidīns | `-version 1.2.0` | `-version 1.2.0` |
| Izstruodis versija | `-dev` | `-dev` |
| Sova īstateišonys mape | `-o /path` (Linux var atkārtuot) | `-o D:\path` voi `-output D:\path` |
| Sovs qBittorrent konfiguracejis fails | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automatiski sakonfigurēt qBittorrent | `-configure` | `-configure` |
| Atgrīztīs uz īprīkšējū īstateišonu | `-rollback` | `-rollback` |
| Pylnīga atīstateišona (rezervis kopijys nasagloboj) | `-uninstall -purge` | `-uninstall -purge` |
| Pylnīga paleidzeiba | `-help` | `-help` |
| Izavielēt Docker konteineri | `--container=NAME` | — |
| Paruodeit Docker konteineru sarokstu | `--list-containers` | — |
| Nūruodeit saimnīkdatora mapi, kas pīvīnuota kai Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Pīzeimis (nūspīdīsit, lai atvērt)</b></summary>

Pīzeimis:

- Bez `-dev` tīk lītuots stabilais `main`; ar `-dev` tīk izavielāts tagadējis izstruodis versijas konkretais Git SHA.
- `-o` nūzeimoj **output** i nūruoda WeiG qB WebUI īstateišonys mapi. Linux vidē tū var atkārtuot, lai atjaunuot vairuokys mapis ar vīnu puorbaudeitu lejupīluodi.
- Īstateituoja rezervis kopijys atrodās `~/.config/weig-qb-webui/backups/`, i **pādejuos 3 rezervis kopijys tīk saglobuotys atseviški kotrai mērka mapei**.
- `-configure` īslēdz qBittorrent **Use alternative WebUI** i pēc īstateišonys nūruoda **Files location**. Tei apzyneigi paredzāta tikai vīnai mērka mapei.
- `-rollback` atjaunoj pādejū īstateituoja izveiduotū rezervis kopiju izavielātajai mērka mapei; vairuokim konkretim mērkim atkārtojīt `-o`.
- `-version` īstatej konkretu GitHub Release versiju, pīmāram, `1.2.0`. Ja praseituos versijas nav, īstateišona nūzaglūdoj ar klaidu i **nakuod automatikai napuorsaslēdz uz latest voi dev**.
- `-help` paruoda tagadējū atbolsteitū Linux komandu sintaksi.
- Ja ir vairuoki qBittorrent Docker konteineri, lītojit `--list-containers`, tod izavielējit vīnu ar `--container=NAME`. Ja jau zynojit qBittorrent saimnīkdatora konfiguracejis mapi, var lītuot ari `--config-root=/path`.

### Konkreta versija i īstateišonys mape


Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Atgrīšona uz īprīkšējū versiju

Linux:

```sh

```

```powershell

```

<details>
<summary><b>Pylnīga atīstateišona Linux / NAS, Docker i Windows PowerShell</b></summary>

Zamuok īteiktuo komanda veic pylnīgu atīstateišonu **nasaglobojūt īstateituoja rezervis kopijys**: izdzēš WebUI, izslēdz atbiļstūšū Alternative WebUI konfiguraceju, nūteira šai mērka mapei pīdareiguos rezervis kopijys i atgrīšonys stōvūkli, tod izdzēš lejupīluodātū īstateišonys skriptu nu tagadējis mapis.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Ja īstateišonys mape ir cita, pīvienojit `-o /path/to/weig-qb-webui`.

### Docker

Vīns konteiners / automatiska atpazeišona:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Vairuoki konteineri:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Ja lītojit `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Ja īstateišonys mape ir cita, pīvienojit `-o D:\weig-qb-webui`.

`-purge` izdzēš tikai tagadējai atīstateišonys mapei pīdareiguos rezervis kopijys; cytu īstateišonu kopijys tyks naītīkmej. Kod kūpeiguo stōvūkļa mape palīk tukša, tīk izdzēsta ari Linux `~/.config/weig-qb-webui` (root gadiejumā `/root/.config/weig-qb-webui`) voi Windows `%APPDATA%\weig-qb-webui` mape.

Ja gribit vēluok lītuot rezervis kopijys ar `-rollback`, vienkuorši nalītojit `-purge`.

</details>
