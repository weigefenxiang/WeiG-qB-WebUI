## Sānjosla vairākām instancēm

Vairākas neatkarīgas qBittorrent instances var izmantot vienu un to pašu sagatavoto WeiG mapi **tikai lasīšanas režīmā**. Pievienojiet resursdatora mapi katram Docker konteineram atsevišķi, piemēram, `/root/weig-qb-webui:/weig-qb-webui:ro`, un katrā qBittorrent instancē norādiet `/weig-qb-webui` kā Alternative WebUI saknes direktoriju. Katras instances torrenti, iestatījumi un pierakstīšanās paliek atsevišķi.

Sānjoslas sadaļā **Instances** var pievienot instances, pārslēgties starp tām, atverot citu lapu, un tās pārdēvēt (ar peles labo pogu vai rindas izvēlnē). Pašreizējo instanci nosaka faktiskā URL adrese, nevis saglabāts nosaukuma sufikss. Automātiskās pārbaudes intervāls atrodams **Settings → WeiG WebUI → Interface**; pēc noklusējuma tas ir `30 min`, bet to var izslēgt vai izvēlēties no 5 līdz 1440 minūtēm.

**Savienojuma stāvokļa pierādījumi tiek vērtēti piesardzīgi:** autentificēta WebAPI atbilde no tās pašas izcelsmes apstiprina, ka qB ir tiešsaistē. `no-cors` atbilde no citas izcelsmes bez akreditācijas datiem apliecina tikai HTTP adreses sasniedzamību, arī tad, ja atbilde ir 403/404. Netiek lasīti citas izcelsmes Cookie/SID, pārsūtītas paroles vai sesijas, apieta CORS aizsardzība vai izmantots servera starpnieks. Iepriekšējas veiksmīgas pārbaudes saglabātais laiks ir **vēsturisks pierādījums**, nevis pašreizējā tiešsaistes stāvokļa apstiprinājums. Adrese `127.0.0.1` pārlūkprogrammā attiecas uz ierīci, kurā darbojas pārlūkprogramma, nevis attālu VPS.

## Instalēšana iesācējiem

<details>
<summary><b>Instalējat pirmoreiz? Atveriet šo īso ceļvedi</b></summary>

### 1. Izpakojiet ZIP arhīvu

Lejupielādējiet `weig-qb-webui.zip` un izpakojiet to. Arhīvā jau ir standarta mape:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Visa mape **`weig-qb-webui`** ir WebUI saknes direktorijs. Nekopējiet tikai `public` vai `private`.

### 2. Pārvietojiet uz pastāvīgu vietu

Piemēram:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Šo ceļu vēlāk būs jānorāda qBittorrent.

### 3. Iespējojiet qBittorrent programmā

Atveriet qBittorrent:

**Tools → Options... → WebUI**

Tie ir precīzi pašreizējās qBittorrent angļu saskarnes izvēļņu nosaukumi. Pēc tam:

1. Iespējojiet **Use alternative WebUI**.
2. Atrodiet lauku **Files location:**.
3. Ievadiet ceļu uz mapi `weig-qb-webui`.

Windows piemērs:

```text
D:\weig-qb-webui
```

Linux piemērs:

```text
/opt/weig-qb-webui
```

4. Noklikšķiniet uz **OK**, lai saglabātu.
5. Pārlādējiet qBittorrent WebUI lapu. Ja pārlūkprogrammas kešatmiņā joprojām ir vecā saskarne, vienreiz izmēģiniet `Ctrl + F5`.

> **Ceļa pārbaude:** norādītajā direktorijā tieši jāatrodas `public`, `private`, `VERSION` un pārējiem WebUI failiem.

> **Docker lietotājiem:** qBittorrent darbojas konteinerā, tādēļ parasti jānorāda konteinerā redzamais ceļš, nevis resursdatora ceļš.

</details>

## Instalēšana ar vienu komandu

Linux/NAS instalēšanas skripts vienmēr tiek lejupielādēts no zemāk norādītās fiksētās Dev Pages adreses. **Skripta URL nenosaka instalēšanas kanālu:** bez `-dev` tiek instalēts jaunākais pārbaudītais stabilais GitHub Release laidiens; `-dev` izvēlas pašreizējo izstrādes versiju pēc precīza Git SHA. Lejupielādētais skripts paliek pašreizējā mapē turpmākai atjaunināšanai vai iepriekšējās versijas atjaunošanai.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Rādīt skripta adresi un noklusēto instalēšanas direktoriju</b></summary>

```text
./install.sh
```

Pēc noklusējuma WebUI tiek instalēts šeit:

```text
~/.local/share/weig-qb-webui
```

Palaižot kā `root`, parasti šeit:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, vairāki konteineri un ceļu skaidrojums</b></summary>

#### Resursdators un konteiners

- **Resursdators:** Linux/NAS ierīce, kurā darbojas Docker.
- **Konteiners:** izolēta vide, kurā darbojas qBittorrent.

Piemēram:

```text
Хост:       /root/qbittorrent/config
   ↓ montēts kā
Konteiners:  /config
```

Docker Compose piemērs:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Ja WebUI resursdatorā atrodas šeit:

```text
/root/qbittorrent/config/weig-qb-webui
```

tad qBittorrent laukā **Files location:** ievadiet:

```text
/config/weig-qb-webui
```

#### Viens qBittorrent konteiners

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Instalētājs mēģina automātiski noteikt konteineru un tā `/config` montējumu.

#### Konteineru atrašana

Vispirms apskatiet atrasto qBittorrent konteineru sarakstu:

```sh
sh install.sh --list-containers
```

Vai izmantojiet Docker tieši:

```sh
docker ps
```

Piemēram, konteinera nosaukums var būt:

```text
qbittorrent
```

Tad norādiet to nepārprotami:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Ja darbojas vairāki qBittorrent konteineri

Piemēram, galvenā un testēšanas instance:

```text
qbittorrent
qbittorrent-test
```

Vispirms parādiet to sarakstu:

```sh
sh install.sh --list-containers
```

Galvenajai instancei:

```sh
sh install.sh --container=qbittorrent -configure
```

Testēšanas instancei:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ja ir vairāki konteineri, instalētājs patvaļīgi neizvēlas kādu no tiem.

#### Resursdatora mapes norādīšana, kas montēta kā `/config`

Ja qBittorrent konfigurācijas mape resursdatorā atrodas šeit:

```text
/root/qbittorrent/config
```

Varat to norādīt tieši:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology piemērs:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Citas NAS sistēmas piemērs:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Aizstājiet piemēru ceļus ar faktisko resursdatora ceļu, kas qBittorrent ir montēts kā `/config`.

#### WebUI instalēšanas mapes izvēle

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Vairāku WebUI instalāciju atjaunināšana ar vienu lejupielādi

Linux/NAS sistēmā var atkārtot parametru `-o`, lai ar vienu lejupielādi atjauninātu vairākas esošas instalācijas. Šajā režīmā nelietojiet `-configure`, `--container` un `--config-root` vienlaikus.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Ceļu pārbaude pēc instalēšanas

Instalētājs parāda resursdatora ceļu un qBittorrent redzamo ceļu:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent iestatījumā **Files location** izmantojiet otro ceļu — konteinerā redzamo. Ja `-configure` izdodas, instalētājs to iestata automātiski.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Rādīt instalēšanas direktoriju</b></summary>

```text
C:\Users\<lietotājvārds>\AppData\Local\weig-qb-webui
```

</details>

## Biežāk lietotie parametri
PowerShell parametru nosaukumos lielie un mazie burti netiek atšķirti.

| Mērķis | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Jaunākais stabilais laidiens | Noklusējums | Noklusējums |
| Konkrēts Release laidiens | `-version 1.2.0` | `-version 1.2.0` |
| Izstrādes versija | `-dev` | `-dev` |
| Instalēšanas mape | `-o /path` (var atkārtot) | `-o D:\path` vai `-output D:\path` |
| qBittorrent konfigurācijas fails | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automātiska qBittorrent konfigurēšana | `-configure` | `-configure` |
| Iepriekšējās instalācijas atjaunošana | `-rollback` | `-rollback` |
| Pilnīga atinstalēšana (bez instalētāja rezerves kopijām) | `-uninstall -purge` | `-uninstall -purge` |
| Pilna palīdzība | `-help` | `-help` |
| Docker konteinera izvēle | `--container=NAME` | — |
| Docker konteineru saraksts | `--list-containers` | — |
| Resursdatora mape, kas montēta kā Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Piezīmes (noklikšķiniet, lai izvērstu)</b></summary>

- Ja pieprasītais laidiens neeksistē, instalēšana beidzas ar kļūdu un netiek automātiski pārslēgta uz latest vai dev.
- `-dev` nevar lietot kopā ar `-version`.

### Konkrēta versija un instalēšanas mape

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Atgriešanās pie iepriekšējās versijas

Atjaunošana:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Atinstalēšana ar vienu komandu

<details>
<summary><b>Pilnīga atinstalēšana Linux / NAS, Docker un Windows PowerShell vidē</b></summary>

Ieteiktā komanda veic **pilnīgu atinstalēšanu, nesaglabājot instalētāja rezerves kopijas**: tā noņem WebUI, atspējo atbilstošo alternatīvās WebUI konfigurāciju, izdzēš šīs instalācijas rezerves kopijas un atjaunošanas stāvokli, un pēc tam noņem lejupielādēto instalēšanas skriptu no pašreizējās mapes.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Pielāgotai instalēšanas mapei pievienojiet `-o /path/to/weig-qb-webui`.

### Docker

Viens konteiners / automātiska noteikšana:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Vairāki konteineri:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Izmantojot `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Pielāgotai mapei pievienojiet `-o D:\weig-qb-webui`.

`-purge` izdzēš tikai pašreizējās instalācijas rezerves kopijas un neskar citas instalācijas. Ja kopīgā stāvokļa mape kļūst tukša, tiek noņemta arī `~/.config/weig-qb-webui` Linux sistēmā (root lietotājam: `/root/.config/weig-qb-webui`) vai `%APPDATA%\weig-qb-webui` Windows sistēmā.

Lai saglabātu rezerves kopijas turpmākai `-rollback` izmantošanai, vienkārši neiekļaujiet `-purge`.

</details>
