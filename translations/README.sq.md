## Shiriti anësor për disa instanca

Disa instanca të pavarura të qBittorrent mund të përdorin të njëjtën dosje të përgatitur WeiG në mënyrën **vetëm për lexim**. Monto dosjen e hostit në secilin kontejner Docker, për shembull `/root/weig-qb-webui:/weig-qb-webui:ro`, dhe cakto `/weig-qb-webui` si dosjen rrënjë të Alternative WebUI në çdo instancë qBittorrent. Torrentët, cilësimet dhe identifikimi mbeten të ndara për secilën instancë.

Nga seksioni **Instances** në shiritin anësor mund të shtosh instanca, të kalosh nga njëra te tjetra duke hapur një faqe të plotë dhe t'i riemërtosh (me klikim të djathtë ose nga menyja e rreshtit). Instanca aktuale përcaktohet nga URL-ja reale dhe jo nga një prapashtesë e ruajtur. Intervali i kontrollit automatik gjendet te **Settings → WeiG WebUI → Interface**; si parazgjedhje është `30 min`, por mund të çaktivizohet ose të caktohet nga 5 deri në 1440 minuta.

**Provat për gjendjen interpretohen me kujdes:** një përgjigje e autentikuar WebAPI nga e njëjta origjinë tregon se qB është në linjë. Një përgjigje `no-cors` nga një origjinë tjetër, pa kredenciale, provon vetëm se adresa HTTP është e arritshme, edhe nëse kthen 403/404. Nuk lexohen Cookie/SID nga origjina të tjera, nuk përcillen fjalëkalime ose sesione, nuk anashkalohet CORS dhe nuk përdoret ndërmjetës serveri. Koha e ruajtur e një kontrolli të mëparshëm është **dëshmi historike**, jo vërtetim i gjendjes aktuale. Adresa `127.0.0.1` në shfletues i përket pajisjes ku funksionon shfletuesi, jo një VPS-je të largët.

## Instalimi për fillestarët

<details>
<summary><b>Po instalon për herë të parë? Hap këtë udhëzues të shkurtër</b></summary>

### 1. Nxirr përmbajtjen e arkivit ZIP

Shkarko dhe çpaketo `weig-qb-webui.zip`. Arkivi përmban tashmë dosjen standarde:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

E gjithë dosja **`weig-qb-webui`** është rrënja e WebUI. Mos kopjo vetëm `public` ose `private`.

### 2. Zhvendose në një vend të përhershëm

Për shembull:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Këtë shteg do ta vendosësh më pas në qBittorrent.

### 3. Aktivizoje në qBittorrent

Hap qBittorrent:

**Tools → Options... → WebUI**

Këta janë emrat e saktë të menysë në ndërfaqen aktuale të qBittorrent në anglisht. Më pas:

1. Aktivizo **Use alternative WebUI**.
2. Gjej fushën **Files location:**.
3. Shkruaj shtegun drejt dosjes `weig-qb-webui`.

Shembull për Windows:

```text
D:\weig-qb-webui
```

Shembull për Linux:

```text
/opt/weig-qb-webui
```

4. Kliko **OK** për të ruajtur.
5. Rifresko faqen e qBittorrent WebUI. Nëse faqja e vjetër mbetet në memorien e përkohshme të shfletuesit, provo një herë `Ctrl + F5`.

> **Kontrolli i shtegut:** dosja e përcaktuar duhet të përmbajë drejtpërdrejt `public`, `private`, `VERSION` dhe skedarët e tjerë të WebUI.

> **Për përdoruesit e Docker:** qBittorrent funksionon brenda një kontejneri, ndaj zakonisht duhet shtegu që shihet nga brenda kontejnerit, jo shtegu i hostit.

</details>

## Instalimi me një komandë

Skripti i instalimit për Linux/NAS shkarkohet gjithmonë nga adresa fikse Dev Pages më poshtë. **Adresa e skriptit nuk përcakton kanalin e instalimit:** pa `-dev` instalohet versioni më i fundit i qëndrueshëm dhe i verifikuar i GitHub Release; `-dev` zgjedh versionin aktual të zhvillimit sipas Git SHA të saktë. Skripti i shkarkuar mbetet në dosjen aktuale për përditësime ose rikthime të mëvonshme.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Shfaq adresën e skriptit dhe dosjen e parazgjedhur të instalimit</b></summary>

```text
./install.sh
```

Si parazgjedhje, WebUI instalohet te:

```text
~/.local/share/weig-qb-webui
```

Kur ekzekutohet si `root`, zakonisht te:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, disa kontejnerë dhe shpjegimi i shtigjeve</b></summary>

#### Hosti dhe kontejneri

- **Hosti:** kompjuteri Linux/NAS ku ekzekutohet Docker.
- **Kontejneri:** mjedisi i izoluar ku funksionon qBittorrent.

Për shembull:

```text
Хост:       /root/qbittorrent/config
   ↓ montuar si
Kontejneri:  /config
```

Shembull me Docker Compose:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Nëse WebUI ndodhet në këtë shteg të hostit:

```text
/root/qbittorrent/config/weig-qb-webui
```

atëherë në fushën **Files location:** të qBittorrent vendos:

```text
/config/weig-qb-webui
```

#### Një kontejner qBittorrent

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Instaluesi do të përpiqet ta zbulojë automatikisht kontejnerin dhe montimin e tij `/config`.

#### Gjej kontejnerët

Së pari, shfaq listën e kontejnerëve qBittorrent të zbuluar:

```sh
sh install.sh --list-containers
```

Ose përdor Docker drejtpërdrejt:

```sh
docker ps
```

Për shembull, emri i kontejnerit mund të jetë:

```text
qbittorrent
```

Pastaj zgjidhe shprehimisht:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Kur ka disa kontejnerë qBittorrent

Për shembull, një instancë kryesore dhe një instancë testimi:

```text
qbittorrent
qbittorrent-test
```

Së pari, shfaq listën e tyre:

```sh
sh install.sh --list-containers
```

Për instancën kryesore:

```sh
sh install.sh --container=qbittorrent -configure
```

Për instancën e testimit:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Kur ka disa kontejnerë, instaluesi nuk zgjedh njërin prej tyre rastësisht.

#### Përcakto dosjen e hostit të montuar si `/config`

Nëse dosja e konfigurimit të qBittorrent në host ndodhet këtu:

```text
/root/qbittorrent/config
```

Mund ta përcaktosh drejtpërdrejt:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Shembull për Synology:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Shembull për një NAS tjetër:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Zëvendëso shtigjet e shembullit me shtegun e vërtetë në host të montuar si `/config` në qBittorrent.

#### Zgjidh dosjen e instalimit të WebUI

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Përditëso disa instalime WebUI me një shkarkim

Në Linux/NAS mund të përsëritësh parametrin `-o` për të përditësuar disa instalime ekzistuese pas një shkarkimi të vetëm. Në këtë mënyrë mos përdor njëkohësisht `-configure`, `--container` dhe `--config-root`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Kontrollo shtigjet pas instalimit

Instaluesi shfaq shtegun në host dhe atë që sheh qBittorrent:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Te **Files location** në qBittorrent përdor shtegun e dytë, pra atë brenda kontejnerit. Nëse `-configure` përfundon me sukses, instaluesi e vendos automatikisht.

</details>

## Parametrat e zakonshëm
Emrat e parametrave të PowerShell nuk dallojnë shkronjat e mëdha nga të voglat.

| Qëllimi | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Versioni më i fundit i qëndrueshëm | Parazgjedhje | Parazgjedhje |
| Version i caktuar Release | `-version 1.2.0` | `-version 1.2.0` |
| Version zhvillimi | `-dev` | `-dev` |
| Dosje instalimi e personalizuar | `-o /path` (përsëritet) | `-o D:\path` ose `-output D:\path` |
| Skedar konfigurimi i qBittorrent | — | `-qbconfig D:\path\qBittorrent.ini` |
| Konfiguro automatikisht qBittorrent | `-configure` | `-configure` |
| Rikthe instalimin e mëparshëm | `-rollback` | `-rollback` |
| Çinstalim i plotë (pa kopje rezervë të instaluesit) | `-uninstall -purge` | `-uninstall -purge` |
| Ndihma e plotë | `-help` | `-help` |
| Zgjidh një kontejner Docker | `--container=NAME` | — |
| Shfaq kontejnerët Docker | `--list-containers` | — |
| Dosja e hostit e montuar si Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Shënime (kliko për t'i hapur)</b></summary>

- Nëse versioni i kërkuar nuk ekziston, instalimi dështon dhe nuk kalon automatikisht te latest ose dev.
- `-dev` nuk mund të përdoret bashkë me `-version`.

### Version dhe dosje instalimi të caktuara

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Rikthim te versioni i mëparshëm

Rikthim:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Çinstalimi me një komandë

<details>
<summary><b>Çinstalim i plotë në Linux / NAS, Docker dhe Windows PowerShell</b></summary>

Komanda e rekomanduar bën **çinstalim të plotë pa ruajtur kopjet rezervë të instaluesit**: heq WebUI, çaktivizon konfigurimin përkatës të ndërfaqes alternative, fshin kopjet rezervë dhe gjendjen e rikthimit për këtë objektiv dhe në fund heq skriptin e shkarkuar të instalimit nga dosja aktuale.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Për dosje instalimi të personalizuar, shto `-o /path/to/weig-qb-webui`.

### Docker

Një kontejner / zbulim automatik:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Disa kontejnerë:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Me `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Për dosje të personalizuar, shto `-o D:\weig-qb-webui`.

`-purge` fshin vetëm kopjet rezervë të objektivit aktual dhe nuk prek instalime të tjera. Nëse dosja e përbashkët e gjendjes mbetet bosh, hiqet gjithashtu `~/.config/weig-qb-webui` në Linux (për root: `/root/.config/weig-qb-webui`) ose `%APPDATA%\weig-qb-webui` në Windows.

Për të ruajtur kopjet rezervë për një `-rollback` të mëvonshëm, thjesht mos përdor `-purge`.

</details>
