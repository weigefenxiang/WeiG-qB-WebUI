## Ručná inštalácia pre začiatočníkov

<details>
<summary><b>Inštalujete prvýkrát? Rozbaľte tento stručný postup</b></summary>

### 1. Rozbaľte ZIP archív

Stiahnite `weig-qb-webui.zip` a rozbaľte ho. V archíve už je pripravená táto štruktúra priečinkov:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

**Celý priečinok `weig-qb-webui`** predstavuje koreňový adresár webového rozhrania. Nekopírujte iba `public` alebo `private`.

### 2. Vyberte trvalé umiestnenie

Presuňte celý priečinok na miesto, kde ho omylom nevymažete, napríklad:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Práve cestu k tomuto priečinku potom zadáte v nastaveniach qBittorrent.

### 3. Zapnite alternatívne WebUI v qBittorrent

Otvorte **Nástroje → Možnosti → Webové rozhranie**. Presné názvy položiek sa môžu líšiť podľa jazyka qBittorrent.

1. Začiarknite **Použiť alternatívne webové rozhranie** (*Use alternative WebUI*).
2. Nájdite pole **Umiestnenie súborov** (*Files location*).
3. Zadajte cestu k priečinku `weig-qb-webui`.

Príklad pre Windows:

```text
D:\weig-qb-webui
```

Príklad pre Linux:

```text
/opt/weig-qb-webui
```

4. Kliknutím na **OK** uložte zmeny.
5. Obnovte stránku qBittorrent. Ak sa naďalej zobrazuje pôvodné rozhranie, vynúťte obnovenie klávesmi `Ctrl + F5`.

> **Ako skontrolovať cestu?** V zvolenom priečinku musia byť priamo viditeľné položky `public`, `private` a `VERSION`. Ak musíte ešte otvoriť ďalší priečinok `weig-qb-webui`, vybrali ste nesprávnu úroveň.

> **Používate Docker?** qBittorrent beží **v kontajneri**. V jeho nastaveniach preto použite cestu dostupnú v kontajneri, nie cestu, ktorá existuje iba na hostiteľovi. Podrobnosti nájdete nižšie.

</details>

## Inštalácia jedným príkazom

Inštalačný skript pre Linux a NAS sa vždy sťahuje z pevnej adresy Dev Pages uvedenej nižšie. **Adresa skriptu neurčuje inštalačný kanál:** bez `-dev` sa nainštaluje najnovšie overené stabilné vydanie z GitHub Releases; s `-dev` sa použije vývojová verzia určená presným Git SHA. Skript zostane v aktuálnom priečinku, aby ste mohli neskôr aktualizovať alebo obnoviť predchádzajúcu inštaláciu.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Zobraziť umiestnenie skriptu a predvolený inštalačný priečinok</b></summary>

Stiahnutý skript sa uloží sem:

```text
./install.sh
```

Predvolený inštalačný priečinok WebUI:

```text
~/.local/share/weig-qb-webui
```

Pri spustení pod používateľom `root` to zvyčajne znamená:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Inštalácia v Dockeri, viac kontajnerov a správne cesty</b></summary>

#### Hostiteľský systém a kontajner

Ak Docker používate na VPS, linuxovom serveri, Synology, QNAP alebo inom NAS:

- **Hostiteľ (host)** je systém Linux alebo NAS, na ktorom beží Docker. Zvyčajne sa k nemu pripájate cez SSH.
- **Kontajner (container)** je oddelené prostredie, v ktorom beží qBittorrent. Vidí iba priečinky sprístupnené cez pripojené zväzky.

Predstavme si takéto pripojenie konfiguračného priečinka:

```text
Hostiteľ: /root/qbittorrent/config
   ↓ pripojené ako
V kontajneri: /config
```

V Docker Compose môže vyzerať takto:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Cesta **naľavo od dvojbodky** patrí **hostiteľovi**; cesta **napravo** označuje umiestnenie **v kontajneri**.

Ak je WeiG na hostiteľovi nainštalovaný tu:

```text
Hostiteľ: /root/qbittorrent/config/weig-qb-webui
```

do poľa **Files location** v qBittorrent zadajte:

```text
/config/weig-qb-webui
```

**Nezadávajte `/root/qbittorrent/config/weig-qb-webui`**. Ide o cestu na hostiteľovi, ktorú kontajner spravidla nevidí.

#### Prípad 1: Máte iba jeden kontajner qBittorrent

Spustite:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Inštalátor sa pokúsi nájsť spustený kontajner qBittorrent, pripojenie `/config` a zodpovedajúci priečinok na hostiteľovi. Ak konfiguráciu dokáže bezpečne rozpoznať, nastaví qBittorrent automaticky.

#### Prípad 2: Nepoznáte názov kontajnera

Zobrazte dostupné kontajnery:

```sh
sh install.sh --list-containers
```

Alebo si ich pozrite priamo v Dockeri:

```sh
docker ps
```

Ak sa kontajner volá napríklad:

```text
qbittorrent
```

vyberte ho výslovne:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Prípad 3: Prevádzkujete viac kontajnerov qBittorrent

Napríklad jeden hlavný a jeden testovací:

```text
qbittorrent
qbittorrent-test
```

Najprv si vypíšte ich zoznam:

```sh
sh install.sh --list-containers
```

Inštalácia do hlavného kontajnera:

```sh
sh install.sh --container=qbittorrent -configure
```

Inštalácia do testovacieho kontajnera:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ak inštalátor nájde viac kontajnerov, **žiadny nevyberie náhodne**.

#### Prípad 4: Poznáte priečinok `/config` na hostiteľovi

Napríklad:

```text
/root/qbittorrent/config
```

Môžete ho zadať priamo:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Na Synology môže cesta vyzerať takto:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Na inom NAS napríklad takto:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Sú to iba príklady. Použite skutočnú cestu ku konfigurácii qBittorrent na vašom hostiteľovi.

#### Prípad 5: Vyberte inštalačný priečinok WebUI

Ak ste si už vybrali kontajner, môžete určiť aj umiestnenie WebUI v ňom:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Inštalátor podľa pripojeného zväzku Docker `/config` zistí príslušnú cestu na hostiteľovi.

#### Prípad 6: Aktualizácia viacerých inštalácií naraz

Ak spravujete viac inštancií qBittorrent, parameter `-o` môžete zadať opakovane. Balík sa stiahne a overí iba raz; žiadny cieľ sa nenahradí, kým nie sú pripravené všetky. Pre každý cieľ sa samostatne uchovávajú **tri najnovšie zálohy** v `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Pri viacerých cieľoch nepoužívajte `-configure`. Každá inštancia si má ponechať pôvodnú cestu k svojmu alternatívnemu WebUI. Všetky možnosti nájdete cez `sh install.sh -help`.

#### Kontrola ciest po inštalácii

Po úspešnej inštalácii sa môže zobraziť napríklad:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

- `Host install path`: skutočné umiestnenie súborov na hostiteľovi.
- `qBittorrent Root Folder`: cesta **v kontajneri**, ktorú zadáte do poľa *Files location* v qBittorrent.

Pri použití `-configure` inštalátor zapne alternatívne WebUI a nastaví cestu, ak dokáže bezpečne rozpoznať konfiguráciu qBittorrent. V opačnom prípade postupujte podľa pokynov na ručnú inštaláciu vyššie.

</details>

## Bežné parametre

Základné parametre majú rovnaké názvy v Linuxe aj vo Windows; PowerShell pri ich názvoch nerozlišuje veľké a malé písmená.

| Účel | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Nainštalovať najnovšie stabilné vydanie (`main`) | Predvolené, bez parametrov | Predvolené, bez parametrov |
| Nainštalovať konkrétne stabilné vydanie | `-version 1.2.0` | `-version 1.2.0` |
| Nainštalovať vývojovú verziu | `-dev` | `-dev` |
| Vybrať inštalačný priečinok | `-o /path` (v Linuxe možno zopakovať) | `-o D:\path` alebo `-output D:\path` |
| Zadať konfiguračný súbor qBittorrent | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automaticky nastaviť qBittorrent | `-configure` | `-configure` |
| Obnoviť predchádzajúcu inštaláciu | `-rollback` | `-rollback` |
| Odinštalovať vrátane záloh | `-uninstall -purge` | `-uninstall -purge` |
| Zobraziť úplného pomocníka | `-help` | `-help` |
| Vybrať kontajner Docker | `--container=NAME` | — |
| Zobraziť kontajnery | `--list-containers` | — |
| Priečinok `/config` na hostiteľovi | `--config-root=/path` | — |

<details>
<summary><b>Vysvetlenie parametrov (rozbaliť)</b></summary>

- Bez `-dev` sa používa stabilný kanál `main`; s `-dev` vývojová verzia určená presným Git SHA.
- Písmeno `o` v `-o` znamená **output**. V Linuxe môžete parameter zopakovať a jedným stiahnutím aktualizovať niekoľko existujúcich inštalácií.
- Zálohy vytvorené inštalátorom sa ukladajú do `~/.config/weig-qb-webui/backups/`; pre každý cieľ sa uchovávajú **najviac tri najnovšie zálohy**.
- `-configure` zapne *Use alternative WebUI* a nastaví *Files location*, no iba pre jeden cieľ.
- `-rollback` obnoví poslednú zálohu vytvorenú inštalátorom pre zvolený cieľ. Opakovaním `-o` možno obnoviť viac výslovne uvedených cieľov.
- `-uninstall -purge` odstráni zálohy a informácie na obnovenie **iba aktuálnej inštalácie**; ostatné inštalácie zostanú nedotknuté.
- Ak chcete zálohy zachovať na neskoršie `-rollback`, vynechajte `-purge`.
- Pomocou `-version` nainštalujete konkrétne vydanie z GitHub Releases, napríklad `1.2.0`. Ak neexistuje, inštalácia sa ukončí chybou a **automaticky neprejde** na latest ani dev.
- Pri viacerých kontajneroch použite `--list-containers` a vyberte `--container=NAME`, prípadne zadajte hostiteľský priečinok `/config` cez `--config-root=/path`.

### Výber verzie a inštalačného priečinka

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Obnovenie predchádzajúcej inštalácie

Linux:

```sh
sh install.sh -rollback
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Odinštalácia jedným príkazom

<details>
<summary><b>Úplné odinštalovanie v Linuxe / NAS, Dockeri aj Windows PowerShell</b></summary>

Spravidla odporúčame **odstrániť WebUI bez ponechania záloh inštalátora**. Nasledujúce príkazy odstránia rozhranie, vypnú alternatívne WebUI daného cieľa, vymažú jeho zálohy a stav potrebný na obnovenie a nakoniec odstránia stiahnutý inštalačný skript z aktuálneho priečinka.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Ak používate vlastný priečinok, pridajte `-o /cesta/weig-qb-webui`.

### Docker

Jeden kontajner s automatickým rozpoznaním:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Viac kontajnerov:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Pri použití `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Pre vlastný priečinok pridajte `-o D:\weig-qb-webui`.

Parameter `-purge` odstráni iba zálohy práve odinštalovanej inštalácie. Ostatné inštancie zostanú nedotknuté. Ak sa spoločný priečinok so stavom úplne vyprázdni, odstráni sa aj `~/.config/weig-qb-webui` v Linuxe (pre `root`: `/root/.config/weig-qb-webui`) alebo `%APPDATA%\weig-qb-webui` vo Windows.

Ak chcete zálohy zachovať pre neskoršie `-rollback`, odinštalujte bez `-purge`.

</details>
