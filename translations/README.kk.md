## Бірнеше данаға арналған бүйірлік тақта

Бірнеше тәуелсіз qBittorrent данасы бір дайындалған WeiG бумасын **тек оқу** режимінде пайдалана алады. Хост бумасын әрбір Docker контейнеріне, мысалы, `/root/weig-qb-webui:/weig-qb-webui:ro` түрінде тіркеп, әр qBittorrent данасының Alternative WebUI түбірін `/weig-qb-webui` етіп орнатыңыз. Әр дананың torrent дерекқоры, баптаулары мен кіру деректері бөлек сақталады.

Бүйірлік тақтадағы **Instances** бөлімі даналарды тіркеуге, толық бетке ауысып өтуге және атын өзгертуге (оң жақ батырмамен не жол мәзірінен) мүмкіндік береді. Мысалы, ағымдағы дананы `524 (current)` деп атауға болады; ағымдағы белгі сақталған атаудың жалғауына емес, нақты URL мекенжайына сүйенеді. Автоматты тексеру аралығы **Settings → WeiG WebUI → Interface** ішінде орнатылады, әдепкісі `30 min`; өшіруге немесе 5–1440 минут аралығын таңдауға болады.

**Қолжетімділік туралы дәлел әдейі сақтықпен түсіндіріледі:** бір түпкі мекеннен расталған WebAPI qB-ның желіде екенін көрсетеді, ал тіркелгі деректерінсіз басқа түпкі мекенге жасалған `no-cors` сұрауының жауабы HTTP мекенжайының қолжетімді екенін ғана білдіреді, оның ішінде 403/404 жауабы да болуы мүмкін. Басқа түпкі мекеннің Cookie/SID деректерін оқу, құпиясөз не сеансты тасымалдау, CORS айналып өту немесе серверлік шлюз қарастырылмаған. Бұрынғы qB тексеруінен кейін сақталған уақыт — **тарихи дәлел**, қазір онлайн екенін растамайды. Браузердегі `127.0.0.1` қашықтағы VPS-ке емес, сол браузер жұмыс істейтін құрылғыға қатысты.

## Жаңадан бастаушыларға орнату

<details>
<summary><b>Алғаш рет орнатып жатырсыз ба? Осы бір минуттық нұсқаулықты ашыңыз</b></summary>

### 1. ZIP мұрағатын ашу

`weig-qb-webui.zip` файлын жүктеп, мұрағаттан шығарыңыз. Мұрағаттың ішінде стандартты бума дайын:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

**`weig-qb-webui` бумасының барлығы** WebUI түбірі болып саналады. Тек `public` не `private` бумасын көшірмеңіз.

### 2. Тұрақты орынға көшіру

`weig-qb-webui` бумасын кейін кездейсоқ жойып алмайтын тұрақты орынға көшіріңіз, мысалы:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

qBittorrent ішінде дәл осы буманың жолын көрсету керек.

### 3. qBittorrent ішінде қосу

qBittorrent бағдарламасын ашыңыз:

**Tools → Options... → WebUI**

Бұлар qBittorrent-тің қазіргі ағылшын интерфейсіндегі атаулар. Содан кейін:

1. **Use alternative WebUI** параметрін қосыңыз.
2. **Files location:** өрісін табыңыз.
3. `weig-qb-webui` бумасының жолын енгізіңіз.

Windows мысалы:

```text
D:\weig-qb-webui
```

Кәдімгі Linux мысалы:

```text
/opt/weig-qb-webui
```

4. Сақтау үшін **OK** басыңыз.
5. qBittorrent WebUI бетін жаңартыңыз. Браузер кэштегі ескі бетті көрсетсе, `Ctrl + F5` пернелерін бір рет басып көріңіз.

> **Жолдың дұрыстығын қалай білуге болады?** Көрсетілген бумада тікелей `public`, `private`, `VERSION` және басқа WebUI файлдары болуы тиіс. Оларды көру үшін тағы бір `weig-qb-webui` бумасына кіру керек болса, жол бір деңгейге қате көрсетілген.

> **Docker пайдаланушыларына:** qBittorrent контейнер ішінде жұмыс істейді, сондықтан хосттағы жолды тікелей көрсету көп жағдайда мүмкін емес. Хост пен контейнер жолдарының айырмасын төмендегі **Docker** бөлімінен қараңыз.

</details>

## Бір пәрменмен орнату

Linux/NAS үшін бір пәрмендік орнатқыш әрдайым төмендегі тұрақты Dev Pages URL мекенжайынан жүктеледі. **Скрипт URL-і орнату арнасын таңдамайды:** `-dev` параметрінсіз соңғы тексерілген тұрақты GitHub Release орнатылады; дәл Git SHA-мен анықталған ағымдағы әзірлеме нұсқасын арнайы орнатқыңыз келсе ғана `-dev` қосыңыз. Жүктелген скрипт кейін жаңарту немесе кері қайтару үшін ағымдағы бумада қалады.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Скрипт орнын және әдепкі WebUI орнату бумасын көрсету</b></summary>

```text
./install.sh
```

Әдепкіде WebUI мына жерге орнатылады:

```text
~/.local/share/weig-qb-webui
```

Мысалы, `root` ретінде іске қосқанда, әдетте:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker-ді бір пәрменмен орнату / бірнеше контейнер / жолдар нұсқаулығы (жаңа пайдаланушыларға ұсынылады)</b></summary>

#### Алдымен «хост» пен «контейнер» ұғымдарын түсініңіз

Егер qBittorrent Docker ішінде VPS, Linux сервері, Synology, QNAP немесе басқа NAS құрылғысында жұмыс істесе:

- **Хост**: Docker жұмыс істейтін нақты Linux/NAS машинасы, яғни SSH арқылы кіргендегі жүйе.
- **Контейнер**: Docker qBittorrent үшін жасайтын оқшауланған орта. qBittorrent контейнер ішіндегі жолдарды көре алады, бірақ хосттағы кез келген жолды тікелей көре алмайды.

Мысалы, qBittorrent контейнерінде мынадай сәйкестік болуы мүмкін:

```text
Host:      /root/qbittorrent/config
   ↓ mapped to
Container: /config
```

Әдеттегі Docker Compose жазбасы:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Қос нүктенің сол жағындағы `/root/qbittorrent/config` — **хост жолы**, ал оң жақтағы `/config` — **контейнер жолы**.

WeiG qB WebUI хостта нақты мына жерде орнатылса:

```text
Host: /root/qbittorrent/config/weig-qb-webui
```

онда qBittorrent-тің **Files location:** өрісіне мына жолды жазыңыз:

```text
/config/weig-qb-webui
```

**qBittorrent ішінде `/root/qbittorrent/config/weig-qb-webui` жолын енгізбеңіз**, өйткені контейнер хосттағы бұл жолды әдетте тікелей көрмейді.

#### 1-жағдай: бір ғана qBittorrent контейнері жұмыс істейді

Кәдімгі бір пәрмендік орнатуды пайдаланыңыз:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Орнатқыш жұмыс істеп тұрған qBittorrent контейнерін және оның `/config` сәйкестігін анықтауға, WebUI-ді хосттағы тиісті орынға орнатуға және qBittorrent-ті автоматты баптауға тырысады.

#### 2-жағдай: алдымен qBittorrent контейнерінің атын табу

Контейнердің атын білмесеңіз:

```sh
sh install.sh --list-containers
```

Docker-ді тікелей де пайдалануға болады:

```sh
docker ps
```

Егер qBittorrent контейнерінің аты:

```text
qbittorrent
```

оны нақты таңдаңыз:

```sh
sh install.sh --container=qbittorrent -configure
```

#### 3-жағдай: бірнеше qBittorrent контейнері

Мысалы:

```text
qbittorrent
qbittorrent-test
```

Алдымен тізімді алыңыз:

```sh
sh install.sh --list-containers
```

Негізгі `qbittorrent` контейнері үшін орнату:

```sh
sh install.sh --container=qbittorrent -configure
```

Сынақ контейнері үшін орнату:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Бірнеше qBittorrent контейнері бар кезде орнатқыш олардың бірін үнсіз кездейсоқ таңдамайды.

#### 4-жағдай: `/config` ретінде жалғанған хост бумасын білесіз

Мысалы:

```text
/root/qbittorrent/config
```

Оны тікелей көрсетіңіз:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology жолының мысалы:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Басқа NAS жолының мысалы:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Бұлар тек мысалдар. **Оларды qBittorrent-тің `/config` жолына жалғанған нақты хост жолымен ауыстырыңыз.**

#### 5-жағдай: WebUI орнату жолын таңдау

Контейнерді таңдағаннан кейін сол контейнерге көрінетін WebUI жолын да көрсетуге болады:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Орнатқыш контейнердің `/config/...` жолын хосттағы сәйкес орнату жолына түрлендіреді.

#### 6-жағдай: бір жүктеумен бірнеше WebUI бумасын жаңарту

Бірнеше qBittorrent данасы үшін `-o` параметрін қайталаңыз. Пакет бір рет жүктеліп, тексеріледі; барлық нысана ауыстырылмай тұрып дайындалады және әр нысана өзінің соңғы үш сақтық көшірмесін `~/.config/weig-qb-webui/backups/` ішінде бөлек сақтайды.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Бірнеше нысана режимінде `-configure` қоспаңыз: әр qBittorrent данасы бұрынғы Alternative WebUI түбір бумасын сақтайды. Ағымдағы пәрмен синтаксисін көру үшін `sh install.sh -help` орындаңыз.

#### Орнатудан кейін не көрінуі тиіс?

Сәтті орнату шамамен мынадай деректерді көрсетеді:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Мағынасы:

- `Host install path`: файлдардың хосттағы нақты орны;
- `qBittorrent Root Folder`: **qBittorrent Files location өрісінде қолдануы тиіс контейнер ішіндегі жол**.

Егер `-configure` qBittorrent баптауларын тапса, орнатқыш **Use alternative WebUI** параметрін қосып, жолды автоматты түрде орнатады. Әйтпесе жоғарыдағы **Жаңадан бастаушыларға орнату → qBittorrent ішінде қосу** қадамдарын қолмен орындаңыз.

</details>

## Негізгі параметрлер
Linux пен Windows мүмкіндігінше бірдей ашық параметр атауларын қолданады. Құжатта кіші әріптер жазылған, ал PowerShell параметр атаулары бас және кіші әріптерді ажыратпайды.

| Мақсаты | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Тұрақты main | Әдепкі, параметрсіз | Әдепкі, параметрсіз |
| Нақты шығарылым | `-version 1.2.0` | `-version 1.2.0` |
| Әзірлеме нұсқасы | `-dev` | `-dev` |
| Өз орнату бумасы | `-o /path` (Linux-та қайталауға болады) | `-o D:\path` немесе `-output D:\path` |
| Өз qBittorrent баптау файлы | — | `-qbconfig D:\path\qBittorrent.ini` |
| qBittorrent-ті автоматты баптау | `-configure` | `-configure` |
| Алдыңғы орнатуға қайту | `-rollback` | `-rollback` |
| Толық жою (сақтық көшірмелерді сақтамау) | `-uninstall -purge` | `-uninstall -purge` |
| Толық анықтама | `-help` | `-help` |
| Docker контейнерін таңдау | `--container=NAME` | — |
| Docker контейнерлерін тізімдеу | `--list-containers` | — |
| Docker `/config` ретінде жалғанған хост бумасын көрсету | `--config-root=/path` | — |

<details>
<summary><b>Ескертпелер (ашу үшін басыңыз)</b></summary>

Ескертпелер:

- `-dev` болмаса, тұрақты `main` қолданылады; `-dev` әзірлеменің ағымдағы нақты Git SHA нұсқасын таңдайды.
- `-o` **output** дегенді білдіреді және WeiG qB WebUI орнату бумасын таңдайды. Linux-та оны бір тексерілген жүктеумен бірнеше нысананы жаңарту үшін қайталауға болады.
- Орнатқыш сақтық көшірмелері `~/.config/weig-qb-webui/backups/` ішінде орналасады, әр нысана үшін **соңғы 3 көшірме бөлек сақталады**.
- `-configure` qBittorrent-тің **Use alternative WebUI** параметрін қосады және орнатудан кейін **Files location** жолын орнатады. Ол әдейі тек бір нысанаға арналған.
- `-rollback` таңдалған нысананың орнатқыш жасаған соңғы сақтық көшірмесін қайтарады; бірнеше нақты нысана үшін `-o` қайталаңыз.
- `-version` нақты GitHub Release нұсқасын орнатады, мысалы `1.2.0`. Сұралған нұсқа жоқ болса, орнату сәтсіз аяқталады және **latest не dev нұсқасына ешқашан автоматты ауыспайды**.
- `-help` Linux-тың қазіргі қолдау көрсетілетін пәрмен синтаксисін көрсетеді.
- Бірнеше qBittorrent Docker контейнері болса, `--list-containers` қолданып, бірін `--container=NAME` арқылы таңдаңыз. Хосттағы qBittorrent баптау бумасын білсеңіз, `--config-root=/path` да қолдана аласыз.

## Бір пәрменмен жою

<details>
<summary><b>Linux / NAS, Docker және Windows PowerShell жүйелерінде толық жою</b></summary>

Төмендегі ұсынылған пәрмен **орнатқыштың сақтық көшірмелерін қалдырмай**, WebUI-ді толық жояды: сәйкес Alternative WebUI баптауын өшіреді, осы нысанаға тиесілі сақтық көшірмелер мен кері қайтару күйін тазалайды, содан кейін ағымдағы бумадан жүктелген орнату скриптін жояды.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Өз орнату бумасы үшін `-o /path/to/weig-qb-webui` қосыңыз.

### Docker

Бір контейнер / автоматты анықтау:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Бірнеше контейнер:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` қолданғанда:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Өз орнату бумасы үшін `-o D:\weig-qb-webui` қосыңыз.

`-purge` тек ағымдағы жойылатын нысанаға тиесілі сақтық көшірмелерді жояды, басқа орнатуларға тимейді. Ортақ күй бумасы бос қалса, Linux-тағы `~/.config/weig-qb-webui` (root үшін `/root/.config/weig-qb-webui`) немесе Windows-тағы `%APPDATA%\weig-qb-webui` бумасы да жойылады.

Кейін `-rollback` үшін сақтық көшірмелерді қалдырғыңыз келсе, жай ғана `-purge` қолданбаңыз.

</details>
