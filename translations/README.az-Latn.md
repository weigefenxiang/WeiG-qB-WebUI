## Bir neçə instansiya üçün yan panel

Bir neçə müstəqil qBittorrent instansiyası eyni hazırlanmış WeiG qovluğunu **yalnız oxuma rejimində** paylaşa bilər. Host qovluğunu hər Docker konteynerinə ayrıca qoşun, məsələn `/root/weig-qb-webui:/weig-qb-webui:ro`, və hər qBittorrent instansiyasında `/weig-qb-webui` yolunu Alternative WebUI-nin kök qovluğu kimi göstərin. Hər instansiyanın torrentləri, sazlamaları və giriş məlumatları ayrı qalır.

Yan paneldəki **Instances** bölməsində instansiyalar əlavə etmək, aralarında ayrıca səhifəni açmaqla keçid etmək və adlarını dəyişmək olar (sağ klik və ya sətir menyusu ilə). Cari instansiya saxlanmış ad sonluğuna görə deyil, həqiqi URL əsasında müəyyən edilir. Avtomatik yoxlama intervalı **Settings → WeiG WebUI → Interface** bölməsində tənzimlənir; standart olaraq `30 min`-dir, onu söndürmək və ya 5–1440 dəqiqə aralığında seçmək mümkündür.

**Status sübutları ehtiyatla şərh olunur:** eyni mənbədən autentifikasiya olunmuş WebAPI cavabı qB-nin onlayn olduğunu təsdiqləyir. Başqa mənbədən, giriş məlumatları olmadan alınan `no-cors` cavabı yalnız HTTP ünvanının əlçatan olduğunu göstərir, cavab 403/404 olduqda belə. Mənbələr arasında Cookie/SID oxunmur, parollar və sessiyalar ötürülmür, CORS-dan yan keçilmir və server vasitəçisi istifadə olunmur. Əvvəlki uğurlu yoxlamanın saxlanmış vaxtı **tarixi göstəricidir**, cari onlayn vəziyyətin təsdiqi deyil. Brauzerdə `127.0.0.1` brauzerin işlədiyi cihazı bildirir, uzaqdakı VPS-i deyil.

## Yeni başlayanlar üçün quraşdırma

<details>
<summary><b>İlk dəfə quraşdırırsınız? Bu qısa təlimatı açın</b></summary>

### 1. ZIP arxivini açın

`weig-qb-webui.zip` faylını endirib arxivdən çıxarın. Arxivdə standart qovluq artıq var:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Bütün **`weig-qb-webui`** qovluğu WebUI-nin kök qovluğudur. Təkcə `public` və ya `private` qovluğunu köçürməyin.

### 2. Daimi yerə köçürün

Məsələn:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Bu yolu sonradan qBittorrent-də göstərməlisiniz.

### 3. qBittorrent-də aktivləşdirin

qBittorrent-i açın:

**Tools → Options... → WebUI**

Bunlar qBittorrent-in hazırkı ingilisdilli interfeysindəki dəqiq menyu adlarıdır. Sonra:

1. **Use alternative WebUI** seçimini aktivləşdirin.
2. **Files location:** sahəsini tapın.
3. `weig-qb-webui` qovluğunun yolunu daxil edin.

Windows nümunəsi:

```text
D:\weig-qb-webui
```

Linux nümunəsi:

```text
/opt/weig-qb-webui
```

4. Yadda saxlamaq üçün **OK** düyməsini basın.
5. qBittorrent WebUI səhifəsini yeniləyin. Brauzer keşində köhnə səhifə qalarsa, bir dəfə `Ctrl + F5` sınayın.

> **Yolun yoxlanılması:** göstərdiyiniz qovluqda birbaşa `public`, `private`, `VERSION` və digər WebUI faylları olmalıdır.

> **Docker istifadəçiləri üçün:** qBittorrent konteyner daxilində işləyir, buna görə adətən hostdakı deyil, konteynerin daxilindən görünən yolu daxil etmək lazımdır.

</details>

## Bir əmrlə quraşdırma

Linux/NAS quraşdırma skripti həmişə aşağıdakı sabit Dev Pages ünvanından endirilir. **Skriptin URL-si quraşdırma kanalını seçmir:** `-dev` olmadan GitHub Release-in ən son yoxlanmış stabil versiyası quraşdırılır; `-dev` isə dəqiq Git SHA əsasında cari inkişaf versiyasını seçir. Endirilmiş skript gələcək yeniləmə və əvvəlki versiyaya qayıtmaq üçün cari qovluqda qalır.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Skriptin ünvanını və standart quraşdırma qovluğunu göstər</b></summary>

```text
./install.sh
```

WebUI standart olaraq burada quraşdırılır:

```text
~/.local/share/weig-qb-webui
```

`root` istifadəçisi ilə işə salındıqda adətən burada:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, bir neçə konteyner və yolların izahı</b></summary>

#### Host və konteyner

- **Host:** Docker-in işlədiyi Linux/NAS maşını.
- **Konteyner:** qBittorrent-in işlədiyi təcrid olunmuş mühit.

Məsələn:

```text
Хост:       /root/qbittorrent/config
   ↓ qoşulub
Konteyner:  /config
```

Docker Compose nümunəsi:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

WebUI hostda bu yerdədirsə:

```text
/root/qbittorrent/config/weig-qb-webui
```

qBittorrent-in **Files location:** sahəsinə bunu daxil edin:

```text
/config/weig-qb-webui
```

#### Bir qBittorrent konteyneri

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Quraşdırıcı konteyneri və onun `/config` qoşulmasını avtomatik müəyyən etməyə çalışacaq.

#### Konteynerləri tapın

Əvvəlcə aşkarlanmış qBittorrent konteynerlərinin siyahısını göstərin:

```sh
sh install.sh --list-containers
```

Yaxud Docker-dən birbaşa istifadə edin:

```sh
docker ps
```

Məsələn, konteynerin adı belə ola bilər:

```text
qbittorrent
```

Sonra onu açıq şəkildə seçin:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Bir neçə qBittorrent konteyneri varsa

Məsələn, əsas və sınaq instansiyaları:

```text
qbittorrent
qbittorrent-test
```

Əvvəlcə onların siyahısını alın:

```sh
sh install.sh --list-containers
```

Əsas instansiya üçün:

```sh
sh install.sh --container=qbittorrent -configure
```

Sınaq instansiyası üçün:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Bir neçə konteyner olduqda quraşdırıcı onların birini təsadüfi seçməyəcək.

#### `/config` kimi qoşulmuş host qovluğunu göstərmək

qBittorrent-in konfiqurasiya qovluğu hostda buradadırsa:

```text
/root/qbittorrent/config
```

Onu birbaşa göstərə bilərsiniz:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology nümunəsi:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Başqa NAS nümunəsi:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Nümunə yollarını qBittorrent-də `/config` kimi qoşulmuş həqiqi host yolu ilə əvəz edin.

#### WebUI quraşdırma qovluğunu seçin

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Bir endirmə ilə bir neçə WebUI quraşdırmasını yeniləyin

Linux/NAS sistemlərində `-o` parametrini təkrarlamaqla bir endirmədən sonra bir neçə mövcud quraşdırmanı yeniləmək olar. Bu rejimdə `-configure`, `--container` və `--config-root` parametrlərindən eyni vaxtda istifadə etməyin.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Quraşdırmadan sonra yolları yoxlayın

Quraşdırıcı həm hostdakı, həm də qBittorrent-in gördüyü yolu göstərir:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent-in **Files location** parametrində ikinci yolu — konteyner daxilindəki yolu — istifadə edin. `-configure` uğurla işləsə, quraşdırıcı onu avtomatik təyin edəcək.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Quraşdırma qovluğunu göstər</b></summary>

```text
C:\Users\<istifadəçi-adı>\AppData\Local\weig-qb-webui
```

</details>

## Ümumi parametrlər
PowerShell parametrlərinin adlarında böyük və kiçik hərflər fərqləndirilmir.

<summary><b>Qeydlər (açmaq üçün klikləyin)</b></summary>

```powershell

```

</details>

## Bir əmrlə silinmə

<details>
<summary><b>Linux / NAS, Docker və Windows PowerShell üçün tam silinmə</b></summary>

Tövsiyə olunan əmr **quraşdırıcının ehtiyat nüsxələrini saxlamadan tam silmə** həyata keçirir: WebUI-ni silir, müvafiq alternativ WebUI sazlamasını söndürür, həmin quraşdırmanın ehtiyat nüsxələrini və geri qaytarma vəziyyətini təmizləyir, sonra cari qovluqdan endirilmiş quraşdırma skriptini silir.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Fərdi quraşdırma qovluğu üçün `-o /path/to/weig-qb-webui` əlavə edin.

### Docker

Bir konteyner / avtomatik aşkarlama:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Bir neçə konteyner:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` istifadə etdikdə:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Fərdi qovluq üçün `-o D:\weig-qb-webui` əlavə edin.

`-purge` yalnız cari hədəfin ehtiyat nüsxələrini silir və digər quraşdırmalara toxunmur. Ortaq vəziyyət qovluğu boşaldıqda Linux-də `~/.config/weig-qb-webui` (root üçün: `/root/.config/weig-qb-webui`), Windows-da isə `%APPDATA%\weig-qb-webui` də silinir.

Sonradan `-rollback` üçün ehtiyat nüsxələri saxlamaq istəyirsinizsə, sadəcə `-purge` parametrini buraxın.

</details>
