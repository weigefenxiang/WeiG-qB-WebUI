## Bir nechta nusxa uchun yon panel

Bir nechta mustaqil qBittorrent nusxasi tayyorlangan bir xil WeiG papkasidan **faqat oʻqish rejimida** foydalanishi mumkin. Xost papkasini har bir Docker konteyneriga alohida ulang, masalan `/root/weig-qb-webui:/weig-qb-webui:ro`, va har bir qBittorrent nusxasida `/weig-qb-webui` manzilini Alternative WebUI ildiz papkasi qilib belgilang. Har bir nusxaning torrentlari, sozlamalari va kirish maʼlumotlari alohida saqlanadi.

Yon paneldagi **Instances** boʻlimida nusxalarni roʻyxatga olish, toʻliq sahifani ochish orqali ular orasida oʻtish va nomini oʻzgartirish (sichqonchaning oʻng tugmasi yoki qator menyusi orqali) mumkin. Joriy nusxa saqlangan nom qoʻshimchasiga emas, haqiqiy URL manziliga qarab aniqlanadi. Avtomatik tekshirish oraligʻi **Settings → WeiG WebUI → Interface** da sozlanadi; standart qiymat `30 min`, uni oʻchirish yoki 5 dan 1440 daqiqagacha tanlash mumkin.

**Holat dalillari ehtiyotkorlik bilan talqin qilinadi:** bir xil manbadan tasdiqlangan WebAPI javobi qB onlayn ekanini bildiradi. Boshqa manbadan hisob maʼlumotlarisiz olingan `no-cors` javobi, hatto 403/404 qaytarsa ham, faqat HTTP manziliga yetib borish mumkinligini koʻrsatadi. Manbalar orasida Cookie/SID oʻqilmaydi, parollar yoki sessiyalar uzatilmaydi, CORS chetlab oʻtilmaydi va server proksisi ishlatilmaydi. Oldingi muvaffaqiyatli tekshiruvning saqlangan vaqti **tarixiy dalil**, joriy onlayn holat tasdigʻi emas. Brauzerdagi `127.0.0.1` masofadagi VPS ni emas, brauzer ishlayotgan qurilmani anglatadi.

## Yangi foydalanuvchilar uchun oʻrnatish

<details>
<summary><b>Birinchi marta oʻrnatyapsizmi? Ushbu qisqa qoʻllanmani oching</b></summary>

### 1. ZIP arxivni oching

`weig-qb-webui.zip` faylini yuklab olib, arxivdan chiqaring. Arxivda standart papka allaqachon mavjud:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Butun **`weig-qb-webui`** papkasi WebUI ildiz katalogidir. Faqat `public` yoki `private` papkasini nusxalamang.

### 2. Doimiy joyga koʻchiring

Masalan:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Bu yoʻlni keyinchalik qBittorrent dasturiga kiritasiz.

### 3. qBittorrent dasturida faollashtiring

qBittorrent dasturini oching:

**Tools → Options... → WebUI**

Bular qBittorrent dasturining hozirgi inglizcha interfeysidagi aniq menyu nomlari. Keyin:

1. **Use alternative WebUI** parametrini yoqing.
2. **Files location:** maydonini toping.
3. `weig-qb-webui` papkasiga yoʻlni kiriting.

Windows uchun misol:

```text
D:\weig-qb-webui
```

Linux uchun misol:

```text
/opt/weig-qb-webui
```

4. Saqlash uchun **OK** tugmasini bosing.
5. qBittorrent WebUI sahifasini yangilang. Agar keshdan eski sahifa ochilaversa, bir marta `Ctrl + F5` ni sinab koʻring.

> **Yoʻlni tekshirish:** koʻrsatilgan papkada `public`, `private`, `VERSION` va boshqa WebUI fayllari bevosita joylashgan boʻlishi kerak.

> **Docker foydalanuvchilari uchun:** qBittorrent konteyner ichida ishlaydi. Shuning uchun odatda xostdagi yoʻl emas, konteyner ichida koʻrinadigan yoʻl kiritiladi.

</details>

## Bitta buyruq bilan oʻrnatish

Linux/NAS oʻrnatish skripti doimo quyidagi oʻzgarmas Dev Pages manzilidan yuklab olinadi. **Skript URL manzili oʻrnatish kanalini tanlamaydi:** `-dev` boʻlmasa, eng soʻnggi tekshirilgan barqaror GitHub Release oʻrnatiladi; `-dev` esa aniq Git SHA boʻyicha joriy ishlab chiqish versiyasini tanlaydi. Yuklab olingan skript keyingi yangilash yoki oldingi holatga qaytarish uchun joriy papkada qoladi.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Skript manzili va standart oʻrnatish papkasini koʻrsatish</b></summary>

```text
./install.sh
```

WebUI odatda quyidagi manzilga oʻrnatiladi:

```text
~/.local/share/weig-qb-webui
```

`root` nomidan ishga tushirilganda odatda:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, bir nechta konteyner va yoʻllar izohi</b></summary>

#### Xost va konteyner

- **Xost:** Docker ishlayotgan Linux/NAS qurilmasi.
- **Konteyner:** qBittorrent ishlayotgan ajratilgan muhit.

Masalan:

```text
Хост:       /root/qbittorrent/config
   ↓ ulangan
Konteyner:  /config
```

Docker Compose misoli:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Agar WebUI xostda quyidagi yoʻlda boʻlsa:

```text
/root/qbittorrent/config/weig-qb-webui
```

qBittorrent dagi **Files location:** maydoniga quyidagini kiriting:

```text
/config/weig-qb-webui
```

#### Bitta qBittorrent konteyneri

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Oʻrnatgich konteynerni va uning `/config` ulanishini avtomatik aniqlashga harakat qiladi.

#### Konteynerlarni topish

Avval aniqlangan qBittorrent konteynerlari roʻyxatini koʻring:

```sh
sh install.sh --list-containers
```

Yoki toʻgʻridan-toʻgʻri Docker dan foydalaning:

```sh
docker ps
```

Masalan, konteyner nomi quyidagicha boʻlishi mumkin:

```text
qbittorrent
```

Soʻng uni aniq tanlang:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Bir nechta qBittorrent konteyneri boʻlsa

Masalan, asosiy va sinov nusxalari:

```text
qbittorrent
qbittorrent-test
```

Avval ularning roʻyxatini chiqaring:

```sh
sh install.sh --list-containers
```

Asosiy nusxa uchun:

```sh
sh install.sh --container=qbittorrent -configure
```

Sinov nusxasi uchun:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Bir nechta konteyner boʻlganda oʻrnatgich ulardan birini taxminan tanlamaydi.

#### `/config` sifatida ulangan xost papkasini koʻrsatish

Agar qBittorrent sozlamalari papkasi xostda bu yerda joylashgan boʻlsa:

```text
/root/qbittorrent/config
```

Uni bevosita koʻrsatishingiz mumkin:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology uchun misol:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Boshqa NAS uchun misol:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Namunadagi yoʻllarni qBittorrent da `/config` sifatida ulangan xostning haqiqiy yoʻli bilan almashtiring.

#### WebUI oʻrnatish papkasini tanlash

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Bitta yuklab olish bilan bir nechta WebUI oʻrnatilishini yangilash

Linux/NAS da `-o` parametrini takrorlab, bir yuklab olishdan soʻng bir nechta mavjud oʻrnatilishni yangilashingiz mumkin. Bu rejimda `-configure`, `--container` va `--config-root` parametrlarini birgalikda ishlatmang.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Oʻrnatishdan keyin yoʻllarni tekshirish

Oʻrnatgich xostdagi yoʻlni va qBittorrent koʻradigan yoʻlni koʻrsatadi:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent ning **Files location** sozlamasida ikkinchi yoʻlni, yaʼni konteyner ichidagi yoʻlni ishlating. `-configure` muvaffaqiyatli bajarilsa, oʻrnatgich uni avtomatik sozlaydi.

</details>

## Koʻp ishlatiladigan parametrlar
PowerShell parametrlari nomida katta-kichik harflar farqlanmaydi.

| Maqsad | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Eng soʻnggi barqaror nashr | Standart | Standart |
| Muayyan Release versiyasi | `-version 1.2.0` | `-version 1.2.0` |
| Ishlab chiqish versiyasi | `-dev` | `-dev` |
| Oʻrnatish papkasi | `-o /path` (takrorlash mumkin) | `-o D:\path` yoki `-output D:\path` |
| qBittorrent sozlamalar fayli | — | `-qbconfig D:\path\qBittorrent.ini` |

| Toʻliq yordam | `-help` | `-help` |
| Docker konteynerini tanlash | `--container=NAME` | — |
| Docker konteynerlari roʻyxati | `--list-containers` | — |
| Docker `/config` sifatida ulangan xost papkasi | `--config-root=/path` | — |

## Bitta buyruq bilan oʻchirish

<details>
<summary><b>Linux / NAS, Docker va Windows PowerShell da toʻliq oʻchirish</b></summary>

Tavsiya etilgan buyruq **oʻrnatgichning zaxira nusxalarini saqlamasdan butunlay oʻchiradi**: WebUI ni olib tashlaydi, unga tegishli alternativ WebUI sozlamasini oʻchiradi, ushbu oʻrnatilish zaxiralarini va qaytarish holatini tozalaydi, soʻng joriy papkadan yuklab olingan oʻrnatish skriptini oʻchiradi.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Maxsus oʻrnatish papkasi uchun `-o /path/to/weig-qb-webui` ni qoʻshing.

### Docker

Bitta konteyner / avtomatik aniqlash:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Bir nechta konteyner:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` bilan:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Maxsus papka uchun `-o D:\weig-qb-webui` ni qoʻshing.

`-purge` faqat joriy manzilning zaxira nusxalarini oʻchiradi va boshqa oʻrnatilishlarga tegmaydi. Umumiy holat papkasi boʻsh qolsa, Linux da `~/.config/weig-qb-webui` (root uchun: `/root/.config/weig-qb-webui`) yoki Windows da `%APPDATA%\weig-qb-webui` ham oʻchiriladi.

Keyinchalik `-rollback` yordamida tiklash uchun zaxiralarni saqlamoqchi boʻlsangiz, `-purge` ni ishlatmang.

</details>
