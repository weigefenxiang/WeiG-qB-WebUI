## Mitme eksemplari külgriba

Mitu sõltumatut qBittorrenti eksemplari võivad kasutada sama ettevalmistatud WeiG kausta **kirjutuskaitstud** jagatud ressursina. Ühenda hosti kaust igasse Dockeri konteinerisse eraldi, näiteks `/root/weig-qb-webui:/weig-qb-webui:ro`, ja määra igas qBittorrenti eksemplaris `/weig-qb-webui` Alternative WebUI juurkaustaks. Iga eksemplari torrentid, seaded ja sisselogimisandmed jäävad eraldi.

Külgriba jaotis **Instances** võimaldab eksemplare lisada, nende vahel täieliku lehenavigeerimisega liikuda ja neid ümber nimetada (paremklõpsuga või rea menüüst). Praegust eksemplari tähistab tegelik URL, mitte salvestatud nime lõpp. Automaatse kontrolli intervall asub menüüs **Settings → WeiG WebUI → Interface**: vaikimisi `30 min`; kontrolli saab välja lülitada või määrata vahemikku 5–1440 minutit.

**Oleku tõlgendamisel ollakse teadlikult ettevaatlik:** samalt päritolult autentitud WebAPI vastus kinnitab, et qB on võrgus. Teise päritoluga `no-cors` päringu vastus ilma autentimisandmeteta näitab ainult HTTP-aadressi kättesaadavust, ka siis, kui vastuseks on 403/404. Teise päritoluga Cookie/SID andmeid ei loeta, paroole ega seansse ei edastata ning CORS-i ei mööduta ega kasutata serveripoolset vahendajat. Varasema eduka kontrolli salvestatud aeg on **ajalooline tõend**, mitte praeguse võrguoleku kinnitus. Brauseris tähendab `127.0.0.1` brauserit käitavat seadet, mitte kaug-VPS-i.

## Paigaldamine algajale

<details>
<summary><b>Paigaldad esimest korda? Ava see lühijuhend</b></summary>

### 1. Paki ZIP-arhiiv lahti

Laadi `weig-qb-webui.zip` alla ja paki lahti. Arhiiv sisaldab juba tavapärast kausta:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Kogu **`weig-qb-webui`** kaust on WebUI juurkaust. Ära kopeeri ainult `public` või `private` kausta.

### 2. Teisalda püsivasse asukohta

Näiteks:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Selle asukoha pead hiljem qBittorrentis määrama.

### 3. Luba qBittorrentis

Ava qBittorrent:

**Tools → Options... → WebUI**

Need on qBittorrenti praeguse ingliskeelse liidese täpsed menüünimed. Seejärel:

1. Lülita sisse **Use alternative WebUI**.
2. Leia väli **Files location:**.
3. Sisesta `weig-qb-webui` kausta asukoht.

Näide Windowsis:

```text
D:\weig-qb-webui
```

Näide Linuxis:

```text
/opt/weig-qb-webui
```

4. Salvestamiseks vajuta **OK**.
5. Värskenda qBittorrent WebUI lehte. Kui näed brauseri vahemälust endiselt vana liidest, proovi korra `Ctrl + F5`.

> **Asukoha kontroll:** määratud kaustas peavad vahetult asuma `public`, `private`, `VERSION` ja teised WebUI failid.

> **Dockeri kasutajale:** qBittorrent töötab konteineris, seega pead üldjuhul määrama konteineri sees nähtava tee, mitte hostmasina tee.

</details>

## Paigaldamine ühe käsuga

Linuxi/NAS-i paigaldusskript laaditakse alati alla allolevalt püsivalt Dev Pagesi aadressilt. **Skripti URL ei vali paigalduskanalit:** ilma võtmeta `-dev` paigaldatakse GitHub Release'i uusim kontrollitud stabiilne versioon; `-dev` valib praeguse arendusversiooni täpse Git SHA alusel. Allalaaditud skript jääb käesolevasse kausta edaspidiste uuenduste ja varasema versiooni taastamise jaoks.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Näita skripti aadressi ja vaikimisi paigalduskausta</b></summary>

```text
./install.sh
```

WebUI paigaldatakse vaikimisi kausta:

```text
~/.local/share/weig-qb-webui
```

Kasutajana `root` käivitamisel tavaliselt kausta:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, mitu konteinerit ja asukohtade selgitus</b></summary>

#### Host ja konteiner

- **Host:** Linuxi/NAS-i masin, millel Docker töötab.
- **Konteiner:** eraldatud keskkond, kus qBittorrent töötab.

Näiteks:

```text
Хост:       /root/qbittorrent/config
   ↓ смонтировано как
Контейнер:  /config
```

Docker Compose'i näide:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Kui WebUI paikneb hostis järgmisel teel:

```text
/root/qbittorrent/config/weig-qb-webui
```

siis qBittorrenti väljal **Files location:** tuleb määrata:

```text
/config/weig-qb-webui
```

#### Üks qBittorrenti konteiner

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Paigaldaja proovib konteineri ja selle `/config` ühenduse automaatselt leida.

#### Konteinerite leidmine

Esmalt vaata tuvastatud qBittorrenti konteinerite loendit:

```sh
sh install.sh --list-containers
```

Või kasuta Dockerit otse:

```sh
docker ps
```

Näiteks võib konteineri nimi olla:

```text
qbittorrent
```

Seejärel määra see sõnaselgelt:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Kui qBittorrenti konteinereid on mitu

Näiteks põhi- ja testeksemplar:

```text
qbittorrent
qbittorrent-test
```

Esmalt kuva nende loend:

```sh
sh install.sh --list-containers
```

Põhieksemplari jaoks:

```sh
sh install.sh --container=qbittorrent -configure
```

Testeksemplari jaoks:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Mitme konteineri korral ei vali paigaldaja neist ühte juhuslikult.

#### Hostikausta määramine, mis on ühendatud asukohta `/config`

Kui qBittorrenti seadistuste kaust asub hostis siin:

```text
/root/qbittorrent/config
```

Võid selle otse määrata:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Näide Synology jaoks:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Näide mõne muu NAS-i jaoks:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Asenda näidisteed tegeliku hostiteega, mis on qBittorrentis ühendatud kui `/config`.

#### WebUI paigalduskausta valimine

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Mitme WebUI paigalduse uuendamine ühe allalaadimisega

Linuxis ja NAS-is saad võtit `-o` korrata, et ühe allalaadimise järel uuendada mitut olemasolevat paigaldust. Selles režiimis ära kasuta samaaegselt võtmeid `-configure`, `--container` ja `--config-root`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Teede kontrollimine pärast paigaldamist

Paigaldaja näitab hostis olevat teed ja qBittorrentile nähtavat teed:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrenti väljal **Files location** kasuta teist, konteinerisisest teed. Kui `-configure` õnnestub, määrab paigaldaja selle automaatselt.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

```text
C:\Users\<имя-пользователя>\AppData\Local\weig-qb-webui
```

</details>

## Eemaldamine ühe käsuga

<details>
<summary><b>Täielik eemaldamine Linuxi / NAS-i, Dockeri ja Windows PowerShelli jaoks</b></summary>

Soovitatav käsk teeb **täieliku eemaldamise ilma paigaldaja varukoopiaid alles jätmata**: see eemaldab WebUI, lülitab välja vastava alternatiivse WebUI seadistuse, kustutab selle sihtkoha varukoopiad ja taastamise oleku ning eemaldab lõpuks allalaaditud paigaldusskripti praegusest kaustast.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Kohandatud paigalduskausta jaoks lisa `-o /path/to/weig-qb-webui`.

### Docker

Üks konteiner / automaatne tuvastamine:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Mitu konteinerit:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Võtmega `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Kohandatud paigalduskausta jaoks lisa `-o D:\weig-qb-webui`.

`-purge` kustutab ainult praeguse sihtkoha varukoopiad ega mõjuta teisi paigaldusi. Kui ühine olekukaust tühjeneb, eemaldatakse Linuxis ka `~/.config/weig-qb-webui` (root-kasutajal `/root/.config/weig-qb-webui`) või Windowsis `%APPDATA%\weig-qb-webui`.

Kui soovid hilisemaks `-rollback` käsuks varukoopiaid säilitada, jäta `-purge` ära.

</details>
