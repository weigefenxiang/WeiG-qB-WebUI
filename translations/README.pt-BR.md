## Primeiros passos

<details>
<summary><b>Primeira instalação? Abra o guia de 1 minuto</b></summary>

### 1. Extrair o ZIP

Baixe `weig-qb-webui.zip` e extraia o arquivo. Ele já contém uma pasta com o nome padrão:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

A pasta **`weig-qb-webui` inteira** é a raiz da interface Web. Não copie apenas `public` ou `private`.

### 2. Salvar em um local permanente

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

É essa pasta que você deverá selecionar no qBittorrent.

### 3. Ativar no qBittorrent

Abra o qBittorrent:

**Ferramentas → Opções... → WebUI**

Os nomes das opções variam conforme o idioma configurado no qBittorrent. Em seguida:

1. Ative **Usar interface Web alternativa** (ou **Use alternative WebUI**).
2. Localize o campo **Localização dos arquivos** (ou **Files location**).
3. Informe o caminho da pasta `weig-qb-webui`.

Exemplo Windows:

```text
D:\weig-qb-webui
```

Exemplo Linux:

```text
/opt/weig-qb-webui
```

4. Clique em **OK** para salvar.
5. Atualize a página da interface Web. Se a interface antiga continuar em cache, pressione `Ctrl + F5`.

> **Como confirmar o caminho:** dentro da pasta indicada, você deverá ver diretamente `public`, `private`, `VERSION` e os demais arquivos.

> **Docker:** o qBittorrent roda dentro de um contêiner. Use um caminho visível pelo contêiner, não um caminho que só existe no computador host.

</details>

## Instalação com um único comando

O instalador para Linux e NAS é baixado pelo endereço fixo do Dev Pages abaixo. **O endereço do script não determina qual versão será instalada:** sem `-dev`, instala a versão estável mais recente, publicada e verificada; use `-dev` somente para instalar a versão de desenvolvimento atual.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Ver onde o script fica salvo e qual é a pasta padrão de instalação</b></summary>

```text
./install.sh
```

Pasta padrão da interface Web:

```text
~/.local/share/weig-qb-webui
```

Ao executar como `root`, normalmente será:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Instalação no Docker / vários contêineres / caminhos</b></summary>

#### Host e contêiner

- **Host**: o sistema Linux ou NAS onde o Docker está instalado.
- **Contêiner**: o ambiente isolado em que o qBittorrent roda.

Exemplo:

```text
Anfitrião: /root/qbittorrent/config
   ↓ montado em
Contentor: /config
```

Docker Compose:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Se a interface Web estiver instalada no host em:

```text
/root/qbittorrent/config/weig-qb-webui
```

o campo **Files location** do qBittorrent deverá apontar para:

```text
/config/weig-qb-webui
```

#### Apenas um contêiner do qBittorrent

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

O instalador tenta identificar automaticamente o contêiner em execução e o volume montado em `/config`.

#### Listar os contêineres

Confira quais contêineres do qBittorrent estão em execução:

```sh
sh install.sh --list-containers
```

Ou use o Docker diretamente:

```sh
docker ps
```

Se a lista mostrar um contêiner chamado:

```text
qbittorrent
```

selecione-o explicitamente:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Escolher o contêiner certo quando há vários

Por exemplo, se você tiver uma instância principal e outra de testes:

```text
qbittorrent
qbittorrent-test
```

Consulte a lista:

```sh
sh install.sh --list-containers
```

Para configurar a instância principal:

```sh
sh install.sh --container=qbittorrent -configure
```

Para configurar a instância de testes:

```sh
sh install.sh --container=qbittorrent-test -configure
```

O instalador não escolhe automaticamente entre vários contêineres.

#### Informar a pasta do host montada como `/config`

Suponha que a configuração do qBittorrent esteja no host em:

```text
/root/qbittorrent/config
```

Você pode informar diretamente essa pasta:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Em um NAS Synology, o caminho pode ser:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Em outro NAS:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Esses caminhos são exemplos: use a pasta real do qBittorrent no seu host.

#### Escolher a pasta da interface Web

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Atualizar várias instalações de uma vez

No Linux ou NAS, repita `-o` para atualizar várias instalações existentes com um único download. Nesse modo, não combine `-configure`, `--container` nem `--config-root`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Conferir os caminhos após a instalação

A saída mostra separadamente a pasta no host e a pasta que o qBittorrent consegue acessar:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

No qBittorrent, use o segundo caminho no campo **Files location**. Com `-configure`, o instalador ajusta esse campo automaticamente quando a detecção funciona.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Ver a pasta de instalação</b></summary>

```text
C:\Users\<nome-de-usuário>\AppData\Local\weig-qb-webui
```

</details>

## Parâmetros mais usados
Os parâmetros do PowerShell não diferenciam letras maiúsculas de minúsculas.

| Finalidade | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Versão estável mais recente | Padrão | Padrão |
| Versão estável específica | `-version 1.2.0` | `-version 1.2.0` |
| Versão de desenvolvimento | `-dev` | `-dev` |
| Pasta de instalação | `-o /path` ou `-o /path` | `-o D:\path` ou `-output D:\path` |
| Arquivo de configuração do qBittorrent | — | `-qbconfig D:\path\qBittorrent.ini` |
| Configurar o qBittorrent | `-configure` | `-configure` |
| Restaurar a instalação anterior | `-rollback` | `-rollback` |
| Desinstalação completa (sem backups do instalador) | `-uninstall -purge` | `-uninstall -purge` |
| Ajuda | `-help` | `-help` |
| Escolher um contêiner Docker | `--container=NAME` | — |
| Listar contêineres Docker | `--list-containers` | — |
| Pasta do host montada como `/config` | `--config-root=/path` | — |

<details>
<summary><b>Observações (clique para expandir)</b></summary>

- Uma versão que não existe gera um erro; o instalador não muda automaticamente para latest ou dev.
- `-dev` não pode ser combinado com `-version`.

### Versão específica e pasta de instalação

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Restauração

Para restaurar a instalação anterior:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Desinstalação com um único comando

<details>
<summary><b>Remoção completa no Linux / NAS, Docker e Windows PowerShell</b></summary>

Por padrão, recomendamos **remover a interface sem manter os backups do instalador**: remove a WebUI, desativa a interface alternativa daquele destino, apaga os backups e o estado de reversão da instalação e, por fim, remove o script de instalação baixado na pasta atual.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Para usar uma pasta personalizada, adicione `-o /path/to/weig-qb-webui`.

### Docker

Um contêiner / detecção automática:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Vários contêineres:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Se estiver usando `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Para usar uma pasta personalizada, adicione `-o D:\weig-qb-webui`.

`-purge` apaga somente os backups pertencentes à instalação selecionada, sem afetar outras instalações. Se a pasta compartilhada de estado ficar vazia, `~/.config/weig-qb-webui` no Linux (root: `/root/.config/weig-qb-webui`) ou `%APPDATA%\weig-qb-webui` no Windows também será removida.

Para guardar os backups e poder executar `-rollback` depois, basta retirar `-purge`.

</details>
