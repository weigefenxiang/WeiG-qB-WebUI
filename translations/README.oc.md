## Barra laterala per mai d'una instància

Mantunas instàncias independentas de qBittorrent pòdon utilizar lo meteis dorsièr WeiG preparat en **lectura sola**. Montatz lo dorsièr de l'òste dins cada contenidor Docker, per exemple `/root/weig-qb-webui:/weig-qb-webui:ro`, puèi definissètz la raiç de l'Alternative WebUI de cada instància coma `/weig-qb-webui`. Cada instància consèrva sa pròpria basa de donadas de torrents, sos paramètres e sa connexion.

La seccion **Instances** de la barra laterala permet d'enregistrar d'instàncias, de cambiar de pagina entièra e de las tornar nomenar (clic drech o menú de la linha). Podètz nomenar l'instància actuala `524 (current)`, per exemple; lo marcador actual seguís l'URL reala e non pas un sufix enregistrat. L'interval de verificacion automatica se configura dins **Settings → WeiG WebUI → Interface**; la valor per defaut es `30 min`, e podètz lo desactivar o causir entre 5 e 1440 minutas.

**Las pròvas de disponibilitat son volontàriament prudentas:** una responsa WebAPI verificada de la meteissa origina pròva que qB es en linha; una responsa `no-cors` entre originas sens identificants indica sonque qu'una adreça HTTP es accessibla, quitament se renvia 403/404. Cap de lectura de Cookie/SID entre originas, de transferiment de senhal o de session, de contornament CORS ni de passarela backend es provesit. Una ora enregistrada aprèp una verificacion anciana de qB es una **pròva istorica**, pas una pròva de disponibilitat actuala. Lo `127.0.0.1` d'un navegador designa l'aparelh qu'executa aquel navegador, e non pas un VPS distant.

## Installacion pels utilizaires novèls

<details>
<summary><b>Primièra installacion? Desplegatz aquela guida d'una minuta</b></summary>

### 1. Descomprimir lo ZIP

Telecargatz `weig-qb-webui.zip` e descomprimitz-lo. L'archiu conten ja lo dorsièr estandard:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Lo dorsièr **`weig-qb-webui` entièr** es la raiç de la WebUI. Copietz pas sonque `public` o `private`.

### 2. Desplaçar cap a un emplaçament permanent

Plaçatz lo dorsièr `weig-qb-webui` entièr dins un emplaçament ont riscatz pas de l'escafar per error mai tard, per exemple:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Es aquel repertòri que caldrà indicar dins qBittorrent.

### 3. Activar dins qBittorrent

Dobritz qBittorrent:

**Tools → Options... → WebUI**

Aqueles son los tèrmes actuals de l'interfàcia anglesa de qBittorrent. Puèi:

1. Activatz **Use alternative WebUI**.
2. Cercatz lo camp **Files location:**.
3. Indicatz lo camin del dorsièr `weig-qb-webui`.

Exemple sus Windows:

```text
D:\weig-qb-webui
```

Exemple sus Linux:

```text
/opt/weig-qb-webui
```

4. Clicatz sus **OK** per enregistrar.
5. Actualizatz la pagina WebUI de qBittorrent. Se lo navegador mòstra encara la pagina anciana en cache, ensajatz un còp `Ctrl + F5`.

> **Cossí verificar lo camin?** Lo repertòri indicat deu conténer dirèctament `public`, `private`, `VERSION` e los autres fichièrs WebUI. Se cal dintrar dins un autre dorsièr `weig-qb-webui` abans de los veire, lo camin es descalat d'un nivèl.

> **Utilizaires Docker:** qBittorrent fonciona dins un contenidor, doncas podètz pas normalament utilizar dirèctament lo camin de l'òste. Consultatz la guida **Docker** çai jos per comprene la diferéncia entre los camins de l'òste e del contenidor.

</details>

## Installacion en una comanda

L'installador en una comanda per Linux/NAS se telecarga totjorn dempuèi l'URL fixa Dev Pages çai jos. **L'URL de l'escript causís pas lo canal d'installacion:** sens `-dev`, installa la darrièra version establa verificada de GitHub Release; ajustatz `-dev` sonque per installar exprèssament la version de desvolopament actuala identificada per son Git SHA exacte. L'escript telecargat demòra dins lo repertòri actual per las mesas a jorn o los retorns en arrièr futurs.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Afichar l'emplaçament de l'escript e lo repertòri d'installacion per defaut</b></summary>

```text
./install.sh
```

Per defaut, la WebUI s'installa dins:

```text
~/.local/share/weig-qb-webui
```

Per exemple, en executant coma `root`, es generalament:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Installacion Docker en una comanda / mantun contenidor / guida dels camins (recomandada pels debutants)</b></summary>

#### Comprene d'en primièr «òste» e «contenidor»

Se qBittorrent fonciona dins Docker sus un VPS, un servidor Linux, Synology, QNAP o un autre NAS:

- **Òste**: la maquina Linux/NAS vertadièra qu'executa Docker, çò que vesètz aprèp una connexion SSH.
- **Contenidor**: l'environament isolat creat per Docker per qBittorrent. qBittorrent pòt veire los camins del contenidor, mas pas quin que siá camin de l'òste.

Per exemple, vòstre contenidor qBittorrent pòt aver aquela correspondéncia:

```text
Host:      /root/qbittorrent/config
   ↓ mapped to
Container: /config
```

Una entrada Docker Compose tipica se presenta atal:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

A esquèrra dels dos punts, `/root/qbittorrent/config` es lo **camin de l'òste**. A drecha, `/config` es lo **camin del contenidor**.

Se WeiG qB WebUI es fisicament installat a:

```text
Host: /root/qbittorrent/config/weig-qb-webui
```

alavetz lo camp **Files location:** de qBittorrent deu conténer:

```text
/config/weig-qb-webui
```

**Metetz pas `/root/qbittorrent/config/weig-qb-webui` dins qBittorrent**, perque lo contenidor pòt pas generalament veire dirèctament aquel camin de l'òste.

#### Cas 1: un sol contenidor qBittorrent en cors d'execucion

Utilizatz la comanda d'installacion normala:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

L'installador ensajarà de detectar lo contenidor qBittorrent actiu, sa correspondéncia `/config`, d'installar la WebUI dins l'emplaçament correspondent sus l'òste e de configurar qBittorrent automaticament.

#### Cas 2: trobar d'en primièr lo nom del contenidor qBittorrent

Se coneissètz pas lo nom del contenidor:

```sh
sh install.sh --list-containers
```

Podètz tanben utilizar Docker dirèctament:

```sh
docker ps
```

Se lo contenidor qBittorrent se sona:

```text
qbittorrent
```

seleccionatz-lo explicitament:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Cas 3: mantun contenidor qBittorrent

Per exemple:

```text
qbittorrent
qbittorrent-test
```

Listatz-los d'en primièr:

```sh
sh install.sh --list-containers
```

Installar pel contenidor principal `qbittorrent`:

```sh
sh install.sh --container=qbittorrent -configure
```

Installar pel contenidor de tèst:

```sh
sh install.sh --container=qbittorrent-test -configure
```

L'installador causirà pas silenciosament un contenidor a l'azard quand n'i a mantun.

#### Cas 4: coneissètz ja lo repertòri de l'òste montat coma `/config`

Per exemple:

```text
/root/qbittorrent/config
```

Indicatz-lo dirèctament:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Un camin Synology pòt semblar a:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Un autre NAS pòt utilizar per exemple:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Aquò son sonque d'exemples. **Remplaçatz-los pel camin real de l'òste montat coma `/config` de qBittorrent.**

#### Cas 5: causir lo camin d'installacion de la WebUI

Aprèp aver seleccionat un contenidor, podètz tanben causir l'emplaçament WebUI visible dins aquel contenidor:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

L'installador convertís lo camin `/config/...` del contenidor en camin d'installacion correspondent sus l'òste.

#### Cas 6: metre a jorn mantun repertòri WebUI amb un sol telecargament

Per mantunas instàncias qBittorrent, repetissètz `-o`. Lo paquet se telecarga e se verifica un sol còp, totes los emplaçaments son preparats abans de cambiar de version, e cada destinacion consèrva sas tres darrièras còpias de salvament pròprias jos `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Ajustetz pas `-configure` en mòde multidestinacion; cada instància qBittorrent consèrva son dorsièr raiç Alternative WebUI existent. Per veire la sintaxi actuala de las comandas, executatz `sh install.sh -help`.

#### Qué deuriá aparéisser aprèp l'installacion?

Una installacion capitada aficha de valors semblablas a:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Significacion:

- `Host install path`: ont los fichièrs son fisicament enregistrats sus l'òste;
- `qBittorrent Root Folder`: **lo camin dins lo contenidor que qBittorrent deu utilizar pel camp Files location**.

Se `-configure` tròba la configuracion de qBittorrent, l'installador activa **Use alternative WebUI** e definís lo camin automaticament. Autrament, seguissètz las etapas manualas de **Installacion pels utilizaires novèls → Activar dins qBittorrent** çai sus.

</details>

## Opcions correntas
Linux e Windows utilizan los meteisses noms d'opcions publicas quand es possible. La documentacion utiliza de minusculas; los noms de paramètres PowerShell distinguisson pas las majusculas de las minusculas.

| Objectiu | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| main estable | Per defaut, sens opcion | Per defaut, sens opcion |
| Version publicada especifica | `-version 1.2.0` | `-version 1.2.0` |
| Version de desvolopament | `-dev` | `-dev` |
| Repertòri d'installacion personalizat | `-o /path` (repetible sus Linux) | `-o D:\path` o `-output D:\path` |
| Fichièr de configuracion qBittorrent personalizat | — | `-qbconfig D:\path\qBittorrent.ini` |
| Configurar qBittorrent automaticament | `-configure` | `-configure` |
| Tornar a l'installacion precedenta | `-rollback` | `-rollback` |
| Desinstallacion completa (sens conservar las còpias) | `-uninstall -purge` | `-uninstall -purge` |
| Ajuda completa | `-help` | `-help` |
| Seleccionar lo contenidor Docker | `--container=NAME` | — |
| Listar los contenidors Docker | `--list-containers` | — |
| Indicar lo repertòri de l'òste montat coma Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Nòtas (clicatz per desplegar)</b></summary>

Nòtas:

- Sens `-dev`, s'utiliza `main` estable; `-dev` selecciona lo Git SHA exacte de la version de desvolopament actuala.
- `-o` significa **output** e definís lo repertòri d'installacion de WeiG qB WebUI. Sus Linux, se pòt repetir per metre a jorn mantunas destinacions amb un sol telecargament verificat.
- Las còpias de salvament de l'installador se tròban jos `~/.config/weig-qb-webui/backups/` e las **3 darrièras còpias son conservadas separadament per destinacion**.
- `-configure` activa **Use alternative WebUI** dins qBittorrent e definís **Files location** aprèp l'installacion. S'utiliza exprèssament per una sola destinacion.
- `-rollback` restaura la darrièra còpia de salvament de l'installador per la destinacion seleccionada; repetissètz `-o` per restaurar mantunas destinacions explicitas.
- `-version` installa una version GitHub Release exacta, coma `1.2.0`. Se la version demandada existís pas, l'installacion fracassa e **passa pas automaticament a latest o dev**.
- `-help` aficha la sintaxi actuala de las comandas Linux suportadas.
- Amb mantun contenidor Docker qBittorrent, utilizatz `--list-containers`, puèi causissètz-ne un amb `--container=NAME`. Podètz tanben utilizar `--config-root=/path` se coneissètz ja lo repertòri de configuracion de qBittorrent sus l'òste.

### Version e repertòri d'installacion especifics

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Tornar a la version precedenta

Linux:

```sh
sh install.sh -rollback
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Desinstallacion en una comanda

<details>
<summary><b>Desinstallacion completa per Linux / NAS, Docker e Windows PowerShell</b></summary>

La comanda recomandada çai jos fa una desinstallacion completa **sens conservar las còpias de salvament de l'installador**: escafa la WebUI, desactiva la configuracion Alternative WebUI correspondenta, purga las còpias e l'estat de retorn en arrièr pròpris a aquela destinacion, puèi escafa l'escript d'installacion telecargat del repertòri actual.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Per un repertòri d'installacion personalizat, ajustatz `-o /path/to/weig-qb-webui`.

### Docker

Un sol contenidor / deteccion automatica:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Mantun contenidor:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

En utilizant `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Per un repertòri d'installacion personalizat, ajustatz `-o D:\weig-qb-webui`.

`-purge` escafa sonque las còpias de salvament pròprias a la destinacion de desinstallacion actuala; modifica pas las còpias d'autras installacions. Quand lo repertòri d'estat partejat ven void, lo repertòri Linux `~/.config/weig-qb-webui` (per root: `/root/.config/weig-qb-webui`) o Windows `%APPDATA%\weig-qb-webui` es tanben suprimit.

Per conservar las còpias de l'installador per un futur `-rollback`, ometetz simplament `-purge`.

</details>
