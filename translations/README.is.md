## Hliðarstika fyrir mörg tilvik

Mörg sjálfstæð qBittorrent-tilvik geta notað sömu undirbúnu WeiG-möppuna í **skrifvörðum** ham. Tengdu möppu hýsilsins inn í hvern Docker-gám, til dæmis `/root/weig-qb-webui:/weig-qb-webui:ro`, og skilgreindu `/weig-qb-webui` sem rót Alternative WebUI í hverju qBittorrent-tilviki. Hvert tilvik heldur sínum straumum, stillingum og innskráningu aðskildum.

Í hlutanum **Instances** á hliðarstikunni er hægt að skrá tilvik, skipta á milli þeirra með því að opna aðra síðu og endurnefna þau (með hægrismelli eða valmynd línunnar). Núverandi tilvik er ákvarðað út frá raunverulegu URL, ekki vistuðu viðskeyti. Sjálfvirku athugunarbili má breyta undir **Settings → WeiG WebUI → Interface**; sjálfgefið er `30 min`, en einnig má slökkva á athugunum eða velja bil á milli 5 og 1440 mínútna.

**Staða er vísvitandi túlkuð varlega:** staðfest WebAPI-svar af sama uppruna sýnir að qB er nettengt. `no-cors`-svar frá öðrum uppruna án auðkennisupplýsinga sýnir aðeins að HTTP-vistfangið sé aðgengilegt, jafnvel þótt það skili 403/404. Engin Cookie/SID-gögn eru lesin á milli uppruna, lykilorð eða lotur eru ekki flutt, CORS er ekki sniðgengið og enginn þjónamiðlari er notaður. Skráður tími eldri athugunar er **söguleg vísbending**, ekki staðfesting á núverandi tengingu. `127.0.0.1` í vafra vísar til tækisins sem keyrir vafrann, ekki fjarlægs VPS.

## Uppsetning fyrir byrjendur

<details>
<summary><b>Ertu að setja upp í fyrsta sinn? Opnaðu þessa stuttu leiðbeiningu</b></summary>

### 1. Afþjappaðu ZIP-skrána

Sæktu `weig-qb-webui.zip` og afþjappaðu henni. Safnskráin inniheldur þegar venjulegu möppuna:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Öll mappan **`weig-qb-webui`** er rót WebUI. Ekki afrita aðeins `public` eða `private`.

### 2. Færðu möppuna á varanlegan stað

Til dæmis:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Þessa slóð þarftu síðar að færa inn í qBittorrent.

### 3. Virkjaðu í qBittorrent

Opnaðu qBittorrent:

**Tools → Options... → WebUI**

Þetta eru nákvæm heiti í núverandi ensku útgáfu qBittorrent. Síðan:

1. Virkjaðu **Use alternative WebUI**.
2. Finndu reitinn **Files location:**.
3. Sláðu inn slóðina að möppunni `weig-qb-webui`.

Dæmi fyrir Windows:

```text
D:\weig-qb-webui
```

Dæmi fyrir Linux:

```text
/opt/weig-qb-webui
```

4. Smelltu á **OK** til að vista.
5. Endurhladdu qBittorrent WebUI-síðuna. Ef gamla síðan birtist enn úr skyndiminni skaltu prófa `Ctrl + F5` einu sinni.

> **Athugun á slóð:** mappan sem þú slærð inn verður að innihalda `public`, `private`, `VERSION` og aðrar WebUI-skrár beint.

> **Fyrir Docker:** qBittorrent keyrir inni í gámi. Yfirleitt þarf því að nota slóð sem sést inni í gámnum, ekki slóð hýsilsins.

</details>

## Uppsetning með einni skipun

Linux/NAS-uppsetningarskriftan er alltaf sótt af fasta Dev Pages-veffanginu hér fyrir neðan. **Veffang skriftunnar velur ekki uppsetningarrás:** án `-dev` er nýjasta staðfesta stöðuga GitHub Release-útgáfan sett upp; `-dev` velur núverandi þróunarútgáfu samkvæmt nákvæmu Git SHA. Skriftan sem sótt er helst í núverandi möppu fyrir síðari uppfærslur eða afturköllun.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Sýna veffang skriftunnar og sjálfgefna uppsetningarmöppu</b></summary>

```text
./install.sh
```

Sjálfgefin uppsetningarmappa WebUI er:

```text
~/.local/share/weig-qb-webui
```

Þegar keyrt er sem `root` er hún yfirleitt:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, margir gámar og skýringar á slóðum</b></summary>

#### Hýsill og gámur

- **Hýsill:** Linux/NAS-tölvan sem keyrir Docker.
- **Gámur:** einangraða umhverfið þar sem qBittorrent keyrir.

Til dæmis:

```text
Хост:       /root/qbittorrent/config
   ↓ tengt sem
Gámur:  /config
```

Dæmi um Docker Compose:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Ef WebUI er á þessari slóð á hýslinum:

```text
/root/qbittorrent/config/weig-qb-webui
```

þá skaltu setja eftirfarandi í **Files location:** í qBittorrent:

```text
/config/weig-qb-webui
```

#### Einn qBittorrent-gámur

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Uppsetningarforritið reynir að greina gáminn og tengingu hans við `/config` sjálfkrafa.

#### Finna gáma

Skoðaðu fyrst lista yfir greinda qBittorrent-gáma:

```sh
sh install.sh --list-containers
```

Eða notaðu Docker beint:

```sh
docker ps
```

Gámurinn gæti til dæmis heitið:

```text
qbittorrent
```

Veldu hann þá sérstaklega:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Ef nokkrir qBittorrent-gámar eru í gangi

Til dæmis aðaltilvik og prófunartilvik:

```text
qbittorrent
qbittorrent-test
```

Birtu fyrst lista yfir þau:

```sh
sh install.sh --list-containers
```

Fyrir aðaltilvikið:

```sh
sh install.sh --container=qbittorrent -configure
```

Fyrir prófunartilvikið:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ef nokkrir gámar finnast velur uppsetningarforritið ekki einn þeirra af handahófi.

#### Tilgreina möppu á hýslinum sem tengd er sem `/config`

Ef stillingamappa qBittorrent er á þessari slóð á hýslinum:

```text
/root/qbittorrent/config
```

Geturðu tilgreint hana beint:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Dæmi fyrir Synology:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Dæmi fyrir annað NAS-tæki:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Skiptu dæmaslóðunum út fyrir raunverulegu slóðina á hýslinum sem tengd er sem `/config` í qBittorrent.

#### Velja uppsetningarmöppu WebUI

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Uppfæra margar WebUI-uppsetningar með einu niðurhali

Á Linux/NAS er hægt að endurtaka `-o` til að uppfæra margar uppsetningar með einu niðurhali. Í þeirri stillingu má ekki nota `-configure`, `--container` og `--config-root` samtímis.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Staðfesta slóðir eftir uppsetningu

Uppsetningarforritið sýnir bæði slóðina á hýslinum og slóðina sem qBittorrent sér:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Í **Files location** í qBittorrent skaltu nota seinni slóðina, þ.e. slóðina inni í gámnum. Ef `-configure` tekst stillir uppsetningarforritið hana sjálfkrafa.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<summary><b>Sýna uppsetningarmöppu</b></summary>

```text
C:\Users\<notandanafn>\AppData\Local\weig-qb-webui
```

</details>

## Algengir valkostir
Stafir í heitum PowerShell-viðfanga eru ekki háðir há- eða lágstöfum.

| Tilgangur | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Nýjasta stöðuga útgáfa | Sjálfgefið | Sjálfgefið |
| Ákveðin Release-útgáfa | `-version 1.2.0` | `-version 1.2.0` |
| Þróunarútgáfa | `-dev` | `-dev` |
| Uppsetningarmappa | `-o /path` (má endurtaka) | `-o D:\path` eða `-output D:\path` |
| Stillingaskrá qBittorrent | — | `-qbconfig D:\path\qBittorrent.ini` |
| Stilla qBittorrent sjálfkrafa | `-configure` | `-configure` |
| Endurheimta fyrri uppsetningu | `-rollback` | `-rollback` |
| Fjarlægja allt (án afrita uppsetningarforritsins) | `-uninstall -purge` | `-uninstall -purge` |
| Öll hjálp | `-help` | `-help` |
| Velja Docker-gám | `--container=NAME` | — |
| Telja upp Docker-gáma | `--list-containers` | — |
| Mappa hýsils tengd sem Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Athugasemdir (smelltu til að opna)</b></summary>

- Ef umbeðin útgáfa er ekki til stöðvast uppsetningin og skiptir ekki sjálfkrafa yfir í latest eða dev.

Linux:

## Fjarlægja með einni skipun

<details>
<summary><b>Full fjarlæging fyrir Linux / NAS, Docker og Windows PowerShell</b></summary>

Ráðlagða aðferðin framkvæmir **fulla fjarlægingu án þess að geyma öryggisafrit uppsetningarforritsins**: hún fjarlægir WebUI, slekkur á viðeigandi Alternative WebUI-stillingu, eyðir afritum og afturköllunarstöðu þessa uppsetningarstaðar og fjarlægir að lokum niðurhalaða uppsetningarskriftu úr núverandi möppu.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Fyrir sérsniðna uppsetningarmöppu skaltu bæta við `-o /path/to/weig-qb-webui`.

### Docker

Einn gámur / sjálfvirk greining:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Margir gámar:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Með `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Fyrir sérsniðna möppu skaltu bæta við `-o D:\weig-qb-webui`.

`-purge` eyðir aðeins öryggisafritum núverandi uppsetningarstaðar og snertir ekki aðrar uppsetningar. Ef sameiginleg ástandsmappa tæmist er `~/.config/weig-qb-webui` einnig fjarlægð á Linux (fyrir root: `/root/.config/weig-qb-webui`), eða `%APPDATA%\weig-qb-webui` á Windows.

Til að halda öryggisafritum fyrir seinna `-rollback` skaltu einfaldlega sleppa `-purge`.

</details>
