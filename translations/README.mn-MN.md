## Олон инстанцийн хажуугийн самбар

qBittorrent-ийн хэд хэдэн бие даасан инстанц ижил бэлтгэсэн WeiG хавтсыг **зөвхөн унших** горимоор ашиглаж болно. Хостын хавтсыг Docker контейнер бүрт, жишээлбэл `/root/weig-qb-webui:/weig-qb-webui:ro` гэж холбож, дараа нь qBittorrent инстанц бүрийн Alternative WebUI үндсэн хавтсыг `/weig-qb-webui` гэж тохируулна. Инстанц бүр өөрийн torrent мэдээллийн сан, тохиргоо болон нэвтрэх эрхээ тусад нь хадгална.

Хажуугийн самбарын **Instances** хэсэгт инстанц бүртгэх, бүтэн хуудсаар шилжих, нэр өөрчлөх (баруун товшилт эсвэл мөрийн цэсээр) боломжтой. Одоогийн инстанцийг `524 (current)` гэж нэрлэж болно; одоогийн гэсэн тэмдэг нь хадгалсан нэрийн дагавар бус бодит URL-аас хамаарна. Автоматаар шалгах хугацааг **Settings → WeiG WebUI → Interface** дотроос тохируулна. Анхдагч утга нь `30 min`; унтраах эсвэл 5–1440 минутын аль нэгийг сонгож болно.

**Холболтын төлөвийн нотолгоог болгоомжтой тайлбарлана:** нэг гарал үүсэлтэй баталгаажсан WebAPI хариу нь qB онлайн байгааг харуулна; харин нэвтрэх мэдээлэлгүй өөр гарал үүсэл рүү илгээсэн `no-cors` хүсэлтийн хариу нь HTTP хаягт хүрч болохыг л харуулна, бүр 403/404 хариу ирсэн байж болно. Өөр гарал үүсэлтэй Cookie/SID унших, нууц үг эсвэл session шилжүүлэх, CORS тойрох, backend гарц ашиглахгүй. Өмнө нь qB-г баталгаажуулсны дараа хадгалсан цаг нь **түүхэн нотолгоо** болохоос одоо онлайн байгааг батлахгүй. Хөтчийн `127.0.0.1` нь алсын VPS биш, тухайн хөтчийг ажиллуулж буй төхөөрөмжийг заана.

## Шинэ хэрэглэгчид зориулсан суулгалт

<details>
<summary><b>Анх удаа суулгаж байна уу? Энэ нэг минутын зааврыг нээнэ үү</b></summary>

### 1. ZIP файлыг задлах

`weig-qb-webui.zip` файлыг татаж задлаарай. Архив өөрөө дараах стандарт хавтсыг үүсгэнэ:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Бүхэл **`weig-qb-webui` хавтас** нь WebUI-ийн үндсэн хавтас юм. Зөвхөн `public` эсвэл `private` хавтсыг хуулж болохгүй.

### 2. Байнгын байрлалд шилжүүлэх

Бүхэл `weig-qb-webui` хавтсыг дараа нь санамсаргүй устгахгүй байнгын байршилд тавина уу. Жишээлбэл:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

qBittorrent-д энэ хавтасны замыг оруулна.

### 3. qBittorrent-д идэвхжүүлэх

qBittorrent-ийг нээнэ үү:

**Tools → Options... → WebUI**

Эдгээр нь qBittorrent-ийн одоогийн англи интерфейсийн нэршлүүд юм. Дараа нь:

1. **Use alternative WebUI** сонголтыг идэвхжүүлнэ.
2. **Files location:** талбарыг олно.
3. `weig-qb-webui` хавтасны замыг оруулна.

Windows жишээ:

```text
D:\weig-qb-webui
```

Энгийн Linux жишээ:

```text
/opt/weig-qb-webui
```

4. Хадгалахын тулд **OK** дарна.
5. qBittorrent WebUI хуудсыг шинэчилнэ. Хөтөч хуучин хуудсыг кэшээс харуулсаар байвал `Ctrl + F5`-ийг нэг удаа дарж үзнэ үү.

> **Зам зөв эсэхийг яаж мэдэх вэ?** Заасан хавтас дотор шууд `public`, `private`, `VERSION` болон бусад WebUI файлууд байх ёстой. Эдгээрийг харахын тулд дахин `weig-qb-webui` хавтас руу орох шаардлагатай бол зам нэг түвшнээр зөрсөн байна.

> **Docker хэрэглэгчдэд:** qBittorrent контейнер дотор ажилладаг тул хостын замыг шууд ашиглах нь ихэвчлэн боломжгүй. Доорх **Docker** заавраас хост болон контейнерийн замын ялгааг харна уу.

</details>

## Нэг командаар суулгах

Linux/NAS-д зориулсан нэг командын суулгагчийг доорх тогтмол Dev Pages URL-аас үргэлж татаж авна. **Скриптийн URL суулгах сувгийг сонгодоггүй:** `-dev`-гүй бол хамгийн сүүлд баталгаажсан тогтвортой GitHub Release суулгана. Яг Git SHA-аар тодорхойлогдох хөгжүүлэлтийн одоогийн хувилбарыг зориуд суулгах үед л `-dev` нэмнэ. Татсан скрипт нь дараа шинэчлэх буюу буцаахад хэрэглэхээр одоогийн хавтсанд үлдэнэ.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```


Анхдагчаар WebUI дараах хавтсанд сууна:

```text
~/.local/share/weig-qb-webui
```

Жишээ нь `root` хэрэглэгчээр ажиллуулахад ихэвчлэн:

```text
/root/.local/share/weig-qb-webui
```

### Docker

<details>
<summary><b>Docker-ийг нэг командаар суулгах / олон контейнер / замын заавар (анхлан хэрэглэгчдэд санал болгоно)</b></summary>

#### Эхлээд «хост» ба «контейнер» гэдгийг ойлгох

Хэрэв qBittorrent нь VPS, Linux сервер, Synology, QNAP эсвэл өөр NAS дээр Docker-т ажиллаж байгаа бол:

- **Хост**: Docker ажиллаж буй бодит Linux/NAS машин, өөрөөр хэлбэл SSH-ээр нэвтрэхэд харагддаг систем.
- **Контейнер**: Docker-оос qBittorrent-д зориулан үүсгэдэг тусгаарлагдсан орчин. qBittorrent нь контейнер доторх замыг шууд харна, харин хостын ямар ч замыг автоматаар харахгүй.

Жишээ нь qBittorrent контейнерт дараах замын холболт байж болно:

```text
Host:      /root/qbittorrent/config
   ↓ mapped to
Container: /config
```

Docker Compose-ийн ердийн бичлэг:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Хоёр цэгийн зүүн талын `/root/qbittorrent/config` нь **хостын зам**, баруун талын `/config` нь **контейнерийн зам** юм.

Хэрэв WeiG qB WebUI нь хост дээр бодитоор энд суусан бол:

```text
Host: /root/qbittorrent/config/weig-qb-webui
```

qBittorrent-ийн **Files location:** талбарт дараахыг бичнэ:

```text
/config/weig-qb-webui
```

**qBittorrent-д `/root/qbittorrent/config/weig-qb-webui` замыг бүү оруул**, учир нь контейнер энэ хостын замыг ихэвчлэн шууд харахгүй.

#### Тохиолдол 1: зөвхөн нэг qBittorrent контейнер ажиллаж байна

Энгийн нэг командын суулгалтыг ашиглана:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Суулгагч ажиллаж буй qBittorrent контейнер, түүний `/config` холболтыг олох, WebUI-ийг хостын тохирох байршилд суулгах, qBittorrent-ийг автоматаар тохируулахыг оролдоно.

#### Тохиолдол 2: эхлээд qBittorrent контейнерийн нэрийг олох

Контейнерийн нэрийг мэдэхгүй бол:

```sh
sh install.sh --list-containers
```

Docker-ийг шууд ашиглаж ч болно:

```sh
docker ps
```

Хэрэв qBittorrent контейнерийн нэр:

```text
qbittorrent
```

түүнийг тодорхой сонгоно:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Тохиолдол 3: олон qBittorrent контейнер

Жишээ нь:

```text
qbittorrent
qbittorrent-test
```

Эхлээд тэдгээрийн жагсаалтыг харна:

```sh
sh install.sh --list-containers
```

Үндсэн `qbittorrent` контейнерт суулгах:

```sh
sh install.sh --container=qbittorrent -configure
```

Туршилтын контейнерт суулгах:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Олон qBittorrent контейнер байвал суулгагч өөрөө санамсаргүйгээр аль нэгийг сонгохгүй.

#### Тохиолдол 4: `/config` гэж холбогдсон хостын хавтсыг мэдэж байгаа

Жишээ нь:

```text
/root/qbittorrent/config
```

Шууд зааж өгнө:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology замын жишээ:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Өөр NAS-ийн замын жишээ:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Эдгээр нь зөвхөн жишээ. **qBittorrent-ийн `/config` гэж холбогдсон хостын бодит замаар солино уу.**

#### Тохиолдол 5: WebUI суулгах замыг сонгох

Контейнер сонгосны дараа түүн дотроос харагдах WebUI байрлалыг мөн сонгож болно:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Суулгагч контейнерийн `/config/...` замыг хост дахь тохирох суулгах зам руу хөрвүүлнэ.

#### Тохиолдол 6: нэг таталтаар олон WebUI хавтсыг шинэчлэх

Олон qBittorrent инстанцийн хувьд `-o` сонголтыг давтана. Багцыг зөвхөн нэг удаа татаж баталгаажуулна, бүх байршлыг солихоос өмнө бэлтгэнэ, байршил тус бүр өөрийн сүүлийн гурван нөөц хуулбарыг `~/.config/weig-qb-webui/backups/` дотор хадгална.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Олон зорилтот горимд `-configure` нэмэхгүй; qBittorrent инстанц бүр өмнөх Alternative WebUI үндсэн хавтсаа хэвээр хадгална. Одоогийн командын синтаксыг харахын тулд `sh install.sh -help` ажиллуулна.

#### Суулгасны дараа юу харагдах вэ?

Амжилттай суулгасан үед ойролцоогоор дараах мэдээллийг харуулна:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Утга нь:

- `Host install path`: хост дээр файл бодитоор хадгалагдах байршил;
- `qBittorrent Root Folder`: **qBittorrent-ийн Files location талбарт ашиглах ёстой контейнерийн зам**.

Хэрэв `-configure` qBittorrent-ийн тохиргоог амжилттай олбол суулгагч **Use alternative WebUI**-ийг идэвхжүүлж замыг автоматаар тохируулна. Үгүй бол дээрх **Шинэ хэрэглэгчид зориулсан суулгалт → qBittorrent-д идэвхжүүлэх** хэсгийн гарын авлагын алхмуудыг дагана уу.

</details>

Linux болон Windows боломжтой үед ижил нийтлэг сонголтын нэр ашигладаг. Баримт бичигт жижиг үсгээр бичсэн; PowerShell параметрийн нэр том, жижиг үсгийг ялгахгүй.

| Зорилго | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Тогтвортой main | Анхдагч, сонголтгүй | Анхдагч, сонголтгүй |
| Тодорхой хувилбар | `-version 1.2.0` | `-version 1.2.0` |
| Хөгжүүлэлтийн хувилбар | `-dev` | `-dev` |
| Өөрийн суулгах хавтас | `-o /path` (Linux дээр давтаж болно) | `-o D:\path` эсвэл `-output D:\path` |
| qBittorrent-ийн өөрийн тохиргооны файл | — | `-qbconfig D:\path\qBittorrent.ini` |
| qBittorrent-ийг автоматаар тохируулах | `-configure` | `-configure` |
| Өмнөх суулгалт руу буцах | `-rollback` | `-rollback` |
| Бүрэн устгах (нөөц хуулбар үлдээхгүй) | `-uninstall -purge` | `-uninstall -purge` |
| Бүрэн тусламж | `-help` | `-help` |
| Docker контейнер сонгох | `--container=NAME` | — |
| Docker контейнерүүдийг жагсаах | `--list-containers` | — |
| Docker-ийн `/config` гэж холбогдсон хостын хавтсыг заах | `--config-root=/path` | — |

<details>
<summary><b>Тэмдэглэл (дарж дэлгэнэ үү)</b></summary>

Тэмдэглэл:

- `-dev` байхгүй бол тогтвортой `main`-ийг ашиглана; `-dev` одоогийн хөгжүүлэлтийн яг таг Git SHA хувилбарыг сонгоно.
- `-o` нь **output** гэсэн утгатай бөгөөд WeiG qB WebUI суулгах хавтсыг заана. Linux дээр нэг баталгаажсан таталтаар олон байршлыг шинэчлэхийн тулд давтаж болно.
- Суулгагчийн нөөц хуулбарууд `~/.config/weig-qb-webui/backups/` дотор байна; байршил тус бүрт **сүүлийн 3 нөөц хуулбар тусад нь хадгалагдана**.
- `-configure` нь qBittorrent-ийн **Use alternative WebUI**-ийг идэвхжүүлж суулгасны дараа **Files location**-ийг тохируулна. Энэ нь зөвхөн нэг байршилд зориулагдсан.
- `-rollback` нь сонгосон байршлын суулгагчийн сүүлийн нөөц хуулбарыг сэргээнэ; олон тодорхой байршлыг сэргээхдээ `-o`-г давтана.
- `-version` нь `1.2.0` зэрэг тодорхой GitHub Release хувилбарыг суулгана. Хүссэн хувилбар байхгүй бол суулгалт амжилтгүй болж, **latest эсвэл dev рүү хэзээ ч автоматаар шилжихгүй**.
- `-help` нь одоогийн Linux командын дэмжигдэх синтаксыг харуулна.
- Хэд хэдэн qBittorrent Docker контейнертэй бол `--list-containers` ашиглаад `--container=NAME`-ээр нэгийг нь сонгоно. Хостын тохиргооны хавтсыг мэдэж байвал `--config-root=/path` ашиглаж болно.

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```


Windows:


## Нэг командаар устгах

<details>
<summary><b>Linux / NAS, Docker, Windows PowerShell дээр бүрэн устгах</b></summary>

Доорх санал болгосон команд нь суулгагчийн нөөц хуулбарыг **үлдээлгүйгээр бүрэн устгана**: WebUI-ийг арилгаж, тохирох Alternative WebUI тохиргоог идэвхгүй болгож, тухайн байршлын нөөц хуулбар болон буцаах төлөвийг цэвэрлээд, одоогийн хавтсанд татсан суулгах скриптийг устгана.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Өөрийн суулгах хавтастай бол `-o /path/to/weig-qb-webui` нэмнэ.

### Docker

Нэг контейнер / автоматаар илрүүлэх:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Олон контейнер:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` ашиглах үед:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Өөрийн суулгах хавтастай бол `-o D:\weig-qb-webui` нэмнэ.

`-purge` нь зөвхөн одоогийн устгаж буй байршлын нөөц хуулбарыг арилгах бөгөөд бусад суулгалтын нөөцөд хүрэхгүй. Хамтын төлөвийн хавтас хоосорвол Linux-ийн `~/.config/weig-qb-webui` (root хэрэглэгчид `/root/.config/weig-qb-webui`) эсвэл Windows-ийн `%APPDATA%\weig-qb-webui` хавтас мөн устна.

Хожим `-rollback` хийхээр нөөц хуулбарыг хадгалахыг хүсвэл `-purge`-г зүгээр л орхино уу.

</details>
