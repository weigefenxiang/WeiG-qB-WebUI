## Ručna instalacija za početnike

<details>
<summary><b>Instalirate prvi put? Otvorite kratke upute</b></summary>

### 1. Raspakirajte ZIP arhivu

Preuzmite `weig-qb-webui.zip` i raspakirajte ga. Arhiva već sadrži sljedeću strukturu mapa:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

**Cijela mapa `weig-qb-webui`** korijenska je mapa web-sučelja. Nemojte kopirati samo `public` ili `private`.

### 2. Odaberite trajnu lokaciju

Premjestite cijelu mapu na mjesto gdje je nećete slučajno izbrisati, primjerice:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Put do te mape zatim unesite u postavke qBittorrenta.

### 3. Uključite alternativno WebUI sučelje u qBittorrentu

Otvorite **Alati → Mogućnosti → Web-sučelje**. Nazivi stavki mogu se razlikovati ovisno o jeziku odabranom u qBittorrentu.

1. Označite **Koristi alternativno web-sučelje** (*Use alternative WebUI*).
2. Pronađite polje **Lokacija datoteka** (*Files location*).
3. Unesite put do mape `weig-qb-webui`.

Primjer za Windows:

```text
D:\weig-qb-webui
```

Primjer za Linux:

```text
/opt/weig-qb-webui
```

4. Kliknite **OK** kako biste spremili promjene.
5. Ponovno učitajte stranicu qBittorrenta. Ako se i dalje prikazuje staro sučelje, pritisnite `Ctrl + F5` za prisilno osvježavanje.

> **Kako provjeriti put?** U odabranoj mapi moraju se izravno nalaziti `public`, `private` i `VERSION`. Ako prvo morate otvoriti još jednu mapu `weig-qb-webui`, odabrali ste pogrešnu razinu.

> **Koristite Docker?** qBittorrent se pokreće **unutar spremnika**. Zato u njegove postavke morate unijeti put koji je dostupan unutar spremnika, a ne put koji postoji samo na računalu domaćinu. Objašnjenje slijedi u nastavku.

</details>

## Instalacija jednom naredbom

Instalacijska skripta za Linux i NAS uvijek se preuzima s niže navedene stalne adrese Dev Pages. **Adresa skripte ne određuje instalacijski kanal:** bez `-dev` instalira se posljednje provjereno stabilno izdanje s GitHub Releases; uz `-dev` instalira se razvojna verzija određena točnim Git SHA identifikatorom. Skripta ostaje u trenutačnoj mapi radi kasnijeg ažuriranja ili vraćanja prethodne instalacije.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Prikaži lokaciju skripte i zadanu instalacijsku mapu</b></summary>

Preuzeta skripta sprema se ovdje:

```text
./install.sh
```

Zadana instalacijska mapa za WebUI:

```text
~/.local/share/weig-qb-webui
```

Kada se pokreće kao korisnik `root`, to je obično:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Instalacija u Dockeru, više spremnika i ispravni putovi</b></summary>

#### Domaćin i spremnik

Ako koristite Docker na VPS-u, Linux poslužitelju, Synologyju, QNAP-u ili drugom NAS uređaju:

- **Domaćin (host)** je Linux ili NAS sustav na kojem je pokrenut Docker. Obično mu pristupate putem SSH-a.
- **Spremnik (container)** odvojeno je okruženje u kojem radi qBittorrent. Vidi samo mape koje su u njega povezane.

Pretpostavimo da je konfiguracijska mapa povezana ovako:

```text
Domaćin: /root/qbittorrent/config
   ↓ povezano kao
Unutar spremnika: /config
```

U Docker Compose konfiguraciji to može izgledati ovako:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Put **lijevo od dvotočke** pripada **domaćinu**, a put **desno** označava lokaciju **unutar spremnika**.

Ako je WeiG instaliran na domaćinu ovdje:

```text
Domaćin: /root/qbittorrent/config/weig-qb-webui
```

u polje **Files location** u qBittorrentu unesite:

```text
/config/weig-qb-webui
```

**Nemojte unositi `/root/qbittorrent/config/weig-qb-webui`**. To je put na domaćinu koji spremnik uglavnom ne može izravno vidjeti.

#### Slučaj 1: Imate samo jedan qBittorrent spremnik

Pokrenite:

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Instalacijska skripta pokušat će pronaći pokrenuti qBittorrent spremnik, povezani `/config` i odgovarajuću mapu na domaćinu. Ako može sigurno prepoznati konfiguraciju, automatski će postaviti qBittorrent.

#### Slučaj 2: Ne znate naziv spremnika

Prikažite dostupne spremnike:

```sh
sh install.sh --list-containers
```

Ili ih provjerite izravno u Dockeru:

```sh
docker ps
```

Ako se spremnik, primjerice, zove:

```text
qbittorrent
```

izričito ga odaberite:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Slučaj 3: Koristite više qBittorrent spremnika

Primjerice, jedan glavni i jedan testni:

```text
qbittorrent
qbittorrent-test
```

Najprije prikažite popis:

```sh
sh install.sh --list-containers
```

Instalacija u glavni spremnik:

```sh
sh install.sh --container=qbittorrent -configure
```

Instalacija u testni spremnik:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Ako instalacijska skripta pronađe više spremnika, **neće nasumično odabrati nijedan**.

#### Slučaj 4: Znate lokaciju mape `/config` na domaćinu

Primjerice:

```text
/root/qbittorrent/config
```

Možete je izravno navesti:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Na Synologyju put može izgledati ovako:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Na drugom NAS uređaju, primjerice:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Ovo su samo primjeri. Koristite stvarni put do konfiguracije qBittorrenta na svojem domaćinu.

#### Slučaj 5: Odaberite instalacijsku mapu za WebUI

Ako ste već odabrali spremnik, možete zadati i lokaciju WebUI-ja unutar njega:

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

Instalacijska skripta prema Docker povezivanju `/config` pronalazi odgovarajući put na domaćinu.

#### Slučaj 6: Ažurirajte više instalacija odjednom

Ako upravljate s više instanci qBittorrenta, možete ponoviti parametar `-o`. Paket se preuzima i provjerava samo jednom; nijedna se odredišna instalacija ne zamjenjuje dok sve nisu pripremljene. Za svako se odredište zasebno čuvaju **tri najnovije sigurnosne kopije** u `~/.config/weig-qb-webui/backups/`.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

Za više odredišta nemojte koristiti `-configure`. Svaka instanca treba zadržati prethodno postavljen put do svojeg alternativnog WebUI-ja. Sve mogućnosti prikazuju se naredbom `sh install.sh -help`.

#### Provjera putova nakon instalacije

Nakon uspješne instalacije može se prikazati nešto poput ovoga:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

- `Host install path`: stvarna lokacija datoteka na domaćinu.
- `qBittorrent Root Folder`: put **unutar spremnika** koji unosite u polje *Files location* u qBittorrentu.

Ako skriptu pokrenete uz `-configure`, ona uključuje alternativni WebUI i postavlja put ako može sigurno otkriti konfiguraciju qBittorrenta. U protivnom slijedite gornje upute za ručnu instalaciju.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

## Uobičajeni parametri

Osnovni parametri jednako se zovu na Linuxu i Windowsima; PowerShell pri njihovu navođenju ne razlikuje velika i mala slova.

| Namjena | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Instaliraj najnovije stabilno izdanje (`main`) | Zadano, bez parametara | Zadano, bez parametara |
| Instaliraj određeno stabilno izdanje | `-version 1.2.0` | `-version 1.2.0` |
| Instaliraj razvojnu verziju | `-dev` | `-dev` |
| Odaberi instalacijsku mapu | `-o /path` (na Linuxu se može ponoviti) | `-o D:\path` ili `-output D:\path` |
| Navedi konfiguracijsku datoteku qBittorrenta | — | `-qbconfig D:\path\qBittorrent.ini` |
| Automatski postavi qBittorrent | `-configure` | `-configure` |
| Vrati prethodnu instalaciju | `-rollback` | `-rollback` |
| Deinstaliraj i ukloni sigurnosne kopije | `-uninstall -purge` | `-uninstall -purge` |
| Prikaži potpunu pomoć | `-help` | `-help` |
| Odaberi Docker spremnik | `--container=NAME` | — |
| Prikaži popis spremnika | `--list-containers` | — |
| Mapa `/config` na domaćinu | `--config-root=/path` | — |

<details>
<summary><b>Objašnjenje parametara (proširi)</b></summary>

- Bez `-dev` koristi se stabilni kanal `main`; s `-dev` razvojna verzija određena točnim Git SHA identifikatorom.
- Slovo `o` u `-o` znači **output**. Na Linuxu se parametar može ponavljati kako biste jednim preuzimanjem ažurirali više postojećih instalacija.
- Sigurnosne kopije kojima upravlja instalacijska skripta nalaze se u `~/.config/weig-qb-webui/backups/`; za svako se odredište čuvaju **najviše tri najnovije sigurnosne kopije**.
- `-configure` uključuje *Use alternative WebUI* i postavlja *Files location*, ali samo za jedno odredište.
- `-rollback` vraća posljednju sigurnosnu kopiju koju je za odabrano odredište napravila instalacijska skripta. Ponavljanjem `-o` možete vratiti više izričito navedenih odredišta.
- `-uninstall -purge` uklanja sigurnosne kopije i stanje za povratak **samo trenutačne instalacije**; ostale instalacije ostaju netaknute.
- Ako želite sačuvati kopije za kasniji `-rollback`, izostavite `-purge`.
- Parametrom `-version` instalirate određeno izdanje s GitHub Releases, primjerice `1.2.0`. Ako ne postoji, instalacija završava pogreškom i **ne prelazi automatski** na latest ili dev.
- Za više spremnika pokrenite `--list-containers` i odaberite `--container=NAME`; alternativno navedite mapu domaćina za `/config` preko `--config-root=/path`.

### Odabir verzije i instalacijske mape

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Povratak na prethodnu instalaciju

Linux:

```sh
sh install.sh -rollback
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Deinstalacija jednom naredbom

<details>
<summary><b>Potpuna deinstalacija na Linuxu / NAS-u, u Dockeru i Windows PowerShellu</b></summary>

Preporučujemo **ukloniti WebUI bez zadržavanja sigurnosnih kopija instalacijske skripte**. Naredbe u nastavku uklanjaju sučelje, isključuju alternativni WebUI odabranog odredišta, brišu sigurnosne kopije i stanje potrebno za povratak te na kraju uklanjaju preuzetu instalacijsku skriptu iz trenutačne mape.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Ako koristite prilagođenu mapu, dodajte `-o /put/do/weig-qb-webui`.

### Docker

Jedan spremnik s automatskim otkrivanjem:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Više spremnika:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Kada koristite `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Za prilagođenu mapu dodajte `-o D:\weig-qb-webui`.

Parametar `-purge` uklanja samo sigurnosne kopije instalacije koju upravo deinstalirate. Ostale instance ostaju netaknute. Ako zajednička mapa sa stanjem postane potpuno prazna, uklanja se i `~/.config/weig-qb-webui` na Linuxu (za `root`: `/root/.config/weig-qb-webui`) ili `%APPDATA%\weig-qb-webui` na Windowsima.

Ako želite zadržati sigurnosne kopije za kasniji `-rollback`, deinstalirajte bez `-purge`.

</details>
