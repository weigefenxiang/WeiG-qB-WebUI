## कई इंस्टेंस की साइडबार

कई स्वतंत्र qBittorrent इंस्टेंस एक ही तैयार WeiG फ़ोल्डर को **केवल-पढ़ने योग्य** रूप में साझा कर सकते हैं। होस्ट के फ़ोल्डर को हर Docker कंटेनर में अलग-अलग माउंट करें, जैसे `/root/weig-qb-webui:/weig-qb-webui:ro`, और प्रत्येक qBittorrent इंस्टेंस में `/weig-qb-webui` को Alternative WebUI का रूट बताएँ। हर इंस्टेंस के टोरेंट, सेटिंग और लॉगिन अलग रहते हैं।

साइडबार के **Instances** अनुभाग में इंस्टेंस जोड़ सकते हैं, अलग पृष्ठ खोलकर उनके बीच स्विच कर सकते हैं और नाम बदल सकते हैं (राइट-क्लिक या पंक्ति के मेनू से)। वर्तमान इंस्टेंस की पहचान वास्तविक URL से होती है, सहेजे हुए नाम के प्रत्यय से नहीं। स्वचालित जाँच का अंतराल **Settings → WeiG WebUI → Interface** में मिलता है; डिफ़ॉल्ट `30 min` है और इसे बंद कर सकते हैं या 5 से 1440 मिनट तक चुन सकते हैं।

**कनेक्शन स्थिति के प्रमाणों को सावधानी से समझें:** उसी ओरिजिन से प्रमाणित WebAPI उत्तर से पता चलता है कि qB ऑनलाइन है। किसी दूसरे ओरिजिन से बिना क्रेडेंशियल के आया `no-cors` उत्तर केवल HTTP पते तक पहुँच की पुष्टि करता है, भले ही उत्तर 403/404 हो। दूसरे ओरिजिन की Cookie/SID नहीं पढ़ी जाती, पासवर्ड या सेशन साझा नहीं होते, CORS को बायपास नहीं किया जाता और कोई सर्वर प्रॉक्सी इस्तेमाल नहीं होता। पिछली सफल जाँच का सहेजा समय **ऐतिहासिक प्रमाण** है, वर्तमान ऑनलाइन स्थिति की पुष्टि नहीं। ब्राउज़र में `127.0.0.1` का अर्थ वह उपकरण है जिस पर ब्राउज़र चल रहा है, कोई दूरस्थ VPS नहीं।

## नए उपयोगकर्ताओं के लिए इंस्टॉलेशन

<details>
<summary><b>पहली बार इंस्टॉल कर रहे हैं? यह संक्षिप्त मार्गदर्शिका खोलें</b></summary>

### 1. ZIP फ़ाइल निकालें

`weig-qb-webui.zip` डाउनलोड करके अनज़िप करें। संग्रह में मानक फ़ोल्डर पहले से मौजूद है:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

पूरा **`weig-qb-webui`** फ़ोल्डर WebUI का रूट है। केवल `public` या `private` फ़ोल्डर कॉपी न करें।

### 2. इसे स्थायी स्थान पर रखें

उदाहरण के लिए:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

यही पथ आपको बाद में qBittorrent में दर्ज करना होगा।

### 3. qBittorrent में इसे सक्षम करें

qBittorrent खोलें:

**Tools → Options... → WebUI**

ये वर्तमान अंग्रेज़ी qBittorrent इंटरफ़ेस में मेनू के सटीक नाम हैं। इसके बाद:

1. **Use alternative WebUI** सक्षम करें।
2. **Files location:** फ़ील्ड ढूँढें।
3. `weig-qb-webui` फ़ोल्डर का पथ दर्ज करें।

Windows का उदाहरण:

```text
D:\weig-qb-webui
```

Linux का उदाहरण:

```text
/opt/weig-qb-webui
```

4. सहेजने के लिए **OK** क्लिक करें।
5. qBittorrent WebUI पृष्ठ दोबारा लोड करें। यदि कैश से पुराना पृष्ठ दिखता रहे, तो एक बार `Ctrl + F5` दबाएँ।

> **सही पथ की जाँच:** दर्ज किए गए फ़ोल्डर में सीधे `public`, `private`, `VERSION` और अन्य WebUI फ़ाइलें मौजूद होनी चाहिए।

> **Docker उपयोगकर्ताओं के लिए:** qBittorrent कंटेनर के भीतर चलता है, इसलिए आम तौर पर होस्ट का पथ नहीं बल्कि कंटेनर में दिखाई देने वाला पथ दर्ज करना होता है।

</details>

## एक कमांड से इंस्टॉल करें

Linux/NAS इंस्टॉलर स्क्रिप्ट हमेशा नीचे दिए गए निश्चित Dev Pages URL से डाउनलोड की जाती है। **स्क्रिप्ट का URL इंस्टॉलेशन चैनल नहीं चुनता:** `-dev` के बिना नवीनतम सत्यापित स्थिर GitHub Release इंस्टॉल होता है; `-dev` सटीक Git SHA के अनुसार वर्तमान विकास संस्करण चुनता है। डाउनलोड की गई स्क्रिप्ट बाद में अपडेट या रोलबैक के लिए मौजूदा फ़ोल्डर में रहती है।

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>स्क्रिप्ट का URL और डिफ़ॉल्ट इंस्टॉलेशन फ़ोल्डर दिखाएँ</b></summary>

```text
./install.sh
```

डिफ़ॉल्ट रूप से WebUI यहाँ इंस्टॉल होता है:

```text
~/.local/share/weig-qb-webui
```

`root` के रूप में चलाने पर आम तौर पर यहाँ:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, अनेक कंटेनर और पथों की व्याख्या</b></summary>

#### होस्ट और कंटेनर

- **होस्ट:** वह Linux/NAS मशीन जिस पर Docker चलता है।
- **कंटेनर:** वह अलग-थलग वातावरण जिसमें qBittorrent चलता है।

उदाहरण के लिए:

```text
Хост:       /root/qbittorrent/config
   ↓ इस रूप में माउंट
कंटेनर:  /config
```

Docker Compose का उदाहरण:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

यदि होस्ट पर WebUI यहाँ मौजूद है:

```text
/root/qbittorrent/config/weig-qb-webui
```

तो qBittorrent के **Files location:** फ़ील्ड में यह दर्ज करें:

```text
/config/weig-qb-webui
```

#### एक qBittorrent कंटेनर

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

इंस्टॉलर कंटेनर और उसके `/config` माउंट का पता अपने आप लगाने का प्रयास करेगा।

#### कंटेनर ढूँढें

सबसे पहले पता लगाए गए qBittorrent कंटेनरों की सूची देखें:

```sh
sh install.sh --list-containers
```

या सीधे Docker का उपयोग करें:

```sh
docker ps
```

उदाहरण के लिए, कंटेनर का नाम हो सकता है:

```text
qbittorrent
```

फिर उसे स्पष्ट रूप से चुनें:

```sh
sh install.sh --container=qbittorrent -configure
```

#### यदि कई qBittorrent कंटेनर चल रहे हों

जैसे एक मुख्य और एक परीक्षण इंस्टेंस:

```text
qbittorrent
qbittorrent-test
```

पहले उनकी सूची निकालें:

```sh
sh install.sh --list-containers
```

मुख्य इंस्टेंस के लिए:

```sh
sh install.sh --container=qbittorrent -configure
```

परीक्षण इंस्टेंस के लिए:

```sh
sh install.sh --container=qbittorrent-test -configure
```

कई कंटेनर होने पर इंस्टॉलर किसी एक को मनमाने ढंग से नहीं चुनेगा।

#### होस्ट का वह फ़ोल्डर बताना जो `/config` पर माउंट है

यदि qBittorrent का कॉन्फ़िगरेशन फ़ोल्डर होस्ट पर यहाँ है:

```text
/root/qbittorrent/config
```

तो उसे सीधे बता सकते हैं:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Synology का उदाहरण:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

किसी दूसरे NAS का उदाहरण:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

उदाहरण पथों को होस्ट के वास्तविक पथ से बदलें, जिसे qBittorrent में `/config` के रूप में माउंट किया गया है।

#### WebUI इंस्टॉलेशन फ़ोल्डर चुनें

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### एक डाउनलोड से कई WebUI इंस्टॉलेशन अपडेट करें

Linux/NAS पर `-o` विकल्प दोहराकर एक ही डाउनलोड से कई मौजूदा इंस्टॉलेशन अपडेट किए जा सकते हैं। इस मोड में `-configure`, `--container` और `--config-root` को साथ उपयोग न करें।

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### इंस्टॉलेशन के बाद पथ जाँचें

इंस्टॉलर होस्ट का पथ और qBittorrent को दिखाई देने वाला पथ दिखाता है:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

qBittorrent की **Files location** सेटिंग में दूसरा, यानी कंटेनर के अंदर वाला पथ इस्तेमाल करें। `-configure` सफल होने पर इंस्टॉलर इसे अपने आप सेट कर देता है।

</details>

## सामान्य विकल्प
PowerShell में पैरामीटर के नाम बड़े या छोटे अक्षर होने से नहीं बदलते।

| उद्देश्य | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| नवीनतम स्थिर रिलीज़ | डिफ़ॉल्ट | डिफ़ॉल्ट |
| विशेष Release संस्करण | `-version 1.2.0` | `-version 1.2.0` |
| विकास संस्करण | `-dev` | `-dev` |
| इंस्टॉलेशन फ़ोल्डर | `-o /path` (दोहराया जा सकता है) | `-o D:\path` या `-output D:\path` |

## एक कमांड से अनइंस्टॉल करें

<details>
<summary><b>Linux / NAS, Docker और Windows PowerShell पर पूरा अनइंस्टॉल</b></summary>

अनुशंसित कमांड **इंस्टॉलर के बैकअप रखे बिना पूरी तरह अनइंस्टॉल** करती है: यह WebUI हटाती है, संबंधित वैकल्पिक WebUI सेटिंग बंद करती है, इस इंस्टॉलेशन के बैकअप और रोलबैक स्थिति मिटाती है, और अंत में मौजूदा फ़ोल्डर से डाउनलोड की गई इंस्टॉलर स्क्रिप्ट भी हटा देती है।

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

अपने चुने हुए इंस्टॉलेशन फ़ोल्डर के लिए `-o /path/to/weig-qb-webui` जोड़ें।

### Docker

एक कंटेनर / स्वतः पहचान:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

कई कंटेनर:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

`--config-root` के साथ:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

अपना फ़ोल्डर चुनने के लिए `-o D:\weig-qb-webui` जोड़ें।

`-purge` सिर्फ़ मौजूदा लक्ष्य के बैकअप हटाता है; दूसरे इंस्टॉलेशन प्रभावित नहीं होते। साझा स्थिति फ़ोल्डर खाली हो जाने पर Linux का `~/.config/weig-qb-webui` (root के लिए: `/root/.config/weig-qb-webui`) या Windows का `%APPDATA%\weig-qb-webui` भी हटा दिया जाता है।

बाद में `-rollback` के लिए बैकअप रखने हों, तो `-purge` का उपयोग न करें।

</details>
