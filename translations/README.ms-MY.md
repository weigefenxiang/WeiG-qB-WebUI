## Bar sisi berbilang contoh

Beberapa contoh qBittorrent yang berasingan boleh menggunakan folder WeiG yang sama dan telah disediakan dalam mod **baca sahaja**. Pasangkan folder hos ke dalam setiap bekas Docker, contohnya `/root/weig-qb-webui:/weig-qb-webui:ro`, kemudian tetapkan `/weig-qb-webui` sebagai folder akar Alternative WebUI untuk setiap qBittorrent. Pangkalan data torrent, tetapan dan log masuk setiap contoh kekal berasingan.

Bahagian **Instances** pada bar sisi membolehkan anda mendaftarkan contoh, bertukar melalui navigasi halaman penuh dan menamakannya semula (klik kanan atau gunakan menu baris). Penanda contoh semasa mengikuti URL sebenar, bukannya akhiran nama yang disimpan. Selang semakan automatik terletak di **Settings → WeiG WebUI → Interface** dengan nilai lalai `30 min`; ia boleh dimatikan atau ditetapkan antara 5 hingga 1440 minit.

**Bukti status sengaja ditafsir secara berhati-hati:** WebAPI asal yang sama dan telah disahkan bermakna qB berada dalam talian. Respons rentas asal `no-cors` tanpa kelayakan hanya membuktikan alamat HTTP dapat dicapai, walaupun mungkin memulangkan 403/404. Tiada pembacaan Cookie/SID rentas asal, pemindahan kata laluan atau sesi, pintasan CORS ataupun gerbang pelayan. Masa yang direkod selepas semakan terdahulu ialah **bukti sejarah**, bukan bukti keadaan dalam talian sekarang. Alamat `127.0.0.1` dalam pelayar merujuk peranti yang menjalankan pelayar tersebut, bukannya VPS jauh.

## Pemasangan untuk pengguna baharu

<details>
<summary><b>Baru pertama kali memasang? Buka panduan ringkas ini</b></summary>

### 1. Ekstrak fail ZIP

Muat turun `weig-qb-webui.zip` dan ekstraknya. Arkib tersebut sudah mengandungi folder standard:

```text
weig-qb-webui/
├── public/
├── private/
├── VERSION
└── GIT_SHA
```

Keseluruhan folder **`weig-qb-webui`** merupakan folder akar WebUI. Jangan salin `public` atau `private` sahaja.

### 2. Pindahkan ke lokasi tetap

Contohnya:

```text
Windows: D:\weig-qb-webui
Linux:   /opt/weig-qb-webui
```

Inilah laluan yang perlu anda masukkan dalam qBittorrent kemudian.

### 3. Dayakan dalam qBittorrent

Buka qBittorrent:

**Tools → Options... → WebUI**

Ini ialah nama menu sebenar dalam antara muka qBittorrent bahasa Inggeris semasa. Kemudian:

1. Dayakan **Use alternative WebUI**.
2. Cari medan **Files location:**.
3. Masukkan laluan ke folder `weig-qb-webui`.

Contoh untuk Windows:

```text
D:\weig-qb-webui
```

Contoh untuk Linux:

```text
/opt/weig-qb-webui
```

4. Klik **OK** untuk menyimpan.
5. Muat semula halaman qBittorrent WebUI. Jika halaman lama masih disimpan dalam cache, cuba `Ctrl + F5` sekali.

> **Semak laluan:** direktori yang anda masukkan perlu terus mengandungi `public`, `private`, `VERSION` dan fail WebUI yang lain.

> **Pengguna Docker:** qBittorrent berjalan di dalam bekas, jadi anda biasanya mesti menggunakan laluan yang boleh dilihat dari dalam bekas, bukannya laluan pada hos.

</details>

## Pemasangan satu arahan

Pemasang Linux/NAS sentiasa dimuat turun melalui URL Dev Pages tetap di bawah. **URL skrip tidak menentukan saluran pemasangan:** tanpa `-dev`, keluaran stabil GitHub Release terkini yang telah disahkan akan dipasang; `-dev` hanya digunakan apabila anda sengaja memilih binaan pembangunan semasa dengan Git SHA tepatnya. Skrip yang dimuat turun kekal dalam direktori semasa untuk kemas kini atau pengembalian versi pada masa hadapan.

### Linux / NAS

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

<details>
<summary><b>Paparkan URL skrip dan direktori pemasangan lalai</b></summary>

```text
./install.sh
```

Secara lalai, WebUI dipasang di:

```text
~/.local/share/weig-qb-webui
```

Apabila dijalankan sebagai `root`, biasanya di:

```text
/root/.local/share/weig-qb-webui
```

</details>

### Docker

<details>
<summary><b>Docker, berbilang bekas dan penerangan laluan</b></summary>

#### Hos dan bekas

- **Hos:** mesin Linux/NAS sebenar yang menjalankan Docker.
- **Bekas:** persekitaran terasing yang menjalankan qBittorrent.

Contohnya:

```text
Хост:       /root/qbittorrent/config
   ↓ dipasang sebagai
Bekas:  /config
```

Contoh Docker Compose:

```yaml
volumes:
  - /root/qbittorrent/config:/config
```

Jika WebUI terletak pada hos di:

```text
/root/qbittorrent/config/weig-qb-webui
```

maka dalam medan qBittorrent **Files location:**, masukkan:

```text
/config/weig-qb-webui
```

#### Satu bekas qBittorrent

```sh
curl -fsSL https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.sh -o install.sh && sh install.sh -configure
```

Pemasang akan cuba mengesan bekas dan pemetaan `/config` secara automatik.

#### Cari nama bekas

Mula-mula, lihat senarai bekas qBittorrent yang dikesan:

```sh
sh install.sh --list-containers
```

Atau gunakan Docker secara terus:

```sh
docker ps
```

Contohnya, nama bekas mungkin:

```text
qbittorrent
```

Kemudian pilihnya secara jelas:

```sh
sh install.sh --container=qbittorrent -configure
```

#### Jika terdapat beberapa bekas qBittorrent

Contohnya, satu contoh utama dan satu contoh ujian:

```text
qbittorrent
qbittorrent-test
```

Senaraikannya dahulu:

```sh
sh install.sh --list-containers
```

Untuk contoh utama:

```sh
sh install.sh --container=qbittorrent -configure
```

Untuk contoh ujian:

```sh
sh install.sh --container=qbittorrent-test -configure
```

Jika terdapat berbilang bekas, pemasang tidak akan memilih satu daripadanya secara sembarangan.

#### Nyatakan folder hos yang dipasang sebagai `/config`

Jika folder konfigurasi qBittorrent pada hos berada di:

```text
/root/qbittorrent/config
```

Anda boleh menyatakannya secara langsung:

```sh
sh install.sh --config-root=/root/qbittorrent/config -configure
```

Contoh untuk Synology:

```sh
sh install.sh --config-root=/volume1/docker/qbittorrent -configure
```

Contoh untuk NAS lain:

```sh
sh install.sh --config-root=/share/Container/qbittorrent -configure
```

Gantikan laluan contoh dengan laluan hos sebenar yang dipasang sebagai `/config` dalam qBittorrent.

#### Pilih folder pemasangan WebUI

```sh
sh install.sh --container=qbittorrent -o /config/weig-qb-webui -configure
```

#### Kemas kini beberapa pemasangan WebUI dengan satu muat turun

Dalam Linux/NAS, ulang pilihan `-o` untuk mengemas kini beberapa pemasangan sedia ada menggunakan satu muat turun. Dalam mod ini, jangan gunakan `-configure`, `--container` dan `--config-root` serentak.

```sh
sh install.sh -dev \
  -o /root/qbittorrent/config/weig-qb-webui \
  -o /root/qbittorrent3/config/weig-qb-webui
```

#### Semak laluan selepas pemasangan

Pemasang memaparkan laluan pemasangan pada hos dan laluan yang dilihat oleh qBittorrent:

```text
Host install path: /root/qbittorrent/config/weig-qb-webui
qBittorrent Root Folder: /config/weig-qb-webui
```

Dalam tetapan qBittorrent **Files location**, gunakan laluan kedua, iaitu laluan di dalam bekas. Jika `-configure` berjaya, pemasang menetapkannya secara automatik.

</details>

### Windows PowerShell

```powershell
Invoke-WebRequest https://weigefenxiang.github.io/WeiG-qB-WebUI/downloads/dev/install.ps1 -OutFile .\install.ps1; powershell -ExecutionPolicy Bypass -File .\install.ps1 -configure
```

<details>
<summary><b>Paparkan direktori pemasangan</b></summary>

```text
C:\Users\<nama-pengguna>\AppData\Local\weig-qb-webui
```

</details>

## Pilihan lazim
Nama parameter PowerShell tidak membezakan huruf besar dan huruf kecil.

| Tujuan | Linux / Docker / NAS | Windows PowerShell |
|---|---|---|
| Keluaran stabil terkini | Lalai | Lalai |
| Keluaran Release tertentu | `-version 1.2.0` | `-version 1.2.0` |
| Binaan pembangunan | `-dev` | `-dev` |
| Direktori pemasangan tersuai | `-o /path` (boleh diulang) | `-o D:\path` atau `-output D:\path` |
| Fail konfigurasi qBittorrent tersuai | — | `-qbconfig D:\path\qBittorrent.ini` |
| Konfigurasikan qBittorrent secara automatik | `-configure` | `-configure` |
| Kembalikan pemasangan sebelumnya | `-rollback` | `-rollback` |
| Nyahpasang sepenuhnya (tanpa sandaran pemasang) | `-uninstall -purge` | `-uninstall -purge` |
| Bantuan penuh | `-help` | `-help` |
| Pilih bekas Docker | `--container=NAME` | — |
| Senaraikan bekas Docker | `--list-containers` | — |
| Folder hos yang dipasang sebagai Docker `/config` | `--config-root=/path` | — |

<details>
<summary><b>Nota (klik untuk kembangkan)</b></summary>

- Jika versi yang diminta tidak wujud, pemasangan gagal dan tidak akan beralih secara automatik kepada latest atau dev.
- `-dev` tidak boleh digunakan bersama `-version`.

### Versi dan direktori pemasangan tertentu

Linux:

```sh
sh install.sh -version 1.2.0 -o /opt/weig-qb-webui -configure
```

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -version 1.2.0 -o D:\weig-qb-webui -configure
```

### Kembalikan pemasangan

Pengembalian:

```sh
sh install.sh -rollback
```

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -rollback
```

</details>

## Nyahpasang dengan satu arahan

<details>
<summary><b>Nyahpasang sepenuhnya untuk Linux / NAS, Docker dan Windows PowerShell</b></summary>

Arahan disyorkan melakukan **nyahpasang sepenuhnya tanpa menyimpan sandaran pemasang**: ia membuang WebUI, melumpuhkan konfigurasi WebUI alternatif yang sepadan, memadam sandaran serta keadaan pengembalian bagi sasaran ini, kemudian memadam skrip pemasangan yang dimuat turun daripada direktori semasa.

### Linux / NAS

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Untuk direktori tersuai, tambahkan `-o /path/to/weig-qb-webui`.

### Docker

Satu bekas / pengesanan automatik:

```sh
sh install.sh -uninstall -configure -purge && rm -f -- ./install.sh
```

Berbilang bekas:

```sh
sh install.sh -uninstall -configure -purge --container=qbittorrent && rm -f -- ./install.sh
```

Apabila menggunakan `--config-root`:

```sh
sh install.sh -uninstall -configure -purge --config-root=/path/to/qbittorrent/config && rm -f -- ./install.sh
```

### Windows PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -uninstall -configure -purge; if ($LASTEXITCODE -eq 0) { Remove-Item .\install.ps1 -Force }
```

Untuk direktori tersuai, tambahkan `-o D:\weig-qb-webui`.

`-purge` hanya membuang sandaran bagi sasaran nyahpasang semasa dan tidak menyentuh pemasangan lain. Jika direktori keadaan bersama menjadi kosong, `~/.config/weig-qb-webui` di Linux (bagi root: `/root/.config/weig-qb-webui`) atau `%APPDATA%\weig-qb-webui` di Windows juga dibuang.

Untuk mengekalkan sandaran pemasang bagi `-rollback` kemudian, abaikan sahaja `-purge`.

</details>
