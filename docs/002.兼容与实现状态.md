## 3. Runtime compatibility truth

浏览器总控制面是 `W.CapabilityRegistry + webui/private/data/capabilities.json`，但 `capabilities.json` 不是所有版本事实的大杂烩。完整 admitted release source truth 属于 build/CI Frozen catalog/LKG；browser 只按 domain lazy-load compact facts：

```text
capabilities.json      release identity / high-level gates / compatFiles
torrent-compat.json    Torrent filters/status/fields/columns; B 仍需 native facet manifest
detail-compat.json     Torrent Detail source projection
settings-compat.json   current Settings/Options compact facts; A 仍需 source-native surface cutover
rss-compat.json        RSS Downloader native surface/rule field facts
source-actions.json    exact action/parameter provenance
qB-owned copy artifact source/context + official locale route
```

`capabilities.json.compatFiles` 当前已经包含 torrent/detail/actions/settings/rss。正式 runtime 不得重新加载 65-release full catalog。

危险 write 继续 fine-grained fail closed：certified exact/equivalent identity、source action/endpoint、required parameter、payload semantics 缺一不可；Settings 另要求 exact Preference setter/type agreement。UNKNOWN/future 不允许用 major/nearest-version 猜写能力。

## 4. A — Options / Preferences 当前事实

已完成的 source/admission 层：

- 已建立 `tools/qb-preferences-surface-source.mjs`，从 exact qB source 提取 native tabs/sections/control/copy/dependency 并与 `app/preferences` descriptors 对齐。
- 已建立 `tools/qb-preferences-compact.mjs`，把 source refs、tabs、sections、controls、options、units、dependencies 与 getter/setter/type provenance 编译成 keyed compact IR。
- `tests/full-stable-preferences-source-contract.mjs` 已在当前 native-surface CI 上覆盖全部 65 admitted stable，并验证 release/source SHA identity 与 compact round-trip。

仍未完成的正式产品层：

- `W.SettingsSchema/settings-schema.js` 仍包含固定 `SURFACES`、`SECTION_ORDER`、`SECTION_TITLES`、`META`、显式 `add()` lists 与 `FAMILY_RULES` 等大量手工 qB-owned presentation truth。
- `tools/qb-compact-runtime.mjs` 的 `nativeSettingsTabs()` 仍有固定八 tab `allowed` 白名单；未来第九个 upstream native tab 仍可能被静默过滤。
- 新 Preferences compact IR 尚未成为正式 Settings runtime owner；不能长期保留 source-native IR 与旧手工 schema 双 active。
- 当前 all-stable Preferences source contract 有 bounded coverage-ratio gate，但还不是“independent census = mapped + explicit exclusions、unaccounted=0”的最终 completeness proof。

最终 Options UI 必须收口为：

```text
exact source Preference native manifest
∩ GET /api/v2/app/preferences
= current instance native Options projection
```

历史差异继续 source-driven 保留，例如 4.2.x 没有 RSS/Behavior、4.3.x 有 RSS、4.6+ 有 Behavior；不得为了看齐最新版手工补 tab。

## 5. B / E — Torrent Sidebar 与 Detail 当前事实

Status filter semantics 已走 `W.CapabilityRegistry + W.TorrentSemantics`；Torrent Detail 已有成熟的 `torrentDetailUi() -> detail-compat.json -> W.QbUiEvidence -> generic Detail runtime` 链，E 不另造第二套 Detail 系统。

B 仍未完成：`spatial.js` 目前固定声明 category/tag/tracker/savePath 四个 facet，LibraryController 也仍按固定 state/setter 知道这些维度。目标是 source-derived native facet inventory/order/semantics -> generic state/projection；所有 qB-native facets 按 exact source 顺序出现，WeiG-owned Path 永远最后。`All` 只是默认/no-filter option，不应成为额外持久 facet 标题。

E 的剩余工作是做 source/copy/action completeness audit并补真正缺口，不能因为 A/B/C/F 重构而复制 renderer、polling、columns 或 Detail state owner。

## 6. C — qB-owned copy 当前事实

`W.I18n` 已存在 exact-release official translation 主链，`qb-settings-native.txt` 仍是当前 Settings-focused runtime copy registry；但 Settings 外层、RSS 等 surface 仍存在手写英文/中文 fallback。

目标规则：qB-owned copy 只以 exact upstream `{source, context}` 为身份；目标 locale 从 exact release official translation facts 解析；官方目标翻译不存在时只安全回退 upstream English source，不维护 WeiG 英文→中文第二数据库。WeiG-owned Path、Private/PT、WeiG WebUI、About 等继续 WeiG i18n。

若将 `qb-settings-native.txt` 泛化为 domain-neutral qB-owned copy artifact，必须原子替换文件、loader、callers、tests 与 distribution contract；禁止新旧两个 copy registry 并存。

## 7. D — RSS 当前事实

D 的真实 rule-fidelity bug 已修入当前产品：

- qB 4.3.0+ `smartFilter` 现在由 source manifest 渲染/写回。
- qB 4.6+/5.x 的现代规则使用 `torrentParams.stopped`，不再错误寻找 `torrentParams.paused`。
- historical `addPaused/createSubfolder` 与 modern `stopped/content_layout` 的 default/null 语义由 source options 保留，避免 checkbox 把 `null/default` 破坏性改成 `false`。
- `rss.js` 以 source-returned完整 rule object 作为 draft base，只更新 manifest 映射字段，未知字段继续保留。
- `rss-compat.json` 已成为正式 lazy-load runtime domain，releaseSet 当前覆盖 65 stable（4.1.0 -> 5.2.3）。
- 当前 native-surface CI 已验证每个 admitted stable 的 RSS native-surface source fact与 compact timeline。

D 仍不能直接宣告整体完成：还需要和 C/F 一起完成 qB-owned official copy 路由、independent inventory/census completeness、cross-domain catalog identity，以及对 RSS feeds/articles/read-state/Downloader actions 等最终 surface coverage 做一次阶段收口审计。不得再恢复手写 rule-field owner。

## 8. F — Source admission / compact runtime 当前事实

当前已有 Frozen 65-release source catalog、torrent/detail/settings/actions compact contracts、RSS compact domain、Preferences source-native compact IR，以及 `native-surfaces` CI lane。

F 仍有关键缺口：

```text
qb-compact-runtime.mjs still compiles legacy Settings shape and fixed tab whitelist
rss-compat generation is not yet unified into the same compact-runtime compiler path
Preferences native IR is not yet wired into formal Settings runtime
all compact domains do not yet enforce one common catalog/release-set identity
independent inventory/census proof is not yet universal
```

最终 F 要求每个 compact domain 与 qB-owned copy 都携带/验证同一 Frozen catalog identity，并由同一 admitted source set编译；浏览器只加载 compact current-domain facts，不加载 full history。

## 9. 验证边界

阶段内部只跑 unit/source/focused change-point tests。阶段完整收口后最多一次 admitted-stable 65-release offline/Virtual full matrix。阶段 65 的 expected set必须直接来自 Frozen catalog，并校验 `executed==expected`、missing/duplicate/unexpected 为空。

最终 completeness gate 还必须引入与 semantic extractor 相互独立的 upstream inventory/census：

```text
upstream inventory
= mapped facts + explicit reviewed exclusions
unaccounted = 0
duplicates = 0
```

这样 parser 新语法不能因为 extractor 和测试共享同一盲点而静默遗漏。

A–F 全部完成并冻结 final dev exact SHA 后，才按 `docs/011` 运行一次昂贵 real-qB Full Frozen Matrix；若 real-qB 后又产生新的最终产品 commit，则旧 SHA evidence 不能证明新 SHA。
