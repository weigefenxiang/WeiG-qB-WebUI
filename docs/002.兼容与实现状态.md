## 4. Lab A 认证问题结论

4.1.9.1 已通过直接 WebAPI 登录验证：

```text
Ok.
HTTP 200
```

因此：

- `/api/v2/auth/login` 请求格式正常；
- 反向代理路径正常；
- qB 4.1.9 WebUI authentication contract 正常；
- 之前失败的 `Fails.` 来自旧 `Password_ha1` 与输入密码不匹配；
- 早期一次手工恢复脚本还曾错误匹配双反斜杠键；真实配置键必须按单反斜杠处理：

```text
WebUI\Username
WebUI\Password_ha1
```

普通 WeiG installer 不修改 WebUI username/password。

## 5. v0.3.0 Stable Virtual UI

### 已实现

`VirtualList` 现在：

- 在 container 上记录 `__weiggVirtualScrollTop`；
- 新 VirtualList 接管同一 container 时恢复用户滚动位置；
- 替换旧 scroll handler，避免轮询重建产生 listener leak；
- `setItems()` 默认 preserve viewport；
- 位置超过新数据最大高度时做 clamp；
- 暴露 `resetScroll()` 给 deliberate context change。

主 Torrent 页面在以下用户主动上下文变化时 reset：

```text
Filter / Tracker / Save Path / Category / Tag
Prev / Next page
Page size
Torrent search
```

普通轮询/刷新不应该再把中间或底部位置自动跳回顶部。

> 该行为已通过静态/结构 CI；Lab A 实际滚动 2s/5s/10s 稳定性仍需用户本轮验证。

## 7. Transfer Control Dock

Desktop 状态栏现在作为居中操作 Dock：

```text
↓ DL | ↑ UL | ALT | Connection | Torrent count | Refresh | Transfer
```

点击 ↓ / ↑ 可修改全局限速；ALT 切换备用限速；Transfer 打开 Session + Graph；Connection 继续打开 qB/WebAPI/Compatibility 详情。

### 跨版本 API

以下端点是 4.1.9 floor 与现代 5.x 的共同基础：

```text
GET  transfer/downloadLimit
POST transfer/setDownloadLimit
GET  transfer/uploadLimit
POST transfer/setUploadLimit
GET  transfer/speedLimitsMode
POST transfer/toggleSpeedLimitsMode
GET  transfer/info
GET  sync/maindata
```

`QBClient` 已封装：

```text
getGlobalDownloadLimit
setGlobalDownloadLimit
getGlobalUploadLimit
setGlobalUploadLimit
getAltSpeedMode
toggleAltSpeedMode
getMainData
```

UI 不直接 fetch `/api/v2/*`。

## 8. Session Stats / Transfer Graph

已实现：

- 订阅现有 `getTransferInfo()`；
- 不新增第二个高频 transfer timer；
- ring buffer 最大 900 samples；
- 1 / 5 / 15 min；
- Session downloaded / uploaded；
- current Global DL / UL limit；
- DHT / Peer connections；
- `sync/maindata.server_state.free_space_on_disk` 可用时显示 free space；
- Canvas 原生绘图。

## 11. VueTorrent 差距审查

已确认 VueTorrent 当前具备或暴露：Session stats、Transfer graphs、Configurable Dashboard、PWA/mobile、Torrent Creator、Cookie Manager、Search、RSS、Logs、丰富快捷键/多选等。

WeiG v0.3 已补：

```text
Session stats
Transfer graph
Global speed controls
Alternative speed mode
rendered-row Ctrl/Cmd/Shift selection
```

已建立兼容层基础但尚未做完整 UI：

```text
Torrent Creator
Cookie Manager
```

原因：VueTorrent 当前面向较新的 qB 版本；WeiG 必须保留 4.1.9 floor，因此所有现代功能都必须 Capability gate。
