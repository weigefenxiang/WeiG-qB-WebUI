
## 4. Locale / qB-owned copy / runtime slimming

唯一 persisted language truth仍是：

```text

```

qB-owned wording统一走一个 source-derived runtime IR：

```text

-> deduplicated refs/bindings/bridge sets
-> private/data/qb-settings-native.txt
-> W.I18n.qbSetting/qbText/loadQbOwnedText
```

Native-capable active-root family只生成 **WeiG实际引用 refs** 的 minimal `webui_<locale>.qm`；完整 deterministic recovery union仍是 build-time evidence，不进入 runtime。

Translator hard boundary保持：

```text
4.1.0 -> 4.1.3   qApp/application translator
4.1.4            dedicated strict
```

所以 `4.5.0 -> 4.6.4` 的 11 个 stable release继续 exact compact official-TS bridge；不能因 QM存在就伪装 native。


## 8. Installer / Universal Portable / distribution

Stable installer消费 immutable Release + checksum/identity；Dev installer只消费 Pages exact-SHA materialized distribution，禁止 raw-source fallback。

Dev channel 必须区分 **installer bootstrap identity** 与 **WebUI payload identity**：在当前 dev 尚未晋级 main 时，测试开发版应从 `dev/installers/*` 获取当前 installer bootstrap；正式 WebUI payload仍只能来自 `downloads/dev` materialized distribution。不得用 main 上尚未晋级的旧 installer 去判断当前 dev distribution contract，也不得因为 bootstrap 来自 dev 就回退到 raw `webui/**` source。

如果 current dev 只比已发布 materialized SHA 多 Pages-irrelevant changes，当前 dev installer必须通过 exact GitHub compare证明后复用已验证 payload；如果存在 Pages-relevant change、compare不是 `ahead`、changed files无法完整证明或 compare失败，则必须 fail closed并等待 exact-ref Pages materialization。
