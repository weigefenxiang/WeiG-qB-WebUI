## 3. Settings 当前实现

Current value/presence owner已经是真实 qB WebAPI：

```text

-> app/preferences actual keys + values
-> W.SettingsSchema semantic grouping/control
```

## 4. Locale / qB-owned copy / runtime slimming（0.3.86）

唯一 persisted language truth仍是：

```text
qB app/preferences.locale
```

qB-owned wording现在统一走一个 source-derived runtime IR：

```text
exact source/context + certified official translation evidence
-> deduplicated refs/bindings/bridge sets
-> private/data/qb-settings-native.txt
-> W.I18n.qbSetting/qbText/loadQbOwnedText
```

Native-capable active-root family只生成 **WeiG实际引用 refs** 的 minimal `webui_<locale>.qm`；完整 deterministic recovery union仍是 build-time evidence，不进入 runtime。

Translator hard boundary保持：

```text
4.1.0 -> 4.1.3   qApp/application translator
4.1.4            dedicated strict
4.1.5 -> 4.4.5   dedicated native
4.5.0 -> 4.6.4   Alternative WebUI document translation disabled
4.6.5+            dedicated native restored
```

所以 `4.5.0 -> 4.6.4` 的 11 个 stable release继续 exact compact official-TS bridge；不能因 QM存在就伪装 native。

已退休 end-user runtime assets/loaders：

```text

old full qb-settings-native.txt registry BODY/FORMAT
W.I18n loadSettingsData/loadNativeSettingsData dual path
release-profile settingsTranslationPath/settingsNativeLocales/settingsTranslationLocales duplicates

```

`qb-release-profiles` 仍保留 exact source/action/parameter/field/Preference provenance；其 dedupe是独立后续 Batch B，不属于0.3.86，且当前没有用户授权继续该工作。
