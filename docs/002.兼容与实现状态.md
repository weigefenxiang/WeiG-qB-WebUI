```text

```

Release profile继续提供 exact torrent columns、Torrent Detail UI/action facts、Preference getter/setter/type provenance、action/parameter surface、translator behavior/locale facts等。Resolution保持：

```text
EXACT -> EQUIVALENT -> bounded INHERITED -> FALLBACK
```

Future/unknown dangerous writes fail closed；field/action/Preference presence不得按 patch version猜。

## 3. Settings 当前实现

Current value/presence owner已经是真实 qB WebAPI：

```text
W.QBClient.getPreferences()
-> app/preferences actual keys + values
-> W.SettingsSchema semantic grouping/control
-> W.ReleaseProfile exact setter/type/action provenance
-> W.SettingsRenderer
```

Write仍要求 source-proven writable/type + `setPreferences` action，并在 POST 后 `getPreferences()` verification reread；unknown returned Preference没有 exact setter/type proof时只读。

0.3.86 不再依赖 historical runtime Settings translation shard来决定当前值或当前 key存在性。

## 4. Locale / qB-owned copy / runtime slimming（0.3.86）

唯一 persisted language truth仍是：

```text
qB app/preferences.locale
```

qB-owned wording现在统一走一个 source-derived runtime IR：

```text
exact source/context + certified official translation evidence
-> deduplicated refs/bindings/bridge sets
-> private/data/qb-settings-native.txt
-> W.I18n.qbSetting/qbText/loadQbOwnedText
```

Native-capable active-root family只生成 **WeiG实际引用 refs** 的 minimal `webui_<locale>.qm`；完整 deterministic recovery union仍是 build-time evidence，不进入 runtime。

Translator hard boundary保持：

```text
4.1.0 -> 4.1.3   qApp/application translator
4.1.4            dedicated strict
4.1.5 -> 4.4.5   dedicated native
4.5.0 -> 4.6.4   Alternative WebUI document translation disabled
4.6.5+            dedicated native restored
```

所以 `4.5.0 -> 4.6.4` 的 11 个 stable release继续 exact compact official-TS bridge；不能因 QM存在就伪装 native。

已退休 end-user runtime assets/loaders：

```text
private/data/qb-settings/
old full qb-settings-native.txt registry BODY/FORMAT
W.I18n loadSettingsData/loadNativeSettingsData dual path
release-profile settingsTranslationPath/settingsNativeLocales/settingsTranslationLocales duplicates
full/unfiltered recovery QM runtime payload
```

`qb-release-profiles` 仍保留 exact source/action/parameter/field/Preference provenance；其 dedupe是独立后续 Batch B，不属于0.3.86。

## 7. Transfer / capability / shared owner

Transfer继续使用 existing `transfer/info` + `W.TransferRuntime`；没有第二 polling owner。Read/write/action/field/parameter capability继续分离证明；dangerous `UNKNOWN` 必须 transport前阻断。

一个 semantic purpose只有一个 Current Owner；禁止 runtime alias、monkey patch、MutationObserver repair、post-render repair、第二业务状态或重复 polling。

## 8. Installer / Universal Portable / distribution

Stable installer消费 immutable Release + checksum/identity；Dev installer只消费 Pages exact-SHA materialized distribution，禁止 raw-source fallback。

Universal Portable要求继续成立：

```text
one materialized WeiG-qB-WebUI folder
+ offline
+ copy to supported qB host
+ set Alternative WebUI path
= works
```

0.3.86 materialized runtime保留：

```text
qb-releases.json
qb-release-profiles/
qb-settings-native.txt   # compact qB-owned runtime IR; compatibility filename
minimal translations/webui_*.qm
VERSION / GIT_SHA
```

并拒绝旧 `qb-settings/` 与旧 native-registry body/dual-loader 回流；`qb-settings-native.txt` 只保留为 compact IR 的兼容文件名。Distribution manifest输出 core/profile/translation/redundant/total/ZIP/max-file size breakdown；单文件继续低于 qB 10 MiB hard limit，并以项目 `<5 MiB` target fail closed。

Windows qB config mutation的 running/recovery-file/encoding/BOM/byte-roundtrip/atomic-replace/post-verify/rollback safety不变；installer-owned backup最多保留3份且必须先更新 `last-backup` 再 prune。
