## 3. Runtime compatibility truth

浏览器总控制面是 `W.CapabilityRegistry + webui/private/data/capabilities.json`，但 `capabilities.json` 不是所有版本事实的大杂烩。完整 admitted release source truth属于 build/CI Frozen catalog/LKG；browser只按 domain lazy-load compact facts：

```text
capabilities.json      release identity / high-level gates / compatFiles
torrent-compat.json    Torrent filters/status/fields/columns; B still needs native facet manifest
detail-compat.json     Torrent Detail source projection
settings-compat.json   current Settings runtime facts; A still needs native IR cutover
rss-compat.json        RSS Downloader native surface/rule facts
source-actions.json    exact action/parameter provenance
qB-owned copy artifact source/context + official locale route
```

`capabilities.json.compatFiles` 当前包含 torrent/detail/actions/settings/rss。正式 runtime不得重新加载65-release full catalog。

危险 write继续 fine-grained fail closed：certified exact/equivalent identity、source action/endpoint、required parameter、payload semantics缺一不可；Settings另要求 exact Preference setter/type agreement。A cutover后还必须要求 source value projection明确证明安全写回。UNKNOWN/future不允许用 major/nearest-version猜写能力。

## 4. A — Options / Preferences 当前事实

### 已完成：source/admission foundation

- `tools/qb-preferences-surface-source.mjs` 已从 exact qB source提取 native tabs/sections/order/control/copy/dependency，并与 Preference descriptors对齐。
- `tools/qb-preferences-compact.mjs` 已生成 keyed compact IR，包含 exact release identity、source refs、tabs、sections、controls、options、units、dependencies、getter/setter/type provenance。
- 固定八 tab whitelist 已从 `tools/qb-compact-runtime.mjs::nativeSettingsTabs()` 退休；当前按 `qbOwnedUi` 中的 `settings.tab.*` source facts动态提取 native tabs，不再静默过滤未来第九个 tab。
- `tools/qb-preferences-inventory.mjs` + `tools/qb-preferences-census-source.mjs` 已建立与 semantic extractor分离的 inventory/census路径；full-stable contract会对每个 admitted release的 `tabs / preferences / bindings` 执行 accounting并要求 complete。
- `tests/full-stable-preferences-source-contract.mjs` 已把 Preferences census作为 65-release source gate的一部分；`unaccounted / overlap / escaped / duplicate` 任一出现都会 fail。
- 新增 source value projection：每个 source-mapped Preference现在带 `projection`，区分 `identity / scale / switch-map / unproven`，并携带 `safeWrite`。当前 contract明确检查最新 `dl_limit` 的 1024 scale、`torrent_file_size_limit` 的 1048576 scale，以及历史 `proxy_type` switch-map；没有 source-proven inverse的 composite写回继续 `safeWrite:false`。
- projection extractor 已从“每个 Preference 重扫整份 source”优化为“每个 release预索引一次 source、随后按 key/control查询”，避免明显 O(N×source)回归。
- `tools/qb-catalog-identity.mjs` 已提供 common Frozen catalog identity；`qb-compact-runtime.mjs` 当前已给 capabilities/torrent/detail/actions/settings compact outputs注入同一 identity foundation。

### 仍未完成：formal runtime atomic cutover

- `W.SettingsSchema/settings-schema.js` 仍包含固定 `SURFACES`、`SECTION_ORDER`、`SECTION_TITLES`、`META`、显式 `add()` lists 与 `FAMILY_RULES` 等大量手工 qB-owned runtime truth。
- 正式 `settings-compat.json -> W.SettingsSchema -> W.SettingsRenderer` 仍消费旧 Settings compact shape；source-native Preferences schema v2还没有成为 canonical browser runtime owner。
- `settings.js` 仍保留 Listening port / Schedule range 的手工 compound layout逻辑；是否保留、替换或改为 source-driven projection必须以 exact native IR可以证明的语义为准，不能为了“原子 cutover”丢功能，也不能恢复版本 if/else。
- 当前 browser write path尚未消费 `projection.safeWrite`；A cutover时必须把 source projection与 descriptor一起纳入 write/read display转换，unproven/composite inverse未知时 HTTP前fail closed。
- A完成后旧手工 qB-owned schema truth必须同批删除，不能保留 source schema + legacy schema双 active。

最终 Options UI必须收口为：

```text
exact source native Preferences manifest
+ exact Preference descriptor/projection provenance
∩ GET /api/v2/app/preferences
= current instance native Options projection
```

历史差异继续 source-driven保留；future native tab/control不能靠固定列表或 patch-version branch进入。

## 5. B / E — Torrent Sidebar 与 Detail 当前事实

Status filter semantics已走 `W.CapabilityRegistry + W.TorrentSemantics`；Torrent Detail已有成熟的 `torrentDetailUi() -> detail-compat.json -> W.QbUiEvidence -> generic Detail runtime` 链，E不另造第二套 Detail系统。

B仍未完成：`spatial.js` 目前固定声明 category/tag/tracker/savePath四个 facet，LibraryController也仍按固定 state/setter知道这些维度。目标是 source-derived native facet inventory/order/semantics -> generic state/projection；所有 qB-native facets按 exact source顺序出现，WeiG-owned Path永远最后。`All`只是 no-filter option，不应成为额外持久 facet标题。

E剩余工作是 source/copy/action completeness audit并补真正缺口，不能因为A/B/C/F重构而复制 renderer、polling、columns或 Detail state owner。

## 6. C — qB-owned copy 当前事实

`W.I18n` 已存在 exact-release official translation主链，`qb-settings-native.txt` 仍是当前 Settings-focused runtime copy registry；但 Settings外层、RSS、Sidebar等 surface仍存在手写英文/中文 fallback。

目标规则：qB-owned copy只以 exact upstream `{source, context}` 为身份；目标 locale从 exact release official translation facts解析；官方目标翻译不存在时只安全回退 upstream English source，不维护 WeiG英文→中文第二数据库。WeiG-owned Path、Private/PT、WeiG WebUI、About等继续 WeiG i18n。

若将 `qb-settings-native.txt` 泛化为 domain-neutral qB-owned copy artifact，必须原子替换文件、loader、callers、tests与 distribution contract；禁止新旧两个 copy registry并存。

## 7. D — RSS 当前事实

D的真实 rule-fidelity bug已修入当前产品：

- qB 4.3.0+ `smartFilter` 由 source manifest渲染/写回。

- historical `addPaused/createSubfolder` 与 modern `stopped/content_layout` 的 default/null语义由 source options保留，避免 checkbox破坏 null/default。
- `rss.js` 以 source-returned完整 rule object作为 draft base，只更新 manifest映射字段，未知字段保留。
- `rss-compat.json` 已成为正式 lazy-load runtime domain。
- native-surface source contract已经覆盖 all admitted stable；当前 latest exact SHA的最终 run状态仍需 fresh-read Actions确认。

D仍不能宣告整体完成：还需要 C/F 的 qB-owned official copy、independent RSS inventory/census、common catalog identity integration，以及 feeds/articles/read-state/Downloader actions final audit。不得恢复手写 rule-field owner。
