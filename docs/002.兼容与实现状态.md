## 3. Main Torrent table 当前实现

Exact/certified release 的主表链：

```text
W.ReleaseProfile.torrentTableColumns
-> W.TorrentFieldRegistry
-> W.DataGrid / Columns UI / row renderer
```

Source schema拥有 native key/order/defaultVisible/defaultWidth/dataProperties；用户 visibility/order/width 是 override，不是第二固定列清单。暂时 unavailable 的 saved preference 不得破坏性删除。

Header resize/reorder继续由 canonical DataGrid owner负责：

```text
resize handle -> resize only
header body drag threshold -> reorder
ordinary click -> existing sort
pointermove -> live width/grid-template only
pointerup -> one canonical persistence/reconciliation
```

Field presence不等于 server sort proof。

### 3.1 当前主列表横向滚动优化

`#torrent-list` 的 native scroll container / `W.VirtualList` 仍是唯一横向滚动 owner。当前行为：

```text
horizontal motion期间 polling继续
polling得到的新 items只保留最新 snapshot
horizontal motion期间不 repaint 主 VirtualList
连续横移重启同一个 bounded idle timer
140 ms horizontal idle后只 flush 最新 snapshot 一次
非主列表 VirtualList保持即时 setItems/render
```

该优化没有新增第二 scroll/poll/state owner，没有通过 transform 同步 `scrollLeft`，也没有 MutationObserver、monkey patch 或 post-render repair。

## 4. Torrent Detail 当前实现

Current source/data chain：

```text
exact qB properties markup / detail scripts
-> extractTorrentDetailUi()
-> W.ReleaseProfile.torrentDetailUi
-> W.QbUiEvidence / canonical detail projection
-> W.SharedColumns user override
-> W.ColumnInteraction
-> detail DOM
```

已实现并必须保留：

```text
source-driven Detail table schema/provenance
Detail Columns canonical visibility/order/width persistence
column checkbox live-apply through ctx.apply/applyDetailColumns
pointerId-filtered resize lifecycle
pointermove只paint，pointerup再persist
mobile ordinary touch scroll不误reorder
long-press reorder走同一 W.SharedColumns owner
shared-table viewport是horizontal scroll owner
```

Tracker source projection当前必须能够证明：

```text
peers      -> num_peers
seeds      -> num_seeds
leeches    -> num_leeches
downloaded -> num_downloaded
message    -> msg
```

Parser支持 legacy indexed row、`row=[...]`、source-proven bare local/helper relation、modern `rows.push({...})`、nested `tracker.endpoints` dependency；未知 upstream shape继续 fail closed。

Properties surface同时考虑 `KEY_PROP_*` 与 `propertiesAction()` 实际使用的 shared `KEY_TORRENT_*` serializer keys。

qB 5.2 Content已证明：

```text
checked   -> priority
remaining -> size + progress + priority
priority == 0 -> checked=false, remaining=0
else remaining = size * (1 - progress)
```

Tracker Detail display/edit继续使用 `torrents/trackers` 返回的 **exact `url`**；不能重新经 `normalizeTracker()` 丢失 path/query。

## 6. Installer / distribution 当前实现

Stable installer消费 immutable Release + checksum/identity；Dev installer只消费 Pages materialized distribution，禁止 raw-source fallback。

Windows external qB config mutation当前安全边界：

```text
qB running / recovery file / ambiguous config -> fail closed
strict decode + byte round-trip
byte-identical backup
exact [Preferences] ownership check
temp write + strict reread
encoding/BOM/invariant verification
target unchanged recheck
safe replace + post-verify
safe rollback when applicable
```

Installer backup retention：成功建立新 backup 后**先写 `state/last-backup`**，再 prune；只删除名称严格为 timestamp 且同时含 `had-webui` + `dest-path` markers 的 installer-owned backup，最多保留最新 3 份。用户普通目录/文件不属于删除边界。
