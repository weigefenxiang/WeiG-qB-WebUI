# 002. 兼容与实现状态

> 当前兼容状态与剩余工作。Structural truth 以 upstream source-derived stable catalog 为准；same-endpoint semantic evolution 由 Endpoint Contract 拥有；HTTP/transport evolution 由 Transport Contract 拥有；Phase C ledger 是 chronology/classification truth。旧实现由 Git history 保存。

## 1. 正式支持范围

- WebAPI v2 主线正式下限：**qBittorrent 4.1.0 / WebAPI 2.0.0**；
- 正式支持策略：**qBittorrent 4.1.0 -> latest official stable**；
- 当前 audited semantic ceiling：**WebAPI 2.15.1**；
- 当前完整 stable matrix 已验证 **qBittorrent 4.1.0 -> 5.2.3，共 65 个官方 stable profile**；
- 5.2.3 使用 WebAPI 2.15.1；
- Alpha / Beta / RC / master 不进入正式 stable matrix；
- upstream master 可以领先于 stable，未知未来 semantic revision 必须 fail closed；
- qB 4.0.x 属于旧 WebAPI v1，当前不在主线支持范围。未来如支持，使用独立 Legacy WebAPI v1 Adapter，不污染 v2 router/contract owner。

## 2. Structural compatibility truth — Current Owner

```text
qB upstream official stable source
-> source parsers
-> tools/qb-release-catalog.mjs
-> qb-releases.json
-> W.ReleaseProfile
```

每个 exact profile 至少包含：

- qB version / WebAPI version / tag / source SHA；
- Preferences getter/setter descriptors；
- `apiActions`；
- Torrent filter surface；
- `torrents/info` parameter surface。

Structural truth 回答：

```text
endpoint 有没有？
Preference 有没有 getter/setter？
Torrent filter / info parameter 有没有？
```

这部分是正式 Current Owner，不由 router/caller 手写 allowlist 或 patch-version guesses。

## 3. Product runtime compatibility — Current Owners

### Capability

`W.ReleaseProfile` 提供 exact source facts，`W.CapabilityRegistry` 负责 user-visible policy。Source-bound feature 不在 exact upstream surface 时正常 UI 隐藏；unknown capability id fail closed。

### Torrent

`W.TorrentSemantics` 是 status/filter semantic owner：

- qB4 source `paused/resumed` <-> canonical `stopped/running`；
- qB5 使用 `stopped/running`；
- unknown/retired filter fail closed；
- Completed != Seeding；
- Private authoritative metadata 与 PT domain classification 分开处理。

### Settings

`W.SettingsSchema + exact Preference descriptors` 决定 route/type/editability。Setter missing/unresolved/type mismatch/missing descriptor 均 read-only；structured value 仍 read-only，直到有专用 editor contract。

## 4. Virtual protocol semantic owners — Current

```text

```


### Endpoint existence

`apiActions + upstream-gates.js` 继续负责 structural endpoint existence。它与 Endpoint/Transport Contract 职责正交。

## 9. Future stable strategy

新 official stable：

```text
new tag discovered
-> exact structural catalog
-> WebAPI revision comparison
-> chronology/classification audit
```

- 已知 semantic revision：继续自动验证；
- 同 WebAPI revision 的 stable supplement：必须按 qB patch evidence 单独登记；
- semantic revision > 2.15.1 或存在未分类 delta：fail closed；
- 不允许“版本更高应该兼容”的推断。

## 10. Validation layers

每个 runtime-bearing SHA 必须重新通过：

- `npm test` / normal CI；
- Upstream Compatibility Audit；
- source-derived full stable catalog；
- every official stable release audit；
- WebAPI evolution chronology/classification audit；
- Virtual qB Pages Source；
- Formal Pages build / deploy / Hosted Chrome live verify；
- exact source SHA / expected simulator SHA identity。

Docs-only SHA 仍是新的 code identity，也应跑自动 gate；但产品 VERSION 不变。

## 12. 工作纪律

- 正式开发分支是 `dev`；未经用户明确授权不动 `main`；
- 写前和 ref 更新前 fresh-read `dev` exact HEAD；
- 只允许 `force:false` fast-forward；
- 每个大阶段完成后停下复盘，由用户拍板下一方向；
- red gate 先确认 runtime truth，再判断是 production bug 还是 stale test；
- 不为测试绿而回退已由 upstream 证明正确的 runtime；
- 不为“清债速度”制造不存在的 simulator lifecycle；
- VERSION 只在正式 `webui/**` 产品内容变化时升级。
