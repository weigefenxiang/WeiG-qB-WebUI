# 002. qBittorrent 兼容与实现状态

更新时间：2026-09-01  
当前产品版本：**0.3.7 Final Candidate**

## 1. 支持边界与判定原则

WeiG qB WebUI 当前稳定兼容目标：

```text
qBittorrent 4.1.9.1 / WebAPI 2.2.1
→ 所有后续官方正式 4.x / 5.x
→ 当前稳定版 5.2.3 / WebAPI 2.15.1
→ current upstream master
```

兼容判定遵循 **COMPAT-001**：优先检测 WebAPI、endpoint、Preference key、response field 与 capability，禁止仅凭 qB major version 决定功能。

截至本次发布审计，qBittorrent 官方尚无 6.x 正式版。`6.0.0-synthetic / WebAPI 3.0.0-synthetic` 只用于 forward-major sentinel，验证代码不存在 `major > 5 => unsupported` 一类硬编码，不代表正式宣称支持 qB 6.x。

## 4. 关键 API bridge

WeiG `QBClient` 负责跨版本语义归一：

```text
qB 4.x resume/pause
        ↕
WeiG semantic resume/pause
        ↕
qB 5.x start/stop
```

同样处理：

```text
paused / stopped filter vocabulary
editTracker origUrl / url parameter migration
legacy/modern auth response
WebAPI capability thresholds
structured torrents/add
exact private field availability
```

Release compatibility contract 会逐 representative release 验证这些 bridge，避免“页面能打开，但操作 endpoint 已变”的假兼容。

## 5. Alternate WebUI entry contract

qB Alternate WebUI package 必须同时存在：

```text
public/index.html
public/login.html
private/index.html
```

`public/index.html` 不能省略。qB 5.x 在入口缺失时可能退回内置 WebUI，因此 Linux/Windows installer、platform contract、release candidate 均强制验证三个入口。

登录兼容同时覆盖：

```text
legacy qB 4.x: HTTP 200 + "Ok."
modern qB 5.x: HTTP 204
invalid credentials: legacy/modern response
HTTP 403 temporary ban
```

## 10. Display Time Zone

时区属于 WeiG 前端显示层：

```text
qB timestamp
→ normalized epoch
→ W.Time
→ Intl.DateTimeFormat(timeZone)
```

v0.3.7 canonical contract：**时区控制只在 Settings 中存在**，底部 statusbar 不再复制 timezone control。

当前选择保存在 `localStorage: weigg.timeZone`，不会调用 `setPreferences()`，不会修改 qB daemon、Docker 或宿主机系统时区。

## 11. Advanced Unit / Enum

经过官方源码/API 验证的 Advanced 字段提供 unit、API unit、display unit、enum 与 special value。涉及单位转换的字段必须完成 read → display → write round-trip；未经验证禁止猜单位或自动换算。

## 12. Storage telemetry

数据源：

```text
sync/maindata
→ server_state.free_space_on_disk
```

表示 qBittorrent 默认保存路径所在文件系统可用空间，不等于通用 VPS `/` 剩余空间。显示使用 IEC 自动单位 `B/KiB/MiB/GiB/TiB`。

## 13. Stable installer contract

Linux / Windows bootstrap 只允许稳定 Release：

```text
latest GitHub Release ZIP
+ SHA256SUMS
+ valid 40-char GIT_SHA
+ public/index.html
+ public/login.html
+ private/index.html
```

任何一项缺失即 fail closed。稳定 installer 不再下载 `main.zip`，也不把 `main` 当 fallback payload。
