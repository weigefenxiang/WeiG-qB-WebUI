## 2. Runtime compatibility truth

当前浏览器 compatibility owner 为 `W.CapabilityRegistry`。它消费 checked-in compact contracts，并结合 `W.QBClient` 检测的 qB/WebAPI identity 解析 exact/equivalent/bounded inherited/fallback 状态。`W.QBClient` 只拥有 transport 与运行实例版本检测，不重新拥有 capability/version policy。

运行时 compact contracts 是 **source-derived / 上游源码生成** 的兼容真值。正式 runtime 不包含旧 release-profile owner、`qb-releases.json` 或 per-release profile shards；qB official source、65-release catalog、完整 translation/source evidence 只留在 tools/tests/CI/simulator，用来生成或审计 compact contracts。

危险 write 继续遵循 fine-grained provenance 与 fail-closed：endpoint proof、required parameter proof、具体 Preference/action proof 缺一不可。future UNKNOWN 不得通过 nearest-version/major guessing 放开写操作。

## 4. Settings / Locale

Preference current value/presence 只来自 `app/preferences`。`W.SettingsSchema + settings-compat.json` 拥有 Preference semantic/type/setter descriptor，以及 qB-native tab presence/order compact facts；certified write gate 来自当前 compatibility identity；`W.QBClient.setPreferences()` 后必须 `getPreferences()` verification reread。唯一 persisted language truth 仍是 `app/preferences.locale`。

Settings 顶层 qB tab **不是固定 8 项**。浏览器只渲染当前 exact source contract证明存在的 native tabs，并保留 source DOM order。`Behavior`、`RSS`、`Advanced` 等是否出现由当前 release source决定，不能由 `settings.js` 固定数组补齐。

qB-owned copy 走 `W.I18n` + source-proven official QM/bridge；WeiG-owned copy 继续走 WeiG i18n。Settings compound controls（例如 Listen port + Random、schedule From/To）仍是单个 canonical SettingRow 内的组合控件；测试按 source Preference → canonical row projection验证，不强迫“一 Preference = 一 DOM row”。

Locale bootstrap 必须同时尊重 browser locale、qB persisted `app/preferences.locale`、source-proven writable proof 与 `W.I18n` presentation 边界；只改 DOM 文字、W.I18n active locale 或 localStorage 都不能替代 qB persisted truth。

## 5. Torrent / Detail / Sidebar protected state

`W.TorrentSemantics`、`W.TorrentFieldRegistry`、`W.Selection/ActionRegistry`、`W.QbUiEvidence`、`W.SharedColumns`、`W.ColumnInteraction`、`W.VirtualList` 等既有唯一 owner 不变。Files 必须保持 qB response order 与 exact source file index；synthetic folder != qB source file；file/folder Rename provenance 独立；Tracker 使用 exact URL；Peer flags 本地 source-pinned；Copy browser-local；transport mutation 只经 QBClient；checked Tag removal 必须 exact `removeTagsAction`；unknown dangerous write 零 HTTP。

主 Torrent / Detail 滚动期间允许 polling 继续取得数据，但 canonical `W.VirtualList` 不得用新 snapshot 在 active scroll/drag 中替换当前 DOM；只保留 latest pending snapshot，idle 后一次提交。Detail Files 展开/收起继续以用户点击 folder row 的 viewport Y 为 anchor。

Sidebar ownership：

- `Status` 使用 qB-owned exact source text；状态项由 canonical Torrent filter semantics 决定。
- `Categories / Tags / Trackers` 的 label/source/context 属于 qB-owned；有效性由 release capability/provenance 决定。
- `Path` 是 WeiG-owned extension，永远位于 qB-native facets 之后。
- facet label 自身就是 canonical Select trigger；All 项只在展开列表内承担零筛选值。
- Select/Context Menu 共享 bounded floating geometry；长列表内部滚动，菜单不能越出 visual viewport。

## 6. RSS protected state

RSS feed/article 与 auto-download rule 是同一 RSS product family 下的 source-proven contracts：

- `rss/items` 是 feeds/articles current truth；article read-state 使用 qB 返回的 `isRead`，`markAsRead` 仅在 source action proof 存在时开放。
- Feed refresh/add/remove 与现代 refresh interval/url 等能力按 exact action contract出现。
- `rss/rules` 读取 current rules；`setRule / renameRule / removeRule` 分别经过 source-action descriptor，不能因为 RSS route 可用就整体放开写权限。
- `matchingArticles` 仅在 source证明的 release出现。
- 编辑已有 rule 时以 qB 返回 object 为 draft base，只修改 UI 实际拥有字段；未知/未来字段保留。
- Rule definition 可投影 must/must-not contain、regex、episode/smart filtering、affected feeds、category/tags/save path、ignore interval、start paused/stopped/content layout 等 source-returned字段。
- RSS route/runtime 不得形成第二套 navigation/polling/state/transport owner。
