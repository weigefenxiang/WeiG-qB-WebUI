## 7. “65/65 compatible”的正式含义

**65/65 compatible = 同一份 `webui/**` 对 65 个已验证 official stable 自动给出正确产品行为；不等于每个旧版本都拥有后来新增的 qB API。**

```text

qB 无能力     -> UI 隐藏/禁用/降级，transport 不盲发
future UNKNOWN -> 只关闭未证明 capability，危险写 HTTP 前 fail closed
```
