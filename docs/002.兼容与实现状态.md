## 5. v0.3.1 Scroll teardown hotfix

Lab A 实机反馈确认：底部 `Refresh HH:MM:SS` 每约 3 秒更新时，Torrent 列表也发生向上位移。时间文字本身不是滚动原因；它只是和主轮询同频，因此暴露了问题。

根因：

```text
polling
→ app renderList()
→ 旧列表 container 被清空
→ 浏览器产生瞬时 programmatic scrollTop=0
→ 旧 VirtualList scroll handler 仍可能收到这次 scroll event
→ __weiggVirtualScrollTop 被覆盖成 0/更小值
→ 新 VirtualList 恢复了错误位置
```

v0.3.1 修复：旧 scroll handler 在自己的 spacer 已从 active container 脱离时直接忽略 scroll event：

```text
!spacer.isConnected
或
spacer.parentNode !== container
→ 不更新 remembered scroll state
```

真实用户滚动仍正常更新 `__weiggVirtualScrollTop`。

同时隐藏底部 `Refresh HH:MM:SS`。DOM hook 暂时保留，以避免旧 controller 的 `last-refresh` 写入产生 null 错误；它不再作为产品 UI 展示。

## 6. v0.3 Stable Virtual UI

`VirtualList`：

- 在 container 上记录 `__weiggVirtualScrollTop`；
- 新 VirtualList 接管同一 container 时恢复用户滚动位置；
- 替换旧 scroll handler，避免轮询重建 listener leak；
- `setItems()` 默认 preserve viewport；
- 位置超过新数据最大高度时做 clamp；
- 暴露 `resetScroll()` 给 deliberate context change。

以下用户主动上下文变化才 reset：

```text
Filter / Tracker / Save Path / Category / Tag
Prev / Next page
Page size
Torrent search
```

普通 polling / manual Refresh 应保持当前位置。

## 8. Transfer Control Dock

Desktop 状态栏：

```text
↓ DL | ↑ UL | ALT | Connection | Torrent count | Transfer
```

`Refresh HH:MM:SS` 从 v0.3.1 起不再展示。

点击 ↓ / ↑ 可修改全局限速；ALT 切换备用限速；Transfer 打开 Session + Graph；Connection 继续打开 qB/WebAPI/Compatibility 详情。

### 跨版本 API

```text
GET  transfer/downloadLimit
POST transfer/setDownloadLimit
GET  transfer/uploadLimit
POST transfer/setUploadLimit
GET  transfer/speedLimitsMode
POST transfer/toggleSpeedLimitsMode
GET  transfer/info
GET  sync/maindata
```

`QBClient` 已封装：

```text

setGlobalDownloadLimit
getGlobalUploadLimit
setGlobalUploadLimit
getAltSpeedMode
toggleAltSpeedMode
getMainData
```

UI 不直接 fetch `/api/v2/*`。

## 9. Session Stats / Transfer Graph

已实现：

- 订阅现有 `getTransferInfo()`；
- 不新增第二个高频 transfer timer；
- ring buffer 最大 900 samples；
- 1 / 5 / 15 min；
- Session downloaded / uploaded；
- current Global DL / UL limit；
- DHT / Peer connections；
- `sync/maindata.server_state.free_space_on_disk` 可用时显示 free space；
