# 002. qBittorrent 兼容与实现状态

更新时间：2026-09-03  
当前产品版本：**0.3.7 dev candidate**

## 1. 支持边界

兼容目标：qBittorrent 4.1.9.1 floor -> 官方 4.x/5.x -> 当前稳定 5.2.x。版本差异集中在 `QBClient` 与 capability boundary；前端只有一套。

旧版缺 authoritative/低成本能力时默认明确降级；Collection/List 禁止默认 N items -> N API fallback。

## 2. Current-only boundary

WeiG 自身旧 release runtime/tests/deploy scripts 不保留兼容副本。文件名使用稳定职责名；历史恢复用 Git history / tags / Releases。

这不影响当前 qB/WebAPI compatibility facts：

```text
Minimum qBittorrent: 4.1.9.1
Private/PT: qBittorrent 5.0.0+
Tags: WebAPI 2.3.0+
Representative audit: qB 4.1.9.1 + 5.2.0
```

**此功能需要 qBittorrent 5.0.0+** 这类提示必须保留。

## 3. Dev / Release

普通 `dev`：current static/syntax/platform contracts + qB 4.1.9.1/5.2.0 upstream audit + `[ui]` focused Linux Chromium。

`main` candidate：full stable-tag audit + Linux/Windows browser matrix + exact-SHA packaging。Fixture PASS 不替代 daemon LIVE。

## 4. Private / PT

qB5：authoritative Private metadata -> `TorrentSemantics` -> filter/badge/detail。

qB4：Private/PT visible `5+` -> shared capability dialog -> filter unchanged -> 0 tracker scan -> 0 per-torrent privacy fallback。

## 5. Capability Matrix

| 能力 | qB 4.1.9.1 / 4.x | qB 5.0+ | 实现 |
| --- | --- | --- | --- |
| Resume/Pause | ✓ | ✓ | QBClient bridge |
| Global DL/UL limits | ✓ | ✓ | Native |
| ALT speed mode | ✓ | ✓ | Native + unit normalization |
| Logs | ✓ | ✓ | Native |
| Settings/responsive shell | ✓ | ✓ | Shared frontend |
| Private/PT filter | `5+` capability notice | ✓ | authoritative metadata + PT rules |
| Private badge/detail | unavailable without authoritative metadata | ✓ | TorrentSemantics |
| Tags | capability entry if WebAPI <2.3.0 | ✓ if WebAPI >=2.3.0 | QBClient capability + canonical Select |
| Search/RSS | capability | capability | WebAPI threshold |

Tags boundary = **WebAPI 2.3.0+**。Unsupported 时 `全部标签` 保持可见；open 只显示 shared dialog，不请求 Tags endpoint，不改变 filter。

## 6. Rate / Transfer

Canonical rate = B/s；NORMAL endpoint B/s；ALT preference KiB/s；QBClient read ×1024 / write ÷1024。

Transfer windows `1m/5m/15m/30m/1h/3h/6h/12h`；raw max 900；minute buckets max 720；long window 不增加 polling。

## 8. LIVE gate

Current exact `dev` SHA 在 qB 4.1.9.1 与 qB 5.2.x 两个真实实例验证。重点保持 qB4 capability degradation、qB5 native path、Tags threshold、route/settings、desktop/mobile、DHT/Peers idempotence、Connection truth、Reduced Motion、Transfer units/history。

任何 code/test/docs 变化产生新 candidate，旧 SHA 证据不继承。
