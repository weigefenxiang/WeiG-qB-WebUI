## 5. Logs 兼容状态

### 5.1 API floor

WeiG 支持范围内：

```text
qB >= 4.1.0 → logs=true
```

### 5.2 Timestamp normalization

`QBClient.logs()` / `peerLogs()` 统一输出秒：

```text
legacy milliseconds >= 1e12 → /1000
modern seconds               → unchanged
```

### 5.3 v0.3.6 newest-first

浏览器模型：

```text
ID descending
fallback timestamp descending
retain newest 5000
```

增量 API 仍发送：

```text
last_known_id = max ID
```

### 5.4 Follow latest

Newest-first 后：

```text
Follow ON  → top = latest
manual down-scroll → Follow OFF
Follow OFF + new rows → compensate scrollTop
```

用户查看旧日志时不会被轮询强行拉回顶部。

## 6. Client Time Zone

时区属于前端显示层：

```text
normalized epoch
→ W.Time
→ Intl.DateTimeFormat(timeZone)
```

首项为 System / Browser；浏览器支持时通过 `Intl.supportedValuesOf('timeZone')` 获得完整 IANA 列表。

存储：

```text
localStorage: weigg.timeZone
```

不会调用 `setPreferences()`，不会修改 VPS/qB 时区。

测试必须保证：

```text
visible time text may change
source epoch unchanged
<time datetime> unchanged
```

## 7. Canonical Select / Control

v0.3.6 不再依赖 OS 原生 popup 的视觉主题。Native `<select>` 可以作为 compatibility/data bridge，显示层通过 canonical Listbox 呈现。

验证：

```text
Dark / Light surface
Hover / Focus / Selected / Disabled
Arrow Up/Down
Home/End
Enter/Space
Escape
mobile-safe floating surface
```

Logs severity chips、Follow latest、Select 都使用 Components 层，不再 feature-local 造车。

## 8. AmbientMark

仅前端：

```text
orbit / spark / tilt / shine / breathe
```

调度随机且克制：大致 8–28 秒检查一次并允许跳过。页面隐藏停止；Reduced Motion 下不执行动画。

测试使用可注入 RNG/显式 trigger，避免 CI 依赖概率。

## 9. Torrent Detail context navigation

测试目标：

```text
Page 2 + list scroll
→ open Torrent Detail
→ local Back / Esc
→ Page 2 + same list scroll
```

直接 URL 打开 Torrent Detail 时没有内部 list context，因此 fallback 到 Torrent home，而不是任意外部 history。
