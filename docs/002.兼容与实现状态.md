# 002. 兼容与实现状态

> 本文件记录当前真实产品兼容状态。`webui/**` 是正式产品；source catalog、evolution audit、Virtual qB 和 browser fixtures 都是为了实现/证明正式产品兼容，不替代真实产品语义。

## 1. 正式支持范围与优先级

正式支持 floor：

```text
qBittorrent 4.1.0
-> 每一个 4.x official stable
-> 每一个 5.x official stable
-> 当前最新 official stable
-> 未来 5.x / 6.x / 7.x / x.x.x official stable
```

当前 source-derived stable matrix 已验证：

```text
qB 4.1.0 -> 5.2.3
65 个 official stable profiles
当前 audited WebAPI ceiling: 2.15.1
```

优先级固定为：

```text
P0 当前最新 stable 正确可用
P0 未来新 stable / 新 major 能自动进入发现、事实提取和产品验证
P1 qB 4.1.0 起所有历史 stable 保持兼容
P2 representative real-qB / promotion hardening
```

### qB 4.0.x

qB4.0.x / WebAPI v1 **不是当前实现、测试、CI 或阶段目标**。

只保留未来可选扩展原则：

```text
Legacy WebAPI v1 Adapter slot
-> canonical WeiG semantics
-> same UI
```

只有未来明确决定支持 qB4.0.x 时才实现。禁止为了这个低使用率旧版本牺牲当前/未来 stable 的开发优先级，也禁止把 v1/v2 分支散落到 UI、Settings、Torrent View。

### 4.1 Filters

产品 filter 现在按以下优先级解析：

```text
native upstream filter
-> normalized alias
-> reliable local derivation from source-proven Torrent fields/states
-> unavailable
```

qB4 的 `paused/resumed` 与 WeiG canonical `stopped/running` 继续统一；`stalled/checking/...` 在没有 native filter、但 source facts 足以可靠判断时使用已有 Torrent catalog 本地推导。

Native HTTP capability 不再有权隐藏一个可以可靠 local-derived 的产品 filter。

### 4.2 Category / Tags read 与 write 分离

现在正式拆成：

```text
Category/Tags read + facet + filter
!=
Category/Tags taxonomy endpoint / mutation actions
```

例如 qB4.1.0：

```text
torrents/info.category    source-proven -> Category facet 可用
torrents/info.tags        source-proven -> Tags facet 可用
native Tags taxonomy API  不存在         -> 不冒充 native list/write
Tags mutation actions     不存在         -> 写操作隐藏/拒绝
```

`SpatialRuntime` 的正式 UI owner 现在绑定：

```text
Category Select -> categoryFacet
Tags Select     -> tagFacet
```

而不是把 Tags facet 错误绑定到 native `tags` endpoint capability。

### 4.3 Torrent Actions

ReleaseProfile / Selection / QBClient 使用 exact source action facts。

已确认修复：

```text
Reannounce
Remove Tracker
```

在缺少 upstream action 的 release 上：

- UI 不暴露可点击动作；
- QBClient 再做一次 fail-closed；
- 不发送必然 404 的 HTTP 请求。

### 4.4 Performance

本地 derivation 复用既有批量 Torrent catalog；没有加入：

```text

```

Catalog 继续按批量 `torrents/info` 分页获取并多处复用。

## 7. 兼容规则

每项产品能力按顺序处理：

```text
1. NATIVE       upstream 直接支持
2. NORMALIZED   endpoint/名称/参数不同，由兼容层归一化
3. DERIVED      从已拥有且 source-proven 的数据可靠本地实现
4. READ_ONLY    能证明读取，不能证明写入
5. UNAVAILABLE  无法安全实现
6. UNKNOWN      未来未知 surface，尤其写操作 fail closed
```

禁止：

- presentation 中散落 qB version `if`；
- 因为 major 变成 6/7 就自动拒绝；
- 用版本号猜 source facts；
- 把 read capability 和 write capability 合并成一个 `true/false`；
- 点击后 404 才算“检测不支持”；
- 用 Simulator PASS 代替正式产品证明。
