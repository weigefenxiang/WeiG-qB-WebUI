## 3. v0.3.2 Logs 结论

### 修复 1：4.1.9 日志能力被错误隐藏

旧 capability：

```text
logs = WebAPI >= 2.3.0
```

因此 Lab A 的 WebAPI 2.2.1 被错误标记为不支持 Logs。

v0.3.2：

```text
logs = qBittorrent >= 4.1.0
```

在 WeiG 支持范围内，4.1.9、成熟 4.x、5.x 都显示 Logs。

### 修复 2：日志 timestamp 单位

`QBClient.logs()` 和 `peerLogs()` 现在统一输出秒：

```text
legacy milliseconds >= 1e12 → /1000
modern seconds               → unchanged
```

UI 只处理一个稳定时间 contract。

### 修复 3：Adaptive DataPanel

Logs 新页面：

```text
Auto    fill remaining workspace
Compact intentionally smaller panel
Max     maximize log workspace
```

并提供 VirtualList、增量 `last_known_id`、搜索、级别过滤、Follow latest 和 5000 条 bounded buffer。
