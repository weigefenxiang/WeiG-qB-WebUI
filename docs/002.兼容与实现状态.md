# 002. qBittorrent 兼容与实现状态

更新时间：2026-09-03  
当前产品版本：**0.3.7 dev candidate**

## 1. 支持边界

兼容目标：qBittorrent 4.1.9.1 legacy floor -> 后续官方 4.x/5.x -> 当前稳定 5.2.x。版本差异集中在 `QBClient` 与明确 capability boundary；前端只有一套。

### COMPAT-DEGRADE-001

旧版缺 authoritative/低成本能力时，默认明确降级，不进行复杂模拟。

### PERF-COMPAT-001

Collection/List 功能禁止默认 `N items -> N API requests` fallback。

## 2. Dev / Release 分层

普通 `dev`：smoke/static/syntax/platform contracts + qB 4.1.9.1/5.2.0 representative upstream audit + `[ui]` focused Linux Chromium。

`main` Release candidate：full stable-tag source/API audit + Linux/Windows browser matrix + exact-SHA packaging。

Fixture PASS 不替代真实 daemon LIVE。

## 3. Private / PT

qB5：authoritative Private metadata -> `TorrentSemantics` -> filter/badge/detail，0 per-torrent tracker requests。

qB4：Private/PT entry visible with capability notice `5+`。点击 shared capability dialog；filter unchanged。

运行时保证：

```text
0 legacy Private tracker scan
0 resolveMany
0 per-torrent privacy queue
0 DHT/PeX/LSD inference
```

## 4. Capability Matrix

| 能力 | qB 4.1.9.1 / 4.x | qB 5.0+ | 实现 |
| --- | --- | --- | --- |
| Resume/Pause | ✓ | ✓ | QBClient bridge |
| Global DL/UL limits | ✓ | ✓ | Native |
| ALT speed mode | ✓ | ✓ | Native + unit normalization |
| Logs | ✓ | ✓ | Native |
| Settings/responsive shell | ✓ | ✓ | Shared frontend |
| Private/PT filter | capability notice `5+` | ✓ | authoritative metadata + PT rules |
| Private badge/detail | unavailable if authoritative metadata absent | ✓ | TorrentSemantics |
| Tags | capability entry if WebAPI <2.3.0 | ✓ if WebAPI >=2.3.0 | QBClient capability + canonical Select |
| Search/RSS | capability | capability | WebAPI threshold |

Tags 边界是 **WebAPI 2.3.0+**，不是 qB5-only。Unsupported 时 `全部标签` 保持可见；click/open 只显示 shared dialog，不请求 Tags endpoint，不改变 filter。

## 5. Rate normalization

WeiG Transfer internal state = B/s。

```text
NORMAL endpoint qB native B/s -> canonical B/s
ALT preferences qB native KiB/s <-> QBClient <-> canonical B/s
```

Read ALT ×1024；write ALT ÷1024。Transfer UI 不直接碰 ALT preference keys。

## 6. Large-library progressive data

Current page 是 primary content；count/Facet index 是 background enrichment。

```text
spinner Page 1 · 50
→ exact Page 1 / N
failure -> ! Page 1 · 50
never ?
```

Native page 使用 `pageSize + 1` bounded look-ahead。

## 7. Transfer history

不增加 speed polling。Existing `getTransferInfo()` 被 canonical TransferRuntime 捕获。窗口 `1m/5m/15m/30m/1h/3h/6h/12h`；raw max 900；minute buckets max 720；history 只在当前 browser memory。

## 8. Modal Select

`W.Components.selectControl()` 同一 owner 支持 floating 与 `native:true`。Transfer modal 的 time window/rate unit 使用 native mode；Torrent Facets 使用 canonical floating mode。无第二 Select system。

## 9. Route / Torrent workspace compatibility

Route Frame 只有 `app.js` 一个 owner。Torrent workspace：

```text
Facet state            W.LibraryController
Facet presentation     W.SpatialRuntime
Select                 W.Components.selectControl()
Mobile placement       W.MobileAdaptive
DHT/Peers source       W.TransferRuntime / sync/maindata
Connection semantics   existing transfer cycle -> weigg:status-state
Connection UI          W.MobileAdaptive
Desktop geometry       css/layout.css
```

Desktop 数据工作台不再显示 Stats dashboard；同一 Stats Grid 是 Mobile Summary only。Desktop Footer durable state：Torrent count + storage + Transfer + Connection。`Refreshed / 已刷新` 仍禁止作为 persistent heartbeat。

Topbar 不再包含 qB passive product marker 或 manual Refresh；automatic polling 保留。

## 10. LIVE gate

新 exact `dev` SHA 在两个真实实例验证：Legacy qB 4.1.9.1；Modern qB 5.2.x。

重点：


任何 code/test/docs 变化产生新 exact candidate；旧 SHA 证据不继承。

## 12. Fixture / forward sentinel

Daily fast gate 固定 `4.1.9.1 + 5.2.0`。Release fixture matrix 可包含较新 5.x 代表节点，例如 **5.2.3**。

未来 major 只允许明确标记的 **synthetic / 哨兵 (sentinel)** fixture 做前向兼容检查；synthetic 不是实际支持声明，也不能替代真实 release audit。
