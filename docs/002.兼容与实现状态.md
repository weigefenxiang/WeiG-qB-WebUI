### 1.1 正式 compatibility scope anchors

正式兼容优先级始终是：

```text
qB 4.1.0+ official stable
-> current stable
-> future official stable / future new major
```

Future stable/new-major compatibility必须继续由 source-derived exact release facts、bounded inheritance与fail-closed UNKNOWN驱动，不能因为 major更高就整体拒绝，也不能盲继承 current latest 的危险写语义。

`qB 4.0.x` 不是当前实现/CI scope；未来可选扩展只能经用户明确扩大范围，并通过集中 Legacy Adapter进入 canonical WeiG semantics，禁止把 WebAPI v1/v2 patch分支散落到UI/caller。

验证职责继续分开：Linux/Windows browser candidate提供代表性跨平台浏览器证据；Full qB Release compatibility audit / all-stable upstream source audit证明完整 admitted stable source/product compatibility；需要真实 runtime/hosting 的行为还必须由 real-qB evidence证明。任何一层PASS都不能自动替代另一层。

## 3. 0.3.76 DataGrid 原生列正式消费

### 3.1 Source truth

Exact source/LKG已生成并保留 `torrentTableColumns`：

```text

```

正式产品链：

```text

```

对 exact/certified profile，这份 source schema 是 Desktop DataGrid column set/defaults 的 authoritative input。旧 legacy registry只保留 semantic/fallback职责，不再限制 exact release 的原生列集合。

### 3.2 User override / 非破坏迁移

用户状态是 override：

```text
key
width
visible
layoutVersion: 2
```

规则：

- 旧用户显示/隐藏、宽度与可识别顺序尽量保留；
- `state/status` 等通过已证明的 `dataProperties` 做 canonical mapping；
- qB 新增 exact native column按source-relative位置合入；
- 无用户override的新列使用 upstream `defaultVisible/defaultWidth`；
- 暂时不存在的saved preference不因effective view被删除；
- FALLBACK/UNKNOWN不宣称native column parity。

Source-only native column使用现有 torrentInfo object 的source/dataProperty值渲染，不因为不在旧固定字段表就只显示 `—`。

### 3.3 Interaction / sort 边界

Columns interaction仍由：

```text
app.js -> openColumns()
```

单一 owner负责 checkbox、↑/↓、Desktop drag、Android 360ms long-press drag。Android长按激活前移动超过阈值会取消drag，普通纵向滚动仍交给浏览器。没有MutationObserver、monkey patch、post-render repair或第二layout owner。

Field presence不等于server-sort proof；source-only column默认不得发明server sort。

## 4. 0.3.77 Transfer / Locale / Tracker 当前产品语义

### 4.1 Transfer owner不变

现有 app transfer cycle仍通过同一个 `transfer/info`取得：

```text
dl_info_data / up_info_data        session cumulative totals
dl_info_speed / up_info_speed      realtime rates
connection_status                  connection state
```

`W.TransferRuntime`继续只保存bounded realtime samples/history与现有metadata snapshot，不新增request、timer、poll owner或第二state store。

### 4.2 Transfer presentation

Canonical compact transfer capsule仍只显示session cumulative totals；Drawer compact chart legend同样totals-only。

完整Transfer statistics dialog删除图表上方重复summary strip，唯一Download/Upload summary位于chart下方：

```text
left:  ↓ <realtime download> | 下载 <session downloaded>
right: 上传 <session uploaded> | ↑ <realtime upload>
```

Desktop/Mobile复用同一组节点；窄屏只自适应换行/收缩，不恢复旧第二summary owner。

Display-only smoothing：

```text
default: 10 s
choices: Raw / 3 / 5 / 10 / 15 / 20 / 30 s
```

长窗口继续使用bounded minute buckets，不增加poll/history。

### 4.3 Native WebUI return locale/root handoff

Persisted language truth仍只有：

```text
qB app/preferences.locale
```

当同一次verified Settings save把 `alternative_webui_enabled`切为false时，`W.SessionController`可在Alternative root仍active时先写/验证临时locale，完成root switch后再写/验证最终目标locale。

该transaction不保存 `previousLocale`，不做exit restore，不创建第二language owner。若用户同一次save明确选择locale，该locale必须保持final target。

### 4.4 Tracker detail exact URL

qB upstream `TorrentsController::trackersAction()` 对普通Tracker直接把 `tracker.url`放进API JSON；`[DHT] / [PeX] / [LSD]`为特殊entries。

Torrent detail的Tracker display/edit直接消费 exact API `url`，不再通过 `U.normalizeTracker()`。长URL使用variable-height + wrap，编辑prompt以exact URL为初值。Facet/domain分类可继续使用归一化，但不得覆盖详情exact URL truth。
