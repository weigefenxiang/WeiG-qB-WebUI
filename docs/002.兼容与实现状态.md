## 4. Compatibility resolution rules

统一状态：

```text
NATIVE
NORMALIZED
DERIVED
READ_ONLY
UNAVAILABLE
UNKNOWN
```

优先级：

```text
NATIVE
-> NORMALIZED / ADAPTER
-> reliable old-API composition
-> reliable DERIVED
-> READ_ONLY when applicable
-> UNAVAILABLE
```

future `UNKNOWN` 只关闭无法证明的具体 capability，尤其危险写操作。

禁止：

- 因 major 变成 6/7 就整体拒绝；
- 因版本更高就自动继承 current latest semantics；
- 用版本号猜 source facts；
- read/write 粗粒度合并；
- 点击后 404/501 才算检测不支持；
- N items -> N compatibility requests；
- presentation self-probe / second state / duplicate polling；
- 用 Simulator PASS 代替 formal product / real-qB evidence。
