# 003. WeiG qB WebUI 项目架构

Status: **Architecture authority for v0.3.0+**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文负责“文件放在哪里、谁依赖谁、每层允许做什么”。视觉/交互看 `DESIGN.md`；产品硬规则看 `001.项目总方案.md`；实时兼容状态看 `002.兼容与实现状态.md`。

## 1. 架构目标

```text
qB API/version differences → QBClient + Capability
Torrent/business state     → Application Controller
DOM primitives             → Components/Core
Large-list mechanics       → VirtualList/DataGrid
Settings semantics         → SettingsSchema/Translations
Global i18n                → i18n.js
v0.3 feature translations  → i18n-v030.js overlay
Navigation/i18n bridge     → UX layer
Spatial composition        → Spatial layer
v0.3 interaction surfaces  → v030 runtime layer
Visual material            → CSS layers
Install/backup/rollback    → Installer
```

硬约束：

```text
UI / Spatial / Components / v030
        × 不直接散落 fetch('/api/v2/...')
        × 不直接写 qB 主版本特例
        × 不建立第二份 Torrent canonical state
        × 不直接写 locale 分支

QBClient
        ✓ 唯一 API contract/compatibility boundary

Application Controller
        ✓ Torrent filter/page/selection/catalog/settings canonical state
```

## 3. 运行时依赖方向

```text
public/login.html
        ↓ authenticated
private/index.html
        ↓
i18n.js
        ↓
core.js
        ↓
settings-schema.js + settings-translations.js
        ↓
qb-client.js
        ↓
components.js
        ↓
app.js + ux-v021.js
        ↓
spatial-v022.js
        ↓
i18n-v030.js
        ↓
v030.js
```

`components.js` 动态加载 Spatial/v0.3 assets，并用 `?v=0.3.0` cache-bust。`i18n-v030.js` 必须先于 `v030.js` 完成加载，Runtime 只请求语义 key。

长期目标不是无限增加 `v031.js/v032.js`；稳定后应把成熟能力回收到 canonical feature/component/css/i18n 模块。

## 4. `i18n.js` / `i18n-v030.js`

`i18n.js` 负责全局：

- English canonical dictionary；
- zh-CN maintained overlay；
- browser locale detection；
- explicit user override；
- English fallback；
- language-change event。

`i18n-v030.js` 是 v0.3 功能的**独立翻译 overlay**，把 Transfer Dock / Global Limit / Session Graph 文案与 Runtime 分离。

```text
Feature Runtime
   ↓ semantic key
Translation overlay
   ↓
English canonical / zh-CN
```

Feature 不允许：

```js
if (locale === 'zh-CN') ...
```

`QBClient` canonical error 也不能只写中文。

## 5. `core.js`

核心无业务 primitive：

```text
formatters
DOM helpers
Config
Router
Tooltip
VirtualList
DataGrid
Tracker normalization
```

### VirtualList v0.3 contract

- viewport + overscan；
- mounted row count 与 data count 解耦；
- container-scoped `__weiggVirtualScrollTop`；
- 替换旧 scroll listener，防止 listener leak；
- `setItems()` 默认 preserve scroll；
- scroll clamp；
- `resetScroll()` deliberate reset。

```text
Data count != DOM count
Poll update != scroll reset
```

目前 `app.js` 仍可能重建 VirtualList object，但同一主 list container 会恢复稳定 scroll state。后续 Controller 拆分时可进一步真正长期复用 main VirtualList；禁止退化 SCROLL-001。

## 6. `qb-client.js`

这是**唯一 qB WebAPI/版本兼容边界**。

职责：

- request / form / JSON / blob transport；
- qB/WebAPI version detect；
- Capability profile；
- 4.x ↔ 5.x action bridge；
- Torrent API；
- Transfer API；
- Settings；
- Search/RSS/Logs；
- modern API foundations。

### 6.1 版本桥

```text
4.x resume ↔ 5.x start
4.x pause  ↔ 5.x stop
4.x paused ↔ 5.x stopped
```

### 6.2 v0.3 Transfer API

```text
getTransferInfo()
getMainData()
getGlobalDownloadLimit()
setGlobalDownloadLimit()
getGlobalUploadLimit()
setGlobalUploadLimit()
getAltSpeedMode()
toggleAltSpeedMode()
```

Feature 层不得重复构造 endpoints。

### 6.3 Capability foundation

```text
globalSpeedLimits
altSpeedLimits
mainData
sessionStats
cookies
torrentCreator
```

`cookies` / `torrentCreator` 当前代表 API foundation，不代表完整 UI 已完成。

## 7. `settings-schema.js` / `settings-translations.js`

把 qB Preference raw key 映射到：

```text
canonical English label
description
control type
category/section
units/options
localized copy
```

普通 Settings 不直接展示 `auto_tmm_enabled`、`save_path` 等 raw identifier。

## 8. `components.js`

Canonical DOM components：

- Torrent row；
- Mobile Torrent Card；
- Status Pill；
- Progress；
- KV；
- Settings Preference Field；
- runtime CSS/JS layer loader。

Component 接收 model data，不自己调用 qB API。

Runtime loader 顺序：

```text
v022.css + v030.css
spatial-v022.js (independent)
i18n-v030.js
   onload ↓
v030.js
```

## 9. `app.js` — Canonical Application Controller

Canonical state：

```text
client
filter
tracker
category
tag
savePath
page/pageSize
torrents
catalog
selected
search/sort/reverse
columns
settings state
route/detail state
poll timers
```

负责：loadPage/Catalog、selection、filters、paging、Torrent actions、detail tabs、Settings、Search/RSS/Logs、poll scheduling。

### 当前技术债务

`app.js` 仍偏大，而且一个 `app.virtual` 引用会被不同 detail/log list 复用。后续应拆：

```text
features/torrents
features/detail
features/settings
features/search
features/rss
features/logs
```

迁移 ownership，不复制 state。

## 10. `ux-v021.js`

过渡 UX bridge：

- Topbar application navigation；
- contextual search；
- Settings search/metadata presentation bridge；
- mobile bottom navigation；
- 旧动态 copy 向 canonical i18n 迁移期间的兼容逻辑。

它不能膨胀成第二个 app controller。

## 11. `spatial-v022.js`

Spatial Composition：

- Filter Shelf；
- Tracker/Path/Category/Tag facet popover；
- Connection Dock；
- Settings card polish；
- Wei.G branding injection。

只移动/包装已有 DOM，不拥有 Torrent/filter canonical state。

## 12. `v030.js`

v0.3 Interaction Runtime：

```text
Deliberate scroll-reset boundaries
Compact Empty State observer
Centered Transfer Dock composition
Global DL/UL speed-limit dialog
Alternative speed mode
Transfer/session dialog
Bounded Transfer Graph samples
Rendered-row Ctrl/Cmd/Shift selection bridge
```

### v030 不拥有

```text
× Torrent catalog
× current filter
× canonical selected Set
× qB version branching
× language dictionaries
× Settings source of truth
```

Transfer Graph data flow：

```text
app loadTransfer()
  ↓ QBClient.getTransferInfo()
wrapped once at prototype
  ↓ weigg:transfer event
v030 bounded ring buffer — MAX 900 samples
  ↓ Canvas only when needed
```

不启动第二套高频 transfer poller。

## 13. CSS ownership

### `app.css`
Canonical tokens + base primitives + stable shell。

### `v021.css`
Topbar/i18n/Settings UX bridge。

### `v022.css`
Nebula Spatial：Surface hierarchy、Filter Shelf、Connection Dock、Settings cards、raised inputs。

### `v030.css`

```text
Compact empty state
Centered Transfer Dock
Global speed dialog
Session stat cards
Transfer chart shell
v0.3 selection feedback
```

长期应归并成熟规则，不允许无限叠版本 CSS。

## 14. API 调用规则

允许：

```text
app/feature → QBClient.someSemanticMethod()
v030 → QBClient transfer semantic methods
```

禁止：

```text
component → fetch('/api/v2/...')
CSS/spatial → API
feature → hard-coded qB major branches
```

## 15. Compatibility matrix tests

`tests/compat-v030.mjs`：

```text
4.1.9.1 / WebAPI 2.2.1
4.6.x   / WebAPI 2.8.3
5.2.0   / WebAPI 2.14.1
```

断言 capability、resume/pause ↔ start/stop、paused ↔ stopped、Global DL/UL、ALT、sync/maindata、Cookie/Creator gate。

Fixture 验证 contract，不是 live server certification。

## 16. Installer boundary

```text
installers/install.sh / install.ps1
        ↓
backup
payload validation
atomic replacement
optional Alternate UI configuration
rollback metadata
```

普通安装不修改 WebUI credentials。Docker 多实例必须明确选择。

## 17. 架构演进优先级

```text
1. 实机验证主 VirtualList 滚动稳定
2. app.js 拆 Feature Controllers
3. canonical i18n 清理剩余动态硬编码
4. RSS Rule Editor / Search Plugin Manager
5. Torrent Creator 完整 Feature（capability gated）
6. Cookie Manager 完整 Feature（capability gated）
7. mature v021/v022/v030 rules 回收到 canonical modules
```

任何重构必须保证：4.1.9 floor、5.x capability、English/简体中文、Tracker privacy、Virtual DOM、NAV-001 和 Installer rollback 不退化。
