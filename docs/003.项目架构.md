# 003. WeiG qB WebUI 项目架构

Status: **v0.3.7 Semantic Ownership 3.7**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义运行时层次、数据流、模块边界与 Current Owner。视觉/交互总规则以根目录 `DESIGN.md` 为最高 authority；兼容、UI/缓存、v0.3.7 实现、发布边界和 Torrent 工作区分别见 `002`、`004`、`005`、`006`、`008`。

## 1. 总体数据流

```text
qB WebAPI
  ↓
QBClient
  ├─ endpoint compatibility
  ├─ capability normalization
  └─ API-unit normalization
  ↓
canonical business/data owner
  ├─ AppState / LibraryController / Route Frame
  ├─ SettingsState
  ├─ Selection
  ├─ TorrentSemantics
  ├─ TransferRuntime
  └─ SessionController
  ↓
semantic events / source DOM
  ↓
canonical components + shared UI primitives
  ↓
layout / responsive / visual presentation
```

核心边界：

```text
business owner produces state
presentation owner consumes state
DOM is not application state
behavior owner != permission for feature-local skin
Data count != DOM count
capability missing != permission to emulate expensively
retired caller != archive
```

## 3. QBClient boundary

`QBClient` 是唯一 endpoint/版本/API-unit adapter。

业务 owner 可发请求：

```text
app.js          torrent page/catalog + existing transfer info cycle
settings.js     preferences
selection.js    user-command / intentional all-matching operation
transfer.js     maindata telemetry + rate APIs
session.js      auth/session state machine
```

Presentation-only runtime 禁止创建独立 qB client/API timer：

```text
responsive.js
spatial.js
layout.js
polish.js
ux.js
```

### RATE-UNIT-001

业务层 rate 统一 **B/s**：

```text
NORMAL transfer limit endpoint: B/s -> B/s
ALT preferences: KiB/s <-> QBClient <-> B/s
```

`transfer.js` 不直接读写 `prefs.alt_dl_limit / alt_up_limit`。

## 4. Capability degradation

缺能力时先评估是否存在 authoritative/batch path。若忠实模拟需要 O(N) 或 N-per-item 网络工作，默认 capability degradation。

qB4 Private/PT：

```text
entry visible + 5+
click -> shared capability dialog
0 filter mutation
0 tracker scan
0 per-torrent queue/cache crawler
```

Tags：

```text
QBClient.capabilities.tags = WebAPI >= 2.3.0
unsupported -> control stays visible
open -> shared capability dialog
0 tag state mutation
0 unsupported Tags request
```

## 5. Explicit lifecycle

First-party runtime 不用 `MutationObserver` 做 ownership/repair。

```text
app.js
  weigg:library-state
  weigg:status-state
  weigg:route-state

settings.js
  weigg:settings-render

transfer.js
  weigg:transfer
  weigg:maindata

shared
  weigg:languagechange
  weigg:configchange
```

消费者只重算自己拥有的 presentation；不通过 DOM 文本反推 business state。

## 6. Stable semantic runtime assets

运行时按职责命名，不按版本命名。

禁止：

```text
*-vNNN.css/js runtime
vNNN runtime owner
old-name alias/shim
old + new 同时加载
hidden loader
Observer reclaim
unreachable retired caller
```

Cache identity：`stable semantic path + exact Git SHA`。

## 7. Route Frame architecture

### ROUTE-OWNER-001

`app.js` 是 Route Frame 唯一 presentation owner。一次 transition 原子同步：

```text
active View
Top Nav
Mobile Nav
Torrent Sidebar visibility
tool-route workspace scope
Back
drawer close
weigg:route-state
```

Settings、RSS、Search、Logs、Torrent detail 等 tool route 不保留 Torrent Sidebar。

`ux.js` 只处理文本；`spatial.js` 只处理 Facet；Settings 只处理自身内容/Tab/保存。

## 8. Torrent workspace architecture

### FACET-OWNER-001

```text
facet business state  -> W.LibraryController
facet UI composition  -> W.SpatialRuntime
Select primitive      -> W.Components.selectControl()
Select skin           -> css/ui.css
mobile placement      -> W.MobileAdaptive
```

Retired：

```text
filter-shelf
facet-trigger / facet-popover / facet-search
tracker/savepath/category/tag hidden nav trees
filter-shelf qBittorrent summary
```

Desktop Sidebar 在 Private/PT 下直接显示四个 canonical Select；无重复外部标签。Mobile 移动同一个 `#facet-controls`，不 clone。

### PRESENTATION-STATE-001

`page-title`、`library-count-copy`、hidden nav 文本不能作为 mobile/selection state source。`Selection.currentQuery()` 消费 `LibraryController.state()`。

## 9. Canonical Select / control skin

`W.Components.selectControl()` 同一入口支持：

```text
floating mode
native:true mode
onOpen capability guard
```

### CONTROL-SKIN-001

共享 Select skin 唯一 owner `css/ui.css`。业务 CSS 只能给 geometry variable。

### NATIVE-THEME-001

Native Select/option 显式跟随 resolved `html[data-theme]`，Dark 不得退回白色 browser default。

## 10. Canonical Dialog

### DIALOG-SCROLL-001

```text
outer dialog shell  overflow:hidden
head                intrinsic
body/form/list      only real overflow scrolls internally
actions             intrinsic
```

Capability、Transfer、Prompt 等都消费同一 shell。业务只提供 `--dialog-*` geometry。

## 11. Selection architecture

`W.Selection` 唯一拥有 selected Set、range anchor、Page/All Matching、Ctrl/Cmd、Shift、Ctrl/Cmd+A、Escape 与 toolbar state。

```text
row/card non-interactive -> selection
title -> detail only
right-click -> ActionRegistry
mobile long press -> same ActionRegistry
More -> same ActionRegistry
```

移动 touch target >=44×44。

### OWNER-RETIRE-001

Canonical API 删除时 caller/shim/no-op hook 同批删除。Selection 不保留 `resolveMany` 或旧 Facet DOM query。

## 12. Progressive paging/catalog

```text
page request = pageSize + 1
first page render immediately
catalog/index runs in background
unknown total -> spinner, never ?
resolved -> exact X / Y
failure -> ! but page remains usable
```

总数只 filter catalog，不为 count 完整排序 catalog。

## 13. Transfer telemetry

`W.TransferRuntime`：

```text
existing getTransferInfo stream -> speed samples
RAW_MAX = 900
minute bucket = 720 max
one sync/maindata rid lifecycle -> DHT / peers / free space
```

窗口：`1m / 5m / 15m / 30m / 1h / 3h / 6h / 12 h`。

### TELEMETRY-PAINT-001

DHT/Peers 只有：

```text
sync/maindata
→ W.TransferRuntime
→ weigg:maindata
→ app.js Network renderer
```

`loadTransfer()` 不写 DHT/Peers。Renderer 发现 formatted value 未变化时不写 DOM。

## 14. Layout ownership

### LAYOUT-OWNER-001

`css/layout.css` 拥有非 Settings shell/Torrent/Footer geometry。

Desktop Torrent：

```text
Stats
TorrentPanel flex:1
  GridToolbar
    page/columns
    Start Pause More Delete
    Expand
  Header
  TorrentList flex:1 internal scroll
  Pager
```

无 Library title block、无 main filter shelf。动作顺序固定 `Start -> Pause -> More -> Delete -> Expand`。

Footer named areas：

```text
"torrent storage transfer message"
```

没有 persistent Connection/Refresh area。

## 15. Status semantics

### STATUS-NOISE-001

后台成功 refresh 静默，不写 `已刷新`/timestamp。

### STATUS-DEDUP-001

Network card 已拥有 connection state，因此 Footer 不重复 `已连接`。Footer 只保留 Torrent count、Free space、Transfer capsule 与 transient actionable message。

Torrent refresh failure 与 Transfer failure 采用 source-scoped transient status；一个子系统成功不能误清另一个仍存在的错误。

## 16. Session / auth

```text
SessionController.logout
→ auth/logout
→ protected endpoint probe
→ invalid session required
```

Back/BFCache fail-closed。

## 17. Test architecture

Static tests验证 owner/retirement；browser tests 必须执行真实动作。

```text
Tracker Select click -> state transition
unsupported Tags click -> capability dialog + no state/request
qB4 Private click -> 5+ dialog + no tracker request
same DHT/Peers event twice -> zero mutation
Desktop toolbar order
Topbar one row
same Facet/action DOM on mobile
Footer no Refreshed/Connected
```

## 18. Exact-head / Release boundary

### EXACT-HEAD-001

任何 LIVE/Release 结论都绑定一个 40-char exact SHA。代码、测试或 docs 变化立即使旧 candidate 失效。

`dev` 只做 representative smoke/UI/upstream audit；完整 Linux/Windows + stable-tag matrix + packaging 是 `main` Release-only。真实 qB 4.1.9.1 与 5.2.x LIVE 通过且 maintainer 明确授权前不晋级 `main`。
