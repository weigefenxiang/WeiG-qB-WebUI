Status: **v0.3.6 architecture authority**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义文件、运行时层次和 ownership。视觉/交互规则看 `DESIGN.md`；产品规则看 `001.项目总方案.md`；兼容状态看 `002.兼容与实现状态.md`；专项 UI/缓存契约看 `004.UI与缓存契约.md`。

## 1. 总体数据流

```text
qB WebAPI
  ↓
QBClient + capability + normalization
  ↓
application state
  ↓
canonical Components / VirtualList / DataGrid
  ↓
feature composition
  ↓
canonical CSS layers
```

硬边界：

```text
QBClient
  ✓ API contract / compatibility / old-new vocabulary bridge

Application Controller
  ✓ Torrent/Search/RSS/Settings/business state

Components/Core
  ✓ DOM primitive / VirtualList / DataGrid / canonical control

Feature runtime
  ✓ compose behavior
  × no qB-major scattered gate
  × no duplicate primitive
  × no fabricated backend data

Deploy layer
  ✓ VERSION / GIT_SHA / weigg-install.json
  ✓ exact Git-SHA asset identity
```

关键不变量：**Data count != DOM count**。

## 3. Bootstrap / Cache ownership

`private/index.html` 是 canonical bootstrap，直接 CSS/JS 使用：

```text
?v=__WEIGG_GIT_SHA__
```

部署时替换为精确 Git SHA。

`components.js` 提供：

```text
<meta name="weigg-build-sha">
      ↓
currentBuildToken()
      ↓
buildAssetUrl(path)
```

lazy runtime 包括：

```text
spatial-v022.js
v030.js / v030.css
v036.js / v036.css
brand-v031.css
```

`adaptive-v036.js` 是 bootstrap 前置的移动/存储适配层，并在 v036 base runtime 就绪后通过 `buildAssetUrl()` 装载 `advanced-v036.js`。

## 4. `core.js`

负责 utility、Config、Router、VirtualList、DataGrid。

### VirtualList

Torrent viewport 使用：

```text
__weiggVirtualScrollTop
__weiggVirtualScrollHandler
```

轮询或隐藏/显示页面不得把用户概念位置无意归零。Torrent Detail 返回也依赖该位置契约。

## 5. `qb-client.js` / QBClient

`QBClient` 是唯一 qB WebAPI compatibility boundary：

```text
4.x resume/pause ↔ stable start/stop semantics ↔ 5.x start/stop
legacy log milliseconds → normalized seconds ← modern seconds
Preference field presence → feature availability
```

feature/UI 不直接散落 major-version 判断。

`getMainData(rid)` 同时服务主状态和低频 storage telemetry；后者读取 `server_state.free_space_on_disk`，使用自己的 incremental RID，不伪造 VPS root filesystem 信息。

## 6. `components.js`

Canonical owner：

```text
preferenceField / readonlySettingField
Select / Listbox
upgradeNativeSelect(s)
FilterChip
CheckControl
Time formatter (`W.Time`)
asset-build helpers
```

Floating Select 的视觉菜单通过 v036 的 body-level FloatingLayer portal，避免业务容器 clipping。

## 7. `v036.js`

负责：

```text
FloatingLayer collision manager
AmbientMark scheduler
Global Display Time Zone status control
Torrent Detail context Back
Escape priority
Settings timezone bridge
```

状态栏 timezone 是唯一全局选择器。Logs 只消费 `W.Time` 与 timezone change event。

## 8. `adaptive-v036.js` + `mobile-v036.css`

共同拥有 **MOBILE-001**：

```text
App Shell grid
  → Workspace remaining track
  → active page flex ownership
  → explicit data viewport scroll
```

禁止 `100vh - magic pixels`。

该层还负责：

- mobile Torrent VirtualList row metrics；
- one-line Torrent secondary metadata compact/fit；
- semantic StatusPill tones；
- Search/RSS/Logs one-screen tool-page behavior；
- free-space status telemetry；
- `advanced-v036.js` 的时序加载。

## 9. `advanced-v036.js`

这是 source-verified Advanced display semantics 层。它不改变 qB 的真实 Preference contract，只负责：

```text
raw API value
  ↕ exact conversion
human-readable display unit
```

例：

```text
torrent_file_size_limit  104857600 bytes ⇄ 100 MiB
socket_receive_buffer     65536 bytes    ⇄ 64 KiB
disk_queue_size           1048576 bytes  ⇄ 1024 KiB
```

同时添加已验证的单位、`0` 特殊语义和 readable enum Select。

## 10. Logs

文件：

```text
logs-v032.js
logs-v032.css
```

数据 contract：

```text
newest first
max 5000
incremental last_known_id=max(ID)
VirtualList viewport only
```

Logs 不再拥有 route-local timezone selector；它使用 status dock 的全局 Display Time Zone。

## 11. Settings

```text
settings-schema.js
settings-translations.js
settings-v034.js
advanced-v036.js
```

`settings-v034.js` 继续拥有 Alternative WebUI 的路径/关闭安全逻辑和 `weigg-install.json` metadata 展示，但视觉必须复用 canonical SettingCard。

`advanced-v036.js` 只增加已验证的单位/enum/round-trip，不允许根据 key 名猜单位。

## 12. Transfer / v0.3 layer

```text
v030.js
v030.css
```

Transfer graph 是 bounded browser telemetry，**MAX 900** samples。它不创建大 chart dependency，不把隐藏 chart work 当后台任务持续运行。

## 13. Spatial / branding layer

`spatial-v022.js` 负责长期空间结构、Filter Shelf、Connection Dock 与 branding attachment。品牌 CSS 仍通过 build SHA 加载；AmbientMark 的随机短动画由 v036 runtime 负责。

## 14. Internationalization

Canonical source language：**English**。维护语言：**English / 简体中文**。

Feature runtime 请求 semantic key，不允许按 locale 写两套业务分支。缺失翻译回退 English。

## 15. Compatibility fixtures

Canonical file：

```text
tests/fixtures/qb-compat-matrix.json
```

完整 release matrix 包含 4.1.9.1 → 5.2.3、upstream/master，以及一个 synthetic 6.x forward-major sentinel。sentinel 只检测错误硬编码，不代表官方 6.x 支持。

## 16. Automated gates

```text
npm test
  smoke
  compatibility
  Logs API contract
  Alternative WebUI contract
  cache contract
  canonical UI contract
  mobile contract
  Advanced unit/enum round-trip

Chromium
  browser-logs-v033.mjs
  browser-settings-v034.mjs
  browser-mobile-v036.mjs
  browser-ui-v036.mjs
```

`browser-ui-v036.mjs` 跑 12 compatibility nodes × mobile/desktop/wide。`browser-mobile-v036.mjs` 额外覆盖 320×568 / 360×800 / 390×844 / 430×932。

## 17. Live deployment/certification

`tests/live-v036.sh` 是 v0.3.6 Final Candidate 的双实例无重启测试部署器：

```text
/root/qbittorrent/config/weigg-qb-webui
/root/qbittorrent3/config/weigg-qb-webui
```

它要求 exact SHA，先 staging/validation，再 atomic switch，生成备份与回滚命令，不执行 Docker/qB restart。

自动 fixture 只能证明 deterministic contract；真实 4.1.9.1 / 5.2.x 仍是 release-blocking LIVE Gate。
