# 003. WeiG qB WebUI 项目架构

Status: **v0.3.7 Semantic Ownership 3.7**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义运行时层次、数据流、模块边界与 Current Owner。视觉/交互总规则以根目录 `DESIGN.md` 为最高 authority；兼容、UI/缓存、v0.3.7 实现与发布边界分别见 `002`、`004`、`005`、`006`。

## 1. 总体数据流

```text
qB WebAPI
  ↓
QBClient
  ├─ endpoint compatibility
  ├─ capability normalization
  └─ API-unit normalization
  ↓
canonical business/data owner
  ├─ AppState / Route Frame / query / paging / catalog
  ├─ SettingsState
  ├─ Selection
  ├─ TorrentSemantics
  ├─ TransferRuntime
  └─ SessionController
  ↓
source renderer / semantic events
  ↓
canonical components + layout owners
  ↓
responsive / visual presentation
```

核心边界：

```text
business owner produces state
presentation owner consumes state
DOM mutation is not an event bus
Data count != DOM count
capability missing != permission to emulate expensively
```

## 3. QBClient boundary

`QBClient` 是唯一 endpoint/版本/API-unit adapter。

允许由业务 owner 发起 qB 请求：

```text
app.js          torrent page/catalog + app poll
settings.js     preferences read/save
selection.js    commands / intentional all-matching scan
transfer.js     transfer telemetry + rate APIs
session.js      auth/session state machine
```

Presentation-only runtime 禁止创建独立 qB client 或 API timer：

```text
responsive.js
spatial.js
layout.js
polish.js
ux.js
```

### 3.1 Rate unit normalization

WeiG 业务层统一使用 **B/s**。

```text
NORMAL transfer/uploadLimit, transfer/downloadLimit
  qB API unit = B/s
  QBClient exposes B/s

ALT preferences.alt_up_limit, preferences.alt_dl_limit
  qB preference unit = KiB/s
  QBClient converts KiB/s <-> B/s
```

`transfer.js` 不得直接读写 `prefs.alt_*_limit` 再自行乘除 1024。

## 4. Capability degradation

兼容目标是“保持正确、低成本的能力边界”，不是在旧版本上伪造所有新能力。

硬规则：

```text
feature requires missing upstream capability
+ faithful emulation would require O(N) / N-per-item network work
=> do not emulate by default
=> keep entry when useful
=> show neutral minimum-version capability notice
=> recommend upgrade only when user wants the feature
=> remind backup before upgrade
```

除非开发者再三确认功能极其必要，并且明确接受性能预算，否则不得把逐种子请求、后台 crawler、长期 cache queue 当兼容方案。

## 5. Explicit lifecycle

First-party runtime 不使用 `MutationObserver` 做 ownership/repair。跨模块同步通过明确事件：

```text
app.js
  weigg:library-state
  weigg:status-state
  weigg:route-state

settings.js
  weigg:settings-render

transfer.js
  weigg:transfer
  weigg:maindata

shared
  weigg:languagechange
  weigg:configchange
```

消费者只刷新自己拥有的 presentation，不重包源 DOM、不从 DOM 猜 business state。

第一方 runtime 文件按职责命名，不按版本命名：

```text

scripts/qb-client.js
scripts/components.js

scripts/settings.js

scripts/transfer.js
scripts/layout.js
```

```text

```

## 7. Route Frame architecture

`app.js` 是 Route Frame 唯一 owner，一次提交以下状态：

```text
active view
Top navigation active state
Mobile navigation active state
sidebar/tool-route visibility scope
Back button state
drawer close
weigg:route-state
```

`ux.js` 只消费 route 生命周期做文本/上下文同步；`spatial.js` 只负责 facet/connection presentation。两者不得再写 route active class 或 `.is-tool-route`。

Settings、RSS、Search、Logs、Torrent detail 等 tool route 必须退出 Torrent sidebar shell，避免“设置页仍残留下载中/做种/Private 等筛选”的半路由状态。

## 8. Settings architecture

Canonical pipeline：

```text
preference
  ↓
PreferenceSchema
  ↓
shared control selection
  ↓
SettingsRenderer
  ↓
SettingsSection
  ↓
SettingsGrid
  ↓
SettingRow
  ├─ SettingCopy
  └─ SettingControlSlot
```

Source renderer 一次生成 final DOM，再发布 `weigg:settings-render`。

Wide 两列，Narrow 一列。Ordinary row `span=1`；只有 multiline/composite/list/table/large editor 可由 schema 明确 `span=full`。

禁止 centered FormRail、Settings Observer、post-render injector、CSS-order repair 和第二套 native Select owner。

## 9. Canonical Select

`W.Components.selectControl(options)` 是唯一 Select primitive，支持两种明确 presentation：

```text
floating mode (default)
  trigger + FloatingLayer menu
  适合普通页面

native mode (native:true)
  one native <select> inside canonical wrapper
  适合 modal/top-layer、平台原生选择更可靠的场景
```

两者共享同一个组件入口、value/onChange contract 和 styling token，不是两个功能实现。

禁止扫描页面 native `<select>` 再自动“升级”。

## 10. Selection architecture

`W.Selection` 唯一拥有 selected Set、range anchor、page/all-matching selection、Ctrl/Cmd、Shift、Ctrl/Cmd+A、Escape 与 toolbar state。

```text
row/card non-interactive click -> selectOnly
Ctrl/Cmd click                 -> toggle
Shift click                    -> range
title/detail                   -> open detail only
checkbox                       -> toggle
right-click                    -> ActionRegistry
mobile long press              -> same ActionRegistry
mobile More / top More         -> same ActionRegistry
```

移动 selection hit-area 至少 44×44 CSS px。

## 11. Private / PT architecture

`W.TorrentSemantics` 只做**已有低成本数据**上的 classification：

```text
PRIVATE_PT
PRIVATE
PT
PUBLIC
UNKNOWN
```

### qB 5.0.0+

Collection/list 的 Private 能力使用 qB 返回的 authoritative `private` / 等价 metadata。`ptTrackers` 只按 tracker hostname 补充 PT 语义。

Metadata 未就绪时返回 `UNKNOWN`，不提前说 Public。

### qB 4.x

qB4 不提供满足本项目性能预算的全库 Private metadata path。WeiG 不通过逐种子 tracker/properties 请求模拟 collection Private filter。

因此：

```text
Private / PT entry remains visible with 5+ capability marker
click on qB4 -> neutral capability dialog
no filter state change
no tracker scan
no per-torrent request queue
no hidden cache crawler
```

提示只说明最低版本、当前版本、建议升级和升级前备份；不向普通用户暴露内部 API/性能实现理由。

## 12. Progressive paging/catalog

首屏/当前页显示不能等待全库 catalog 完成。

```text
page request = pageSize + 1
first page renders immediately
extra row only answers hasNext
background catalog builds independently
```

总数未完成时：

```text
[small CSS spinner] 第 1 页 · 每页 50
```

禁止：

```text
第 1 / ? 页
等待 catalog 才显示当前页
为了知道总页数先做 per-item enrichment
```

Catalog 完成后再显示精确 `第 X / Y 页`。Catalog 失败用轻量 error state，不阻塞当前页分页。

## 13. TransferRuntime telemetry

`W.TransferRuntime` 是 Transfer telemetry 唯一 owner。

### Raw speed

包装 app 已有 `QBClient.getTransferInfo()` 一次，不建立第二 speed poll：

```text
RAW_MAX = 900 samples
weigg:transfer
```

### Long window

长时间窗口不提高网络频率，也不无限保存原始点。Runtime 同时维护分钟 bucket：

```text
BUCKET_MAX = 720
1 bucket / minute
maximum history = 12h
```

Chart windows：

```text
1m / 5m / 15m / 30m / 1h / 3h / 6h / 12h
```

1–15m 使用 raw detail；长窗口使用分钟聚合。数据只在当前浏览器内存中，刷新页面即清空，不写 qB 服务端、不写长期 localStorage history。

### Metadata

一个 `sync/maindata` owner：

```text
one rid
one in-flight promise
one bounded 30s lifecycle
DHT / peers / freeSpace normalization
weigg:maindata
```

## 14. Transfer UI

Stats 顺序：

```text
Session downloaded | Session uploaded | DHT / Peers
Global upload       | Global download | Free space
```

Rate editor：

```text
[NORMAL | ALT] [Auto / KiB/s / MiB/s / GiB/s]
Upload | Download
0 = Unlimited
```

Modal 中 window/unit 使用 canonical Select 的 `native:true` presentation，避免 body portal 与 browser top layer 竞争。

数值输入 `step=any`；显示采用紧凑有效数字，不因切换 GiB/s 等单位把小值舍入成 0。`Auto` 只决定 display unit；提交前转换回 canonical B/s，再由 QBClient 负责 ALT KiB/s API boundary。

## 15. Layout ownership

`css/layout.css` 唯一拥有非 Settings route 的 shell geometry：

```text
Desktop statusbar named grid
Route tool-shell column behavior
Torrent panel/workspace flex-fill
progressive pager/capability marker presentation
mobile primary-scroll geometry
```

Desktop Torrent panel 使用剩余 workspace 高度，不再由 `app.css` 的固定 `62vh/660px` 或手机 `calc(100svh - Npx)` 控制。

`spatial.css` 只负责 surface/facet/connection visual；`polish.css` 只做 tone/tooltip/final visual，二者不得重新拥有 route/status/Torrent viewport geometry。

## 16. Responsive / Spatial / Polish / UX boundaries

`W.MobileAdaptive` 可以移动 toolbar、fit meta、调整 VirtualList row height、消费 snapshot/event；不能 new QBClient、getMainData 或建 API timer。

`W.SpatialRuntime` 只拥有 facet shelf / connection dock presentation。

`W.PolishRuntime` 不修 About、ActionRegistry、Transfer 或 shell geometry。

UX/i18n 通过 explicit lifecycle 同步，不 observe whole body。

## 17. Session / Progress / Brand

Session：真实 `auth/logout` + protected probe + BFCache fail-closed；auth bypass 不能伪造成功。

Progress：`css/progress.css` 唯一 owner，100% 停止装饰运动，尊重系统/WeiG Reduced Motion。

Brand：Header/About 复用同一 Brand/AmbientMark owner。

## 18. Systemic failure modes

本问题链暴露的系统性问题：

```text
1. 同一 route 在 App/UX/Spatial 有多个 active-state writer。
2. 新 capability 为兼容旧 qB 走 O(N) per-torrent 请求。
3. 总页数构建与首屏显示耦合，导致 ? 页长期存在。
4. 固定 vh 高度与 flex shell 同时拥有 Torrent viewport。
5. modal top layer 里仍使用 body-portal floating menu。
6. NORMAL/ALT API 单位不同却在 UI owner 中混算。
7. 长时间图表直接扩大 raw history，容易把功能扩展变成性能负担。
8. Presentation 自己开 QBClient/timer。
9. Observer/post-render repair 代替 source-final DOM。
10. old/new/versioned runtime 同时存活。
```

固定修复顺序：

```text
owner
→ upstream/API capability + performance budget
→ unit/data boundary
→ source component
→ semantic lifecycle
→ layout
→ delete old owner
→ static/browser interaction regression
```

## 19. Hard rules

```text
OWNER-001        one semantic feature, one Current Owner
COMPAT-DEGRADE-001 missing expensive capability -> neutral version degradation, not hidden emulation
PERF-COMPAT-001  no O(N) compatibility network work by default
PROGRESSIVE-DATA-001 current-page usefulness must not wait for total-count enrichment
ROUTE-OWNER-001  app.js alone commits Route Frame state
SELECT-TOPLAYER-001 modal-sensitive Select uses canonical native presentation when portal reliability is weaker
RATE-UNIT-001    business rate unit is B/s; QBClient owns API-unit conversion
TIMESERIES-001   longer history must be bounded/aggregated and must not raise API polling frequency
LAYOUT-OWNER-001 layout.css owns route/status/Torrent viewport geometry
INTERACTION-TEST-001 browser tests must exercise real user interactions, not DOM presence only
EXACT-HEAD-001   any code/test/doc change invalidates previous exact-SHA certification
```

## 20. Automated ownership gates

Static gate 阻止：

```text
versioned runtime assets/loaders/owners
first-party MutationObserver
Route Frame writers outside app.js
qB4 Private per-torrent scanning
second Selection/Transfer owner
presentation API polling
old fixed Torrent viewport height
spatial/polish shell geometry
Transfer direct ALT preference unit handling
unbounded Transfer history
```

Focused Chromium 必须覆盖真实交互：

```text
qB 4.1.9.1: Private click -> capability dialog + zero tracker requests
qB 5.2.0: authoritative Private filter/detail
RSS -> Settings: only Settings active; Torrent sidebar removed
row/title/checkbox/Ctrl/Shift/ActionRegistry
progressive page state
Desktop Torrent panel flex-fill
Transfer 12h selection
native unit selectOption + precision
ALT apply with correct KiB/s API payload
mobile 44px + long-press + qB4 capability filter rollback
progress/reduced motion
Settings/session/logout/BFCache
```

Full stable-tag + Linux/Windows + multi-viewport 仍属于 main Release candidate。

## 21. LIVE / Release boundary

真实 exact-SHA qB 4.1.9.1 + 5.2.x LIVE 是 promotion gate。任何 code/test/doc commit 都产生新 candidate；旧 SHA 的 CI/LIVE PASS 不继承。

`main` 只在 exact candidate 通过 CI + real LIVE 且用户明确授权后晋级。
