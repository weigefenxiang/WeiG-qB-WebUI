# 003. WeiG qB WebUI 项目架构

Status: **v0.3.7 Semantic Ownership 3.7**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义运行时层次、数据流、模块边界与 Current Owner。总 authority 为 `DESIGN.md`；兼容、UI/缓存、统一交互实现、发布边界和 Torrent 工作区分别见 `002`、`004`、`005`、`006`、`008`。

## 1. 总体数据流

```text
qB WebAPI
→ QBClient capability/unit normalization
→ canonical business owner
→ semantic lifecycle / source DOM
→ canonical component + presentation owner
→ layout / responsive / theme
```

business owner produces state；presentation owner consumes state；DOM is not application state。

## 3. QBClient / capability boundary

`QBClient` 是唯一 endpoint/version/API-unit adapter。Presentation-only runtime 禁止创建 qB client/API timer。

Private/PT：qB4 visible `5+` -> shared dialog；qB5 authoritative metadata。**此功能需要 qBittorrent 5.0.0+** 属于当前 capability fact，必须保留。

Tags：WebAPI >=2.3.0；unsupported -> visible control -> shared dialog -> 0 state mutation / 0 unsupported request。

## 4. Current hard rules

### ROUTE-OWNER-001
`app.js` 唯一提交 App route presentation。

### RATE-UNIT-001
Canonical rate = B/s；ALT KiB/s 只在 QBClient boundary normalize。

### LAYOUT-OWNER-001
`css/layout.css` 唯一拥有 non-Settings shell/Torrent/Footer geometry。

### EXACT-HEAD-001
CI/LIVE/Release 结论绑定 exact Git SHA；新提交使旧证据失效。

### CONTROL-SKIN-001
Select behavior only `W.Components.selectControl()`；shared skin only `css/ui.css`。

### DIALOG-SCROLL-001
Dialog shell 不做通用 scroll owner；真实溢出区域内部滚动。

### NATIVE-THEME-001
Native controls 跟随 resolved Light/Dark theme。

### OWNER-RETIRE-001
旧 owner/caller/shim/test expectation 同批退出，Git history 是 archive。

### CURRENT-ONLY-001
当前树不保存 WeiG 旧 release runtime/tests/deploy compatibility copies。

### FILE-NAMING-001
First-party files 使用稳定职责名，不编码 WeiG release 或特定 qB 版本。

## 5. Explicit lifecycle

```text
app.js       weigg:library-state / weigg:status-state / weigg:route-state
settings.js  weigg:settings-render
transfer.js  weigg:transfer / weigg:maindata
shared       weigg:languagechange / weigg:configchange
```

First-party runtime 禁止 `MutationObserver` 做 ownership/repair。

## 6. Torrent workspace

Facet ownership：

```text
state        W.LibraryController
composition  W.SpatialRuntime
Select       W.Components.selectControl()
skin         css/ui.css
mobile       W.MobileAdaptive placement only
```

Desktop：无 Stats dashboard；TorrentPanel flex-fill；动作 `Start -> Pause -> More -> Delete -> Expand`。

Footer：`"torrent storage transfer connection message"`。

## 7. Transfer / Connection

```text
sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer
```

DHT/Peers formatted value unchanged -> no DOM mutation。

```text
getTransferInfo connection_status
→ app emits weigg:status-state
→ W.MobileAdaptive presentation
```

No second polling/client。

## 8. Stable semantic repository

Runtime、tests、LIVE scripts、docs 文件名都描述稳定职责。禁止 `*-vNNN.*`、version-labelled docs、`live-qbNN.sh`、old-name alias/shim、old+new owner coexistence。

WeiG 历史 release implementation 只存在 Git history / tags / Releases。qBittorrent/WebAPI versions 是当前兼容事实，可以并且必须存在 capability copy、fixtures 和 audits。

## 9. Session / auth

`SessionController.logout -> auth/logout -> protected probe -> invalid session required`；Back/BFCache fail closed。

## 10. Tests / exact head

Current tests validate current product contract only；old WeiG release-specific tests are deleted, not wrapped or renamed。

真实 qB 4.1.9.1 + 5.2.x LIVE 与 maintainer 明确授权前不晋级 `main`。
