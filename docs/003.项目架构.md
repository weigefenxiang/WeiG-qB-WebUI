# 003. WeiG qB WebUI 项目架构

Status: **v0.3.6 architecture authority**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义文件、运行时层次和 ownership。视觉/交互规则看 `DESIGN.md`；产品规则看 `001.项目总方案.md`；兼容状态看 `002.兼容与实现状态.md`；专项 UI/缓存契约看 `004.UI与缓存契约.md`。

## 1. 总体数据流

```text
qB WebAPI
  ↓
QBClient + capability + normalization
  ↓
TorrentSemantics + application state
  ↓
canonical Components / VirtualList / DataGrid
  ↓
feature composition
  ↓
canonical CSS layers
```

硬边界：

```text
QBClient
  ✓ API contract / compatibility / old-new vocabulary bridge

TorrentSemantics
  ✓ cross-version domain meaning such as Private OR PT
  × no UI layout
  × no qB-major hardcoding

Application Controller
  ✓ Torrent/Search/RSS/Settings/business state

Components/Core
  ✓ DOM primitive / VirtualList / DataGrid / canonical control

Feature runtime
  ✓ compose behavior
  × no qB-major scattered gate
  × no duplicate primitive
  × no fabricated backend data

Deploy layer
  ✓ VERSION / GIT_SHA / weigg-install.json
  ✓ exact Git-SHA asset identity
  × no deployment URL / credential / host-path constants
```

关键不变量：**Data count != DOM count**。

## 3. Bootstrap / Cache ownership

`private/index.html` 是 canonical bootstrap，直接 CSS/JS 使用 `?v=__WEIGG_GIT_SHA__`，部署时替换为精确 Git SHA。

`components.js` 提供：

```text
<meta name="weigg-build-sha">
      ↓
currentBuildToken()
      ↓
buildAssetUrl(path)
```

lazy runtime 包括 `spatial-v022.js`、`v030.js / v030.css`、`v036.js / v036.css`、`brand-v031.css`。`adaptive-v036.js` 是 bootstrap 前置的移动/存储适配层，并在 v036 base runtime 就绪后通过 `buildAssetUrl()` 装载 `advanced-v036.js`。

## 4. `core.js`

负责 utility、Config、Router、VirtualList、DataGrid。Torrent viewport 使用 `__weiggVirtualScrollTop` / `__weiggVirtualScrollHandler`；轮询或隐藏/显示页面不得把用户概念位置无意归零。

## 5. `qb-client.js` / QBClient

`QBClient` 是唯一 qB WebAPI compatibility boundary：

```text
4.x resume/pause ↔ stable start/stop semantics ↔ 5.x start/stop
legacy log milliseconds → normalized seconds ← modern seconds
Preference field presence → feature availability
```

feature/UI 不直接散落 major-version 判断。`getMainData(rid)` 同时服务主状态和低频 storage telemetry；后者读取 `server_state.free_space_on_disk`，使用自己的 incremental RID，不伪造宿主机 root filesystem 信息。

## 6. `semantics-v036.js`

`W.TorrentSemantics` 是跨版本业务语义层。当前明确拥有：

```text
isPrivate(torrent)
isPt(torrent, rules)
isPrivateOrPt(torrent, rules)
trackerHost(raw)
normalizeRules(rules)
```

Private/PT contract：

```text
有 exact private field 的版本
  exact private OR PT tracker rule

没有 exact private field 的 legacy 版本
  仅 PT tracker rule fallback
```

不得因为 legacy 版本缺字段而伪造 exact-private 结果，也不得把 qB major 号当业务语义来源。

## 7. `components.js`

Canonical owner：

```text
preferenceField / readonlySettingField
Select / Listbox
upgradeNativeSelect(s)
FilterChip
CheckControl
Time formatter (`W.Time`)
asset-build helpers
```

Floating Select 的视觉菜单通过 v036 的 body-level FloatingLayer portal，避免业务容器 clipping。

## 8. `v036.js`

负责 FloatingLayer collision manager、AmbientMark scheduler、Global Display Time Zone status control、Torrent Detail context Back、Escape priority、Settings timezone bridge。状态栏 timezone 是唯一全局选择器，Logs 只消费 `W.Time` 与 timezone change event。

`AmbientMark` 与 branding 是组合关系：任何 branding 层如果重建 logo DOM，都必须在重建后重新调用同一个 `W.AmbientMark.install(mark)`，不能破坏 orbit/spark/shine 子层。

## 9. `adaptive-v036.js` + `mobile-v036.css`

共同拥有 **Mobile Adaptive System 2.0**：

```text
App Shell grid
  → Workspace remaining track
  → active page flex ownership
  → exactly one primary scroll owner
```

主要 contract：

```text
SCROLL-001   每个长页面只有一个 primary scroll owner
COMMAND-001  Torrent filter + count + actions 单行
FACET-001    手机 all-state 使用短语义标签
VIEWPORT-001 Torrent 数据 viewport 吃满剩余空间，可进入 focus mode
MOBILE-CARD  次要指标优先保持一行并动态收紧
TOOL-PAGE    Search/RSS/Logs 不制造第二个 document page
STORAGE-001  qB default-save filesystem free-space telemetry
```

禁止 `100vh - magic pixels`。CSS card height 与 Torrent VirtualList row height共享同一移动 metric contract。focus mode 只改变 chrome 可见性和数据 viewport 空间，不重置用户 scroll state。

## 10. `spatial-v022.js`

该层负责长期空间结构、Filter Shelf、Connection Dock 与 branding attachment，同时是 Facet trigger 文本的 canonical owner。

Desktop all-state 保留完整文案，例如 `All Trackers`；手机 collapsed all-state 使用短语义文案 `Tracker / Path / Category / Tag`。具体选中某个值时显示实际值。

品牌 CSS 仍通过 build SHA 加载；如果 branding attachment 在 `AmbientMark` 之后执行，必须重新安装 AmbientMark，避免 DOM 重建清除其装饰层。

## 11. `advanced-v036.js`

这是 source-verified Advanced display semantics 层。它不改变 qB 的真实 Preference contract，只负责 raw API value 与 human-readable display unit 的精确 round trip，同时添加已验证的单位、`0` 特殊语义和 readable enum Select。

## 12. Logs

`logs-v032.js` / `logs-v032.css` 的数据 contract：

```text
newest first
max 5000
incremental last_known_id=max(ID)
VirtualList viewport only
```

Logs 不再拥有 route-local timezone selector；它使用 status dock 的全局 Display Time Zone。

## 13. Settings

`settings-schema.js`、`settings-translations.js`、`settings-v034.js`、`advanced-v036.js` 共同构成 Settings 层。`settings-v034.js` 继续拥有 Alternative WebUI 的路径/关闭安全逻辑和 `weigg-install.json` metadata 展示，但视觉必须复用 canonical SettingCard。`advanced-v036.js` 只增加已验证的单位/enum/round-trip，不允许根据 key 名猜单位。

手机 Settings 的 `settings-content` 是页面唯一主滚动区；顶部标题、tab strip 与保存操作属于 chrome，不建立竞争滚动容器。

## 14. Transfer / v0.3 layer

`v030.js` / `v030.css`。Transfer graph 是 bounded browser telemetry，**MAX 900** samples，不创建大型 chart dependency。

## 15. Internationalization

Canonical source language：**English**。维护语言：**English / 简体中文**。Feature runtime 请求 semantic key，不允许按 locale 写两套业务分支。缺失翻译回退 English。

## 16. Compatibility fixtures

Canonical file：`tests/fixtures/qb-compat-matrix.json`。完整 release matrix 包含 4.1.9.1 → 5.2.3、upstream/master，以及一个 synthetic 6.x forward-major sentinel。sentinel 只检测错误硬编码，不代表官方 6.x 支持。

Fixture 内的路径、容器名、URL 只能是明确的测试假数据，不得复制维护者真实部署信息。

## 17. Automated gates

```text
npm test
  smoke
  open-source contract
  Torrent semantic contract
  compatibility
  Logs API contract
  Alternative WebUI contract
  cache contract
  canonical UI contract
  mobile contract
  Advanced unit/enum round-trip

Chromium
  browser-logs-v033.mjs
  browser-settings-v034.mjs

  browser-ui-v036.mjs
```

`browser-ui-v036.mjs` 跑 **12 compatibility nodes × mobile/desktop/wide**。`browser-mobile-v036.mjs` 额外覆盖 **qB 4.1.9.1 + 5.2.3 × 320×568 / 360×800 / 390×844 / 430×932**，并跨 Torrent、Settings、Search、RSS、Logs、Detail 验证单滚动区与 viewport contract。

## 18. Live deployment/certification

`tests/live-v036.sh` 是环境中立的 Final Candidate 无重启测试部署器。仓库不保存具体服务器地址或机器路径；调用者通过一个或多个 `--target` 提供已经存在的 WeiG WebUI 安装目录：

```sh
sh tests/live-v036.sh \
  --sha <40-char-sha> \
  --target <installed-webui-dir> \
  --target <another-installed-webui-dir>
```

脚本要求 exact SHA，先 staging/validation，再 atomic switch，生成备份与回滚命令，不执行 Docker/qB restart。已有 `weigg-install.json` 中的真实部署 metadata 被保留，不由脚本猜测。

自动 fixture 只能证明 deterministic contract；真实 4.1.9.1 / 5.2.x 仍是 release-blocking LIVE Gate。
