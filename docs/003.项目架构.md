
## 4. Capability model

统一 modes：

```text
NATIVE
NORMALIZED
DERIVED
READ_ONLY
UNAVAILABLE
UNKNOWN
```

优先级：

```text
native
-> normalized / adapter
-> reliable old-API composition
-> reliable local derivation
-> read-only when applicable
-> unavailable
```

future `UNKNOWN` 只关闭无法证明的具体 capability，尤其危险写操作；不能按 major/version 整体拒绝，也不能自动继承 latest semantics。

## 5. Read / Write / Action / Field 分离

禁止粗粒度 boolean 把不同语义绑死。典型拆分：

```text
Tags:
read/facet/filter != list != assign != create != delete

Category:
read/filter != list != create/delete != assign

Tracker:
read != add != remove != edit != reannounce

Settings:
read endpoint != write endpoint != per-Preference writable

Details:
properties/files/trackers/peers/webseeds read independent
file priority / peer ban / tracker writes independent
```

Phase F 已把这些分离原则落实到 touched Settings / Tool / Detail surfaces 与 QBClient transport guard。

## 8. Phase F surface provenance contract — IMPLEMENTED

### 8.1 Endpoint/action provenance

每个 touched surface 能回答：

```text
read action exists?
write action exists?
required/optional parameters?
response fields available?
future profile exact or UNKNOWN?
```

Certified exact profile：按 source facts 判定 `NATIVE/UNAVAILABLE`。

Future/unadmitted profile：无法证明具体 action/parameter 时为 `UNKNOWN`；尤其 write 不发 HTTP。

### 8.2 Settings two-level write proof

```text
app/setPreferences source action writable
AND
W.SettingsSchema descriptor proves setterPresent + writeType + typeAgreement + writable
```

两层都真才进入 payload。Getter-only、missing setter、unknown endpoint、type mismatch、structured-unproven 都不会 blind write。

Settings 已有 schema/renderer/UI primitives 保持 Current Owner，没有推倒重写。

### 8.3 Search / RSS / Logs

Route availability 与子 action 分离。

RSS historical correction：upstream qB 4.1.0 已声明 core RSS actions，Phase F 已退休 `WebAPI >=2.1.0` 作为最终 availability truth 的错误历史假设。

Search core actions 从 qB 4.1.4 起 source-proven；Logs main/peers 从 qB 4.1.0 起 source-proven。Final product capability 已绑定 exact action facts。

### 8.4 Details

已完成：


### 8.5 Action parameter provenance

QBClient form 优先由 `W.ReleaseProfile.actionDescriptor()` / `apiActionParameters` 组装，避免 version-threshold form guessing。

`editTracker` old stable 与 5.2.x 参数契约已按 exact source parameters 处理；unknown contract 在 HTTP 前 fail closed。
