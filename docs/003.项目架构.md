# 003. WeiG qB WebUI 项目架构

Status: **Architecture authority for v0.3.6+**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文负责“文件放在哪里、谁依赖谁、每层允许做什么”。视觉与交互看 `DESIGN.md`；产品硬规则看 `001.项目总方案.md`；兼容状态看 `002.兼容与实现状态.md`；UI/缓存/交互专项契约看 `004.UI与缓存契约.md`。

## 1. 架构目标

```text
qB API/version differences → QBClient + Capability + normalization
Torrent/business state     → Application Controller
DOM primitives             → Components/Core
Canonical controls         → Components + v036.css
Client time formatting     → W.Time
Ambient brand scheduling   → W.AmbientMark / v036.js
Large-list mechanics       → VirtualList/DataGrid
Settings semantics         → SettingsSchema/Translations + settings compatibility runtime
Navigation/i18n bridge     → UX layer
Detail return context      → v036 navigation context
Feature enhancements       → versioned runtime modules
Visual material            → canonical CSS layers
Build/cache identity       → HTML build SHA + installer/release stamping
Browser compatibility gate → deterministic qB fixtures + Chromium
Install/backup/rollback    → Installer + install metadata
```

硬约束：

```text
UI / Runtime / Components
  × 不直接散落 qB 主版本特例
  × 不伪造不存在的 backend data/write API
  × 不把大型数据变成大型隐藏 DOM
  × 不为已有语义再造第二套 Card/Grid/Modal/Button/Select/Chip
  × 不自行维护 ?v=0.x.y 静态资源版本
  × 不让 polling 改写用户页码/滚动/返回目标

QBClient
  ✓ 唯一 API contract / compatibility / normalization boundary

Components
  ✓ canonical Button-adjacent primitives / Select / Chip / Check / Time formatting

HTML + deploy layer
  ✓ 唯一 build Git SHA 来源
```

## 3. Runtime bootstrap

`private/index.html` 是 canonical bootstrap，直接资源使用：

```text
?v=__WEIGG_GIT_SHA__
```

部署时替换为精确 Git SHA。

`components.js` 负责 lazy runtime：

```text
<meta name="weigg-build-sha" content="<SHA>">
          ↓
currentBuildToken()
          ↓
buildAssetUrl(path)
          ↓
path?v=<SHA>
```

当前 lazy layer：

```text
spatial-v022.js
v030.js / v030.css
v036.js / v036.css
brand-v031.css
```

`spatial-v022.js` 的 Brand stylesheet 也必须经过 `buildAssetUrl()`，不允许重新出现独立 `?v=0.3.x`。

## 4. `core.js` ownership

`core.js` 保持基础 utility / Config / Router / VirtualList / DataGrid。

### 4.1 VirtualList

关键 contract：

```text
Data count != DOM count
```

Torrent list 记忆：

```text
__weiggVirtualScrollTop
__weiggVirtualScrollHandler
```

轮询重建可见窗口时必须恢复 viewport，不允许无意归零。

### 4.2 Router

Router 提供 route/go/home/detail 基础能力；**详情返回上下文不是 Router 猜测出来的**，由 v0.3.6 navigation context 层管理站内来源与 scroll restore。

## 5. `qb-client.js`

`QBClient` 是唯一 qB WebAPI 兼容边界。

### 5.1 4.x / 5.x 语义桥

```text
4.x resume ↔ 5.x start
4.x pause  ↔ 5.x stop
4.x paused ↔ 5.x stopped
```

### 5.2 Logs contract

```text
qB >= 4.1.0 → logs=true
legacy milliseconds → seconds
modern seconds      → seconds
```

UI 只消费稳定 epoch contract，不在视觉层猜单位。

### 5.3 Preferences

Alternative WebUI 读取实际 Preferences：

```text
alternative_webui_enabled
alternative_webui_path
```

存在即使用；缺失不伪造。

## 6. `components.js` ownership

v0.3.6 起 Components 不只是 DOM helper，也是 canonical interaction primitive boundary。

### 6.1 Settings

```text
preferenceField()
  → editable qB SettingCard

readonlySettingField()
  → readonly WeiG/deployment SettingCard
```

### 6.2 Select

```text
selectControl()
upgradeNativeSelect()
upgradeNativeSelects()
closeSelects()
```

Visible dropdown 使用自定义 Listbox/Floating Surface，解决 OS 原生 popup 在暗色模式下可能出现白底的问题。

Native select 仍可作为 compatibility/data bridge，但不拥有 visual authority。

### 6.3 Filter / compact boolean

```text
filterChip()
checkControl()
```

Logs 等 feature 只组合这些组件，不重写视觉。

### 6.4 Client Time

```text
W.Time.getZone()
W.Time.setZone()
W.Time.zones()
W.Time.format()
```

时区保存在浏览器 `weigg.timeZone`，不是 qB Preference。

支持浏览器优先通过：

```text
Intl.supportedValuesOf('timeZone')
```

列出 IANA 时区。

## 7. `v036.js` ownership

v0.3.6 是跨 feature 的交互增强层，不拥有 qB API compatibility。

允许职责：

```text
AmbientMark scheduler
native select → canonical Select progressive upgrade
WeiG timezone Settings entry
Torrent list return context
Detail-local Back
Escape priority coordination
Reduced Motion handling
```

禁止职责：

```text
直接判断 qB major version
实现第二套 Button/Select/Card CSS
保存 qB Preferences
创建新的 Torrent data store
```

## 8. AmbientMark architecture

```text
W.AmbientMark
├─ install(target)
├─ trigger(target,effect)
├─ setRandom(fn)
├─ start()
└─ stop()
```

默认随机窗口约 8–28 秒，并允许本轮不触发。

表现层在 `v036.css`：

```text
orbit
spark
tilt
shine
breathe
```

`setRandom()` 使 browser fixture 能确定性测试，不把 CI 建在随机概率上。

页面隐藏或 Reduced Motion 时停止/拒绝动画。

## 9. Logs architecture

`logs-v032.js` 文件名保留历史 lineage，但 v0.3.6 行为升级。

Ownership：

```text
route-local QBClient stream
main-log buffer max 5000
lastId = max ID
severity Set
query
follow
own VirtualList
Compact / Auto / Max
client timezone Select
route-local timer
```

### 9.1 Newest-first model

```text
merge incremental rows
      ↓
sort ID desc / timestamp desc
      ↓
keep slice(0, 5000)
```

增量请求仍使用最大 `lastId`，与显示顺序无关。

### 9.2 Follow OFF viewport

新增行插入顶部时，如果用户在看历史：

```text
old scrollTop
+ insertedRowCount × rowHeight
= compensated scrollTop
```

保持用户看到同一逻辑内容。

### 9.3 Timezone

`logs-v032.js` 不再包含：

```text
zh()
text(en, cn)
```

翻译走 `i18n-v036.js`；时间走 `W.Time`。

## 10. Torrent Detail return context

v0.3.6 使用 sessionStorage：

```text
weigg.torrentListContext.v036
```

记录至少：

```text
internal return hash
Torrent list scrollTop
savedAt
restore flag
```

App 自身继续持有：

```text
page
pageSize
filter
tracker
category
tag
savePath
search
sort
reverse
```

因此 Page 2 进入 Detail 后，Back/Esc 返回仍是 Page 2；v036 只负责补齐 viewport restore 与安全站内 return contract。

直接 URL 进入 Detail 而无有效站内 context 时 fallback 到 home，不盲目回站外历史。

## 11. Escape ownership

```text
Select/Popover → close
Dialog         → dialog
Editable input → do not steal
Torrent Detail → context Back
Torrent list   → existing selection contract
```

不同 feature 不应各注册互相竞争的全局 Esc。

## 15. Internationalization

Canonical source language：**English**  
Maintained UI：**English + 简体中文**

```text
i18n.js      → base language system
i18n-v030.js → v030 feature copy
i18n-v034.js → Alternative WebUI copy
i18n-v036.js → Logs/timezone/detail/ambient interaction copy
```

Feature runtime 请求 semantic key，不直接做语言 if/else。

## 16. Build / cache identity

Source payload：

```text
webui/GIT_SHA = __WEIGG_GIT_SHA__
HTML build meta = __WEIGG_GIT_SHA__
local CSS/JS query = __WEIGG_GIT_SHA__
weigg-install.json.gitSha = __WEIGG_GIT_SHA__
```

Linux/Windows installer 和 Release packaging 负责注入真实 SHA。

安装身份：

```text
VERSION
GIT_SHA
private/weigg-install.json
```

`weigg-install.json` 记录 version/gitSha/qbPath/hostPath 等部署信息。

## 18. Installer / security boundary

普通 install/update：

- 不修改 WebUI 用户名/密码；
- 多 qB container 时不猜目标；
- 先备份再替换；
- rollback 可恢复；
- qB path 与 Host path 分开；
- `VERSION` 是产品版本；
- `GIT_SHA` 是确切源码身份。
