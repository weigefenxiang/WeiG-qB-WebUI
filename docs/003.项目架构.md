# 003. WeiG qB WebUI 项目架构

Status: **Current Semantic Ownership**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> `DESIGN.md` 是总 authority；本文定义 Current Owner、数据流和模块边界。

## 1. 总体数据流

```text
qB WebAPI
→ QBClient detect / endpoint adapter / unit normalization
→ business semantic owner
→ lifecycle/event
→ canonical component/presentation owner
→ responsive layout / theme
```

Capability UI：

```text
QBClient.detect() -> qbVersion + webApiVersion
→ W.CapabilityRegistry + data/capabilities.json
→ supported / disabled / degraded
→ badge / Tooltip / canonical Capability Dialog
```

Torrent workspace：

```text
qB torrent objects
→ app.js / W.LibraryController query/page/filter/search/sort
→ W.Components canonical row/card renderer
→ W.TorrentFieldRegistry field projection
→ css/layout.css + css/ui.css + css/progress.css
```

## 3. Torrent workspace boundary

Desktop 与 Mobile 共用同一业务状态和同一 controls：

```text
#filter-nav
  ↓
#sidebar-facet-slot > #facet-controls

Desktop #torrent-action-slot
Mobile  #mobile-pager-actions-slot
          ↑
   same #torrent-selection-toolbar
```

四张 Download / Upload / Network / Torrent Summary 已从 DOM 删除。删除 summary 不创建 replacement telemetry owner：Transfer / Connection / count 仍来自已有 semantic owners。

Mobile Sort 直接写 `W.LibraryController.setSort()`；禁止通过隐藏 Columns Dialog、临时列、隐藏表头 click 作为 state bridge。

`W.Components` 直接定义 Desktop/Mobile Torrent renderer；`ui.js` 不再 runtime replacement。`W.MobileAdaptive` 不替换 `W.VirtualList` 或 `W.Components.state`；`W.LayoutRuntime` 不替换 `W.DataGrid` methods。

## 4. Current hard rules

### ROUTE-OWNER-001
`app.js` 唯一提交 App route presentation。

### RATE-UNIT-001
Canonical rate = B/s；ALT KiB/s 只在 QBClient boundary normalize。

### LAYOUT-OWNER-001
`css/layout.css` 唯一拥有 non-Settings shell/Torrent/Footer geometry。

### EXACT-HEAD-001
CI/LIVE/Release 绑定 exact Git SHA；新提交使旧证据失效。

### CONTROL-SKIN-001
Select behavior only `W.Components.selectControl()`；shared primitive skin only `css/ui.css`。

### DIALOG-SCROLL-001
Dialog shell 不做通用 scroll owner；真实溢出区域内部滚动。

### NATIVE-THEME-001
Native controls 跟随 resolved Light/Dark theme。

### FACET-OWNER-001
Facet state/composition/control/placement 各有一个 Current Owner；Desktop/Mobile 不 fork Facet DOM。

### PRESENTATION-STATE-001
DOM 不是业务 state database。Selection count、Sort、Connection help 等必须读 semantic owner。

### CAPABILITY-OWNER-001
User-facing qB/WebAPI compatibility policy 只有 `W.CapabilityRegistry + capabilities.json` 一个 Owner。

### CAPABILITY-RANGE-001
版本条件使用 semantic range，不靠精确 patch 列表。

### OWNER-RETIRE-001
旧 owner/caller/shim/test expectation 同批退出，Git history 是 archive。

### CURRENT-ONLY-001
当前树不保存 WeiG 旧 release runtime/tests/deploy compatibility copies。

### FILE-NAMING-001
First-party files 使用稳定职责名，不编码 WeiG release 或特定 qB 版本。

### SORT-OWNER
Desktop/Mobile Sort 都调用 `W.LibraryController`；禁止 hidden-presentation bridge 与第二 sort persistence。

### TORRENT-RENDERER-OWNER
Torrent Desktop/Mobile renderer 函数由 `W.Components` 一次定义，禁止 post-load replacement。

### MOBILE-LIBRARY-IA
Mobile Drawer = state filters + canonical facets；workspace = compact controls + cards + pager/action rail；无 Summary/command/facet duplicate shelf。

### MOBILE-CONTROL-DENSITY
Mobile toolbar 保持可用 hit area，以 shared canonical skin 做紧凑 visual surface。

### MOBILE-ACTION-PLACEMENT
Selection action toolbar 只有一个 DOM owner，Responsive 只移动它。

### MOBILE-CARD-COMPOSITION
Mobile card 第一行 selection/title/More；第二行 fields；bottom rail 是 canonical real progress。

### HEADER-SEARCH-001
一个 `#search-input` / `app.search`。Mobile Header 只 reveal 同一 input，anchored below Topbar。

### FEEDBACK-OWNER
Transient feedback 只有 `W.Feedback / scripts/feedback.js` 一个 Current Owner；业务唯一入口是 `W.toast(...)`。

### FEEDBACK-TRUTH
Timer 只控制展示寿命；processing 使用 `duration:0`，必须由真实 Promise/result 更新成 success/warning/error。

### FEEDBACK-ACTIVITY
`duration:0` 使用同一卡片上的 indeterminate activity rail，只表达“仍在处理”，不表达业务百分比。

### FEEDBACK-RETIRE
旧 Toast owner/CSS/caller 与测试假设同批退出，不保留 alias/shim。

### TORRENT-PROGRESS-OWNER
Torrent progress 只有 `W.Components.progressVisual/progressTrack/progressCell + css/progress.css` 一条 canonical presentation chain。

### TORRENT-PROGRESS-TRUTH
Progress fill width 只来自真实 `torrent.progress`。

### TORRENT-PROGRESS-STATE
Torrent state 从当前 torrent object 本地映射，不增加 API/polling，不从 DOM 反推业务状态。

### TORRENT-PROGRESS-MOTION
只有真实 active download/seed/checking 使用轻量 flow/sheen；static states 静止，System/WeiG Reduced Motion 都关闭装饰运动。

## 5. Explicit lifecycle

```text
app.js       weigg:library-state / weigg:status-state / weigg:route-state
settings.js  weigg:settings-render
transfer.js  weigg:transfer / weigg:maindata
shared       weigg:languagechange / weigg:configchange
feedback     direct W.toast/W.Feedback record lifecycle
progress     render-time projection from existing torrent object
```

First-party runtime 禁止 `MutationObserver` ownership/repair、QBClient/fetch monkey patch、第二 polling path。

## 6. Connection boundary

```text
getTransferInfo connection_status
→ app emits weigg:status-state
→ W.MobileAdaptive paints canonical status/help
→ css/layout.css paints one marker
```

Connection Dialog 的 qB/WebAPI/DHT/Peers 信息来自已有 `W.TransferRuntime.snapshot()`；0 new requests。四张 Summary 删除后，不从 `#network-meta` 读取 presentation text。

## 7. Capability ranges

Range operators：`eq / gt / gte / lt / lte`；compound：`all / any / not`。

Private exact metadata = qBittorrent 5.0.0+；Tags = WebAPI 2.3.0+，已知 qB-facing milestone = 4.2+。任意 patch 按 range 比较。

## 8. Theme ownership boundary

```text
W.Config.theme = system | time | light | dark
        ↓
W.Theme
        ↓
resolved = light | dark
        ↓
html[data-theme]
        ↓
semantic surface/control tokens
```

### THEME-OWNER
Theme validation/resolution/listener/timer/lifecycle 只有 `W.Theme` 一个 Current Owner。

### THEME-MODE
Canonical preferences = `system / time / light / dark`。

### THEME-RESOLUTION
CSS/native control 只消费 resolved `light / dark`。

### THEME-SYSTEM
System mode 一条 `prefers-color-scheme` listener，无 polling。

### THEME-TIME
Smart Auto 只调度下一个 08:00/20:00 boundary。

### THEME-SURFACE
Light 由 semantic white/cool-blue-violet tokens 表达；禁止 `light-fix.css`。

### THEME-DARK-STABILITY
Dark 是 protected baseline，除非明确进入 Dark redesign scope。

### THEME-MOTION
Theme truth 不依赖 animation，Reduced Motion 只移除装饰运动。

### THEME-RETIRE
旧 Theme resolution/toggle/CSS repair owner 同批退出。

## 9. Validation discipline

真实浏览器门禁必须覆盖 Mobile/Desktop、Light/Dark、Reduced Motion，并验证：

```text
Sidebar facets permanent
no Summary leaves
semantic Selection count / Sort
same Selection action toolbar at Mobile pager
canonical two-line Mobile card + progress rail
Mobile Search below Topbar with header controls still reachable
qB4 degradation + qB5 native capability
Desktop Header/DataGrid/Statusbar protected baseline
```

每一个正式 `dev` tree 改动都必须 patch +1；`VERSION` / `webui/VERSION` / `package.json.version` 在同一 final state 中同步一致。code、webui、tests、fixtures、workflow、docs、DESIGN、installer、CI/gate 修复都遵守同一规则；exact SHA 始终是 CI/LIVE/candidate evidence identity。
