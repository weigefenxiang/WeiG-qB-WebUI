# 003. WeiG qB WebUI 项目架构

Status: **Architecture authority for v0.3.4+**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文负责“文件放在哪里、谁依赖谁、每层允许做什么”。视觉/交互看 `DESIGN.md`；产品硬规则看 `001.项目总方案.md`；兼容状态看 `002.兼容与实现状态.md`。

## 1. 架构目标

```text
qB API/version differences → QBClient + Capability + normalization
Torrent/business state     → Application Controller
DOM primitives             → Components/Core
Large-list mechanics       → VirtualList/DataGrid
Settings semantics         → SettingsSchema/Translations + versioned settings runtime
Navigation/i18n bridge     → UX layer
Feature enhancements       → versioned runtime modules
Visual material            → CSS layers
Browser compatibility gate → deterministic qB fixtures + Chromium
Install/backup/rollback    → Installer + install metadata
```

硬约束：

```text
UI / Runtime / Components
  × 不直接散落 qB 主版本特例
  × 不伪造不存在的 backend data/write API
  × 不把大型数据变成大型隐藏 DOM

QBClient
  ✓ 唯一 API contract / compatibility / normalization boundary
```

## 3. Runtime 依赖

`index.html` 继续直接加载 canonical base assets。v0.3.4 新增：

```text
settings-v034.css?v=0.3.4
scripts/i18n-v034.js?v=0.3.4
scripts/settings-v034.js?v=0.3.4
```

`logs-v032.css/js` 没有改变 bytes，因此仍使用 `?v=0.3.2` 内容 revision。只有真实资源内容发生变化时才推进对应 cache-bust。

长期仍遵循：成熟的 versioned runtime 能力稳定后回收进 canonical modules，避免无限增长。

旧运行时层继续保留职责：

```text
spatial-v022.js  → Filter Shelf / Connection Dock / spatial composition
v030.js          → stable scroll / Transfer Dock / session graph / selection
v030.css         → compact empty state / Transfer surfaces / selection feedback
logs-v032.js     → cross-version Logs stream / filters / adaptive panel
settings-v034.js → Alternative WebUI settings bridge / safe self-disable / install metadata display
```

English 是 canonical source language；简体中文是正式维护语言。`settings-v034.js` 不直接按 locale 分支，文本通过 `i18n-v034.js` 提供。

## 4. `qb-client.js`

唯一 qB WebAPI 兼容边界。

### 4.1 语义桥

```text
4.x resume ↔ 5.x start
4.x pause  ↔ 5.x stop
4.x paused ↔ 5.x stopped
```

### 4.2 Logs contract

Capability：

```text
qB >= 4.1.0 → logs=true
```

Transport normalization：

```text
log timestamp milliseconds → seconds
log timestamp seconds      → seconds
```

### 4.3 Preferences contract

Alternative WebUI 不按 qB 主版本硬编码。v0.3.4 读取实际 `app/preferences` 返回值：

```text
alternative_webui_enabled
alternative_webui_path
```

存在即显示；缺失即显示 Unsupported，不伪造。

写入继续统一走：

```text
QBClient.setPreferences()
→ POST app/setPreferences
```

## 5. `logs-v032.js`

这是 Logs feature enhancement，而不是第二个 Torrent Controller。

Ownership：

```text
own QBClient instance for route-local log stream
main-log item buffer (max 5000)
lastId
severity filter
log search query
follow-latest state
log VirtualList instance
Auto / Compact / Max local UI preference

```

后台 tab 自动降低刷新频率；离开 Logs 路由停止该 poll timer。

## 6. `settings-v034.js`

v0.3.4 在现有 Settings Controller 之外增加一个受限的 feature bridge，不建立第二套全局 Preferences 状态。

职责：

```text
读取 qB app/preferences 中的 Alternative WebUI 两个字段
在 Settings → Web UI 中追加正式设置区
隐藏 Advanced 中同字段的 generic 重复项
复用顶部 Save qB Settings 按钮
保存路径时做风险确认
关闭 Alternative WebUI 时做强确认
关闭成功后返回 /
读取 weigg-install.json 并显示 Host/VPS 安装信息
```

安全规则：

```text
qB path  = qBittorrent 进程看到的路径
Host path = VPS / Docker host 实际路径
```

Docker 场景例如：

```text
Host: /root/qbittorrent3/config/weigg-qb-webui
  ↓ /config mount
qB:   /config/weigg-qb-webui
```

如果用户把已知 Host path 直接填入 qB path，v0.3.4 阻止保存并提示使用 container-visible path。

关闭开关不是普通 cosmetic setting：保存成功后当前 WeiG WebUI 将停止被 qBittorrent 使用，因此必须确认并跳回 `/`，让 qB 官方 WebUI 接管。

## 7. 安装版本与 `weigg-install.json`

`webui/VERSION` 随 WebUI payload 一起安装，用于 SSH/文件系统直接核对部署版本，不再依赖仓库根 `VERSION` 是否被复制。

`private/weigg-install.json` 是 authenticated WebUI runtime 可读取的安装元数据。源码 fallback 只保证版本字段；Linux/Windows installer 可在部署时覆盖为真实值：

```json
{
  "version": "0.3.4",
  "container": "qbittorrent3",
  "qbPath": "/config/weigg-qb-webui",
  "hostPath": "/root/qbittorrent3/config/weigg-qb-webui",
  "installedAt": "...",
  "installer": "linux"
}
```

qB WebAPI 无法推导 Docker Host path，因此 Host path 只能来自部署层元数据，不能由前端猜测。

## 8. VirtualList ownership

主 Torrent VirtualList 仍由 Application Controller 管理；Logs v0.3.2 持有独立 `state.virtual`。

```text
Torrent virtual state != Logs virtual state
Data count != DOM count
```

主 Torrent VirtualList 的既有 `__weiggVirtualScrollTop` contract 不变。

## 12. Installer / security boundary

普通安装仍不修改 WebUI credentials。产品 `VERSION` 与 `webui/VERSION` 每次集成变化都推进；runtime cache-bust 只有在对应 bytes 改变时推进。
