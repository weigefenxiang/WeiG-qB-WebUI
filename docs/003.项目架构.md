# 003. WeiG qB WebUI 项目架构

Status: **v0.3.7 Semantic Ownership 3.7**  
Repository: `weigefenxiang/WeiG-qB-WebUI`

> 本文定义运行时层次、数据流、模块边界与 Current Owner。总视觉/交互 authority 为 `DESIGN.md`；兼容、UI/缓存、v0.3.7 实现、发布边界和 Torrent 工作区分别见 `002`、`004`、`005`、`006`、`008`。

## 1. 总体数据流

```text
qB WebAPI
  ↓
QBClient
  ├─ endpoint compatibility
  ├─ capability normalization
  └─ API-unit normalization
  ↓
canonical business/data owner
  ↓
semantic events / source DOM
  ↓
canonical components + presentation owner
  ↓
layout / responsive / theme
```

核心边界：business owner produces state；presentation owner consumes state；DOM is not application state；capability missing 不等于允许昂贵模拟；retired caller 不是 archive。

## 3. QBClient boundary

`QBClient` 是唯一 endpoint/版本/API-unit adapter。Presentation-only runtime (`responsive.js`, `spatial.js`, `layout.js`, `polish.js`, `ux.js`) 禁止创建独立 qB client/API timer。

### RATE-UNIT-001

业务 rate 统一 B/s：

```text
NORMAL endpoint: B/s -> canonical B/s
ALT preference: KiB/s <-> QBClient <-> canonical B/s
```

Transfer 不直接读写 `prefs.alt_dl_limit / alt_up_limit`。

## 4. Capability degradation

缺能力时优先 authoritative/batch path；忠实模拟若需要 O(N) / N-per-item 网络工作，默认 capability degradation。

qB4 Private/PT：visible `5+` -> shared dialog -> 0 filter mutation -> 0 tracker scan。

Tags：`WebAPI >= 2.3.0`；unsupported 时 control 保持可见，open -> shared dialog，0 state mutation，0 unsupported request。

## 5. Explicit lifecycle

```text
app.js
  weigg:library-state
  weigg:status-state
  weigg:route-state

settings.js
  weigg:settings-render

transfer.js
  weigg:transfer
  weigg:maindata

shared
  weigg:languagechange
  weigg:configchange
```

First-party runtime 禁止 `MutationObserver` 做 ownership/repair。

## 6. Stable semantic runtime

禁止：`*-vNNN.css/js`、old-name alias、hidden loader、old+new 并行、Observer reclaim、unreachable retired caller。Cache identity = stable semantic path + exact Git SHA。

## 7. Route Frame

### ROUTE-OWNER-001

`app.js` 唯一提交 active View、Top Nav、Mobile Nav、Torrent Sidebar visibility、tool-route scope、Back、drawer close 和 `weigg:route-state`。Settings/UX/Spatial 不拥有 App route presentation。

## 8. Torrent workspace

### FACET-OWNER-001

```text
facet state          W.LibraryController
facet composition    W.SpatialRuntime
Select primitive     W.Components.selectControl()
Select skin          css/ui.css
mobile placement     W.MobileAdaptive
```

Retired：`filter-shelf`、feature-local Facet popover/search、hidden Facet nav、qB shelf summary。

### PRESENTATION-STATE-001

`page-title`、`library-count-copy`、hidden nav 文本不能作为 state source。Selection 读取 `LibraryController.state()`。

## 9. Select / Dialog

### CONTROL-SKIN-001

Select behavior/presentation only `W.Components.selectControl()`；shared skin only `css/ui.css`。

### NATIVE-THEME-001

Native Select/option 显式跟随 resolved Light/Dark theme。

### DIALOG-SCROLL-001

Outer dialog shell `overflow:hidden`；只有真实溢出的 body/form/list 内滚。Feature 只提供 `--dialog-*` geometry。

## 10. Selection

`W.Selection` 唯一拥有 selected Set、range anchor、Page/All Matching、Ctrl/Cmd、Shift、Ctrl/Cmd+A、Escape。Title -> Detail；right-click / long press / More -> same ActionRegistry。Touch target >=44×44。

### OWNER-RETIRE-001

Canonical API 删除时 caller/shim/no-op hook 同批删除。Selection 不保留 `resolveMany` 或旧 Facet DOM query。

## 11. Progressive paging

```text
page request = pageSize + 1
first page immediately
catalog/index background
unknown total -> spinner, never ?
resolved -> exact X / Y
failure -> ! while page stays usable
```

## 12. Transfer / telemetry

`W.TransferRuntime`：existing `getTransferInfo` stream -> speed samples；one `sync/maindata` lifecycle -> DHT / Peers / Free space；RAW_MAX=900；minute bucket max=720；窗口最大 12 h。

### TELEMETRY-PAINT-001

DHT/Peers：`sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer`。`loadTransfer()` 不写 DHT/Peers；formatted value 未变化时不写 DOM。

Connection：existing `getTransferInfo` status -> `weigg:status-state`。`W.MobileAdaptive` 只做 presentation，不发请求、不建 timer。

## 13. Layout ownership

### LAYOUT-OWNER-001

`css/layout.css` 拥有非 Settings shell/Torrent/Footer geometry。

Desktop Torrent：

```text
TorrentPanel flex:1
  GridToolbar
    page/columns
    Start Pause More Delete
    Expand
  Header
  TorrentList flex:1 internal scroll

```

Desktop Stats 已退休；同一 `.stats-grid` 明确定义为 Mobile Summary only。无 Library title block、无 filter shelf。动作顺序：`Start -> Pause -> More -> Delete -> Expand`。

Footer named areas：

```text
"torrent storage transfer connection message"
```

## 14. Adaptive status

### STATUS-NOISE-001

后台成功 refresh 静默，不写 `已刷新` / timestamp。

### STATUS-DEDUP-001

同一 viewport 不重复 durable connection。Desktop -> Statusbar；Mobile -> Network Summary；二者消费相同 semantic lifecycle。

### STATUS-PLACEMENT-001

Persistent global state 放到最低成本 persistent surface，不用重复状态占 primary workspace height。

### ADAPTIVE-STATUS-001

Desktop/Mobile 可以换 placement，但不能产生独立状态 owner 或 polling path。

### LIVE-INDICATOR-001

Connected 的绿色在线灯只是 CSS presentation，不创建 API/timer。

### MOTION-STATUS-001

Online glow 尊重 `prefers-reduced-motion` 和 WeiG Reduced Motion，降级为静态 glow。

### HEADER-UTILITY-001

Topbar 永久空间只给 identity/navigation/search/actionable utilities。qB passive product marker 与 manual Refresh 已退休。

## 15. Session / auth

`SessionController.logout -> auth/logout -> protected probe -> invalid session required`；Back/BFCache fail-closed。

## 16. Tests / exact head

静态测试验证 owner/retirement，browser test 执行真实 action -> state -> visible result。

### EXACT-HEAD-001

任何 CI/LIVE/Release 结论绑定 exact 40-char SHA。code/test/docs 变化即作废旧候选。真实 qB 4.1.9.1 + 5.2.x LIVE 与 maintainer 明确授权前不晋级 `main`。
