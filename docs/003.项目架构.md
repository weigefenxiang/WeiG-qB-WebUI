## 1. 总体数据流

```text
qB WebAPI
→ QBClient capability/unit normalization
→ canonical business owner
→ semantic lifecycle / source DOM
→ canonical component + presentation owner
→ layout / responsive / theme
```

business owner produces state；presentation owner consumes state；DOM is not application state。

## 3. QBClient / capability boundary

`QBClient` 是唯一 endpoint/version/API-unit adapter。Presentation-only runtime 禁止创建 qB client/API timer。

Rate canonical unit = B/s；ALT preferences KiB/s 在 QBClient 边界 normalize。

缺 authoritative/低成本能力时默认 capability degradation，不做 N items -> N API 模拟。

Private/PT：qB4 visible `5+` -> shared dialog；qB5 authoritative metadata。**此功能需要 qBittorrent 5.0.0+** 属于当前 capability fact，必须保留。

Tags：WebAPI >=2.3.0；unsupported 时 visible control -> shared dialog -> 0 state mutation / 0 unsupported request。

## 4. Explicit lifecycle

```text
app.js       weigg:library-state / weigg:status-state / weigg:route-state
settings.js  weigg:settings-render
transfer.js  weigg:transfer / weigg:maindata
shared       weigg:languagechange / weigg:configchange
```

First-party runtime 禁止 `MutationObserver` 做 ownership/repair。

## 5. Stable semantic repository

Runtime、tests、LIVE scripts、docs 文件名都描述稳定职责。禁止：

```text
*-vNNN.js/css/mjs/sh
*.v0.x.y*.md
live-qbNN.sh
old-name alias/shim
old+new owner coexistence
```

WeiG 历史 release implementation 只存在 Git history / tags / Releases。qBittorrent/WebAPI versions 是当前兼容事实，可以并且必须存在 capability copy、fixtures 和 audits。

## 7. Transfer / Connection

```text
sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer
```

DHT/Peers formatted value unchanged -> no DOM mutation。

```text
getTransferInfo connection_status
→ app emits weigg:status-state
→ W.MobileAdaptive presentation
```

No second polling/client。

## 8. Adaptive status

Desktop Connection -> Statusbar；Mobile Connection -> Network Summary；same semantic lifecycle。Connected green pulse is CSS-only；Reduced Motion uses static glow。

Routine polling success remains silent；`Refreshed / 已刷新` and refresh timestamps stay retired。

## 9. Session / auth

`SessionController.logout -> auth/logout -> protected probe -> invalid session required`；Back/BFCache fail closed。

## 10. Current tests / exact head

Current tests validate current product contract only；old WeiG release-specific tests are deleted, not wrapped or renamed.

任何 CI/LIVE/Release 结论绑定 exact 40-char SHA。code/test/docs 变化作废旧 candidate。真实 qB 4.1.9.1 + 5.2.x LIVE 与 maintainer 明确授权前不晋级 `main`。
