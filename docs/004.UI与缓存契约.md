# 004. UI、交互与缓存契约

版本：**0.3.7**  
状态：**Semantic Ownership 3.7 / canonical engineering contract**

## 1. 总则

1. 同一种 UI/Data 语义只有一个 Current Owner。
2. Feature 不重新发明 Button / IconButton / Select / Card / Dialog / Popover / SettingRow。
3. First-party runtime 不使用 `MutationObserver` 做修复、升级或接管。
4. Source owner 首次输出 final DOM；跨模块通过 semantic event 同步。
5. Presentation layer 不持有 qB API polling。
6. 手机只改变 presentation；业务/API/state 共用。
7. Touch-primary 交互目标至少 44×44 CSS px。
8. HTML no-store；CSS/JS cache identity 使用 exact Git SHA。
9. Reduced Motion 必须生效。
10. 缺少新版本 capability 时先评估性能预算；禁止默认用 O(N) 网络工作伪造兼容。
11. Modal/top-layer 内的 dropdown 以可靠交互优先，不为了“全自绘”牺牲可用性。
12. 用户看到的是 capability 边界，不是内部兼容实现说明。
13. Shared control/dialog skin 由 `css/ui.css` 统一提供；feature CSS 只允许声明语义 geometry variables。
14. Canonical owner 删除后，不可达 caller、shim、兼容 hook 也必须退出 runtime。

## 3. Runtime asset naming / cache

Active first-party runtime uses stable semantic paths。禁止：

```text
*-vNNN.css/js
vNNN.css/js
old-name alias/shim
old + new semantic pair
hidden loader to deleted version asset
dormant caller to retired compatibility API
```

身份分离：

```text
VERSION        product version
exact Git SHA  runtime/cache/test identity
tag / Release  distribution identity
Git history    previous implementation archive
```

正确 cache URL：

```text
layout.css?v=<exact-sha>
transfer.js?v=<exact-sha>
```

任何 code/test/doc commit 都会产生新的 exact candidate；旧 SHA 的 CI/LIVE 结果不能继承。

## 4. CONTROL-001

所有 interactive control 支持：

```text
Default
Hover
Focus-visible
Active / Selected
Disabled
```

Icon-only action 必须有 accessible label 与 tooltip/title。Disabled control 不做误导性的位移动画。

## 5. CONTROL-SKIN-001 — shared visual primitive owner

行为 owner 与视觉 owner 可以分层，但不能因此出现多个 feature-local visual owner。

```text
Select behavior / floating-native mode
  -> W.Components.selectControl()

Select visual skin
  -> css/ui.css

Dialog visual / scroll skin
  -> css/ui.css

feature CSS
  -> geometry variables only
```

允许 feature 设置：

```text
--ui-select-h
--ui-select-width
--dialog-width
--dialog-max-width
--dialog-max-height
--dialog-padding
```

禁止：

```text
transfer.css .ui-select__native { ...skin... }
settings.css .ui-select__native { ...skin... }
feature-local dark-mode Select patch
app.css generic dialog skin/overflow
feature dialog 用 !important 对抗 shared primitive
```

## 6. SELECT-001 — one primitive, two explicit presentations

所有 Select 通过：

```text
W.Components.selectControl(options)
```

### Floating presentation

默认模式：canonical trigger + FloatingLayer menu。适合普通页面和需要 searchable/collision handling 的选择器。

### Native presentation

```text
W.Components.selectControl({native:true,...})
```

仍由同一个 primitive 创建、同步 value/onChange；内部只有一个 live native `<select>`。用于 browser top-layer/modal 等原生控件更可靠的场景。

禁止：

```text
MutationObserver scan <select>
upgradeNativeSelects()
old native + custom clone 同时存活
feature-local popup math
Settings fallback createElement('select')
```

`native:true` 是 canonical Select 的 presentation mode，不是 compatibility layer。

## 7. NATIVE-THEME-001 — resolved theme owns native controls

Native `<select>` 不得依赖浏览器默认白色主题。

Canonical skin 必须：

```text
html[data-theme=dark]
  -> color-scheme: dark
  -> control surface/text/border from shared dark tokens
  -> option/optgroup surface/text from shared dark tokens

html[data-theme=light]
  -> color-scheme: light
  -> same semantic roles resolved to light tokens
```

Transfer 的 `1 min` Chart window 和 `Auto · KiB/s` Rate unit 必须计算出同一组 canonical surface/text/border/option theme。任何一个 feature 不得单独“修黑”。

## 8. DIALOG-SCROLL-001 — bounded shell, internal overflow only

Canonical Dialog：

```text
outer dialog shell
  overflow: hidden
  bounded width/max-height

head
  intrinsic

body / form / long action list
  internal scroll only when content genuinely overflows

actions
  intrinsic
```

短 capability/confirm/prompt dialog 在普通 desktop/mobile viewport：

```text
outer scrollbar = none
body scrollbar  = none
```

只有真实内容高度超过 viewport 时才允许 internal scroll；禁止用移动端全局 `dialog{overflow:auto}` 把每个短弹窗都变成滚动容器。

## 9. ROUTE-OWNER-001

Route 变化由 `app.js` 一次提交：

```text
active view
Top nav active state
Mobile nav active state
sidebar/tool-route scope
Back state
drawer close
weigg:route-state
```

`ux.js`、`spatial.js`、`settings.js` 不得再次切换/阻断 `.is-active`、`.is-tool-route` 或 canonical route event。

Acceptance：

```text
RSS -> Settings
=> RSS no longer active
=> Settings active
=> Torrent sidebar/filter shell absent

Torrent filter -> Settings
=> old filter state may remain as library state
=> but filter UI is not visible/interactive inside Settings route
```

## 10. SETTINGS-STRUCTURE-002

Canonical ordinary SettingRow：

```text

├─ SettingCopy
│  ├─ SettingTitle
│  └─ Description
└─ SettingControlSlot
```

Wide two-column；narrow one-column。Ordinary row `span=1`；`span=full` 只允许 schema 显式声明 multiline/composite/list/table/large editor。

## 13. SELECTION-001 / OWNER-RETIRE-001

桌面：

```text

Ctrl/Cmd click                 -> toggle
Shift click                    -> range
checkbox                       -> toggle
click title/details            -> detail only
right-click                    -> ActionRegistry
```

Mobile：

```text

```

Top More / right-click / mobile More / long-press 不能维护不同 action list。

`W.Selection` 不得保留 `TorrentSemantics.resolveMany` 或其它 retired qB4 Private resolver caller。Canonical capability 被删除后，所有不可达 caller/shim/no-op hook 也必须删除；Git history 才是 archive。

## 14. COMPAT-DEGRADE-001 / PERF-COMPAT-001

当旧 qB 缺少新能力：

```text
cheap + authoritative fallback exists -> adapter may normalize
faithful fallback requires O(N) / N-per-item requests -> do not emulate by default
```

需要高成本兼容时必须单独设计性能预算并由开发者明确确认；不得悄悄加入 crawler/cache queue。

用户提示保持中立：最低支持版本、当前版本、如需此功能建议升级、升级前备份。不要把“接口缺失、逐种子请求、性能原因”等内部解释塞给普通用户。

## 15. PRIVATE-PT-001

`W.TorrentSemantics.classify()` 输出：

```text
PRIVATE_PT | PRIVATE | PT | PUBLIC | UNKNOWN
```

### qB 5.0.0+

使用 collection/list 中 authoritative `private` / 等价 metadata。Metadata pending -> `UNKNOWN`。PT domain rule 只补充 PT 语义。

### qB 4.x

Collection `私有 / PT` 不做逐种子 tracker/properties 模拟。

Acceptance：

```text
entry remains visible
entry carries 5+ capability marker
click -> capability dialog
filter does not switch
0 tracker requests caused by this action
0 per-torrent privacy enrichment requests
compact dialog has no outer/body scrollbar on desktop/mobile
```

Detail/list 不应假装拥有 qB4 collection Private metadata。

## 16. PROGRESSIVE-DATA-001

首屏可用性不等待全库 count/catalog。

```text
request current page with pageSize+1
render first page immediately
extra item determines hasNext
build catalog in background
```

总数未知时 page label：

```text
[spinner] 第 1 页 · 每页 50
```

禁止 `第 1 / ? 页`。Catalog 完成后再显示 `第 X / Y 页`。

Catalog error 不能把当前 page 变成不可用；用轻量 error indicator，并保留 bounded next/prev behavior。

## 17. TRANSFER-TELEMETRY-001

`W.TransferRuntime` 唯一拥有：

```text
existing getTransferInfo capture -> RAW_MAX 900
minute aggregation              -> BUCKET_MAX 720
sync/maindata                   -> dhtNodes / peers / freeSpace
```

不创建第二套 recurring speed poll。

Long history：

```text
1m / 5m / 15m / 30m / 1h / 3h / 6h / 12h
```

1–15m 可使用 raw samples；更长窗口使用 minute buckets。扩大时间范围不得提高 API polling 频率或无限增加内存。

History 只存在当前页面内存；刷新清空，不写 qB 服务端，也不保存长期 localStorage speed history。

## 18. RATE-UNIT-001

WeiG Transfer business state 统一 B/s。

```text
NORMAL API -> B/s
ALT preference API -> KiB/s
QBClient owns KiB/s <-> B/s
Transfer UI only sees B/s
```

Rate editor：

```text
[NORMAL | ALT] [Auto / KiB/s / MiB/s / GiB/s]
Upload | Download
0 = Unlimited
```

上传字段在下载字段左侧。

`Auto` 是 display policy；显式单位改变 display/input scale。小值切换到 GiB/s 等单位时不能因两位小数格式被显示为 `0`。输入允许 decimal (`step=any`)；显示采用紧凑有效数字。

Dialog 必须先加载 authoritative NORMAL/ALT limits，再开放 `[open]` 可交互状态，避免空输入在快速切单位时被 capture 成 0。

Apply ALT 必须由 `QBClient.setAltSpeedLimits()` 在 API boundary 转回 KiB/s，Transfer UI 不直接写 `prefs.alt_*_limit`。

## 19. SELECT-TOPLAYER-001

Transfer Stats window 与 rate unit 位于 `<dialog>.showModal()` top layer 内，使用 canonical Select `native:true`。

原因不是增加兼容层，而是把 top-layer stacking/interaction 交给 browser native form control，避免 body portal 菜单出现“看见 trigger 但点了没反应/菜单在 modal 后面”的故障。

Browser regression 必须使用真实 `selectOption()` 验证，而不是只检查 option 文本存在；同时验证 dark resolved theme 下两个 native Select 的 computed theme 一致。

## 23. RESPONSIVE-001 / SCROLL-001

每个 active long route 一个 primary scroll owner。

Conceptual torrent result set 变化：

```text
filter / tracker / path / category / tag / search / sort / page / page-size
=> scroll reset 0
```

零结果使用 `.torrent-panel.is-empty`，不保留假可滚动空表格。

Mobile qB4 点击 Private capability 后，canonical mobile filter control 必须同步回真实 active filter，不能视觉假停留在 Private。

Dialog scroll 不属于这个 route primary-scroll 体系：outer dialog 永不做 generic scroll；只有 canonical internal dialog content 在真实溢出时滚动。

## 24. PROGRESS / REDUCED-MOTION

`progress.css` 是唯一 Torrent progress motion owner。100% 停止装饰 motion，并同时尊重：

```text
prefers-reduced-motion: reduce
html[data-motion="reduced"]
```

## 25. AUTH-SESSION-002

Logout acceptance：

```text
SessionController.logout()
→ QBClient.logout()
→ POST auth/logout
→ protected probe
```

Verified invalid 后才 clear/lock/replace。Back/BFCache 不得恢复 private shell。Auth bypass 造成 probe 仍成功时必须报告 `auth-bypass`，不能伪造 logged-out。

## 28. LIVE / cache boundary

One final dev `[ui]` exact HEAD must pass static + qB 4.1.9.1 / 5.2.0 Chromium regressions before it can become LIVE candidate。

Before promotion to `main`, the exact same SHA must pass real qB 4.1.9.1 + 5.2.x LIVE。Full stable-tag/Linux/Windows/multi-viewport remains Release candidate-only。
