# 004. UI、交互与缓存契约

版本：**0.3.7**  
状态：**Canonical engineering contract / Responsive UI System 3.3**

## 1. 总则

1. 同一种 UI 语义只能有一个 canonical owner。
2. feature 不重新发明 Button / IconButton / Select / Card / Dialog / Popover / SettingRow。
3. Settings ordinary row 必须由同一个结构与同一个 alignment contract 渲染。
4. full-span 是 schema metadata，不是字符串 heuristic。
5. 手机只改变 presentation；业务/API/state 共用。
6. HTML no-store；CSS/JS cache identity 使用 exact Git SHA。
7. Reduced Motion 必须生效。
8. qB 兼容按 endpoint/field/capability，不按 major 号硬编码。

## 2. Canonical Primitive Audit

| 语义 | Canonical owner | 规则 |
| --- | --- | --- |
| Button | `.btn` | shared states |
| Icon action | `.icon-btn` / `HeaderUtilityAction` | button/link same visual contract |
| Input | `.field-input` | shared focus/surface |
| Select | `W.Components.selectControl()` | no OS-dependent popup |
| Switch | `switch-control` | one boolean visual |
| Floating | `FloatingLayer` | portal + collision |
| Dialog | `AdaptiveDialog` | Header/Body/Actions |
| Setting layout | `SettingsGrid + SettingRow` | one geometry owner |
| Setting control alignment | `SettingControlSlot` | row-cell right edge |
| Readonly metadata | `FactRow` | not editable SettingRow |
| Brand motion | `W.AmbientMark` | one controller |
| Header utilities | `HeaderUtilityBar` | one icon-action template |
| Torrent selection | `SelectionModelV037` | model state |
| Torrent actions | `TorrentActionController` | one action surface |
| Data layout | `DataGridLayoutController` | rAF layout only |

## 3. CONTROL-001

All interactive controls support:

```text
Default
Hover
Focus-visible
Active / Selected
Disabled
```

Icon-only actions require an accessible label and Tooltip/title. Disabled controls do not animate position.

## 4. SETTINGS-STRUCTURE-002

Canonical ordinary SettingRow:

```text
SettingRow
├─ SettingCopy
│  ├─ SettingTitleLine
│  └─ Description
└─ SettingControlSlot
```

Every renderer/adaptor must converge to this structure before layout CSS applies.

Forbidden permanent second structure:

```text
strong
small
control
```

as three flat siblings with separate geometry CSS.

## 5. SETTINGS-GRID-002

```text
>1180px  -> two SettingsGrid columns
<=1180px -> one SettingsGrid column
```

Ordinary row default:

```text
span=1
layout=inline
```

If the number of ordinary settings is odd, the last row remains in the left cell. It does not stretch across the grid.

## 6. SETTINGS-ALIGN-002

Ordinary row internal geometry:

```text
grid-template-columns: minmax(0,1fr) auto
```

Acceptance rules:

```text
SettingCopy text-align = left
SettingCopy justify-self = stretch/start
SettingControlSlot justify-self = end
ordinary Setting title must not be center-aligned
Switch must not be centered in the cell
input/select right edge follows the control slot axis
```

This contract applies identically to Downloads, Connection, Speed, BitTorrent, Web UI, Advanced and WeiG WebUI.

## 7. SETTINGS-SPAN-002

Only schema can request full width.

Allowed examples:

```text
multiline textarea
tracker/list editor
large rules editor
certificate/key textarea
composite multi-control editor
embedded table/list
```

Not allowed:

```text
/path/
/url/
/host/
/username/
/password/
```

substring matching in key/title/description to decide span.

Paths and host/user/password inputs remain ordinary half-grid cells by default.

## 8. SETTINGS-OWNER-002

Historical centered FormRail geometry is retired for migrated SettingsGrid rows.

Forbidden:

```text
old FormRail width/grid-template !important
+
new SettingsGrid width/grid-template !important
```

controlling the same row.

Canonical geometry path:

```text
SettingsSectionPanel
→ SettingsGrid
→ SettingRow
→ SettingControlSlot
```

## 9. SETTINGS-RENDER-002

MutationObserver normalization may bridge legacy runtime output during migration, but it cannot remain the primary source of layout truth.

Forbidden as final architecture:

```text
observe DOM
→ detect guessed row
→ move row repeatedly
→ repair after every injection
```

Final owner renders/normalizes once from explicit schema/component structure.

## 10. CONTROL-REGISTRY-002

Semantic control mapping is centralized. A verified enum should render canonical Select instead of an unexplained numeric code.

Control width policy is semantic:

```text
switch            intrinsic
number/port       compact
select            content-fit + cap
text              medium
path/url           medium/wide but one cell by default
multiline editor   explicit full-width SettingBlock
```

No setting page defines its own width system.

## 11. HEADER-UTILITY-001

Desktop/tablet canonical order:

```text
[+ Add Torrent] [GitHub] [Blog] [Refresh] [Theme]
```

GitHub / Blog / Refresh / Theme share the same icon-action geometry and states.

External links:

```text
GitHub  https://github.com/weigefenxiang/WeiG-qB-WebUI
Blog    https://www.weigshare.com/
```

External action contract:

```text
semantic <a>
target=_blank
rel=noopener noreferrer
aria-label
Tooltip/title
same icon-btn hit area/focus/hover/active as runtime icon buttons
```

Do not create `.github-btn` / `.blog-btn` visual systems.

On narrow phone widths, external actions may be presented in ContextDrawer `Links`; semantics/registry remain unchanged.

## 12. BRAND-001

Header mark and `WeiG qB` remain separate Home targets using one `Navigation.goHome()` owner. About reuses the same BrandMark and AmbientMark controller.

No duplicate logo asset, SVG animation or separate About motion engine.

## 13. SELECT-001 / FLOATING-001

Visible Select uses `W.Components.selectControl()`. Native select may remain only as hidden data bridge.

Floating surfaces use body-level FloatingLayer with below → flip → shift → max-height → scroll collision behavior.

## 14. RESPONSIVE-001 / SCROLL-001

Each active long route has one primary scroll owner. Settings uses `settings-content`.

Phone is adaptive layout, not a separate application. Settings categories may move to ContextDrawer, but SettingRow semantics remain shared.

## 15. STATUS / TRANSFER

Desktop StatusDock keeps Torrent count left, Storage/Transfer/Connection centered, reserved status right.

Transfer download/upload remains one capsule and one shared editor. ALT mode retints the complete editor.

## 16. CACHE-001

HTML bootstrap:

```text
Cache-Control: no-store, no-cache, must-revalidate
Pragma: no-cache
Expires: 0
```

CSS/JS direct and lazy assets use exact deployment Git SHA. `VERSION` is product version, not cache identity.

## 17. SYSTEMIC-REGRESSION-001

The following patterns are release-blocking architecture regressions:

```text
dual SettingRow DOM shapes
dual Settings geometry owners
key-name full-span heuristic
observer/timer as permanent Settings renderer
high-specificity CSS arms race
center-aligned ordinary setting copy
page-local GitHub/Blog button style
```

## 18. Focused UI acceptance

A dev `[ui]` run uses one Linux Chromium runtime and must cover qB 4.1.9.1 + 5.2.0.

Settings assertions on wide viewport:

```text
all editable tabs use same owner classes
two outer columns
ordinary span=1
copy left aligned
control right aligned
odd final row not stretched
full-span only explicit allowlist
no centered ordinary title
Advanced final setting reachable
```

Header assertions:

```text
GitHub/Blog same dimensions/states as Refresh/Theme
correct external href/target/rel/aria
Brand mark/name separate Home targets
```

Full qB stable-tag / Linux / Windows / multi-viewport matrices run only for main manual Release candidate.

## 19. LIVE

Exact-SHA real qB 4.1.9.1 and 5.2.x validation remains required before promotion to main. Any new code/docs/UI commit produces a new candidate SHA and invalidates old LIVE certification for release promotion.
