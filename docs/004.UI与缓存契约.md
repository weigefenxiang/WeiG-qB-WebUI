# 004. UI 与缓存契约

Status: **current UI/cache contract**

## 1. Cache / file identity

Static asset path is stable; cache identity is exact Git SHA: `stable filename + ?v=<exact SHA>`. First-party runtime/test/deploy/docs filenames do not encode WeiG release versions. `VERSION`, `GIT_SHA`, tag/Release and qB/WebAPI capability versions remain valid identity/facts.

## 2. Canonical UI rules

### SELECT-TOPLAYER-001
Top-layer reliability still uses `W.Components.selectControl({native:true})`; no second Select system.

### CONTROL-SKIN-001
Select behavior = `W.Components.selectControl()`; shared floating/native Select and Dialog skin = `css/ui.css`.

### SELECT-SCROLL-001
`.ui-select__options` is the sole internal Select scroll owner. Mouse wheel/touch/scroll inside it must retain `scrollTop` and must not re-run floating anchor placement. External page/window/visualViewport scroll may reposition the menu.

### INTERACTION-TEST-001
Critical tests perform the real action and assert final state/visible result, not only DOM/class existence.

### PROGRESSIVE-DATA-001
Aggregate/index work never blocks primary data; unknown total uses bounded loading/error state and never a persistent `?`.

### DIALOG-SCROLL-001
Dialog shell stays bounded with `overflow:hidden`; only genuinely overflowing body/form/list regions scroll.

### NATIVE-THEME-001
Native Select/options follow resolved Light/Dark semantic tokens and `color-scheme`.

### OWNER-RETIRE-001
When a canonical owner changes, obsolete caller/state/event/CSS/test expectation leaves in the same change.

### HEADER-SEARCH-001
Header Torrent Search keeps one `#search-input` and one `app.search`. Desktop presentation is bounded full -> compact -> icon; focus expands the same input. Mobile uses the existing mobile Search trigger and the same input/state.

### STATUS-SIGNAL-001
Connection has one explicit semantic dot only. Connected may animate that dot; no second ring/dot/pseudo-element signal.

## 3. Theme / motion

Dark and Light use the same semantic control tokens. System `prefers-reduced-motion: reduce` and WeiG `data-motion="reduced"` disable the Connected pulse while preserving the same static semantic dot.

## 4. Responsive ownership

Mobile is adaptive presentation, not a second app. `W.MobileAdaptive` may move canonical controls or consume semantic state but owns no qB client, polling or independent business state. Touch-primary targets remain >=44×44 CSS px.

Desktop Topbar stays one row. Search is intentionally bounded near 320px on wide desktop, contracts toward 240px, then becomes a 40px icon-only presentation while remaining the same DOM/state owner.

## 5. Capability copy

Repository cleanup must not erase current qB/WebAPI compatibility facts:

```text
此功能需要 qBittorrent 5.0.0+
Tags requires WebAPI 2.3.0+
```

These remain current capability boundaries and are browser-tested.
