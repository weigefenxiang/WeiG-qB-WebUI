# 004. UI、交互与缓存契约

版本：**0.3.7**  
状态：**Canonical engineering contract / Clean Settings + Verified Session 3.4**

## 1. 总则

1. 同一种 UI 语义只能有一个 canonical owner。
2. feature 不重新发明 Button / IconButton / Select / Card / Dialog / Popover / SettingRow。
3. 当前第一方运行资产使用稳定语义文件名，不使用版本号作为文件 ownership。
4. Settings ordinary row 必须由同一个结构与同一个 alignment contract 直接渲染。
5. full-span 是 schema metadata，不是字符串 heuristic。
6. 手机只改变 presentation；业务/API/state 共用。
7. HTML no-store；CSS/JS cache identity 使用 exact Git SHA。
8. Reduced Motion 必须生效。
9. qB 兼容按 endpoint/field/capability，不按 major 号硬编码。

## 3. ASSET-NAMING-001

当前第一方 runtime 文件只按职责命名：

```text
css/app.css
css/ui.css
css/layout.css
css/settings.css
css/brand.css
css/logs.css

scripts/core.js
scripts/components.js
scripts/i18n.js
scripts/ui.js
scripts/layout.js
scripts/settings.js
scripts/brand.js
scripts/header.js
scripts/session.js
scripts/logs.js
scripts/app.js
scripts/bootstrap.js
```

具体是否需要某个 semantic file 由 owner 决定，但以下形式禁止作为最终 active runtime：

```text
*-vNNN.css
*-vNNN.js
vNNN.css
vNNN.js
old-name alias/shim
old + new 同时加载
```

版本号不属于 CSS/JS 文件身份。产品版本在 `VERSION`，分发版本在 tag/Release，缓存与 exact code identity 在 Git SHA。

`settings-brand-v037.css/js` 不直接保留成混合 `settings-brand.css/js`。Settings、Brand、Header、Session 必须拆回各自 semantic owner。

## 5. SETTINGS-STRUCTURE-002

Canonical ordinary SettingRow：

```text
SettingRow
├─ SettingCopy
│  ├─ SettingTitleLine
│  └─ Description
└─ SettingControlSlot
```

源 renderer 第一次就生成最终结构。禁止 final architecture 再把 flat siblings 当兼容输入。

迁移完成后 Settings 范围不允许继续出现：

```text
.settings-control
.settings-row--canonical
.setting-row-grid
.settings-section--rows
.settings-grid-canonical
```

```text

```

## 13. AUTH-SESSION-002

Logout acceptance：

```text
SessionController.logout()
→ QBClient.logout()
→ POST auth/logout
→ QBClient.probeSession()
→ protected request must become unauthenticated
```

仅 `auth/logout` HTTP success 不算完成。

Verified invalid 后：

```text
stop polling
block new authenticated work
clear volatile private app state
set logout guard
lock private shell
location.replace(public root)
```

## 14. AUTH-BFCACHE-001 / AUTH-BYPASS-001

Back/BFCache 不得恢复 private shell。`pageshow.persisted` 或 logout guard 存在时，SessionGate 必须先锁 shell，再重新走 server/session verification。

如果 qB localhost/subnet whitelist auth bypass 使 protected probe 仍成功：

```text
state = auth-bypass
not logged-out
show explicit server-policy explanation
```

前端不得伪造 success。

## 15. BRAND-001

## 16. SELECT-001 / FLOATING-001

Visible Select uses canonical `selectControl()`. Native select may remain only where genuinely needed as a hidden data bridge outside the final Settings renderer.

Floating surfaces use body-level FloatingLayer with below → flip → shift → max-height → scroll collision behavior.

## 17. RESPONSIVE-001 / SCROLL-001

Each active long route has one primary scroll owner. Settings uses `settings-content`.

Phone is adaptive layout, not a separate application. Settings categories may move to ContextDrawer, but SettingRow semantics remain shared.

## 18. STATUS / TRANSFER

Desktop StatusDock keeps Torrent count left, Storage/Transfer/Connection centered, reserved status right.

Transfer download/upload remains one capsule and one shared editor. ALT mode retints the complete editor.

## 19. CACHE-001

HTML bootstrap：

```text
Cache-Control: no-store, no-cache, must-revalidate
Pragma: no-cache
Expires: 0
```

CSS/JS direct and lazy assets use stable semantic paths plus exact deployment Git SHA. `VERSION` is product version, not cache identity.

因此禁止用以下方式做 cache busting：

```text
settings-v038.css
ui-v039.js
v040.css
```

正确方式：

```text
settings.css?v=<exact-git-sha>
ui.js?v=<exact-git-sha>
```

或等价的 `buildAssetUrl()` exact-SHA identity。
