# 004. UI 与缓存契约

Status: **v0.3.7 canonical UI contract**

> 本文定义 first-party UI primitive、交互、响应式、状态更新与缓存身份。总 authority 为 `DESIGN.md`；Torrent 工作区专项见 `008.Torrent工作区与状态所有权.md`。

## 1. UI primitive ownership

```text
Select behavior/presentation   W.Components.selectControl()
Select skin                    css/ui.css
Dialog skin/scroll             css/ui.css
Torrent Facet composition      W.SpatialRuntime
Torrent facet state            W.LibraryController
Selection/action semantics     W.Selection / ActionRegistry
Responsive/status placement    W.MobileAdaptive
Non-Settings geometry          css/layout.css
```

### CONTROL-SKIN-001

Shared control skin 只在 `css/ui.css`。Feature CSS 只能提供 semantic geometry variables，不得重复 native Select/background/border/theme skin。

### NATIVE-THEME-001

Canonical native Select 显式消费 resolved dark/light tokens 与 `color-scheme`；Dark option surface 不得回退 browser-default 白色。

## 2. Select contract

`W.Components.selectControl()` 同一 API：`getValue / setValue / setOptions / setDisabled / onChange`；presentation modes 为 floating 与 `native:true`。

### SELECT-TOPLAYER-001

Browser `<dialog>` top layer 内需要平台 dropdown 时使用同一 canonical Select 的 `native:true`，不新建第二组件、不 portal hack、不 Observer repair。

Torrent Facet 使用 floating mode；大量 Tracker/Path 可 searchable。Unsupported Tags 使用同一 Select 的 `onOpen` guard 打开 shared capability dialog。

## 3. Dialog contract

### DIALOG-SCROLL-001

```text
dialog.dialog        bounded shell + overflow:hidden
head                 intrinsic
body/form            only real overflow scrolls
actions              intrinsic
```

Private/PT、Tags、Transfer、Prompt 都消费同一 shell。

## 4. Torrent Desktop UI

Topbar 一行：

```text
Brand | Nav | flexible Search | + Add | Theme | utilities
```

永久没有 qB passive product badge 和 manual `Refresh`。Search 先缩，Nav/Actions 不换行。

Desktop Workspace：

```text
TorrentPanel only
  GridToolbar
  Header
  TorrentList
  Pager
```

原四张 Stats Card 明确定义为 **Mobile Summary only**，Desktop 不保留其高度或 margin。DataGrid toolbar 顺序：`page/columns ... Start Pause More Delete Expand`。

Torrent Sidebar：state filters -> Private/PT -> canonical Tracker/Path/Category/Tags Select。

## 5. Mobile adaptive UI

Mobile 是同一应用的 adaptive presentation：

```text
same LibraryController
same Selection / ActionRegistry
same Facet host
same TransferRuntime telemetry
same connection semantic event
```

### PRESENTATION-STATE-001

Mobile 不读取另一个 presentation node 作为 state source。Touch target >=44×44 CSS px。

Mobile Summary 保留 Download/Upload/Network/Torrent count；Desktop Statusbar 不在手机显示。

### ADAPTIVE-STATUS-001

Desktop/Mobile 可以把同一 connection state 放在不同 surface，但不得创建独立 API/state/polling owner。

## 6. Connection UI

现有 transfer cycle 取得 `connection_status` 并发布 `weigg:status-state`。`W.MobileAdaptive` 是单一 presentation owner：

```text
Desktop -> Statusbar ConnectionIndicator
Mobile  -> Network Summary
```

状态：connected=success green，firewalled=warning，disconnected/error=danger。

### LIVE-INDICATOR-001

Online pulse 是 CSS presentation only，不新增 timer/API。

### MOTION-STATUS-001

Connected glow 同时尊重 `prefers-reduced-motion: reduce` 与 `html[data-motion="reduced"]`；Reduced Motion 使用静态 glow。

## 7. Interaction testing

### INTERACTION-TEST-001

Critical UI test 必须执行 action -> semantic state transition -> visible/normalized result。

覆盖：

```text
Tracker Select actual choice -> LibraryController.tracker
qB4 Private click -> dialog + filter unchanged + no tracker request
unsupported Tags -> WebAPI 2.3.0 dialog + no request/state mutation
qB5 Tags actual selection
Start/Pause/More/Delete before Expand
Desktop Stats absent and TorrentPanel starts at workspace top
fixture firewalled -> Network limited
semantic connected/disconnected -> ConnectionIndicator changes
Reduced Motion -> pulse disabled
mobile summary consumes same connection state
```

## 8. Progressive data UI

### PROGRESSIVE-DATA-001

Primary page data 不等 catalog/count enrichment：initial spinner + Page 1；resolved Page 1/N；failure `! Page 1`；禁止 `Page 1 / ?`。

## 9. Telemetry paint

### TELEMETRY-PAINT-001

DHT/Peers only：`W.TransferRuntime sync/maindata -> weigg:maindata -> renderer`。Formatted text 未变化时 zero DOM write。禁止额外 timer/debounce polling/MutationObserver/CSS flash workaround。

## 10. Status UI

### STATUS-NOISE-001

后台 refresh success 静默；不显示 `Refreshed / 已刷新` 或 timestamp。

### STATUS-DEDUP-001

同一 viewport 不重复 durable state：Desktop Connection 在 Statusbar；Mobile Connection 在 Network Summary。

### STATUS-PLACEMENT-001

Persistent global state 进入最低成本 persistent surface，不用重复 global telemetry 占 primary workspace height。

Desktop Footer：

```text
Torrent count | Free space | Transfer capsule | Connection | transient actionable message
```

不同子系统 failure source-scoped；一个成功不能清另一个未恢复 failure。

## 11. Header utility contract

### HEADER-UTILITY-001

Permanent Topbar 只保留 identity/navigation/search/actionable utilities。qB product marker 和 manual refresh 的 DOM/caller/CSS/test contract 已退休；automatic polling 不受影响。

## 12. Capability UI

qB4 Private/PT：entry visible + 5+ -> shared dialog -> 0 mutation -> 0 tracker scan。

Tags：WebAPI >=2.3.0 normal canonical Select；低于边界时同一 control `onOpen` -> shared capability dialog。

## 13. Transfer modal UI

Window：`1 min / 5 min / 15 min / 30 min / 1 h / 3 h / 6 h / 12 h`。

Rate unit：`Auto / KiB/s / MiB/s / GiB/s`。Rate dialog 必须 `await loadLimits()` 后 `showModal()`；ALT conversion 留在 QBClient boundary。

## 14. Cache / exact identity

Stable semantic runtime filenames + exact deployment SHA query string。禁止 versioned runtime filename / hidden loader。

### OWNER-RETIRE-001

Canonical 替换时旧 DOM/CSS/caller/test expectation 同批删除。Git history 是 archive。

## 15. Reduced Motion

Torrent progress、pager spinner、ConnectionIndicator pulse 等 motion 同时尊重系统 Reduced Motion 与 WeiG `data-motion="reduced"`。视觉动画不使用 business timer。
