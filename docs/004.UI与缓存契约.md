# 004. UI 与缓存契约

Status: **v0.3.7 canonical UI contract**

> 本文定义 first-party UI primitive、交互、响应式、缓存身份与状态更新规则。总视觉/owner authority 为 `DESIGN.md`；Torrent 工作区专项见 `008.Torrent工作区与状态所有权.md`。

## 1. UI primitive ownership

```text
Select behavior/presentation   W.Components.selectControl()
Select skin                    css/ui.css
Dialog skin/scroll             css/ui.css
Torrent Facet composition      W.SpatialRuntime
Torrent facet state            W.LibraryController
Selection/action semantics     W.Selection / ActionRegistry
Responsive placement           W.MobileAdaptive
Non-Settings geometry          css/layout.css
```

业务模块不得造第二套 Button/Select/Dialog/Popover skin。

### CONTROL-SKIN-001

Shared control skin 只在 `css/ui.css`。Feature CSS 只能给宽高等 semantic geometry variables，不得重新定义 `.ui-select__native` background/color/border/theme。

### NATIVE-THEME-001

Canonical native Select 显式消费 resolved dark/light tokens 与 `color-scheme`。Dark select/option 不得使用 browser-default 白色菜单。

## 2. Select contract

`W.Components.selectControl()` 支持同一语义 API：

```text
getValue
setValue
setOptions
setDisabled
onChange
```

Presentation modes：

```text
floating default
native:true for modal/top-layer reliability
```

### SELECT-TOPLAYER-001

Browser `<dialog>` top layer 内需要平台原生 dropdown 时使用同一 canonical Select 的 `native:true`，不新建第二组件、不通过 portal hack/Observer 修复。

Torrent Facet 使用 floating mode；大量 Tracker/Path 可用 `searchable:true`。Unsupported Tags 使用同一 Select 的 `onOpen` guard 打开 canonical capability dialog。

## 3. Dialog contract

### DIALOG-SCROLL-001

```text
dialog.dialog        bounded shell + overflow:hidden
dialog head          intrinsic
dialog body/form     scroll only on real overflow
dialog actions       intrinsic
```

短 Private/PT / Tags capability dialog 在 desktop/mobile 不显示无意义 outer/body scrollbar。

## 4. Torrent workspace UI

Desktop Topbar 一行：

```text
Brand | Nav | flexible Search | + Add | qBittorrent | Refresh | Theme | utilities
```

Search 先缩，Nav/Actions 不换行。

Torrent Sidebar：

```text
state filters
Private / PT [5+ when unsupported]
[All Trackers]
[All Paths]
[All Categories]
[All Tags]
```

Facet 不重复显示 `Tracker / Save Path / Category / Tags` 外部 label。

Torrent workspace 不再显示：

```text
LIBRARY / 资源库
current filter page title
library-count-copy
filter-shelf
```

DataGrid toolbar desktop 顺序：

```text
page/columns ... Start Pause More Delete Expand
```

## 5. Mobile adaptive UI

Mobile 是同一应用的 adaptive presentation。

### PRESENTATION-STATE-001

Mobile 不读取另一个 presentation node 作为 state。必须消费：

```text
W.LibraryController
W.Selection
W.TransferRuntime
semantic events
```

同一个 `#facet-controls`、同一个 `#torrent-selection-toolbar` 只在显式 desktop/mobile slot 之间移动；不能 clone 第二份业务 DOM。

Touch target >=44×44 CSS px。

## 6. Interaction testing

### INTERACTION-TEST-001

Critical UI test 必须执行 action → state transition → visible/normalized result。

必须覆盖：

```text
Tracker Select actual choice -> LibraryController.tracker
qB4 Private click -> capability dialog -> filter unchanged -> no tracker request
unsupported Tags click -> WebAPI 2.3.0 capability dialog -> tag unchanged -> no Tags request
qB5 Tags actual selection -> tag state changed
Start/Pause/More/Delete before Expand
mobile canonical host movement without duplicate
```

仅检查 option/element 存在不算 interaction PASS。

## 7. Progressive data UI

### PROGRESSIVE-DATA-001

Primary page data 不等 catalog/count enrichment。

```text
initial:  spinner + Page 1 · 50 per page
resolved: Page 1 / N · 50 per page
failure:  ! Page 1 · 50 per page
```

禁止 `Page 1 / ?`。第一页到达即 render。

## 8. Telemetry paint

### TELEMETRY-PAINT-001

DHT/Peers 来源只有：

```text
W.TransferRuntime sync/maindata snapshot
→ weigg:maindata
→ Network renderer
```

如果 formatted text 未变化，不执行 DOM write。禁止额外 timer、debounce polling、MutationObserver 或 CSS 闪烁修补。

## 9. Status UI

### STATUS-NOISE-001

后台 refresh success 静默；不显示 `Refreshed / 已刷新` 或 refresh timestamp。

### STATUS-DEDUP-001

Network card 拥有 Connection；Footer 不重复 `Connected / 已连接`。

Footer durable UI：

```text
Torrent count | Free space | Transfer capsule | transient actionable message
```

不同子系统的 transient failure 要 source-scoped；一个成功不能清另一个尚未恢复的 failure。

## 10. Private/PT + Tags capability UI

qB4 Private/PT：

```text
entry visible + 5+
click -> shared capability dialog
0 filter mutation
0 tracker scan
```

Tags：

```text
entry always visible
WebAPI >= 2.3.0 -> normal Select
WebAPI < 2.3.0 -> onOpen capability dialog
```

Capability copy 面向用户，只写 requirement/current version/upgrade suggestion/backup reminder，不写内部 API 性能解释。

## 11. Transfer modal UI

Window：`1 min / 5 min / 15 min / 30 min / 1 h / 3 h / 6 h / 12 h`。

Rate unit：`Auto / KiB/s / MiB/s / GiB/s`。

Rate dialog 必须 `await loadLimits()` 后才 `showModal()`，避免 unit change 在空值 frame 捕获 0。

ALT Apply 仍通过 QBClient 的 B/s ↔ KiB/s boundary，不把 qB preference unit 泄漏到 UI。

## 12. Cache / exact identity

Runtime asset filename 语义稳定；URL cache identity 使用 exact deployment SHA：

```text
scripts/app.js?v=<exact-sha>
css/ui.css?v=<exact-sha>
```

禁止 versioned runtime filename / hidden loader。

### OWNER-RETIRE-001

Canonical 替换完成时旧 runtime DOM/CSS/caller/test expectation 同批删除。Git history 是 archive。

## 13. Reduced Motion

Torrent progress、pager spinner 等视觉 motion 同时尊重：

```text
prefers-reduced-motion: reduce
html[data-motion="reduced"]
```

视觉动画不使用 business timer。
