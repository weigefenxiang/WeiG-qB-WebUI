# 004. UI、交互与缓存契约

版本：**0.3.6**  
状态：**Canonical engineering contract**

## 1. 总则

WeiG qB WebUI 长期保持以下规则：

1. 同一种 UI 语义只能有一个 canonical component；feature 不重新发明 Button / Select / Card / Chip / Badge / Modal / Popover。
2. 页码、筛选、滚动位置、详情返回目标、focus mode、显示时区都属于用户交互状态；轮询不得破坏。
3. HTML 是 no-store bootstrap；CSS/JS 的资源身份由部署 Git SHA 决定，不使用产品 semver 做 cache key。
4. 手机不是缩小版桌面；App Shell 分配剩余 viewport，每个长页面只允许一个 primary scroll owner。
5. 动效用于短暂反馈和品牌呼吸，不允许持续霓虹、持续旋转或高频耗电动画。
6. 后端能力按 WebAPI/capability/field presence 判断，不按 qB major 号硬编码。

## 2. Canonical UI Primitive Audit

| 语义 | Canonical owner | v0.3.6 规则 |
| --- | --- | --- |
| Button / IconButton | `.btn` / `.icon-btn` | 一个状态系统 |
| Input / Search | `.field-input` / `.search-box` | 一个表面与 Focus ring |
| Select / Dropdown | `W.Components.selectControl()` | 不依赖 OS popup |
| Native Select bridge | `upgradeNativeSelect(s)` | 数据语义保留，视觉交给 canonical Select |
| Filter Chip | `W.Components.filterChip()` | feature 复用 |
| Compact boolean | `W.Components.checkControl()` | Follow latest 等复用 |
| Switch | `switch-control` | Settings boolean 唯一实现 |
| Badge / Status | `status-pill` | 状态语义颜色统一 |
| Card | `surface--card` / SettingCard | 不允许 feature-local card system |
| Panel | `surface--panel` | 数据/Settings 统一 |
| Floating | `surface--floating` + FloatingLayer | Select/Popover/Menu 等 |
| Modal | `dialog + surface--modal` | 不造第二套弹窗 |
| Torrent data | DataGrid + VirtualList | Data count != DOM count |
| Logs | DataPanel + VirtualList | newest-first + bounded |
| Brand motion | `W.AmbientMark` | CSS 表现 + JS 随机调度 |

Feature CSS 可以负责布局、列宽、数据行结构、响应式排列和 feature 独有语义状态；不能重新定义 canonical 控件的颜色、圆角、阴影、Focus、Hover、Disabled。

## 3. CONTROL-001

所有交互控件至少支持：

```text
Default
Hover
Focus-visible
Active / Selected
Disabled
```

Active/Selected 不能只依赖颜色；Disabled 禁止位移动画；Reduced Motion 下移除非必要 transform。

## 4. SELECT-001 / FLOATING-001

可见 Select 使用 `W.Components.selectControl()`。原生 `<select>` 可以保留为兼容/数据桥，但不作为 canonical 可见 popup。

必须支持：

```text
Arrow Up / Down
Home / End
Enter / Space
Escape
aria-haspopup=listbox
role=listbox / option
aria-selected
```

所有浮动 UI 进入 body-level portal：

```text
Trigger
  ↓ getBoundingClientRect()
#weigg-floating-layer
  ↓ position: fixed
Select / Dropdown / Menu / Popover / Timezone picker
```

碰撞规则：优先向下 → 空间不足翻转向上 → 水平 shift → 限制 max-height → 内部滚动。resize、scroll、visualViewport 改变时重新定位。不得通过不断增加 feature-local `z-index` 修复 clipping。

## 5. BRAND-001 — AmbientMark

结构：

```text
AmbientMark
├─ Mark / Logo
├─ Orbit layer
├─ Spark layer
├─ Shine layer
└─ Ambient scheduler
```

约 8–28 秒随机检查一次，允许本轮不触发；一次事件约 1–2 秒。效果池可包含 orbit、spark、tilt、shine、breathe、低概率组合。

硬规则：

- 不允许常驻 RAF loop；
- document hidden 时暂停；
- `prefers-reduced-motion: reduce` 禁用非必要动画；
- 随机源可注入用于 deterministic CI；
- branding 层如果重建 logo DOM，必须重新 `W.AmbientMark.install(mark)`，不能清除 orbit/spark/shine 子层。

## 6. LOGS-001

默认 newest-first：

```text
Newest
Older
Oldest
```

数据 contract：

```text
initial last_known_id = -1
incremental cursor    = current max ID
browser max           = newest 5000 rows
```

Follow Latest ON 时保持顶部；用户主动向下阅读历史后解除 Follow；Follow OFF 时在顶部插入新行必须补偿 scrollTop，保持阅读位置。

Logs 只消费 canonical Search / FilterChip / CheckControl / Select / Button / StatusPill / VirtualList，不拥有第二套控件视觉。

## 7. TIME-001 / TIME-002

显示时区属于浏览器，不写入 qB Preferences：

```text
qB timestamp
→ normalized epoch
→ W.Time / Intl.DateTimeFormat
→ selected IANA timezone
```

唯一全局入口位于 status dock。标准显示类似：

```text
✓ UTC+08:00 · Asia/Shanghai
✓ UTC+08:00 · System / Browser · Asia/Singapore
```

必须支持 DST、`+05:30`、`+05:45` 等真实偏移。选择保存于 `localStorage: weigg.timeZone`。切换时区只改变 visible text，不改变 epoch / `<time datetime>` / qB daemon / Docker / host timezone。

## 8. NAV-001 — Torrent Detail Context Back

Detail tab strip 左侧：

```text
[ ← Back to torrents ] [ Overview ] [ Files ] [ Trackers ] [ Peers ] ...
```

进入 Detail 前保存 list context；Back / Browser Back / Esc 返回原 page + scroll。直接打开 Detail URL 且没有有效内部 context 时 fallback 到 Torrent home。

Esc 优先级：

```text
1. Custom Select / Popover
2. Dialog
3. Input/Textarea editing
4. Torrent Detail Context Back
5. Torrent List existing behavior
```

## 9. SEMANTICS-001 — Private / PT

跨版本语义由 `W.TorrentSemantics` 统一：

```text
exact private field available
  → exact private OR PT tracker rule

exact private field unavailable
  → PT tracker rule fallback only
```

不得把 legacy 缺字段解释为 false-negative 的唯一依据，也不得伪造 exact private。

## 10. MOBILE-001 — Mobile Adaptive System 2.0

App Shell 是唯一 viewport owner：

```text
Topbar
Workspace remaining track
Statusbar
Bottom navigation / safe area
```

禁止页面自己使用 `100vh - Npx`、固定巨大 `min-height` 或多层竞争滚动。

### SCROLL-001

Torrent、Settings、Search、RSS、Logs、Detail 每个 active route 只能有一个 `[data-primary-scroll="1"]` 主滚动区。document 本身不得产生第二页空白。

### COMMAND-001

手机 Torrent 顶部：

```text
[Filter] [Torrent count] [Start] [Pause] [More] [Delete]
```

保持同一视觉行。空间不足时依次收紧 gap、padding、字体与非关键文本；不得先换行制造额外高度。

### FACET-001

手机 collapsed all-state 使用短语义：

```text
Tracker
Path
Category
Tag
```

展开数据源仍保留完整 `All Trackers / All Paths / All Categories / All Tags`。选择具体值后显示真实值。Desktop 保持完整 all-state 文案。

### VIEWPORT-001

Torrent panel 吃满剩余 workspace。Focus Mode 可以隐藏 command/facet/stats chrome，把空间交给数据 viewport；退出时恢复原布局和 scrollTop。

### MOBILE-CARD-001

次要指标优先单行：

```text
↓0B/s  ↑0B/s  ETA 29.8MiB
```

适配优先级：

```text
去掉冗余空格/零小数
→ 缩小 gap
→ 缩小 font/tracking
→ 最后才考虑 fallback
```

CSS 卡片高度和 VirtualList row height 必须共享同一 metric contract。

### MOBILE-STATS-001

手机 stats 信息层级：

```text
Label >= Value > Helper
```

旧 desktop/tablet `!important` 规则不得穿透并破坏 mobile typography token。

### TOOL-PAGE-001

Search / RSS / Logs 在手机只占一个 workspace viewport；结果区作为唯一数据滚动区吃满剩余空间。空结果不得制造巨大固定空白。

专项 viewport：

```text
320×568
360×800
390×844
430×932
```

## 11. STORAGE-001

唯一数据源：

```text
sync/maindata
└─ server_state.free_space_on_disk
```

含义：**qBittorrent 默认保存路径所在文件系统的可用空间**。不得标记为通用 VPS 根盘剩余空间。Docker bind mount 时通常对应挂载数据路径背后的宿主文件系统。

格式：

```text
B / KiB / MiB / GiB / TiB
```

按人类阅读习惯自动换算和自适应小数，**不规定固定 3 位有效数字**。

Telemetry contract：

- 独立于 Torrent polling 的低频刷新；
- 第一次 full snapshot 后使用独立 incremental RID；
- partial sync 未返回该字段时保留上一有效值；
- 从未取得有效值且 unsupported/error 时隐藏；
- `0 B` 是有效真实值，不能转成 unavailable。

## 12. SETTING-UNIT-001

Advanced numeric Preference 只有在 qB 官方源码/API 语义验证后才能增加 unit、display conversion 或 special-value 描述。

已验证示例：

```text
slow torrent timer               s
slow torrent rate threshold      KiB/s
send buffer watermark            KiB
socket recv/send buffer          API B ⇄ display KiB
torrent_file_size_limit          API B ⇄ display MiB
disk_queue_size                  API B ⇄ display KiB
memory_working_set_limit         MiB
checking_memory_use              MiB
hostname_cache_ttl               s
refresh_interval                 ms
save_resume_data_interval        min
```

特殊 `0` 语义必须明确，例如 System default / Disabled / Permanent lease。已验证枚举使用 canonical Select。任何 display conversion 必须 round-trip 到精确 WebAPI raw value。

## 13. Settings Contract

卡片结构保持：

```text
Title
Description
Control / readonly value
```

qB Preference → `W.Components.preferenceField()`  
WeiG readonly metadata → `W.Components.readonlySettingField()`  
WeiG browser/interface preference → `settings-control`

Alternative WebUI 路径/关闭安全逻辑继续存在，但视觉不得建立第二套 Settings system。

手机 Settings 的 `settings-content` 是唯一主滚动区，必须可以到达最后一个设置项。

## 14. CACHE-001 ～ CACHE-005

HTML bootstrap：

```text
Cache-Control: no-store, no-cache, must-revalidate
Pragma: no-cache
Expires: 0
```

部署 HTML：

```html
<meta name="weigg-build-sha" content="<git-sha>">
```

直接与 lazy CSS/JS 都使用同一个 Git SHA：

```text
css/app.css?v=<git-sha>
scripts/app.js?v=<git-sha>
spatial-v022.js?v=<git-sha>
v030.js?v=<git-sha>
v036.js?v=<git-sha>
...
```

禁止使用 `?v=0.3.6` 作为 cache identity。历史文件名版本号只表示 lineage。

安装目录身份：

```text
VERSION                 product version
GIT_SHA                 exact deployed source
private/weigg-install.json deployment metadata
```

生产仍需验证实际 HTTP header，因为反向代理/CDN 可覆盖源站策略。

## 16. LIVE Gate

发布到 `main` 前仍要求至少：

```text
qB 4.1.9.1 / WebAPI 2.2.1
qB 5.2.x   / WebAPI 2.15.x
```

真实环境由操作者提供；仓库不写死服务器 URL、凭据、容器名或机器路径。`tests/live-v036.sh` 只原子替换指定 Alternate WebUI 目录并生成备份/回滚信息，不要求重启 Docker/qBittorrent。

## 17. 结论

v0.3.6 的长期规则：

> **一个语义一个 owner；浮层统一进 FloatingLayer；手机页面一个主滚动区；用户位置属于状态；时间属于浏览器显示层；磁盘空间只展示 qB 实际提供的 filesystem telemetry；Advanced 单位只来自已验证语义；兼容性由 capability 而不是 major 号决定。**
