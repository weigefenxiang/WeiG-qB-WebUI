# 004. UI、交互与缓存契约

版本：**0.3.6**  
状态：**Canonical engineering contract**

## 1. 目标

本文件定义 WeiG qB WebUI 必须长期保持的工程规则：

1. 同一种 UI 语义只能有一个 canonical component；功能版本文件不得重新发明 Card / Grid / Button / Select / Chip / Badge / Modal / Popover。
2. 用户的滚动位置、页码、筛选、详情返回目标、显示时区都属于前端交互状态；后台轮询不得破坏。
3. HTML 是 no-store 启动入口；CSS/JS 的资源身份由部署 Git SHA 决定，不使用产品版本号做缓存键。
4. 动效用于短暂反馈和品牌呼吸，不允许持续霓虹、持续旋转或高频耗电动画。

## 2. Canonical UI Primitive Audit

| 语义 | Canonical owner | v0.3.6 规则 |
| --- | --- | --- |
| Button / IconButton | `.btn` / `.icon-btn` | 一个状态系统 |
| Input / Search | `.field-input` / `.search-box` | 一个表面与 Focus ring |
| Select / Dropdown | `W.Components.selectControl()` | 不依赖 OS 白色 popup |
| Native Select compatibility | `upgradeNativeSelect(s)` | 原控件保留数据语义，视觉交给 canonical Select |
| Filter Chip | `W.Components.filterChip()` | Logs/后续过滤器复用 |
| Checkbox / compact toggle | `W.Components.checkControl()` | Follow latest 等复用 |
| Switch | `switch-control` | Settings boolean 唯一实现 |
| Badge / Status | `status-pill` | 状态语义颜色统一 |
| Card | `surface--card` / SettingCard | 不允许 feature-local card |
| Panel | `surface--panel` | DataPanel/Settings 等统一 |
| Floating / Popover | `surface--floating` | Select/Facet/Connection 等 |
| Modal | `dialog + surface--modal` | 不造第二套弹窗 |
| Tooltip | canonical Tooltip | hover 必须有键盘/触摸替代 |
| Torrent data | DataGrid + VirtualList | DOM 数量与数据量分离 |
| Logs | DataPage + DataPanel + VirtualList | newest-first + bounded |
| Brand motion | `W.AmbientMark` | CSS 表现 + JS 随机调度 |

### UI-001 — 一个语义，一个实现

禁止：

```text
feature-x__button
feature-x__select
feature-x__chip
feature-x__card
feature-x__popover
```

当这些 class 只是重新实现已有组件的颜色、圆角、阴影、Hover、Focus、Disabled 时必须删除。

允许 feature CSS 负责：

```text
布局
列宽
数据行结构
响应式排列
feature 独有的语义状态
```

不允许 feature CSS 负责：

```text
重新定义 Button/Select/Card/Chip 的视觉语言
随意新增一次性颜色
自行维护 Focus ring
自行维护阴影/圆角体系
```

## 3. Control 状态契约

### CONTROL-001 — 五个基本状态

所有交互控件至少支持：

```text
Default
Hover
Focus-visible
Active / Selected
Disabled
```

规则：

- Default 就必须能从背景中识别，不能等 Hover 才看得见；
- Hover 可轻微提升边界/表面，不持续发光；
- Focus-visible 使用统一蓝色 Focus ring；
- Active/Selected 同时通过形状/填充/aria 状态表达，不能只靠颜色；
- Disabled 降低对比度并禁止动画位移；
- Reduced Motion 下移除非必要 transform 动画。

### SELECT-001 — Canonical Select/Listbox

系统原生 `<select>` 的 popup 在 Windows/Chrome 等环境可能由 OS 绘制，从而出现暗色页面中的白色菜单。v0.3.6 起视觉层统一使用：

```text
Select Trigger
  ↓
Floating Listbox
  ├─ optional Search
  ├─ Option
  ├─ Selected Option
  └─ keyboard navigation
```

必须支持：

```text
Arrow Up / Down
Home / End
Enter / Space
Escape
aria-haspopup=listbox
role=listbox / option
aria-selected
```

原生 Select 可以作为兼容/数据桥保留，但不得作为 canonical 可见 UI。

### CHIP-001

Filter Chip 只使用 `W.Components.filterChip()`。Logs 的 Normal / Info / Warning / Critical 不得再拥有自己的 Button 视觉系统。

### CHECK-001

紧凑布尔交互（例如 Logs Follow latest）使用 `W.Components.checkControl()`；Settings boolean 仍使用 Switch，两者语义不同但各自只有一个实现。

## 4. Ambient Brand Mark

### BRAND-001 — 可复用模板

品牌图标使用通用 `AmbientMark` 结构：

```text
AmbientMark
├─ Mark / Logo
├─ Orbit layer
├─ Spark layer
├─ Shine layer
└─ Ambient scheduler
```

CSS 负责表现，JavaScript 只负责随机时机与效果选择。

### BRAND-002 — 偶发而非常驻

默认状态必须安静。调度窗口：

```text
约 8–28 秒随机检查一次
允许本轮不触发
一次事件约 1–2 秒
```

效果池可以包括：

```text
orbit       外圈短暂旋转
spark       少量多色星点闪烁
tilt        轻微 3D 倾斜
shine       一次高光扫过
breathe     轻微亮度/饱和度呼吸
orbit+spark 低概率组合
```

禁止持续旋转、持续闪烁、随机 RGB 霓虹和每帧 JS 动画。

### BRAND-003 — Token 与性能

- 颜色来自 WeiG semantic tokens；
- 页面隐藏时停止 scheduler；
- 不使用常驻 `requestAnimationFrame`；
- `prefers-reduced-motion: reduce` 时关闭 orbit / tilt / spark 动画；
- 随机源可注入，保证 CI 可确定性测试；
- 组件不能写死 WeiG qB，未来其它 WeiG 网站可以复用同一模板。

## 5. Logs 契约

### LOGS-001 — Newest First

日志默认排序：

```text
最新
↓
较旧
↓
最旧
```

内部优先按 numeric ID 降序；没有可靠 ID 时按 timestamp 降序。

### LOGS-002 — Incremental API 不改变

首次：

```text
last_known_id = -1
```

增量：

```text
last_known_id = 当前最大 ID
```

UI 倒序不意味着向 qB 发送倒序 ID。浏览器仍保留最大 ID 作为增量游标。

### LOGS-003 — Bounded

主日志最多保留 **5000 条最新记录**：

```text
newest-first array
→ slice(0, 5000)
```

### LOGS-004 — Follow latest

Newest-first 下“跟随最新”意味着保持顶部。

- 开启：新日志进入后保持 top；
- 用户主动向下滚动看历史时自动解除 Follow；
- Follow 关闭后，新行插入顶部必须补偿 scrollTop，使用户仍看到同一批历史记录；
- 搜索/严重级别改变属于主动 context change，可以回到顶部。

### LOGS-005 — Logs 只消费 canonical controls

Logs 只能组合：

```text
Search
FilterChip
CheckControl
Select
Button
StatusPill
DataPanel
VirtualList
```

不得再出现 `.log-filter-chip`、`.logs-follow-control` 这类重新实现视觉组件的规则。

## 6. Client Time Zone

### TIME-001 — 时区属于显示层

时区选择不写入 qB Preferences，也不修改服务器时间。

```text
qB timestamp
    ↓
稳定 epoch contract
    ↓
W.Time / Intl.DateTimeFormat
    ↓
用户选择的 IANA Time Zone
```

### TIME-002 — 可用时区

首项：

```text
System / Browser
```

然后提供常用 IANA zone，并在浏览器支持时使用：

```js
Intl.supportedValuesOf('timeZone')
```

生成完整列表。

旧浏览器使用常用时区 fallback。

### TIME-003 — 存储

当前选择保存在浏览器 localStorage：

```text
weigg.timeZone
```

Logs toolbar 与 WeiG Settings 访问同一状态，不建立第二份 timezone store。

### TIME-004 — 时间源不可变

切换时区只能改变显示文本：

```text
<time>.textContent  ✓ 可以变化
<time datetime>     × 不可变化
epoch timestamp     × 不可变化
```

## 7. Torrent Detail Navigation

### NAV-001 — Context Back

Torrent Detail 的 tab strip 左侧必须有明确返回：

```text
[ ← Back to torrents ] [ Overview ] [ Files ] [ Trackers ] [ Peers ] ...
```

它与浏览器 Back、Esc 使用同一导航语义。

### NAV-002 — 用户位置属于状态

进入 Detail 前至少保存：

```text
page
page size / current in-memory page state
filter/facet/search state（由 App state 保持）
Torrent list scrollTop
internal return target
```

示例：

```text
Page 2 + scroll 600px
        ↓
Torrent Detail
        ↓ Back / Esc
Page 2 + scroll 600px
```

轮询不得把返回后的用户重新拉到 Page 1 / scroll 0。

### NAV-003 — 站内上下文优先

只有存在有效内部 Torrent list context 时才使用 history return。直接打开 `#/torrent/<hash>` 而没有站内来源时必须 fallback 到 Torrent home，不能把用户送到任意站外历史页面。

## 8. Escape Priority

### KEYBOARD-001

Esc 优先级：

```text
1. Custom Select / Popover 打开 → 关闭它
2. Dialog 打开                → 由 Dialog 处理
3. Input/Textarea 正在编辑     → 不抢按键
4. Torrent Detail             → Context Back
5. Torrent List               → 原有 selection 行为
```

不同 feature 不得各自注册互相冲突的 Esc 语义。

## 9. Settings Contract

所有 Settings 卡片保持：

```text
Title
Description
Control / readonly value
```

qB Preference：`W.Components.preferenceField()`  
WeiG readonly metadata：`W.Components.readonlySettingField()`  
WeiG interface setting：`settings-control`

Alternative WebUI 的安全确认/路径校验仍由兼容层负责，但视觉层不得重新创建卡片。

## 10. Cache Contract

### CACHE-001 — HTML no-store

`private/index.html` 与 `public/login.html`：

```text
Cache-Control: no-store, no-cache, must-revalidate
Pragma: no-cache
Expires: 0
```

生产仍需验证最终 HTTP Header，因为 Cloudflare/Nginx 可能覆盖源站策略。

### CACHE-002 — 一个 Build SHA

部署 HTML：

```html
<meta name="weigg-build-sha" content="<git-sha>">
```

### CACHE-003 — CSS/JS 使用 Git SHA

```text
css/app.css?v=<git-sha>
scripts/app.js?v=<git-sha>
```

禁止：

```text
?v=0.3.6
?v=0.3.x
```

### CACHE-004 — Lazy assets 同一 SHA

所有动态 runtime，包括：

```text
v022.css
v030.css
v036.css
spatial-v022.js
brand-v031.css
v030.js
v036.js
```

必须通过 `buildAssetUrl()` 获取同一个 build SHA。

历史文件名中的版本号只是文件 lineage，不是 cache identity。

### CACHE-005 — 部署身份

安装目录：

```text
VERSION
GIT_SHA
private/weigg-install.json
```

`VERSION` 是产品版本，`GIT_SHA` 是确切代码身份。

## 12. 结论

v0.3.6 的长期规则不是“把某个下拉框涂黑”，而是：

> **所有交互控件共享同一设计语言；品牌动效是随机且克制的可复用模板；Logs 的时间与排序属于浏览器显示层；用户的页面与滚动位置属于必须被保护的交互状态。**
