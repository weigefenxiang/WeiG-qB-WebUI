# 004. UI 与缓存契约

Status: **current UI/cache contract**

## 1. Cache / identity

Static asset path 使用稳定职责名；cache identity 使用 exact Git SHA：`stable filename + ?v=<exact SHA>`。First-party 文件名和 semantic identifier 不编码 WeiG revision，Git history 是 revision archive。

## 2. Canonical UI ownership

- `W.Components.selectControl()`：Select behavior；
- `css/ui.css`：shared Select/Dialog skin；
- `W.Feedback`：transient feedback；
- `W.Components`：Torrent progress projection/DOM；
- `W.HeaderUtilities`：route-aware Header Search dispatch；
- `W.MobileAdaptive`：adaptive placement，不拥有业务 state/client/polling；
- `W.CapabilityRegistry + W.ReleaseProfile`：user-facing compatibility presentation facts。

UI/presentation **不得**拥有 qB/WebAPI historical semantic policy。Parameter rename、response field、HTTP status、mutation/no-op 等历史差异属于 Virtual protocol Endpoint Contract 目标 owner，不得以 UI selector、disabled state 或 feature-local version branch 表达。

## 3. Owner retirement / cutover

### OWNER-RETIRE
Canonical owner 替换旧实现时，obsolete caller/state/event/CSS/test expectation 必须退出。

### OWNER-CUTOVER
新 owner 可以先 dormant/isolated direct-test；一旦开始承担正式 responsibility，必须 atomic cutover 并删除被替代的旧工具/旧代码/旧测试。禁止 old/new dual-active fallback、shim、runtime alias。

## 4. Capability presentation

对 **source-bound** feature：exact upstream release surface 不支持时，normal UI **不渲染**该控件/筛选项；不再保留 disabled + upgrade badge clutter。

Capability Dialog 只在用户确实尝试不可用 route/action 且需要解释时使用。Unknown capability id fail closed。

Version/range/badge 只作为 fallback/diagnostic facts；不得从 WebAPI milestone 虚构 qB patch version，也不得覆盖 exact source truth。

## 5. Canonical interaction rules

### SELECT-TOPLAYER
Top-layer reliability 仍使用 canonical Select；无第二套 Select system。

### SELECT-SCROLL
内部 option list 是自己的 scroll owner，wheel/touch 不重跑 anchor placement。

### DIALOG-SCROLL
Dialog shell bounded；只有真实 overflow region scroll。

### INTERACTION-TEST
关键 browser test 必须执行真实用户动作并断言 semantic + rendered final state。

### PROGRESSIVE-DATA
Aggregate/index/enrichment 不阻塞 primary data。

### HEADER-SEARCH
全产品只有一个 Header Search DOM owner；Torrent/RSS/Logs 只是不同 semantic caller，不创建第二 query store。

### STATUS-SIGNAL
Connection 只有一个 semantic marker；Reduced Motion 保留状态、关闭 decorative movement。

## 6. Feedback contract

`W.Feedback / scripts/feedback.js` 是唯一 transient feedback owner：

- 一个 bounded stack，最多四张；
- capacity/timeout/manual removal 共用 canonical leave lifecycle；
- Desktop bottom-right、Mobile top safe-area 只是 adaptive placement；
- `duration:0` 是 processing activity，不伪造 business progress；
- Promise 完成后同一 card/rail 切换到 finite lifetime；
- error 使用 `alert`，其他使用 `status`；
- System/WeiG Reduced Motion 不改变最终状态。

## 7. Torrent progress contract

```text
real torrent.progress
-> W.Components.progressVisual(torrent)
-> canonical track/fill DOM
-> css/progress.css semantic skin/motion
```

Completed/paused/queued/stalled/error static；只有 active download/seed/checking 可有 subtle decorative motion。Completed 与 Seeding semantic 仍由 Torrent owner 区分。

## 8. Responsive ownership

Mobile 是同一 app state 的 adaptive placement，不创建第二 QBClient、filter、sort、Selection、Settings draft、Transfer history 或 capability state。

Desktop/Mobile 的 filter/facet/control 实例尽可能复用同一 DOM/owner；geometry 可以变化，semantic responsibility 不变。

## 9. Browser acceptance

Browser gates 保留对真实 interaction/final rendering 的覆盖，包括：

- Header Search route semantics；
- capability hide/fail-closed；
- Connection/Transfer/Reduced Motion；
- Feedback queue/lifecycle/adaptive layout；
- Torrent progress/status semantics；
- Desktop/Mobile same-owner behavior。

Browser qB coverage 是 representative generation coverage；全部 official stable structural compatibility 由 upstream stable audit 与 Pages exact catalog 负责，不在每个平台启动所有 qB binary。

## 10. Theme

`W.Theme` 是 Theme preference/resolution Current Owner；`W.Config` 只持久化 preference。System/Time/Light/Dark 解析、native `color-scheme`、Reduced Motion 均不得由 feature-local repair layer 重新实现。
