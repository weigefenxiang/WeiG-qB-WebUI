# 004. UI、交互与缓存契约

版本：**0.3.7**  
状态：**Semantic Ownership 3.6 / canonical engineering contract**

## 1. 总则

1. 同一种 UI/Data 语义只有一个 canonical owner。
2. feature 不重新发明 Button / IconButton / Select / Card / Dialog / Popover / SettingRow。
3. first-party runtime 不使用 `MutationObserver` 做修复、升级或接管。
4. source owner 首次就输出 final DOM；跨模块通过 semantic event 同步。
5. Presentation layer 不持有 qB API polling。
6. 手机只改变 presentation；业务/API/state 共用。
7. touch-primary 交互目标至少 44×44 CSS px。
8. HTML no-store；CSS/JS cache identity 使用 exact Git SHA。
9. Reduced Motion 必须生效。
10. qB 兼容按 endpoint/field/evidence/capability，不按 major 号拍脑袋硬编码。

## 3. Runtime asset naming / cache

Active first-party runtime uses stable semantic paths. 禁止：

```text
*-vNNN.css/js
vNNN.css/js
old-name alias/shim
old + new semantic pair
hidden loader to deleted version asset
```

身份分离：

```text
VERSION            product version
exact Git SHA      code/cache identity
tag / Release      distribution identity
Git history        previous implementation archive
```

正确 cache URL：

```text
settings.css?v=<exact-sha>
transfer.js?v=<exact-sha>
```

## 5. SELECT-001 — explicit canonical Select

Visible custom Select 必须由 source owner 明确调用：

```text
W.Components.selectControl(options)
```

禁止：

```text
MutationObserver scan <select>
upgradeNativeSelects()
old native control + new custom control 同时作为 live owner
Settings fallback createElement('select')
```

选择菜单 collision/portal 由 FloatingLayer 处理；业务 module 不自己算第二套 popup。

## 6. SETTINGS-STRUCTURE-002

Canonical ordinary SettingRow：

```text
SettingRow
├─ SettingCopy
│  ├─ SettingTitle
│  └─ Description
└─ SettingControlSlot
```

源 renderer 一次生成最终结构，然后发布：

```text
weigg:settings-render
```

这个事件允许 i18n/非 owner presentation 做同步，但不允许消费者重包/搬行。

## 11. PRIVATE-PT-001

`W.TorrentSemantics.classify()` 输出：

```text
PRIVATE_PT | PRIVATE | PT | PUBLIC | UNKNOWN
```

### Explicit metadata

qB 返回 authoritative `private`/等价 field 时直接使用。

### Metadata pending

```text
has_metadata=false
or state=metaDL/forcedMetaDL
=> UNKNOWN
```

绝不能伪装为 Public。

### qB 4.1.9.1 source-backed fallback

上游 4.1.9.1 WebAPI 的 synthetic tracker rows：

```text
[DHT] [PeX] [LSD]
```

Private 时三个 `msg` 都是同一个本地化非空理由；Public 时三个 `msg` 为空。关闭全局 DHT/PeX/LSD 只会影响 `status`，不改变这个语义。

Acceptance：

```text
all 3 rows + same non-empty msg -> Private
all 3 msg empty                -> Public
mixed/incomplete               -> Unknown
```

禁止 hardcode 英文文案；禁止 `status=disabled => Private`。

PT domain rule 只补充 PT，不能冒充 authoritative Private。

## 12. PRIVATE-PRESENTATION-001

Torrent list/card 可以展示 compact `PRIVATE` / `PT` / `PRIVATE · PT` badge。`PUBLIC` 和 `UNKNOWN` 默认不加误导 badge。

Detail Overview 可显示：

```text
Torrent 类型
Peer discovery
```

UNKNOWN 使用“待获取元数据”等明确文案，不说 Public。

## 13. TRANSFER-TELEMETRY-001

`W.TransferRuntime` 唯一拥有：

```text
getTransferInfo capture -> speed samples
sync/maindata           -> dhtNodes / peers / freeSpace
```

Speed capture 规则：包装现有 app `getTransferInfo()` 一次，不建立第二套 recurring speed poll。

maindata 规则：

```text
one rid
one in-flight promise
one bounded 30s metadata refresh lifecycle
visibility explicit refresh
weigg:maindata event
snapshot() for consumers
```

Responsive Storage 只能消费 snapshot/event。

## 14. TRANSFER-UI-001

Status capsule 有两个明确入口：

```text
live DL/UL -> realtime statistics
↕          -> global rate editor
```

Stats order：

```text
Session downloaded | Session uploaded | DHT / Peers
Global upload       | Global download | Free space
```

Chart windows：1 / 5 / 15 min。

Rate editor：

```text
[NORMAL | ALT] [unit]
Upload | Download
0 = Unlimited
```

上传字段必须在下载字段左侧。unit 使用 canonical Select。

Desktop compact rate dialog 不使用 Stats 的大 geometry，也不出现无意义 outer scrollbar。

## 15. STATUS-LAYOUT-001

Desktop statusbar 的布局 owner 是 `layout.css`：

```text
grid-template-areas:
"torrent storage transfer connection message"
```

每个主要 cluster 有明确 grid-area。不得依赖 DOM append 顺序 / auto placement。

`polish.css` 禁止重新声明 statusbar shell grid。

## 16. RESPONSIVE-001 / SCROLL-001

每个 active long route 一个 primary scroll owner。Settings 使用 `settings-content`。

Conceptual torrent result set 变化：

```text
filter / tracker / path / category / tag / search / sort / page / page-size
=> torrent scroll reset 0
```

Detail back 可恢复原 conceptual list position。

零结果使用 `.torrent-panel.is-empty`，不保留假可滚动空表格。

## 17. PROGRESS / REDUCED-MOTION

`progress.css` 是唯一 Torrent progress motion owner：

```text
width transition
flow
sweep
```

100% 停止装饰 motion。

必须尊重：

```text
prefers-reduced-motion: reduce
html[data-motion="reduced"]
```

## 18. AUTH-SESSION-002

Logout acceptance：

```text
SessionController.logout()
→ QBClient.logout()
→ POST auth/logout
→ QBClient.probeSession()
→ protected request must be unauthenticated
```

Verified invalid 后才：停止 private work、clear volatile state、set logout guard、lock shell、replace public root。

Back/BFCache 不得恢复 private shell。

qB localhost/subnet auth bypass 造成 protected probe 仍成功时：

```text
state = auth-bypass
not logged-out
```

前端不得伪造成功。

## 21. LIVE / cache boundary

Any code/test/doc commit creates a new exact candidate SHA. Old CI/LIVE certification does not carry forward.

Before promotion to `main`, the exact SHA must pass real qB 4.1.9.1 + 5.2.x LIVE. Full stable-tag/Linux/Windows/multi-viewport is Release candidate-only.
