# 004. UI 与缓存契约

Status: **current UI/cache contract**

## 1. Cache identity

Static resource path 保持稳定；缓存身份来自 exact Git SHA，而不是产品版本文件名。

```text
stable semantic filename + ?v=<exact Git SHA>
```

禁止 `foo-v037.js` / `foo-v038.css` / semver cache buster。允许且必须保留：`VERSION`、`GIT_SHA`、tag/Release、qB/WebAPI capability versions。

## 2. Current-only files

Active runtime / test / deploy / docs 文件名只描述职责。旧 WeiG 版本文件删除，不留 alias/shim/“reference copy”；Git history 是 archive。

## 3. Canonical primitives

Button / Select / Card / Badge / Dialog / SettingRow 使用 canonical primitive。Select = `W.Components.selectControl()`；shared skin = `css/ui.css`。

Dialog outer shell bounded + `overflow:hidden`；只有真实溢出的 body/form/list 内滚。

## 4. Theme / motion

Native Select/option 跟随 resolved Light/Dark tokens 和 `color-scheme`。

System `prefers-reduced-motion: reduce` 与 WeiG `data-motion="reduced"` 都禁用非必要 animation。Connection online indicator 在 Reduced Motion 下静态 glow。

## 5. Responsive ownership

Mobile 是 adaptive presentation，不是第二应用。`W.MobileAdaptive` 可移动 canonical controls / consume semantic state，但不得创建 qB client、polling 或独立 business state。Touch-primary target >=44×44。

## 6. Torrent workspace

Desktop：Topbar 单行；Search 优先伸缩；无 qB passive product marker / manual Refresh；Stats dashboard 不占 workspace；TorrentPanel flex-fill。

Mobile：保留 compact Download/Upload/Network/Torrent Summary；Desktop Statusbar hidden。

Desktop Footer：`"torrent storage transfer connection message"`。

## 7. Status semantics

Connection truthfully maps `connected / firewalled / disconnected / error`，不新增 API polling。Background success 静默；禁止 persistent `Refreshed / 已刷新` / last-refresh timestamp。

## 8. Capability copy

文件名去版本化不影响 current compatibility copy：

```text
此功能需要 qBittorrent 5.0.0+
Tags requires WebAPI 2.3.0+
```

这些属于当前能力边界，必须保留并由 capability tests 验证。
