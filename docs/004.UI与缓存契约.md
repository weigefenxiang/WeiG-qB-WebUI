# 004. UI 与缓存契约

Status: **current UI/cache contract**

## 1. Cache / file identity

Static asset path is stable; cache identity is exact Git SHA: `stable filename + ?v=<exact SHA>`. First-party filenames do not encode WeiG release versions. qB/WebAPI version strings remain current capability facts.

## 2. Canonical UI rules

### SELECT-TOPLAYER-001
Top-layer reliability still uses `W.Components.selectControl({native:true})`; no second Select system.

### CONTROL-SKIN-001
Select behavior = `W.Components.selectControl()`; shared floating/native Select and Dialog primitive skin = `css/ui.css`.

### SELECT-SCROLL-001
`.ui-select__options` is the sole internal Select scroll owner. Mouse wheel/touch/scroll inside it retains `scrollTop` and does not re-run floating anchor placement.

### INTERACTION-TEST-001
Critical tests execute the real interaction and assert semantic + visible final state.

### PROGRESSIVE-DATA-001
Aggregate/index work never blocks primary data; unknown total uses bounded loading/error state.

### DIALOG-SCROLL-001
Dialog shell stays bounded with `overflow:hidden`; only genuinely overflowing body/form/list regions scroll.

### NATIVE-THEME-001
Native Select/options follow resolved Light/Dark tokens and `color-scheme`.

### OWNER-RETIRE-001
When a canonical owner changes, obsolete caller/state/event/CSS/test expectation leaves in the same change.

### HEADER-SEARCH-001
Header Torrent Search keeps one `#search-input` and one `app.search`. Desktop presentation is bounded full -> compact -> icon; Mobile uses the same input/state.

### HEADER-END-ANCHOR-001
Desktop Add/Theme/GitHub/WeiG Share/Logout form one right-edge action rail. Search collapses before that rail loses its end anchor.

### STATUS-SIGNAL-001
Connection has one semantic marker. Motion acts on that marker itself only.

### RENDERED-SIGNAL-001
Visual acceptance is based on final rendering, not DOM count. Pseudo-elements, glow rings or pulse halos that look like a second marker are failures even if only one `.connection-indicator__dot` exists.

### STATUS-EXPLAIN-001
Connection Hover/Click help consumes existing semantic/network state and introduces zero new requests, polling or port scans.

### CAPABILITY-OWNER-001
User-facing compatibility badge/disabled/help policy belongs only to `W.CapabilityRegistry + data/capabilities.json`.

### CAPABILITY-RANGE-001
Capability rules use semantic ranges (`eq/gt/gte/lt/lte`, `all/any/not`), not an exact patch allowlist.

## 3. Capability presentation

Unsupported user-facing feature defaults to:

```text
visible
aria-disabled
qB-facing badge
hover reason
click -> canonical Capability Dialog
no business-state mutation
```

Examples:

```text
Private / PT   5+
Tags           4.2+
```

Dialog keeps the technical requirement too:

```text
Private exact metadata: qBittorrent 5.0.0+
Tags: WebAPI 2.3.0+
```

If a WebAPI requirement has no trustworthy qB equivalent, UI shows `需升级 / Upgrade` instead of inventing a qB version.

## 4. Theme / motion

Dark and Light share semantic tokens. Connected uses one gentle breathing marker; Network limited may use the same one-marker slower motion. `prefers-reduced-motion` and WeiG Reduced Motion make it static without changing semantic state.

`polish.css` must not create Connection `::before/::after` markers or rings.

## 5. Responsive ownership

Mobile is adaptive presentation, not a second app. `W.MobileAdaptive` owns no qB client or polling.

Desktop Topbar stays one row:

```text
wide    Search ~320px -> flexible gap -> actions at right edge
medium  Search ~240px -> flexible gap -> actions at right edge
narrow  Search icon   -> flexible gap -> actions at right edge
mobile  existing mobile trigger, same Search state
```

## 6. Interaction gates

Browser tests must cover:

```text
real time-zone wheel scroll + selection
one rendered Connection marker + animation + Reduced Motion
Connection hover reason + click troubleshooting Dialog
qB4 capability badge/disabled/dialog and unchanged state
qB5 supported state with stale badge removed
arbitrary semantic patch-range boundaries
Header action rail right-edge geometry
same Search state across desktop/mobile
Light/Dark
```
