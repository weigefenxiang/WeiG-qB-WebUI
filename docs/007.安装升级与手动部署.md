# 007. 安装、升级与手动部署

Status: **stable distribution guide + explicit dev channel**

本文件面向用户。默认稳定安装始终以 GitHub Release 为事实源；`dev` 是显式开发频道，只有用户主动选择时才使用，永远不会作为 Release 缺失时的自动 fallback。

## 1. 安装频道

### Release — 默认推荐

```text
Latest Release
https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest

WebUI ZIP
https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/WeiG-qB-WebUI.zip

SHA256 checksum
https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/SHA256SUMS
```

Release 安装必须同时满足：

```text
ZIP 可下载
SHA256SUMS 可下载且校验成功
GIT_SHA 为有效 40 位 Git SHA
public/index.html
public/login.html
private/index.html
```

任一项缺失即 fail closed，不回退 `main` 或 `dev`。

### dev — 显式开发频道

适合需要测试最新开发状态的用户。安装器先解析当前 `dev` exact SHA，再下载这个 SHA 的 source archive，只部署其中 `webui/`，并把 exact SHA 写入 `GIT_SHA` 和安装 metadata。

```text
dev != stable Release
dev != automatic fallback
```

## 2. 平台选择

| 环境 | 推荐方式 |
|---|---|
| Linux 原生 qBittorrent | `install.sh` |
| Docker / Docker Compose | `install.sh` 自动识别 `/config` mount |
| Synology / Unraid / TrueNAS SCALE 等 Linux/NAS | `install.sh`，或浏览器/命令行手动安装 |
| Windows | `install.ps1` |
| macOS / FreeBSD / 其它系统 | 手动安装 Release ZIP |
| 特殊容器/只读系统 | 手动安装到持久可写目录 |

## 3. Linux / Docker / NAS

### 3.1 Release 一键安装

```sh
curl -fsSL https://raw.githubusercontent.com/weigefenxiang/WeiG-qB-WebUI/main/installers/install.sh -o /tmp/weigg-qb-install.sh && sh /tmp/weigg-qb-install.sh --configure
```

默认 `channel=release`，无需额外参数。

### 3.2 dev 一键安装

```sh
curl -fsSL https://raw.githubusercontent.com/weigefenxiang/WeiG-qB-WebUI/dev/installers/install.sh -o /tmp/weigg-qb-install.sh && sh /tmp/weigg-qb-install.sh --channel=dev --configure
```

也可以用环境变量：

```sh
WEIGG_QB_CHANNEL=dev sh /tmp/weigg-qb-install.sh --configure
```

### 3.3 Linux/NAS 工具 fallback

安装器不会要求某一个固定工具组合。Downloader 顺序：

```text
curl
→ wget
→ BusyBox wget
→ Python urllib
```

ZIP extractor 顺序：

```text
unzip
→ BusyBox unzip
→ Python zipfile
→ bsdtar
```

Release SHA256 implementation 顺序：

```text
sha256sum
→ BusyBox sha256sum
→ shasum -a 256
→ openssl dgst -sha256
→ Python hashlib
```

因此精简 NAS 不必同时安装 `curl + unzip + sha256sum`。只要系统存在任意可用组合即可。

如果完全没有支持的 downloader/extractor，可在浏览器下载 ZIP 后上传到 NAS，再用系统现有 ZIP 工具解压。Release 安装如果没有任何 SHA256 实现，则拒绝以“未校验”方式继续。

### 3.4 Docker 自动识别

当宿主机存在一个 qBittorrent container 且有：

```text
/config -> host path
```

安装器可把默认 WebUI 目标映射为：

```text
Host install path:
<host-config>/weigg-qb-webui

qBittorrent Root Folder:
/config/weigg-qb-webui
```

qBittorrent 设置里填写的是 **container-visible path**，不是 Host path。

多个 container 时安装器拒绝猜测：

```sh
sh /tmp/weigg-qb-install.sh --list-containers
```

再显式选择：

```sh
sh /tmp/weigg-qb-install.sh --container=<qb-container> --configure
```

或指定宿主机 `/config` root：

```sh
sh /tmp/weigg-qb-install.sh --config-root=/path/to/qbittorrent/config --configure
```

### 3.5 自定义目录

原生 Linux：

```sh
sh /tmp/weigg-qb-install.sh --dir=/path/to/weigg-qb-webui
```

Docker 可直接给 qB-visible path：

```sh
sh /tmp/weigg-qb-install.sh --container=<qb-container> --dir=/config/weigg-qb-webui --configure
```

### 3.6 只安装文件

不自动修改 qB 配置：

```sh
sh /tmp/weigg-qb-install.sh
```

## 4. Windows PowerShell

### 4.1 Release

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/weigefenxiang/WeiG-qB-WebUI/main/installers/install.ps1 -OutFile $env:TEMP\weigg-qb-install.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Channel Release -Configure
```

Release 使用 `Get-FileHash -Algorithm SHA256` 校验 `SHA256SUMS`。

### 4.2 dev

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/weigefenxiang/WeiG-qB-WebUI/dev/installers/install.ps1 -OutFile $env:TEMP\weigg-qb-install.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Channel Dev -Configure
```

PowerShell installer 使用 GitHub API 解析 current dev SHA，然后下载该 exact SHA。

### 4.3 自定义目录

```powershell
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Channel Release -Destination "D:\Apps\WeiG-qB-WebUI" -Configure
```

默认目录位于当前用户可写的 `%LOCALAPPDATA%`。

### 4.4 只安装文件

```powershell
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Channel Release
```

## 5. qBittorrent 中启用

无论哪个系统，最终都使用 qBittorrent 标准 Alternate WebUI 设置：

```text
Tools / Options / Preferences
→ Web UI
→ Use alternative WebUI
→ Files location / Root Folder
```

目录至少包含：

```text
public/index.html
public/login.html
private/index.html
VERSION
GIT_SHA
```

Docker 通用示例：

```text
Host:        /path/to/qbittorrent/config/weigg-qb-webui
qBittorrent: /config/weigg-qb-webui
```

qBittorrent 必须填写 container-visible path。

## 6. 通用手动安装

适用于 Linux、Windows、macOS、FreeBSD、NAS 或无法使用自动脚本的环境。

### 6.1 浏览器直接下载 Release

打开：

```text
https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest
```

下载同一 Release 的：

```text
WeiG-qB-WebUI.zip
SHA256SUMS
```

### 6.2 curl

```sh
curl -fL https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/WeiG-qB-WebUI.zip -o WeiG-qB-WebUI.zip
curl -fL https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/SHA256SUMS -o SHA256SUMS
sha256sum -c SHA256SUMS
unzip WeiG-qB-WebUI.zip
```

### 6.3 wget

```sh
wget https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/WeiG-qB-WebUI.zip -O WeiG-qB-WebUI.zip
wget https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/SHA256SUMS -O SHA256SUMS
sha256sum -c SHA256SUMS
unzip WeiG-qB-WebUI.zip
```

### 6.4 BusyBox NAS

```sh
busybox wget -O WeiG-qB-WebUI.zip https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/WeiG-qB-WebUI.zip
busybox wget -O SHA256SUMS https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/SHA256SUMS
busybox sha256sum WeiG-qB-WebUI.zip
busybox unzip WeiG-qB-WebUI.zip
```

BusyBox 示例的 SHA256 输出需要与 `SHA256SUMS` 中 `WeiG-qB-WebUI.zip` 的值人工确认一致。

其它 ZIP 解压方式：

```sh
python3 -m zipfile -e WeiG-qB-WebUI.zip .
bsdtar -xf WeiG-qB-WebUI.zip
```

### 6.5 Windows 手动下载/解压

```powershell
Invoke-WebRequest https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/WeiG-qB-WebUI.zip -OutFile .\WeiG-qB-WebUI.zip
Invoke-WebRequest https://github.com/weigefenxiang/WeiG-qB-WebUI/releases/latest/download/SHA256SUMS -OutFile .\SHA256SUMS
Get-FileHash .\WeiG-qB-WebUI.zip -Algorithm SHA256
Get-Content .\SHA256SUMS
Expand-Archive .\WeiG-qB-WebUI.zip .\WeiG-qB-WebUI -Force
```

校验值必须一致。

## 7. 手动 dev 下载

优先使用 installer，因为它会把 `dev` 先解析成 exact SHA。

只做临时手动测试时，可以从 GitHub `Code → dev → Download ZIP`，或：

```sh
curl -fL https://github.com/weigefenxiang/WeiG-qB-WebUI/archive/refs/heads/dev.zip -o WeiG-qB-WebUI-dev.zip
unzip WeiG-qB-WebUI-dev.zip
```

手动 branch ZIP 的 Alternate WebUI root 是：

```text
WeiG-qB-WebUI-dev/webui/
```

不要把 qB Root Folder 指向 repository root。

注意：branch ZIP 是“下载时的 dev”，不像 installer 那样先解析/记录 exact SHA，因此只推荐临时测试。

## 8. 更新

### Release

Linux：

```sh
sh /tmp/weigg-qb-install.sh --update
```

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Mode Update -Channel Release
```

### dev

Linux：

```sh
sh /tmp/weigg-qb-install.sh --update --channel=dev
```

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Mode Update -Channel Dev
```

每次 dev update 都重新解析当前 `dev` exact SHA。

## 9. 停用与回滚

立即回到 qBittorrent 内置 WebUI：关闭 **Use alternative WebUI**。

Linux rollback：

```sh
sh /tmp/weigg-qb-install.sh --rollback
```

Windows rollback：

```powershell
powershell -ExecutionPolicy Bypass -File $env:TEMP\weigg-qb-install.ps1 -Mode Rollback
```

安装器会尽可能恢复上一份 WebUI 和相关 qB 配置备份。

## 10. 部署 identity

安装后检查：

```text
VERSION
GIT_SHA
private/weigg-install.json
```

Metadata 可记录：

```text
version
gitSha
channel
container（如适用）
qbPath
hostPath
installedAt
installer
```

真实部署域名、凭据、维护者 container 名和机器专属路径不得写进公开源码。

## 11. 常见问题

### 页面 404 / Unauthorized

确认 Root Folder 指向 WebUI root，而不是 `private/`、`public/` 或 repository root；检查三个入口文件均存在。

### Docker Host 有文件，但 qB 看不到

通常是把 Host path 填进 qB。qBittorrent 必须使用 container-visible path，例如 `/config/weigg-qb-webui`。

### 多 container 时 installer 拒绝继续

这是安全行为：

```sh
--list-containers
--container=<qb-container>
```

明确目标后再安装。

### Release installer 提示没有 stable Release

表示当前没有可访问的正式 Release。Release 频道不会自动退回 `main`/`dev`。如果明确需要开发版，请显式选择 `--channel=dev` 或 `-Channel Dev`。

### NAS 没有 curl / unzip / sha256sum

先直接运行 installer；它会自动尝试 `wget`、BusyBox、Python、`bsdtar`、`shasum`、`openssl` 等可用实现。若 downloader/extractor 都没有，可浏览器下载/上传。Release 如果无法做 SHA256 校验则拒绝自动安装。

### 更新后浏览器仍像旧版

检查安装目录 `GIT_SHA` 与 `private/weigg-install.json`。WebUI 静态资源使用 exact SHA 作为 cache identity；确认 qB Root Folder 指向正确目录后再强制刷新浏览器。

### 想固定旧稳定版本

进入对应 GitHub Release 页面下载该版本 ZIP + SHA256SUMS，手动安装。不要用 branch archive 冒充固定 Release。
