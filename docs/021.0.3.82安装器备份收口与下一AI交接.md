## 4. 安装器备份 retention 收口

本轮 installer-only 修改没有改 `webui/**`，所以 Product VERSION保持 `0.3.82`。

Windows PowerShell 与 shell installer现在都拥有明确的 backup retention owner：

```text
每次成功建立新 backup
-> 先写 current rollback pointer（last-backup）
-> 再执行 retention pruning
-> 只保留最新 3 个 installer-owned backup
```

删除边界严格限定为：

```text
目录名匹配 YYYYMMDD-HHMMSS
AND 存在 had-webui marker
AND 存在 dest-path marker
```

因此普通文件、用户自己建立的目录、名字看似相近但缺少 ownership markers 的目录都不属于 pruning owner，不能删除。

Windows checkpoint：

```text
0da41a5548b6e02b7c3069a7d8e4bd7897545249
Cap Windows installer backups at three
```

Shell checkpoint：

```text
64535ec7d035d0d64bea3eb3d722848a7eec3a5d
Cap shell installer backups at three
```

随后新增 `tests/installer-backup-retention-contract.mjs`，并由 `a76f8b8...` 接入 `npm test`。Contract明确锁定：timestamp naming、ownership markers、newest-first保留、最多3份、rollback pointer先发布后prune、无关目录不在删除边界内。
