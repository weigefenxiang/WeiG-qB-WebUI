## 5. 为什么 A3 仍然不是 A 完成

第四轮真实 qB Options 人工复核再次发现：

- native compound/group布局错乱、文字竖排、重复标题；
- I2P等qB-owned copy仍有未解析中文；
- Scheduler没有按原生语义组成完整time range；
- 多个实际 Select显示值但不可修改；
- watch-folder grouped options结构不对；
- username后缺write-only Password输入；
- shared Select菜单长文字被截断。

因此自动 fixture / semantic UI PASS只能保留为 regression evidence，不能覆盖真实 qB failure。A3到此归档，A4接管 current Options closure。
