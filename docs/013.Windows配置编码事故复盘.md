# 013. Windows 配置编码事故复盘

Status: **2026-09-11 incident postmortem / current Windows config safety authority**

本文记录真实 Windows qBittorrent 4.6.7 环境中发现的 Dev distribution、runtime catalog 与 PowerShell 5.1 配置写入事故，以及已经落地的永久修复。

## 1. 事故结论

事故不是一个单点问题，而是三条独立故障链：

```text
A. 旧 Dev raw-source 安装 -> materialized runtime facts 缺失
B. 65 full profiles 单体 runtime catalog -> 真实 qB 静态资源链过大/不稳定
C. PowerShell 5.1 whole-file text rewrite -> UTF-8 no-BOM 中文/日文 mojibake
```

三条都必须分别修复；不能用放宽 source guard、手写翻译或只修一个乱码 key 掩盖。

## 2. 用户侧恢复事实

真实环境：Windows 11 + qBittorrent 4.6.7。

恢复后验证：

```text
Locale = zh_CN
DefaultSavePath = D:\\clash\\u\\下载
TempPath = D:\\clash\\其他文件\\下载临时文件夹
中文/日文 Tags 正常
MojibakeMatches = 0
qBittorrent_new.ini = absent
```

已有 torrent 实际保存路径一直正常；损坏集中在 qB 全局 Preferences/config values。

恢复原则：

```text
known-good backup
-> restore proven-corrupted keys
-> strict decode
-> temp validation
-> atomic replace
-> post-start reread verification
```

不要对未知 mojibake 自动“逆转码”。有 known-good backup 时，以备份中的同 key 值为权威。

## 3. Raw-source Dev 事故

历史旧 installer 的 `-dev` 会直接消费 GitHub source archive。raw `webui/**` 不含完整构建期 materialized：

```text
compact release catalog
exact release profile shards
Settings native registry
official QM
exact translation bridge
```

典型表现：

```text
This API action is not source-proven for the current qBittorrent release.
This qBittorrent version returned no settings in this group.
qB-owned Settings labels unexpectedly fall back to English.
```

永久修复：Linux/Windows Dev 都只消费 Virtual qB Pages exact-SHA materialized distribution：

```text
current dev SHA
== downloads/dev/GIT_SHA
== package GIT_SHA
```

不允许 raw-source fallback。

## 4. Runtime catalog 事故

65 个 full profile 塞进单体 `qb-releases.json` 曾接近真实 qB Alternative WebUI 静态资源的实用大小边界，并让 loader failure 被误表现成“source proof 缺失”。

永久结构：

```text
private/data/qb-releases.json                     # compact index
private/data/qb-release-profiles/<sourceSha>.json # active profile shard
```

运行时只加载 compact index + 当前 exact/equivalent/inherited profile shard。

禁止恢复 monolithic 65-profile runtime catalog，也禁止把 HTTP load failure 静默转成空 catalog。

## 5. PowerShell 5.1 转码事故

旧 external config mutation 使用默认文本 I/O 处理整个 `qBittorrent.ini`。Windows PowerShell 5.1 对 UTF-8 no-BOM 可能按系统 ANSI/GBK 解码，再写回 UTF-8，从而产生 mojibake。

真实受污染内容包括：

```text
Session\DefaultSavePath
Session\TempPath
SavePathHistory
Session\Tags
```

禁止重新引入：

```powershell
Get-Content $cfg -Raw
# whole-file mutation
Set-Content -Encoding UTF8 $cfg
```

## 6. 当前 Windows config safety 已完成

`installers/install.ps1` 当前已经完成：

```text
Read-QBConfigText

Test-QBittorrentRunning

Assert-QBWebUIMutation
Invoke-QBAtomicReplace
Restore-QBConfigBackupAtomically
Configure-QBWebUI
```

安全链：

```text
qB running -> fail closed
non-empty recovery/new config -> fail closed
empty/invalid config -> fail closed
multiple config candidates -> fail closed
exactly one [Preferences] -> required
managed keys unique/in [Preferences] -> required
strict decode + byte round-trip
byte-identical safety backup
temp write
strict reread + encoding/BOM/invariant verification
recheck target unchanged
atomic replace
post-replace verification
rollback only when safe to do so
```

支持保留：

```text
UTF-8 BOM
UTF-8 no BOM
UTF-16 LE BOM
UTF-16 BE BOM
```

`tests/windows-config-encoding.ps1` 在 Windows PowerShell 5.1 contract 中覆盖成功路径与关键 fail-closed 负例。

因此旧文档里的“Windows installer guardrails 仍待实现”已经过期。

## 7. qB recovery file 的意义

qB 启动时可能使用 `qBittorrent_new.ini` 作为未完成写入恢复来源。因此外部配置修改器遇到非空 recovery/new file 必须拒绝修改正式 config。

不要删除它后继续写；先由用户/维护者理解 qB 当前 recovery 状态。

## 8. 配置发现纪律

标准 profile 可自动发现常见 config；多个候选、portable/custom profile 时：

```text
refuse to guess
```

Windows 用户可明确传：

```powershell
-qbconfig "<exact path>"
```

## 10. 本事故形成的永久规则

```text
1. Dev 不得 raw-source fallback。
2. Runtime catalog 必须 sharded。
3. Windows external config mutation 必须 encoding-preserving + fail-closed + atomic replace。
4. qB running/recovery state 下不改 config。
5. multiple config candidates 不猜。
6. 不给用户依赖跨段变量状态的恢复脚本；优先单一 script block。
7. 先 temp、再 verify、最后 replace。
8. 不为测试绿灯放宽 source/identity/config safety gate。
9. 所有修复先进入 dev；禁止直接修 main。
```
