# 018. A5 Settings 全版本系统闭环

Status: **current A5 Settings plan / acceptance authority — NOT handoff authority**

> 阅读顺序：先读 docs/015.开发硬规则（长期版）.md，再读 docs/014.AI协作与分支纪律.md STOP 前，然后完整阅读本文件；兼容事实再查 docs/002，Settings owner/interaction 查 docs/005，兼容策略查 docs/010。A1–A3 历史在 docs/016；A4 已实现/自动证据与第五轮触发背景保留在 docs/017，但 **017 不再是 current plan**。

## 1. A5 触发原因与结论

A4 / Product 0.3.133 已完成 ordinary smoke、9/9 semantic UI、Pages 与 5.2.3 focused Settings 自动闭环，但第五轮真实 qB 人工复核继续发现跨版本问题，因此 A4 自动绿灯不能作为 A 完成证据，A 阶段重新打开为 **A5 Settings 全版本系统闭环**。

第五轮已确认两类不同的系统性根因。

### 1.1 Root A — source structure / label ownership 污染

真实现象：qB 4.4.5 Connection 的 bittorrent_protocol / enable_protocol_combobox 值与控件正确，但 WeiG 显示了 Downloads 的 Do not start the download automatically 文案；4.6.7 同一控件显示正确 Peer connection protocol:。

已核实上游：qB 4.4.5 与 4.6.7 官方 preferences.html 中该控件都属于 Connection，官方 label 都是 Peer connection protocol:。错误不是 upstream 版本差异。

已核实当前 source artifact：4.4.5 生成事实曾出现：

~~~
bittorrent_protocol -> enable_protocol_combobox
-> Do not start the download automatically
~~~

而 4.6.7 对应事实是正确的 Peer label。

根因已定位到 source extractor 的结构边界：用于“无 for label 紧邻 control”的 regex 允许 [\s\S]*? 跨越多个 </label> / div / fieldset 直到后续 control，从错误的更早 QBT_TR 开始匹配。即使 controlId 正确，错误 title 已在 source catalog 阶段产生，compact/runtime/renderer只是忠实消费错误事实。

因此禁止在 renderer/CSS/翻译层修 Peer 文案；必须修 **source ownership / structural evidence**。

### 1.2 Root B — historical value projection / write proof 语法代际覆盖不足

真实现象：5.2.3 的 Torrent 内容布局等 Select 可写，但 4.6.7 及其它历史版本显示为只读；同类可能覆盖 Torrent stop condition、Encryption、structured Settings。

当前 source timeline 显示：多个 Preference 在旧版本长期为 projection.kind=unproven / safeWrite=false，到较新的 DOM/JS 写法才突然变成 identity/safeWrite。该现象不能直接解释成“旧 qB 不支持写”，因为旧 qB 原生 Options 本身使用 MooTools 风格 setProperty/getProperty/getSelected/getChildren()[index]/setAttribute(selected) 完成相同交互。

根因方向：当前 qb-preferences-value-projection 对 modern DOM 语法证明能力强于 legacy MooTools 语法，导致旧版本 read/write inverse 无法证明，产品随后按正确 fail-closed 原则退成只读。

因此禁止为 4.6.7 或若干 Preference key 强制 safeWrite=true；必须扩展 **source dialect -> canonical projection IR** 的证明能力。

## 2. A5 总目标：不是修已知项，而是全 Settings × 全版本闭环

A5 范围是 qB exact source 中实际存在的全部 native Options surface，至少覆盖当前 admitted releases 的：

- Behavior；
- Downloads；
- Connection；
- Speed；
- BitTorrent；
- RSS；
- Web UI；
- Advanced；
- 以及未来 exact source 新增/移除/改名的 native tab，不维护固定八 tab whitelist。

已知 4.4.5 Peer、4.6.7 content-layout/stop-condition/encryption 只是 **regression seeds**，只用于证明新体系能抓到已知错误，不能成为实现清单、版本特判或完成条件。

A5 最终必须回答的不是“这些截图修了吗”，而是：

~~~
对 target exact Frozen catalog 中的每一个 admitted stable，
对 exact source 中的每一个 native Settings control / Preference / helper / content / dependency / copy：

source owner是谁？
Preference绑定谁？
label/options/unit/help属于谁？
raw<->UI怎么映射？
官方是否可写？
runtime当前key是否存在？
browser应该editable / disabled / read-only / write-only / structured中的哪一种？
compact与browser是否仍是同一事实？
~~~

任何一步无法回答都必须产生明确 FAIL / PENDING_REVIEW / reviewed exclusion，禁止静默“有东西显示就算完整”。

## 3. A5 canonical architecture

A5 不新建第二 Settings 产品 owner。正式产品链保持：

~~~
exact qB source + WebAPI descriptor/source provenance
-> canonical Settings source IR
-> ownership/evidence resolver
-> projection / dependency / serializer proof
-> compact settings-compat
-> W.SettingsSchema
-> W.SettingsRenderer
-> W.Components / W.I18n
-> same Settings draft
-> QBClient.setPreferences()
-> verified app/preferences reread
~~~

### 3.1 Structural Source IR

必须把 Preferences source 解析成有边界的结构 IR：

~~~
Tab
  -> Fieldset / Group
    -> Row
      -> Control
      -> Helper / source action
      -> Content / note / hint / list
~~~

每个 control 至少携带：

~~~
controlId
source position/range
tab owner
fieldset/group owner
row owner
semantic/type
label evidence
options / option order
unit/adornment
helper/action relation
dependency/gate relation
Preference binding candidates
source copy refs
~~~

允许复用现有 elementRanges/controlIndex 等 bounded parser；是否新增集中 source-tree 模块由实现审计决定。**禁止同时保留两个 active ownership parser**。若新 owner替代旧 extractQbPreferenceUiFacts / composite 的某项职责，必须 atomic cutover、全部 caller/test切换、旧 active inference退出。

### 3.2 Boundary-safe label ownership

Control label只允许来自可证明关系，推荐 evidence rank：

~~~
E1 explicit label-for / aria-labelledby
E2 exact same structural row sibling / owner-scoped native relation
E3 source-proven compound/group relation
E4 reviewed exceptional source relation
~~~

禁止：
- regex 跨 </label>、row、fieldset、tab 猜“最近/相邻”文案；
- 用 fieldset legend 冒充 control label；
- 用某个 Preference 的旧 title覆盖当前 exact control owner的更强证据；
- “第一个候选能出字就算成功”。

如果两个 evidence source 对 Preference -> controlId 或 controlId -> label 冲突，必须进入 AMBIGUOUS 并使 admission FAIL，不能静默优先旧 extractor。

### 3.3 Unified Evidence Resolver

现有 multiple extractor 的结果必须通过一个统一 evidence resolver仲裁，不能使用“旧 ui[key] 有值就拒绝 composite纠错”的逻辑。

Resolver至少比较：
- exact controlId；
- structural owner path；
- evidence rank；
- source range；
- read relation；
- write relation；
- option/semantic compatibility。

输出必须能解释“为什么 Preference X 属于 control Y、为什么 label Z 属于 control Y”。无法唯一证明时 fail closed。

## 4. Full ownership census：从“节点数量一致”升级为“语义归属一致”

现有 structuralCensus.complete 只能证明 source controls/helpers/content被表示，不足以证明 ownership正确。A5新增独立 census，至少包括：

~~~
sourceControls == irControls == compactControls == renderedControls
sourcePreferences == boundPreferences + explicitlyReviewedUnbound
sourceHelpers == representedHelpers
sourceContent == representedContent
sourceCopyRefs == representedCopyRefs
~~~

并要求每个 admitted stable：

~~~
crossTabOwnershipMismatch = 0
crossFieldsetOwnershipMismatch = 0
crossRowOwnershipMismatch = 0
ambiguousBinding = 0
duplicatePreferenceOwnership = 0
duplicateControlOwnership = 0
wrongSourceRef = 0
missingRequiredLabel = 0
missingOptions = 0
optionOrderMismatch = 0
unaccountedNativeControl = 0
unaccountedHelper = 0
unaccountedContent = 0
runtimeRelevantUnknownBehavior = 0
~~~

4.4.5 Peer 必须由这一层自动 FAIL；不能等 browser screenshot 才发现。

Mapping ratio、mappedPreferences/totalPreferences、单纯 control count都只能是健康度指标，不能再承担 completeness proof。

## 5. Projection / writeability system：按语法方言适配，不按版本/key特判

### 5.1 Canonical Projection IR

无论 upstream 使用 modern DOM、MooTools 或未来新语法，最终都编译成同一语义：

~~~
read: raw Preference -> canonical UI value
write: canonical UI value -> raw Preference
domain/options
gate/dependency
safeWrite proof
~~~

合法 projection family继续可以包括：
- identity；
- numeric scale；
- enum/index/switch map；
- sentinel gate；
- presence/empty-string gate；
- structured serializer；
- write-only direct identity；
- 明确 unproven/unknown。

### 5.2 Source dialect adapters

A5 优先扩展语法适配器，而不是写版本分支。至少覆盖：

**Modern DOM**
- .value / .checked；
- .selectedOptions[]；
- .options[]；
- direct assignment / Number conversion。

**Legacy MooTools**
- setProperty/getProperty；
- getSelected()[0]；
- getChildren(option)[index]；
- setAttribute(selected, ...)；
- source switch / index variable / selected-index mapping。

Adapter只负责把不同语法翻译为同一 expression/projection IR；不得把 qB 4.x/5.x 版本号写进 renderer或 SettingsSchema。

### 5.3 Round-trip proof

对于官方可写 Preference，只有证明以下条件时才可 writable：

~~~
source read projection
+ source write projection
+ exact getter/setter/type
+ option/domain proof
=> write(read(raw)) == raw
AND read(write(ui)) == ui
~~~

Select/enum必须遍历全部 source option domain，而不是抽一个值。numeric scale验证合法代表值与 inverse；boolean验证两值；structured验证 parse/edit/serialize；write-only按 P0-11B。

如果 upstream原生可写，但 WeiG因 parser不理解语法而 unproven/read-only，A5 的 writeability census应 FAIL，而不是把 fail-closed 当“兼容完成”。只有 source/API确实不可写或语义无法安全证明时，才允许 reviewed READ_ONLY/UNKNOWN。

## 6. Structured / compound / dependency 统一闭环

Watch folder、Scheduler、IP Filtering、Proxy、credential、ratio gate、Listening Port + Random等都必须落在通用 family，不维护 Preference-key UI patch。

每个 family的 IR应能描述：
- owner row/group；
- members与source order；
- local/section label role；
- gate predicate；
- display format；
- serializer / projection；
- helper/action target；
- enable/disable dependency；
- write transaction owner。

Structured keyed-map 不能只证明 5.x。旧版若 source有等价 parse/serialize逻辑，必须由 dialect/serializer proof支持；证明不了则明确列出确切 source gap，而不是手动开放。

## 7. Copy / locale ownership census

所有 qB-owned tab、section、label、option、unit、note、helper都必须绑定 exact {source,context} 与 exact structural owner。

A5新增 copy ownership断言：

~~~
rendered sourceRef
== compact sourceRef
== IR sourceRef
== exact source owner sourceRef
~~~

有官方目标翻译时走 exact-release translation；无官方翻译才回退 upstream English。禁止因为 title错位在翻译层人工覆盖中文/英文。

4.4.5 Peer这类“controlId正确、title错误”必须在 source/copy ownership stage直接 FAIL。

## 8. Compact round-trip / materialization gate

对每个 admitted stable执行：

~~~
Source IR
-> compact compiler
-> committed/generated compact representation
-> runtime decode
-> canonical decoded IR
~~~

以下字段必须无损或有显式规范化等价：
- tab/section/row owner；
- controlId；
- label/copy ref；
- semantic/type；
- options/order；
- unit/adornment；
- dependency；
- projection；
- structured metadata；
- helper/action；
- write-only metadata。

禁止只检查“JSON能decode”。Source IR正确但compact丢ownership，同样 FAIL。

历史 Frozen facts保护规则仍生效：parser修复确实证明旧 artifact错误时可以重生成受影响 historical facts，但必须由 exact upstream source + independent census证明；不能因“Frozen不可改”保留已经证实错误的 4.4.5 title。

## 9. A5 admitted-version browser Settings matrix

现有 tests/full-stable-product-compat.mjs 主要验证 descriptor/route/基本 capability，不足以证明 Settings UI fidelity。A5需要新增/扩展一个 Settings 专项 admitted-version matrix，expected set只能来自 target exact-SHA Frozen catalog。

对每个 admitted stable：

1. 加载该版本 exact Settings compact profile；
2. 构造该版本合法 app/preferences shape；
3. 渲染所有 exact native tabs；
4. 遍历全部 graph controls，而不是手写 key allowlist；
5. 验证 owner path / label / options / unit / visible/read-only/disabled/editable状态；
6. 对 writable semantic自动生成安全交互；
7. real pointer/keyboard -> draft -> setPreferences payload -> reread；
8. 审计所有 graph item与实际 DOM，一项都不能 silent drop。

自动交互按 semantic生成：
- checkbox：toggle；
- select/radio：选择另一个合法source option，必要时遍历完整domain；
- number：从 projection/domain生成合法替代值；
- text/path：合法 identity替代值；
- textarea：same draft owner；
- structured：source serializer生成安全 edit；
- write-only：POST后不伪造GET secret；
- gate/dependency：切换gate验证成员 enable/disable；
- helper：验证 source-derived action/target，不执行任意 upstream JS。

测试不得靠 Preference key列表决定哪些项“重要”；key只可用于已知 regression seed断言与诊断。

65-version任务允许 shard并行；SKIPPED != PASS。最终 aggregate必须证明 expected == executed，无 missing/duplicate/unexpected。

## 10. A5 regression seeds（仅验新体系，不允许变成特判）

至少固定以下已知失败作为 focused seed：

1. qB 4.4.5：Connection enable_protocol_combobox / bittorrent_protocol 必须归属 Peer connection protocol:，不得出现 Downloads label。
2. qB 4.6.7：Torrent content layout、stop condition、BitTorrent encryption 若 upstream source/API证明可写，WeiG必须是可编辑 canonical Select并save/reread。
3. qB 5.2.3：A4已通过的 external-program、IP Filtering、Scheduler、watch folder、Password、I2P official locale、long Select不得回归。
4. 至少选择 legacy MooTools、过渡期、modern DOM change-point各一个 profile做 focused parser/projection contract。

若实现只让这几个版本PASS、但 ownership/writeability census仍有其它版本 mismatch，A5仍为 FAIL。

## 12. A5 completion formula

A5不能以“已知截图都好了”结束。对 target Frozen admitted set 必须满足：

~~~
source native controls
== structural IR controls
== compact-decoded controls
== browser rendered controls

source Preference bindings
== IR bindings
== SettingsSchema bindings

cross-tab ownership mismatch = 0
cross-fieldset ownership mismatch = 0
cross-row ownership mismatch = 0
ambiguous binding = 0
duplicate ownership = 0
wrong sourceRef = 0
missing required control/label/options = 0
option/order mismatch = 0
unaccounted native control/helper/content = 0
runtime-relevant unknown behavior = 0
unexplained official-writable -> read-only = 0
unsafe false-positive writable = 0
compact round-trip semantic loss = 0
browser silent-drop = 0
~~~

任何 reviewed exclusion必须携带 exact version/source evidence、理由、风险与明确非支持语义；“parser暂时看不懂”不是 reviewed compatibility success。
