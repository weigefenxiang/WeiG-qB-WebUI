## 3. 本轮关闭的真实问题

### 3.1 旧 Sidebar 双层 facet owner

用户安装 exact dev 后实际复现“分类/标签/TRACKER/路径标题下面再出现全部分类等第二层按钮”。源码确认 `spatial.js` 仍创建独立 `facet-control__title`。现已删除该 active truth，四个 label 本身直接成为 `triggerMode:'prefix'` Select trigger。

### 3.2 Settings 固定 tab active truth

用户实际复现 Settings 仍固定显示 Behavior 等 tabs。源码确认 `settings.js` 仍有固定 `QB_TAB_ORDER + ensureQbTabs()`，`index.html` 也有静态 qB tabs，旧测试甚至要求这些代码必须存在。现旧 owner和旧测试保护均已退休；native tabs 来自 source-derived compact facts。

### 3.3 RSS rule source-action 漏收录

RSS “新建规则”不可点击的根因不是按钮本身，而是 compact `source-actions.json` 漏掉 upstream 已存在的 `setRule / renameRule / removeRule` 等 action，CapabilityRegistry 因此正确 fail-closed。现已补回 exact source timeline，modern `matchingArticles / markAsRead` 也按引入版本 source-gated；UI 不再强制解锁未知能力。

### 3.4 RSS transport owner 漂移

早期 rule 模块曾在 `rss.js` 里直接 monkey-patch `W.QBClient.prototype`。该实现已退休；RSS transport全部回归 `W.QBClient` 唯一 transport owner。

### 3.5 通用浮层几何未真正统一

0.3.104 已让 Select 本身 viewport-safe，但 Context Menu 仍有独立 `placeContextMenu()` viewport算法。用户要求这类通用工具统一，因此 0.3.105 将 Select 与 Context Menu 收进同一 `placeBounded()` owner，并新增 contract 防止恢复平行定位算法。
