## 2. 当前最重要的执行策略：webui 优先，tests/tools 是护栏

`webui/** is the product` 现在不仅是架构边界，也是执行优先级。

当前 Preferences source foundation已经足够支撑下一步 A cutover，因此下一位 AI **不要继续把主要时间花在主动扩 Preferences parser/census/test framework**。默认节奏：

```text
1. 明确当前 formal webui blocker
2. 优先修改正式 webui/** owner/caller/runtime contract
3. 只有真实 cutover 暴露具体缺失 source fact / projection / parser / test gap时
   -> 回 tools/tests 修最小根因
4. 立即回到 webui 产品切换
5. 对最终 coherent product batch做 focused validation
6. 阶段完整后才做阶段级 full matrix
```

当前可按约 `70–80% formal product / 20–30% necessary tests+tools` 作为工作启发；这不是永久配额，也不是 commit 数量要求。真正标准是：**每个新的 tools/tests 变更都必须能回答“它正在解除哪个具体 webui blocker、证明哪个即将进入正式 runtime 的 contract，或防止哪个已知产品回归？”** 如果回答不出来，优先不做。

不要走两个极端：

```text
错误 1：一直扩 tools/tests，formal webui 永远不消费成果
错误 2：跳过 source/tests，直接在 webui 猜历史语义
正确：已有 foundation 足够时先切产品；遇到具体 blocker再最小补 foundation
```

## 3. 总方案：A–F Native Surface Projection

总目标：不再给 WebUI 堆 qB patch-version if/else，而是把 qB-owned surface统一收口到 exact upstream truth，再投影给同一份正式 `webui/**`。

核心 ownership：

```text
qB-owned existence / order / native UI semantics <- exact upstream source
qB current values                                <- qB WebAPI responses
qB read/write API provenance                     <- exact source/API descriptors/actions
qB raw <-> native UI transformation              <- exact source value projection
qB wording identity                              <- exact {source, context}
qB target-language text                          <- exact-release official translation
WeiG extensions / presentation / interaction     <- WeiG canonical owners
```

一个 semantic purpose只有一个 Current Owner。Source/admission IR可以先作为 evidence，但正式接管 runtime时必须同一 coherent change完成：新 owner生效、caller切换、旧 owner删除、tests更新、必要 docs/DESIGN同步。禁止 legacy/new、v1/v2、双 renderer、双 state/polling/layout/language owner。

### A — Options / Preferences

目标：

```text
exact qB Preferences source
+ exact app/preferences descriptors
  ├─ semantic extraction
  │    native tabs / sections / source order
  │    native controls / attributes / options / units
  │    dependencies / gates / source-context copy
  │    raw <-> UI value projection
  └─ independent census
       tabs / Preference identities / source-bound controls
       mapped + explicit reviewed exclusions
       unaccounted=0 / duplicates=0
+ exact getter/setter/readType/writeType provenance
∩ runtime GET /api/v2/app/preferences
-> bounded compact Settings contract
-> W.CapabilityRegistry
-> W.SettingsSchema
-> W.SettingsRenderer
-> canonical qB Options UI
```

危险 write必须同时满足：

```text
certified exact/equivalent release
AND setPreferences action proven
AND Preference setter/type proven
AND projection.safeWrite == true
AND Preference exists in current runtime app/preferences
```

A完成不是“新 IR生成成功”，而是 formal browser runtime真正消费 source-native IR，且被替代的 `SURFACES / SECTION_ORDER / SECTION_TITLES / META / FAMILY_RULES / add()` qB-owned truth同批退休。

### B — Torrent Status / Sidebar facets

目标：

```text
exact native status/filter/facet inventory + order
-> filter/value/action bindings
-> torrent compact domain
-> W.CapabilityRegistry / W.TorrentSemantics
-> generic Library facet state/value provider
-> generic Sidebar projection
-> append WeiG Path extension LAST
```

qB-native Categories/Tags/Trackers以及未来同类 facet都来自 exact source；WeiG Path不是 qB-native，始终最后。`All Categories / All Tags / All Trackers / All Paths`只是 no-filter option，不是额外 facet标题。

### C — qB-owned copy

所有正式 qB-owned runtime text都要追到 exact `{source, context}` + exact-release official translation。官方目标语言缺失时只回 upstream English source。WeiG-owned Path、Private/PT、WeiG WebUI、About、diagnostics继续 WeiG i18n。

如果把 `qb-settings-native.txt` 泛化成 domain-neutral registry，必须 atomic replace generator + loader + callers + tests + distribution contract；禁止双 registry。

### D — RSS

保留当前 source-driven rule editor，不重写第二套系统。继续补：feeds/articles/read-state/Downloader inventory、rule/action completeness、independent census、qB-owned copy、common catalog identity。

已经修好的 contract不能回退：smartFilter；4.6+/5.x `torrentParams.stopped`；historical/modern tri-state default/null；编辑完整 source-returned rule并保留未知字段。

### E — Torrent Detail

保留成熟链：

```text
CapabilityRegistry.torrentDetailUi()
-> detail-compat
-> QbUiEvidence
-> generic Detail runtime
-> SharedColumns / ColumnInteraction / VirtualList where applicable
-> source action descriptor
-> QBClient
```

E只做 inventory/copy/action completeness audit和真实缺口。不要创建 DetailV2、第二 renderer、第二 polling/cache/column/scroll owner。

### F — integrated source/compact closure

目标：

```text
one Frozen exact-source catalog
-> one common catalog identity
-> per-domain semantic extractor + independent census
-> bounded compact domains
-> qB-owned copy artifacts
-> browser lazy loading
-> runtime/distribution identity agreement
-> mixed/stale domain bytes fail closed
```

最终 capabilities/torrent/detail/settings/rss/actions/copy都必须证明来自同一 admitted source set。
