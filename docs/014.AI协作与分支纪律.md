## 3. 当前方案与 protected state

当前批准方案包含以下工作，必须保持单一 owner、source-proven、fail-closed：

1. `W.CapabilityRegistry` 收口为 runtime compatibility/current release control plane；浏览器只检测当前 qB/WebAPI，不在 runtime 遍历 65 个版本。Torrent/actions 可启动加载，Detail/Settings 按域 lazy-load；`W.QBClient` 只负责 transport/detected identity，`W.SettingsSchema` 负责 Preference semantics。
2. Settings 以实时 `app/preferences` 为当前值/存在性 truth；写入继续要求 endpoint source proof + specific Preference writable proof + getter，并 POST 后 reread 验证。监听端口/Random、计划限速 From/To 按 upstream source-version UI 关系组合，不按最新版本硬编码旧 qB。
3. Torrent/Detail 共用一个 `W.VirtualList` 实现；主 Torrent 列表保持持久实例，横向/纵向原生滚动或 scrollbar drag 期间不让 polling 数据替换 DOM，只保留 latest pending snapshot，交互结束后一次提交。不得新增第二套 wheel/scroll owner。
4. Detail Content 展开/收起文件夹时，以用户点击 folder row 的 viewport Y 为 anchor；只有用户未主动滚动时才恢复同一行，不再恢复 stale child anchor。
5. 真实 file row 右键本地动作包含“复制文件路径 / 复制所在文件夹路径”。路径分隔符来自 qB 返回的 host path，不来自浏览器 OS；synthetic folder 不伪装成 qB file。
6. Detail hero 结构调整为状态位于上一行，progress + 百分比位于下一行；禁止 margin/repair hack。
7. qB-owned copy runtime 在后续独立 product batch 瘦身：WebAPI 能实时给出的事实不重复存；WebAPI 不能证明的 translation/source facts 才保留 compact contract。不得把完整 release/source/profile catalog 塞回 formal `webui/**`。
8. `Behavior` / `RSS` 等 qB-owned 文案必须来自官方 source/context evidence，不能手写中文。当前 extractor 已支持相关 upstream toolbar binding，但 Frozen Settings/source LKG 仍需新的 certified `settings-evidence` 才能正式物化。

Protected state 继续包括：Files source order/index 与 synthetic folder separation、file/folder Rename 独立 provenance、one ActionRegistry、live Category/Tags truth、removeTags 独立证明、Peer local flags、Locale single persisted truth、Settings verified writes、future UNKNOWN fail closed、raw `webui/` self-contained，以及完整 qB source/catalog 只属于 tools/CI/simulator evidence。

## 6. 验证与证据规则

- CI 红灯必须先读完整日志，先区分真实产品回归与 stale test/docs/simulator gate；owner 优先级是 upstream/source/canonical runtime truth > stale expectation，不能为了旧 gate 恢复已经退休的架构。
- readiness 必须等待真正影响断言的 semantic owner + visible state 收敛，并 bounded fail closed；`releaseIdentity()`、capability flag、DOM attached 或 `document.readyState` 单独都可能只是中间态。
- product/runtime completion 以最近一次真正改变产品的 final exact SHA 及其适用 gate 为准。历史 checkpoint 不能跨实现改动复用。
- ordinary CI 负责 repository contracts；正式 UI 变更需要适用 browser semantic evidence；Pages 必须保持 exact source/materialization/build/deploy/live、stale-head guard 与 live verify 链路。
- heavy/manual Current Stable Locale Matrix、Real qB Full Frozen Matrix、promotion/main/tag/Release 不得自动触发。
