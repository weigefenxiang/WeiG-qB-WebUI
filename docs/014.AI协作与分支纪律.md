## 8. CI / Validation Health

统一时间预算：

```text
< 3 min      正常
3–5 min      记录耗时，判断是否天然可分片
> 5 min      必须输出 progress/timing；可独立任务优先 matrix/shard
> 10 min     release/locale/fixture 等天然可分片全量任务原则上不得继续单 runner
> 30 min     无明确合理原因和持续可观察进度 => 验证设计异常，停止并查根因
```

默认并发策略：

```text
naturally independent full-version work
-> bounded shards
-> max-parallel: 16
-> 65 releases通常约16 shards × 4–5 releases
-> per-shard artifact
-> one aggregate
```

Aggregate 必须来自同一 exact SHA + 同一 Frozen expected set/catalog identity，并证明：

```text
executed == expected
missing == []
duplicate == []
unexpected == []
FAIL == 0
BLOCKED == 0
```

不可安全分片的工作保留单 owner，但必须提供阶段进度和耗时。长任务优先 instrumentation/profile root cause，禁止用 blind timeout/rerun 掩盖问题。

`SKIPPED != PASS`。旧 SHA、cancelled/superseded run、其它 SHA 的 shard都不能证明 current exact SHA。
