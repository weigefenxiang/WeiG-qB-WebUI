## 3. 当前唯一明确未完成产品任务：Torrent Detail 原版语义收口

以下七条目前都应视为 **未完成**，不要因为 source architecture已经存在就误报成产品已经落地。

### 3.1 顶部标签完全跟随 qBittorrent 原版

当前 `概览 / 文件 / Trackers / Peers / HTTP 来源` 不再作为 WeiG自己维护的一套名称。

目标：

```text
exact qB detail tab source facts
+ current qB locale/qB-owned translation path
-> iterate actual supported tabs
-> render original qB wording for that release/locale
```

例如 qB原版中文对应 `普通 / 文件 / Trackers / 用户 / HTTP 来源` 时就显示这组；其它语言跟随 qB官方翻译。某版本没有某个 tab时自然不生成。

约束：

```text
no handwritten zh/en map
no old/new dual tab naming
no fixed five-tab assumption
width follows content/responsive layout
```

### 3.2 General / “普通”恢复原版信息完整度

以对应 qB版本原版 WebUI General页面为产品基准。能由 exact source/API truth得到的字段都应展示，包括适用的：

```text
Transfer:
活动时间
已下载 + 本次会话
下载速度 / 上传速度
下载限制 / 上传限制
分享率
剩余时间
已上传 + 本次会话
连接
种子
用户/Peers
已丢弃
下次汇报/Reannounce
最后完整可见

Information:
总大小
区块/Pieces
添加时间
完成时间
创建者
创建时间
Info Hash v1
Info Hash v2
保存路径
注释
以及该 exact release 原版实际存在的其它 source-proven property
```

实现原则：

```text
reuse existing propertyLayout/dataProperties/QbUiEvidence
reuse existing formatter/helper for time/bytes/speed/ratio/∞/missing values
version-specific absence -> source/capability-safe omission/degrade
never invent value
never maintain a second manual General field list
```

### 3.3 Trackers 恢复原版表格行为

目标：

```text
URL single line
insufficient width -> ellipsis
full exact URL available via existing tooltip/accessibility mechanism
remove permanently visible Edit/Delete cell buttons
row right-click context menu for supported tracker actions
```

Tracker row projection必须继续使用 source-proven真实字段：

```text
peers      -> num_peers
seeds      -> num_seeds
leeches    -> num_leeches
downloaded -> num_downloaded
message    -> msg
```

不能继续因为 UI key不等于 API key就显示 `—`。

Edit/remove/reannounce等 action分别按 exact upstream action/parameter provenance判断；unknown upstream shape继续 fail closed。Display/edit value必须保持 `torrents/trackers` exact URL，不能经过 `normalizeTracker()`丢 path/query。

### 3.4 Peers 恢复国旗与原版右键交互

目标：

```text
country/region text前显示flag
reuse existing qB/project country code / GeoIP / icon renderer
remove IP cell permanent × action
peer actions -> row right-click context menu
only render actions current exact qB source proves supported
```

禁止维护 `country name -> flag` 静态手写 mapping。

IP、port、connection、flags、client、progress、download/upload speed、downloaded等仍是普通表格数据；操作控件不得破坏列布局。

### 3.5 列设置移到首行，并统一 Detail 公共列系统

`列设置` 不再单独占表格上方一整行；放到该页首行工具区域，与同页其它操作在同一 responsive rail，自适应空间，不写绝对定位。

Files / Trackers / Peers 等可配置表格尽量统一为：

```text
exact source column definition
-> iterate header
-> iterate cell
-> W.SharedColumns visibility/order/width
-> shared persistence
-> W.ColumnInteraction resize/reorder
```

不要每个 tab复制一套 column owner/dialog/persistence。

### 3.6 表头与数据严格同定义对齐

Header与body cell必须来自同一 column definition，使用同一：

```text
width
padding
alignment
order
visibility
```

文本列默认左对齐；只有 qB原版/source明确采用其它语义时才按对应规则处理。

Resize/reorder后应天然继续对齐；禁止新增“滚动/渲染后再修表头位置”的 JS、transform或 MutationObserver。

### 3.7 实现原则：数据驱动，不写死，不造第二套工具

这一轮是一次 **Torrent Detail 原版语义收口**，不是逐截图补丁。
