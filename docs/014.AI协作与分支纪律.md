这轮最终不是七个互不相关的 UI patch，而是把 qB source discovery和正式 runtime收口成一条主链：

```text
exact qB source / WebUI markup / controller actions
-> Detail source parsers
-> W.ReleaseProfile.torrentDetailUi + actionDescriptor
-> W.QbUiEvidence / qB-owned translation / shared formatters
-> generic app Detail runtime
-> W.SharedColumns / W.ColumnInteraction
-> W.CapabilityRegistry + W.QBClient
```

已完成的七项结果：

```text
1. 顶部 tabs按 exact qB source order/existence生成，文案走 qB-owned translation，不再固定五-tab或手写中英名称。
2. General/Properties只发一次 properties请求，按 source-generated propertyLayout/dataProperties与per-field provenance渲染；手写 General fallback已退休。
3. Trackers exact URL保持API原值；单行ellipsis + tooltip；source-proven row projection；永久 Edit/Delete按钮退休，action进row context menu。
4. Peers复用country_code + shared U.countryFlag；永久inline ×退休；supported action进row context menu。
5. Files/Trackers/Peers等Detail表格统一吃 exact source columns -> W.QbUiEvidence -> W.SharedColumns -> W.ColumnInteraction；Columns并入first toolbar rail。
6. Header/body来自同一column definition/grid template；shared-table viewport是单一horizontal scroll owner，resize/reorder后天然继续对齐。
7. Tabs/fields/labels/controls/context menus/actions/parameters/options都由source/profile facts驱动；runtime不再按已知Tracker/Peer endpoint写专用分支。
```

关键安全边界：

```text

```
