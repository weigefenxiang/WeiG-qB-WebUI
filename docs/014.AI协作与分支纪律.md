```text

  keep and finish the existing torrentDetailUi/detail-compat generic chain
```

一个 semantic purpose只能有一个 Current Owner。新 owner proven 后同批切换 callers、tests/docs 并删除 superseded runtime；禁止 `v1/v2`、`legacy/new` 双产品实现。允许的版本差异只来自 qBittorrent upstream 的 exact release facts。

## 3. 版本能力归档

`capabilities.json` 是轻量 control plane，不是所有版本事实的大杂烩。完整 source truth 在 build/CI 的 Frozen admitted catalog/LKG；browser 只消费领域 compact contracts：

```text
capabilities.json      release identity / high-level gate / compatFiles index
torrent-compat.json    Status / filters / native facets / Torrent table facts
detail-compat.json     Torrent Detail tabs/layout/tables/controls/actions
settings-compat.json   native Options/Preference facts
rss-compat.json        planned RSS native surface/rule facts
source-actions.json    exact action + parameter provenance
qB-owned copy artifact exact source/context + official locale route
```

所有 domain 必须由同一次 source catalog 编译并能校验相同 release set identity；不得让某个 compact file悄悄停在旧 stable。

## 4. 当前未完成事项判定

当前方案：**NOT COMPLETE**。

已确认 0.3.105 的具体问题：

- qB 4.3.0 原生 RSS Downloader 已读写 `smartFilter`，但 WeiG 0.3.105 draft 虽有该字段，编辑器未渲染/写回。
- qB 4.6+/5.x 原生规则使用 `torrentParams.stopped`，WeiG 0.3.105 却寻找 `torrentParams.paused`。
- 原生 paused/stopped 与 historical create-subfolder/content-layout 是 tri-state（global/default / always / never）；0.3.105 把 stopped/paused 压成 checkbox，保存时可能把 `null/default` 改成 `false`。
- Settings 目前仅 native tab presence/order source-driven；section/order/control/enum/unit/dependency 仍大量由 `settings-schema.js` 手工维护。
- `qb-compact-runtime.mjs` 与 `qb-owned-ui-source.mjs` 仍有固定八个 Settings tab 的已知白名单/ID mapping，未来第九个 native tab 可能被静默漏掉。
- Sidebar facets 仍在 `spatial.js` / LibraryController 中固定 category/tag/tracker/savePath，而不是 generic facet manifest。
- qB-owned copy 主链已经存在，但 RSS、Settings 外层等仍有手写中英文 fallback；`Settings/设置` 尚未完全切到 upstream `Options` 身份。
- RSS 仍缺独立 source-derived compact surface contract；当前 renderer 仍按返回 object shape 手工列字段。

当前执行顺序：**先 D 的真实 RSS fidelity bug → D source contract；再 A/B/C/F；E 只补缺口，不另造 Detail 系统。**
