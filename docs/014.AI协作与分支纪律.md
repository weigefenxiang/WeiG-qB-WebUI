A1 第二轮真实 qB 5.2.x Options 复核发现：

1. **Behavior / 日志文件**：日志总开关无法修改；正确语义应是总开关控制保存路径、backup/delete gate，子 gate再控制 size / age / age type。

   - `Keep incomplete torrents in`、`Copy .torrent files to`、`Copy finished .torrent files to`必须保持“勾选后才允许编辑值”的source交互；
   - `Run external program`下的 `Supported parameters (case sensitive)` 与参数列表当前被silent drop。
3. **Connection**：
   - Listening Port + Random 与 UPnP/NAT-PMP应在desktop合理利用同一行两侧；
   - 四个 Connection Limits应可按两列/同一视觉行紧凑排列；

#### Root causes 已查明

A2必须按下面的通用根因修复，禁止 per-key patch：

1. **Structural census false-green**：当前 `structuralCensus.complete`只比较 control/helper/adornment/behavior assignment是否“被表示”，没有要求 `unknownBehaviors.length === 0`。而runtime `predicateSatisfied('unknown') === false`，会出现“census PASS、真实控件永远disabled”。
2. **Graph content vocabulary不完整**：当前 compact Control Graph只有 control/helper 等结构，没有正式 `note/help/list/hint` source-copy node；纯文字说明和参数列表无处存放，必然silent drop。
3. **Action census不完整**：当前 helper parser主要覆盖 `<button>`；qB Options还存在 `<input type="button">`，不能因不是button tag就绕过action accounting。
4. **Auxiliary gate模型过窄**：A1主要解决numeric sentinel gate；Downloads的 `export_dir/export_dir_fin` 是“空字符串=disabled / 非空=enabled”UI projection，必须通用支持 presence/empty-string gate。boolean gate、nested `allOf/anyOf` 同理。
5. **Typed getter receiver proof不完整**：source descriptor enrichment已支持 session/pref/local member，但像 `app()->isFileLoggerEnabled()` 需要从 exact upstream interface/header（例如 `iapplication.h`）证明return type；不得给 `file_log_enabled` 单独白名单。
6. **Copy closure不完整**：`qb-settings-native` bundle当前主要收 Preference title/description + `qbOwnedUi` refs；A1新增的 fieldset/helper/option/adornment/local-label refs未全部进入minimal official QM / exact bridge，因此中文环境会fallback到upstream English。
7. **Desktop packing过度full-width**：renderer/CSS对compound row存在全宽强制，导致本可左右成对的短控制行浪费空间。布局优化必须是generic presentation packing，不改变source semantics/ownership。
