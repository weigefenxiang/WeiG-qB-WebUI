## 3. 当前最大 blocker

### 🟡 A1 — qB Options Structural Projection / Control Graph

#### Root cause

Current A-base source extractor primarily maps `Preference key -> one canonical row`. It captures tabs/sections/order/basic controls/options/some units/dependencies/descriptors/projections, but it does **not** fully preserve qB-owned UI composition and behavior:

```text
exact qB Preferences HTML / inline JS
  -> current preference-centric extractor
  -> flattened Preference rows
```

This loses:

- sibling helper controls/actions (`Random`);
- multiple Preference controls that form one native row/cluster (`HH:MM`, Host+Port);
- checkbox/sentinel UI semantics (`-1` backend value vs enabled numeric control);
- nested fieldset ownership (Proxy Authentication, BitTorrent proxy, I2P);
- non-boolean dependency predicates (`proxyType != None`, `proxyType != SOCKS4`, parent checkbox + type);
- display adornments whose presence is independent from raw value scaling (`KiB`, `%`, `MiB`, `ms`, `sec`, `min`);
- local source labels such as `From:`, `To:`, `When:`.

#### A1 target model

```text
exact qB release Preferences HTML + inline source behavior + Preference descriptors
  -> generic source parser
       tab / fieldset / nested-fieldset
       row / cluster / source order
       label / local label / note
       preference control
       helper control / source-owned action button
       adornment prefix/suffix/unit
       behavior predicate graph
       descriptor + value projection
  -> compact Control Graph IR per exact release
  -> bounded settings-compat runtime envelope
  -> W.CapabilityRegistry exact-release identity gate
  -> W.SettingsSchema graph adapter ∩ current app/preferences
  -> W.SettingsRenderer generic structural templates
  -> W.QBClient setPreferences only through existing fail-closed write gate
```

Value projection and display adornment are separate contracts. Seeing `KiB` does not automatically prove a `*1024` write transform; unit rendering may be proven from source even when write projection remains read-only.

Behavior predicates must be a small auditable IR, not arbitrary JS execution. Minimum useful operators: `truthy`, `falsy`, `equals`, `notEquals`, `allOf`, `anyOf`. Unknown source behavior remains disabled/read-only/fail closed.

#### Generic template families

A1 renderer may add only generic source-driven templates, for example:

- single control row;
- inline multi-control row/cluster;
- control + source-owned helper button;
- gated value / sentinel-enabled value;
- nested gated fieldset;
- time-range cluster;
- label + prefix/suffix/adornment.

Template selection must come from the graph shape/source facts, not `if (key === 'listen_port')`, patch-version branches, or manual key lists.

#### A1-0 — Product identity / About

`webui/private/weigg-install.json` currently contains stale tracked version `0.3.7`; source-direct dev use exposes it in About. `weigg-install.json` is installation metadata, not canonical product-version authority. A1 must make About consume one canonical Product Identity path that is correct for both source-direct and materialized/install flows. Do not solve this by repeatedly hand-editing a duplicated version literal.
