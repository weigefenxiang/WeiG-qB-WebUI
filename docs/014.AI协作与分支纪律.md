## 3. 已确认的根因与验证缺口

### 3.1 Root A：source label ownership 已在 catalog 生成阶段污染

已核实 qB 4.4.5 与 4.6.7 官方 source：Peer protocol 都属于 Connection，官方 label 都是 Peer connection protocol:。

当前历史 source artifact曾把 4.4.5 生成成：

~~~text
bittorrent_protocol
-> enable_protocol_combobox
-> Do not start the download automatically
~~~

而4.6.7生成正确。

已重放当前 extractor，确认“无 for label + control”正则允许 [\s\S]*? 跨多个 </label> / div / fieldset 到后续 select，因此把更早 Downloads QBT_TR 误归给 Connection control。错误发生在 source catalog，不是 renderer/CSS/翻译。

### 3.2 Root B：legacy MooTools projection proof不足

旧 qB Options大量使用 setProperty/getProperty/getSelected/getChildren()/setAttribute(selected) 与 switch/index 写法。当前 value-projection extractor对 modern DOM证明更完整，旧语法常落为 unproven/safeWrite=false；正式产品按安全规则随后只读。

不能用 force writable 解决。A5必须把不同 source dialect 编译成同一 canonical projection IR，并做完整domain round-trip proof。

### 3.3 现有验证门禁不够

- structuralCensus.complete 目前主要证明 control/helper/content“被表示”，不证明 Preference/control/label/row/tab ownership正确。
- 现有 full-stable-product-compat Settings检查主要证明 descriptor/route/setter/type，不保证逐版本 browser editability、sourceRef ownership与 save/reread。
- 因此 65-release source green 或 5.2.3 browser green都不能证明 A5。
