## 2. 总方案：A–F Native Surface Projection

本轮不是给旧 runtime再叠一层兼容，而是把仍存在的手工 qB-owned truth替换为 exact-source-driven compact projection：

```text
A Options / Preferences
  exact qB source tabs/sections/order/control/copy/dependency
  + exact Preference getter/setter/type provenance
  ∩ runtime app/preferences
  -> canonical native Options projection

B Torrent Status / Sidebar facets
  exact native statuses/filters/facets/order/filter bindings
  -> generic qB-native facet state/projection
  -> WeiG Path extension always last

C qB-owned copy
  exact {source, context}
  + exact release official translation route
  -> W.I18n
  -> upstream English fallback only when official target translation is unavailable

D RSS
  exact native RSS feeds/Downloader/rule source facts
  + exact source-actions
  -> generic rule/surface projection

E Torrent Detail
  keep and finish existing torrentDetailUi/detail-compat generic chain
  -> fill only real source/copy/action gaps
  -> never build a second Detail system

F Source admission / compact runtime
  Frozen exact-source catalog
  -> independent inventory/census
  -> common release-set/catalog identity
  -> domain compact contracts
  -> browser lazy loading
```

核心 ownership split：

```text
qB-owned existence/order/semantics  <- exact upstream source
current values                      <- qB WebAPI
qB wording                          <- exact source/context + official translation
WeiG-owned extensions/presentation  <- WeiG schema/i18n/UI
```

一个 semantic purpose只能有一个 Current Owner。新 owner proven 后同批切换 callers/tests/docs并删除 superseded runtime；禁止 `v1/v2`、`legacy/new` 双产品实现。允许的版本差异只来自 qBittorrent upstream exact release facts。

## 4. 当前未完成事项判定

当前方案：**NOT COMPLETE**。

### A — Options / Preferences：source admission已有，runtime cutover未完成

当前最大 blocker：

- `settings-schema.js` 仍固定 `SURFACES/SECTION_ORDER/SECTION_TITLES/META/FAMILY_RULES` 与大量 `add()` lists。

正式切换必须一个 coherent batch完成新 compact Settings contract、CapabilityRegistry/SettingsSchema/Renderer消费、tests更新和 superseded qB-owned manual truth删除。不要先加“新 schema fallback到旧 schema”。

### B — Torrent Sidebar：仍是固定 facet owner

`spatial.js` 仍固定 category/tag/tracker/savePath，LibraryController仍有固定 facet state/setters。需要 source-derived native facet inventory/order/filter/value bindings + generic state/projection，最后 append WeiG Path。未来 native facet不能靠增加 hard-coded `defs`。

### C — qB-owned copy：主链存在，但 coverage未收口

`W.I18n` 已有 exact-release official translation主链，但 Settings/RSS/Sidebar等仍有手写英文/中文 fallback。需要把正式 qB-owned runtime text全部绑定 exact `{source,context}`，官方翻译缺失只退 upstream English。若泛化 `qb-settings-native.txt`，必须 atomic rename/replace，不能双 registry。

### D — RSS：核心已修，阶段 completeness未完成

保留当前 manifest-driven rule editor；继续补 independent census、common catalog identity、official qB copy routing，并 final-audit feeds/articles/read-state/Downloader actions。不要把已经修好的 tri-state/stopped/smartFilter逻辑改回手写 conditional schema。

### E — Detail：只补缺口

按现有 detail-compat generic chain做 inventory/copy/action audit；不要重写 renderer或引入 DetailV2。

### F — Source admission / compact runtime：共享收口仍未完成

- `qb-compact-runtime.mjs` 仍没有把 RSS与新 Preferences native IR统一编译进 canonical compact output。
- 所有 compact domain尚未统一携带/校验同一 Frozen catalog identity。
- independent inventory/census机制尚未成为所有 domain的 completion gate。
- 新 stable admission还需要使用 census + extractor双路径，避免 parser新语法静默漏项。

## 6. 验证节奏与 completeness gate

禁止每改一步就跑 65 版本。阶段内部只跑 unit/source/focused change-point tests；阶段完整收口后最多跑 **一次** admitted-stable offline/Virtual full matrix。A～F 全部集成完成并冻结 final dev SHA后，才跑一次昂贵的 real-qB Full Frozen Matrix。

阶段 full matrix 的 expected set直接来自 Frozen admitted catalog并校验：

```text
executed == expected
missing == []
duplicate == []
unexpected == []
```

source-driven domain completion还必须满足：

```text
upstream inventory == mapped + explicit reviewed exclusions
unaccounted == 0
duplicates == 0
```

semantic extractor与inventory/census不能只是同一个 parser结果的两个名字。Parser看到未知 upstream结构时必须 fail/PENDING_REVIEW，而不是返回更少数据后继续 PASS。

Real-qB release-grade规则继续由 `docs/011` 负责；阶段离线矩阵不能冒充 real-qB evidence。
