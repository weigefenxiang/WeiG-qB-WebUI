## 3. 当前最大 blocker

### 🟡 A3 — qB Options Real-Interaction / Dynamic Options / Layout & Locale Closure

#### A3 第三轮人工复核事实（A2 FAIL）

真实 qB 5.2.x + WeiG 0.3.124 人工复核已确认以下问题。以下是**观察事实**，不是根因结论：

1. **Downloads / Select**：`Torrent 内容布局` 的“原始 / 创建子文件夹 / 不创建子文件夹”可见但无法真实选择；`Torrent 停止条件` 的 source-owned options 同样无法真实选择。
2. **长文案 / row layout**：Downloads“新增 torrent 时运行外部程序”与 Behavior IP过滤“过滤规则路径 (.dat, .p2p, .p2b)”出现标签/说明/控件重叠；必须修 generic wrap/intrinsic-size row layout，不做字符串专用换行。
3. **Speed / Scheduler time**：“计划备用速度限制的启用时间”分钟显示单个 `0`，人工期望时间语义显示 `00`；查通用 time-composite presentation owner。
4. **BitTorrent / Select + dependency**：`加密模式` options 可见但无法真实选择；做种限制启用后 `然后` 对应 Select 仍无法选择；需区分 Select 事件链与 dependency re-evaluation。
5. **RSS / gate + source action/dialog**：`启用 RSS Torrent 自动下载` 无法勾选；`编辑自动下载规则...` helper/action 未显示或不可用；禁用场景下 qB 原生提示“自动下载 RSS torrent 功能已被禁用！您可以在应用程序的设置中开启它。”及“下载规则”交互未形成。
6. **Web UI / API-omitted or write-only control**：用户名区域旁缺失 source 中应存在的“密码”控制/标签。必须先证明 exact source/API 的 current-value、write-only/omitted-value 语义，不能因为 `app/preferences` 没有当前值就静默删除 source control。
7. **Advanced / dynamic options + locale**：`网络接口`、`绑定到的可选 IP 地址` 属于可选项，当前 runtime 没有形成正确可选体验；`I2P inbound/outbound quantity/length` 等仍出现未正确解析的英文。

#### A3 复盘结论

A2 的 full-fidelity source accounting、typed proof、copy materialization、generic packing 和 automated browser evidence仍有效，但第三轮人工 FAIL 暴露新的 acceptance gap：

~~~text
source/IR/DOM存在
!= 真实用户能用 canonical Select 完成选择
!= draft dependency会在真实交互后即时重算
!= source action/dialog真的可达
!= source control在API不返回current value时仍被正确建模

~~~

因此 A3 **不得先宣称根因已经查明**。每个失败必须先在 exact qB 5.2.x 上沿完整链路定位到唯一/最小 generic owner。若实际根因落在 shared `W.Components.selectControl()`、Settings renderer、schema intersection、source compiler、action model、i18n 或 CSS，修对应 owner；禁止 Preference key / 中文字符串 / tab 名专用分支。

#### A3 根因调查候选（待证明，不是既定结论）

1. **Canonical Select real-interaction pipeline**：验证真实 pointer/click/keyboard option -> callback -> Settings draft -> dependent render -> Save payload；检查 A2 browser 是否用 programmatic value/change 绕过真实用户路径而 false-green。
