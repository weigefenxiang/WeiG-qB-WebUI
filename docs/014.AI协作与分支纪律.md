## 2. 总方案：A–F Native Surface Projection（详细版）

本轮目标不是继续给旧 WebUI叠版本 if/else，而是把 qB-owned surface的存在性、顺序、语义、copy和写回转换统一收口到 exact upstream source + exact WebAPI provenance，再由 bounded compact runtime投影给同一正式 `webui/**`。

核心 ownership split：

```text
qB-owned existence / order / native UI semantics <- exact upstream source
qB current values                                <- qB WebAPI responses
qB read/write API provenance                     <- exact source/API descriptors/actions
qB raw <-> native UI value transformation        <- exact source value projection
qB wording identity                              <- exact {source, context}
qB target-language text                          <- exact-release official translation
WeiG extensions / presentation / interaction     <- WeiG canonical owners
```

一个 semantic purpose只能有一个 Current Owner。Source/admission IR可以先作为 tools/CI evidence存在，但一旦正式接管 runtime，必须同一个 coherent batch完成 caller切换、旧 owner删除、tests更新和必要 docs/DESIGN同步；禁止 `legacy/new`、`v1/v2`、旧/新 renderer双 active。

### A — Options / Preferences

目标链：

```text
exact qB Preferences source
+ exact app/preferences descriptors
  ├─ semantic extraction
  │    native tabs / sections / source order
  │    native controls / attributes / options / units
  │    dependencies / gates / source-context copy
  │    raw <-> UI value projection
  │
  └─ independent census
       native tabs
       read/write Preference identities
       source-proven control bindings
       mapped + explicit exclusions
       unaccounted=0 / duplicates=0

+ exact getter/setter/readType/writeType provenance
∩ runtime GET /api/v2/app/preferences
-> bounded compact Settings contract
-> W.SettingsSchema
-> W.SettingsRenderer
-> canonical qB Options UI
```

最终写回必须同时满足：

```text

AND Preference setter/type proven

AND Preference exists in current runtime app/preferences
```

不能仅因为 getter存在、DOM里有 input或 API value是 number就认为可写。

A完成的关键标志不是“新 IR文件生成成功”，而是：formal browser runtime真正消费 source-native IR；`settings-schema.js` 中被替代的 qB-owned `SURFACES/SECTION_ORDER/SECTION_TITLES/META/FAMILY_RULES/add()` truth退休；旧 legacy Settings shape不再是第二 owner；focused/browser与阶段65 offline/Virtual Settings matrix闭环。
