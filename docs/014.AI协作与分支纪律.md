## 3. 已确认的根因与验证缺口

### 3.1 Root A：source label ownership 曾在 catalog 生成阶段污染；A5-1/2 已收口 owner

已核实 qB 4.4.5 与 4.6.7 官方 source：Peer protocol 都属于 Connection，官方 label 都是 Peer connection protocol:。历史 source artifact 曾把 4.4.5 生成成：

~~~text
bittorrent_protocol
-> enable_protocol_combobox
-> Do not start the download automatically
~~~

A5-1/2 当前 dev 已完成 source-owner 收口：

- `extractQbPreferenceControlCandidates()` 只暴露 raw Preference→control relation candidates；
- canonical owner 复用 `sourceTabs / elementRanges / controlIndex / formRow / tr / fieldset` 建结构边界；
- label evidence 只允许 E1 explicit `for/aria-labelledby`、E2 bounded same-row、E3 nearest fieldset group；缺证据/歧义 fail-closed；
- legacy `extractQbPreferenceUiFacts()` 不再参与 control 选择评分，只允许在 canonical 已选中同一 control 时补 description；
- translation overlay 已切到 `extractQbPreferencesNativeSurface()`，禁止恢复第二套 Settings label owner；
- 新 `ownershipCensus` 覆盖 cross-tab/fieldset/row、ambiguous/duplicate ownership、wrong/ambiguous sourceRef、missing label/options、unaccounted control/helper/content、runtime unknown。

当前 exact-source replay：
- qB 4.4.5：raw `bittorrent_protocol` candidate 只有 `enable_protocol_combobox / legacy-read`；legacy UI adapter 对该项为 null；canonical owner 正确得到 `Connection / Peer connection protocol:`；
- qB 4.6.7：同项同样正确；
- focused boundary fixture：正确 Peer label 时全部 ownership counters=0、`complete=true`；删除 Peer label 后不借 Downloads 文案，而是 `mapped=false + missingRequiredLabel=1 + complete=false`。

因此当前问题已从“已知 parser owner 错误”推进为“必须让新 owner 在全 65 admitted exact source 上通过 hard gate”。尚未取得本轮全 65 generated-source PASS，不能提前进入 A5-3。

### 3.2 Root B：legacy MooTools projection proof不足

旧 qB Options大量使用 setProperty/getProperty/getSelected/getChildren()/setAttribute(selected) 与 switch/index 写法。当前 value-projection extractor对 modern DOM证明更完整，旧语法常落为 unproven/safeWrite=false；正式产品按安全规则随后只读。

不能用 force writable 解决。A5必须把不同 source dialect 编译成同一 canonical projection IR，并做完整domain round-trip proof。

### 3.3 现有验证门禁不够

- structuralCensus.complete 目前主要证明 control/helper/content“被表示”，不证明 Preference/control/label/row/tab ownership正确。
- 现有 full-stable-product-compat Settings检查主要证明 descriptor/route/setter/type，不保证逐版本 browser editability、sourceRef ownership与 save/reread。
- 因此 65-release source green 或 5.2.3 browser green都不能证明 A5。
