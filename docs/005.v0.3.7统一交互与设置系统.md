# 005. v0.3.7 统一交互与设置系统

Status: **Responsive UI System 3.2 contract**

本文件记录 v0.3.7 的统一 UI 契约。目标是减少局部补丁，把桌面与手机收拢到一套共享模型、一套 canonical component system 和明确的 viewport/scroll ownership。

## 1. 核心原则

```text
结构优先于装饰
信息密度优先于空卡片
可读性优先于硬塞
共享模型优先于桌面/手机复制
一个语义只允许一个 canonical owner
随机动效低频、克制、可关闭
presentation 不复制 qB WebAPI business logic
```

当前继续坚持共享 `app.js` / `QBClient` / application state，不拆成 desktop/mobile 两套业务 JS。

## 2. 共享 UI owner

```text
Shared Model / Business
├─ QBClient
├─ PreferenceSchemaV037
├─ SelectionModelV037
├─ TorrentActionController
├─ TorrentFieldRegistry
└─ TransferLimitModel

Shared Presentation
├─ ResponsiveShell 3.0
├─ SettingsPageShell
├─ SettingsViewportLayout
├─ SettingsSectionPanel
├─ SettingsGrid
├─ SettingRow / FactRow
├─ ControlRegistry
├─ BrandMark / BrandIdentity / AmbientMark
├─ FloatingLayer
├─ AdaptiveDialog
└─ DataGridLayoutController
```

手机 adaptive layer 只负责 layout、density、touch interaction 和 presentation，不复制 API/业务规则。

## 3. Canonical Select / FloatingLayer

所有可见 Select 使用同一个 primitive。短值保持 content-fit，不因其它长字段统一拉宽。

浮层统一进入 body-level `FloatingLayer`，按 viewport 做 below/above flip、水平 shift、高度 cap 与内部 scroll；不得依靠祖先 `z-index` 逃逸 clipping。

## 4. Dismiss Policy

所有 Dialog / Popover / Context Menu 统一关闭规则：

```text
popover / context menu
  outside click -> close
  Escape        -> close
  opening other -> close previous

normal dialog
  backdrop double-click -> close
  Escape                -> close
  explicit close        -> close

destructive dialog
  explicit cancel / close required
```

关闭后恢复合理 focus。手机 long-press、桌面 contextmenu、Toolbar More 进入同一 `TorrentActionController`。

## 5. Torrent 列表与 Mobile two-line row

桌面列和手机 metric rail 继续从共享 `TorrentFieldRegistry` 读取字段语义、formatter、sortKey、capability 与 priority。

手机 Torrent row 最多两行：

```text
☐ Torrent name........................  Downloading  ⋯
   72% · 6.2GiB · ↓8.4M · ↑1.2M · 22m · +2
```

空间不足时按 compact formatter → gap → priority → `+N` 收缩，不靠 6–7px 字号硬塞全部字段。

手机 command bar 保持一行，Bottom Navigation 也保持一行 icon + label。

## 6. Settings mother template

旧的“居中 820px Form Rail”不再是当前 authority。所有 qB/WeiG Settings 页统一使用同一个母版：

```text
SettingsPageShell
└─ SettingsViewportLayout
   ├─ SettingsSidebar
   └─ SettingsContentViewport   <- 唯一主滚动区
      └─ SettingsSectionPanel
         ├─ SectionHeader
         └─ SettingsGrid
            ├─ SettingRow
            └─ SettingRow
```

适用页面：

```text
WeiG WebUI
Downloads
Connection
Speed
BitTorrent
Web UI
Advanced
```

这些页面允许不同 schema、字段和 capability，但不允许重新造独立卡片/滚动/两列布局系统。

### 6.1 SettingsSectionPanel

一个逻辑 section 对应一个 Surface/Panel；**不是一项设置一张卡**。

Panel 统一负责：

```text
max width
section spacing
heading relationship
SettingsGrid placement
mobile/desktop shared surface hierarchy
```

当前 settings content 最大宽度：

```text
1240px
```

### 6.2 SettingsGrid

当前响应式 contract：

```text
viewport > 1180px   -> 2 columns
viewport <= 1180px  -> 1 column
```

使用同一个 Grid owner，不创建 desktop/mobile 两套组件。

普通 SettingRow 占一个 cell。语义上需要更多水平空间的字段可 `span=full`：

```text
path
URL
domain/address
tracker
directory/location
username/password
wide textarea/rule
```

是否 full-span 由共享语义策略决定，不允许每个 tab 写一套页面特例。

### 6.3 SettingRow geometry

每行使用：

```text
minmax(0,1fr)  auto
```

规则：

```text
label / description -> 左对齐
control / value      -> 靠该 cell 右边缘对齐
row min height       -> desktop 64px；mobile 更紧凑
short Select/Switch  -> 保持自身合理宽度
long input           -> 可使用 shared wide control policy
```

用户在宽屏看到的是：

```text
语言        自动（浏览器）   |   主题        深色
显示时区    Asia/Shanghai   |   ...
```

而不是左侧标签 + 中间大空洞 + 固定左轴 control 的旧 Form Rail。

### 6.4 Settings data boundary

```text
Settings UI System
       │
  ┌────┴──────────────┐
  │                   │
WeiG state          qB state
                      │
                    QBClient
                      │
                    WebAPI
```

`ControlRegistry` 只负责把 select/switch/number/text/path/rate/duration/port/timezone 等语义映射到 canonical controls。

Settings presentation owner **不得**：

```text
new 第二个 QBClient
复制 setPreferences()
改 qB key/unit/save semantics
用 timer 反复修 DOM 作为正常机制
依赖其它 observer 先补 class 才能识别 SettingRow
```

qB Preferences 继续由原有 draft/QBClient/save path 管理。

## 7. Settings scroll ownership

硬规则：

```text
settings-view          bounded by app workspace
settings-layout        min-height: 0
settings-content       overflow-y: auto
settings-content       reaches final visible row
body/document          not a competing Settings scroll owner
```

Advanced 最后一项必须可滚到完整可见。

手机 category rail 不进入 Settings workspace；它移动到 hamburger `ContextDrawer`。`settings-content` 仍是主滚动区。

## 8. Display Time Zone

显示时区属于浏览器 presentation setting，不修改 qB daemon、Docker 或宿主机时间。

唯一配置入口：

```text
Settings -> WeiG WebUI -> Display Time Zone
```

底部 StatusDock 不再复制 timezone Select。Logs 等消费者读取同一个 `W.Time` 状态。

## 9. About：复用母版，但保持 FactRow 语义

About 复用：

```text
SettingsSectionPanel
responsive grid spacing
scroll owner
breakpoint
```

但它是只读 metadata，不是 preference page：

```text
WeiG WebUI -> SettingRow
About      -> FactRow
```

About **不得**出现语言、主题或其它可编辑 preference control。

结构：

```text
BrandIdentity
├─ animated BrandMark
└─ WeiG qB WebUI

Facts
├─ Version
├─ Git SHA
├─ qBittorrent
├─ WebAPI
├─ GitHub
├─ Blog
└─ GNU GPL-3.0
```

视觉 contract：

```text
Desktop -> compact 2-column facts
Mobile  -> compact 1-column facts
FactRow -> label + value/action stay on same visual row
```

## 10. Brand System

Header 视觉仍是：

```text
[动态图标] WeiG qB
```

但 owner 被拆开：

```text
BrandCluster
├─ BrandMarkHome
│  └─ BrandMark + AmbientMark
└─ BrandNameHome
   └─ WeiG qB
```

图标和文字都是独立点击目标，统一调用 `Navigation.goHome()`。未来迁移图标、hover、spacing、动画时无需搬整块 Header。

About 使用同一个 `BrandMark` 资产和同一个 `W.AmbientMark` controller，只调整 identity size/profile，不复制 SVG/动画实现。

### 10.1 AmbientMark motion

支持：

```text
hover  -> tilt / orbit / shine
click  -> rotate / flip
idle   -> spark / orbit / shine / breathe / combinations
```

要求：

```text
idle 低频随机
无永久 RAF
页面 hidden 暂停
prefers-reduced-motion 关闭非必要 motion
```

## 11. StatusDock + TransferRateEditor

Desktop StatusDock：

```text
left          center runtime cluster                      right
Torrent N     Storage | TransferCapsule | Connection      reserved/status
```

联合 runtime cluster 必须视觉居中。成功轮询 `已刷新 / Refreshed` 静默；一次性的 Connected 状态或异常可占右侧 reserved/status。

下载/上传速率是一个整体 `TransferCapsule`，不再保留两个 legacy speed button。

统一限速编辑器：

```text
canonical width  720px
viewport cap     calc(100vw - 48px)
mobile width     calc(100vw - 24px)
```

Normal / Alternative 共用一套 RateField / RateInput / RateUnitSelect / NumberScrubber。ALT 模式 retint 整个 editor。

## 12. Torrent selection/action/DataGrid

`SelectionModelV037` 管 conceptual selection；VirtualList mounted rows 只是 view。

支持 current page / all matching select/invert，并通过 `BulkActionDispatcher` bounded dispatch。

`TorrentActionController` 统一 Toolbar More、row/card More、right-click 与 long-press。

`DataGridLayoutController` 的 pointermove 只用 rAF 更新 layout，不触发 VirtualList reconstruction/API/storage write；pointerup 才持久化。

## 13. AdaptiveDialog

Dialog 统一 Header / Body / Actions 三轨。只有 Body 在空间不足时滚动；Header/Actions 稳定。桌面空间足够时不能出现无意义的内部 scrollbar。

## 14. Control Height / Motion

紧凑 control 高度级别：

```text
compact  30px
standard 34px
touch    38px+
```

页面动效以 opacity + small translate 为主。Hover 只做轻微 elevation/border enhancement；Settings row 不持续 3D 摇摆/强 glow/粒子动画。
