## 1. Release boundary

### EXACT-HEAD-001

所有 CI/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 变化都使旧 candidate 失效。

真实 qB4/qB5 LIVE 全过且 maintainer 明确授权前：`main` 不晋级、不 tag、不 Release。

## 2. Route Frame

`app.js` 唯一提交 View、Top/Mobile Nav、Torrent Sidebar visibility、tool-route scope、Back、drawer、`weigg:route-state`。Settings/UX/Spatial 不截获 App route。

## 3. Settings

Canonical renderer：`W.SettingsRenderer / W.SettingsState`。Desktop ordinary settings 两列；窄屏一列。Select 全部使用 canonical `W.Components.selectControl()`。


## 10. Transfer history

Window：`1m 5m 15m 30m 1h 3h 6h 12 h`。

Retention：`RAW_MAX=900`，`BUCKET_MAX=720` minute buckets。12 h 不增加 API polling；history 只在 browser memory。

## 11. Transfer rate unit

Canonical internal rate = B/s。

```text
NORMAL endpoint = B/s
ALT preference = KiB/s
QBClient read ALT  ×1024
QBClient write ALT ÷1024
```

Rate dialog：`await loadLimits()` then `showModal()`。

ALT Apply 测试必须确认发给 qB 的 preference 仍为 KiB/s。

## 12. Canonical Select / Dialog

### CONTROL-SKIN-001

Select behavior/presentation only `W.Components.selectControl()`；skin only `css/ui.css`。

### DIALOG-SCROLL-001

Outer dialog `overflow:hidden`；只有真实溢出的 body/form/action list 内滚。

### NATIVE-THEME-001

Dark native Select control + option surface 显式 dark；Light 同理。Transfer modal 的 window/rate unit 使用同一个 Select 的 `native:true`。

### OWNER-RETIRE-001

Canonical owner 上线时旧 DOM/CSS/caller/test 同批删除，Git history 是 archive。

## 13. DHT / Peers

Single writer：

```text

→ W.TransferRuntime
→ weigg:maindata
→ app Network metadata renderer
```

`loadTransfer()` 不写 DHT/Peers；same formatted value 不写 DOM。

## 14. Connection / Footer

Connection 不新增 polling：

```text
existing getTransferInfo connection_status
→ app emits weigg:status-state
→ W.MobileAdaptive presentation
```

Desktop：Transfer capsule 右侧显示 ConnectionIndicator。

```text
connected     ● Connected / 已连接      success green pulse
firewalled    ● Network limited / 网络受限 warning
disconnected  ● Disconnected / 未连接   danger
error         ● Unavailable / 异常       danger
```

Mobile：Footer hidden；Mobile Network Summary 消费同一 semantic state。

后台成功仍静默；删除并继续禁止 `已刷新 / Refreshed` 与 last-refresh timestamp。

Online pulse 必须尊重 system/WeiG Reduced Motion；Reduced Motion 静态 glow。

## 15. Mobile
