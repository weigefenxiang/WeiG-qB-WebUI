## 3. Settings

Canonical renderer：`W.SettingsRenderer / W.SettingsState`。

Desktop ordinary settings 两列；窄屏一列。SettingRow copy/control alignment 左对齐。Select 全部使用 canonical `W.Components.selectControl()`。

## 4. Private / PT

qB5：authoritative Private metadata → `W.TorrentSemantics` → filter/badge/detail。

qB4：

```text

qB4 Private click -> shared capability dialog
filter unchanged
0 tracker scan

0 per-torrent fallback
```

Capability dialog 短内容无 outer/body scrollbar，并包含 current version、5.0.0+ requirement、可选升级建议与备份提醒。

## 5. Tags capability

Tags capability 由 `QBClient.capabilities.tags`（WebAPI >= 2.3.0）定义。

```text
supported   -> canonical Tags Select
unsupported -> same Tags control remains visible
               onOpen -> shared capability dialog
               tag state unchanged
               no unsupported Tags endpoint request
```

不得伪写成 qB 5-only。

## 11. Transfer rate unit

Canonical internal rate = B/s。

```text
NORMAL qB endpoint = B/s
ALT preference = KiB/s
QBClient ALT read  ×1024
QBClient ALT write ÷1024
```

UI unit：Auto/KiB/s/MiB/s/GiB/s。

`Transfer` 不直接碰 `prefs.alt_dl_limit`。

Rate dialog 必须：

```text
await loadLimits()
then showModal()
```

ALT Apply 测试必须检查发给 qB 的 preference 数值仍为 KiB/s，防止 1024× 回归。

## 12. Canonical Select / Dialog

### CONTROL-SKIN-001

Select behavior/presentation only `W.Components.selectControl()`；skin only `css/ui.css`。

### DIALOG-SCROLL-001

Outer dialog `overflow:hidden`；只有真实溢出的 body/form/action list 内滚。

### NATIVE-THEME-001

Dark native Select control + option surface 显式 dark；Light 同理。

Transfer modal 的 window/rate unit 使用同一个 Select 的 `native:true`，不是第二组件。

## 13. DHT / Peers

Single writer：

```text
sync/maindata
→ W.TransferRuntime
→ weigg:maindata
→ app Network renderer
```

`loadTransfer()` 只更新 live speed + connection card，不写 DHT/Peers。

Same formatted value 不写 DOM，所以不闪。

禁止新增 timer / debounce polling / Observer / CSS flash workaround。

## 14. Footer
