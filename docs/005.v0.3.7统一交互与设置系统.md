# 005. v0.3.7 统一交互与设置系统

Status: **Responsive UI System 3.1 contract**

本文件记录 v0.3.7 RC 之后的下一轮 UI 重构契约。目标是减少局部补丁，把桌面与手机收拢到一套共享模型和一套可迁移的组件系统。

## 1. 设计来源与原则

参考 `VoltAgent/awesome-design-md` 的方法论，不复制单一产品外观。

```text
Linear      深色 surface ladder、hairline、克制 accent、少而精的卡片
IBM Carbon  表单/设置行结构、信息密度、明确分组
Raycast     紧凑 command、popover、keyboard-first interaction
Apple       动效节奏、空间关系、减少视觉噪声
WeiG        蓝紫/cyan 品牌色、星空、低频随机 AmbientMark
```

核心目标：

```text
结构优先于装饰
信息密度优先于空卡片
可读性优先于硬塞
共享模型优先于桌面/手机复制
随机动效必须低频、克制、可关闭
```

## 2. 一套应用，两种响应式呈现

当前继续坚持共享 `app.js` / QBClient / application state，不拆成 desktop/mobile 两套业务 JS。

```text
Shared Model
├── TorrentFieldRegistry
├── SortModel
├── SelectionModel
├── DialogModel
├── SettingsSchema
├── TransferLimitModel
└── ResponsiveShell

Presentation
├── Desktop DataGrid
└── Mobile two-line Torrent Row
```

允许手机端有 adaptive layer，但该层只负责 layout、density、touch interaction 和 presentation，不复制 API/业务规则。

## 3. Intrinsic Select 2.0

所有 Select 使用同一 primitive。

### 3.1 宽度

默认由当前内容决定：

```text
50            -> 紧凑宽度
选择          -> 紧凑宽度
下载 ↓        -> 紧凑宽度
Asia/Shanghai -> 根据文字自然变宽
```

禁止给短值统一分配 180/220/330px 之类固定宽度。

### 3.2 视觉识别

Select 不依赖 `▾` 才能被识别。默认隐藏 chevron，通过以下状态区分：

```text
subtle tinted surface
hairline / accent edge
hover elevation
focus ring
open state
```

只有在无障碍或特定复杂控件确有需要时才允许显式展开图标。

### 3.3 弹出层

menu 根据最长合理选项与 viewport 决定宽度，可比 trigger 宽；所有浮层继续使用 body-level FloatingLayer，并执行 flip/shift/collision。

## 4. Dismiss Policy

所有 Dialog / Popover / Context Menu 统一声明类型，由公共控制器管理关闭行为。

```text
popover / context menu
  outside click -> close
  Escape        -> close
  opening other -> close previous

normal dialog
  backdrop double-click -> close
  Escape                -> close
  explicit close        -> close

 destructive / irreversible dialog
  backdrop action -> no implicit close
  explicit cancel / close required
```

关闭后应恢复合理 focus。手机 long-press、桌面 contextmenu、Toolbar More 进入同一 TorrentActionController。

## 5. TorrentFieldRegistry

当前桌面列和手机 `mobileFields` 不应继续长期维护两份定义。建立一个共享 registry，每个字段至少描述：

```text

label
compactLabel
sortKey
formatter
desktop capability
mobile capability
default priority

```

首批字段：

```text

Progress
Download
Upload
ETA
Status
Ratio
Tracker
Category
Tags
Seeds
Peers
Save path
Added time
Completion time

```

仅当当前 qB WebAPI/capability 提供可靠数据时才显示。

## 6. Mobile Torrent Row：严格两行

手机每个种子最多两行：

```text
☐ Torrent name........................  Downloading  ⋯
   72% · 6.2GiB · ↓8.4M · ↑1.2M · 22m · +2
```

第一行固定：

```text
Checkbox | Name | Status | More
```

第二行是用户可配置 Metric Rail。

空间不足的顺序：

```text
1. compact formatter
2. reduce gap within readable range
3. keep higher-priority selected fields
4. collapse remaining fields to +N
```

禁止继续把字号压到 6–7px 来保证所有字段物理显示。

`+N` 打开统一 detail/popover/bottom sheet 显示被折叠字段。

## 7. Mobile command bar：严格一行

手机 Torrent 工具条目标：

```text

```

更窄屏幕允许 compact label，但不允许换成两行。

```text
☑ Download
☑ Upload
```

```text
上传 ↑/↓

```

## 8. Settings：从 Card Grid 改为 Section Rows

禁止继续“一项设置 = 一张大卡”。

桌面：

```text
Section Surface
├── Setting Row
├── Divider
├── Setting Row
├── Divider
└── Setting Row
```

一行结构：

```text
Title / optional description                   Control
```

右侧 control 共用对齐轴。

### 8.1 语义宽度

```text
Boolean           Switch
small enum        60–100px
port              90–110px
time/rate number  90–140px
IP/domain         160–280px
path/long string  flexible, capped
```

数字 `0/1/2` 不允许占满 300–400px。

### 8.2 手机 Settings

手机每项可以变成上下布局，但仍属于同一个 Section Surface，不恢复“一项一大卡”。

## 9. Display Time Zone

显示时区是浏览器 presentation setting，不修改 qB daemon、Docker 或宿主机时间。

唯一配置入口：

```text
Settings -> WeiG WebUI -> Display Time Zone
```

底部桌面 statusbar 删除重复 timezone Select。Logs、About、drawer 等消费者只读取共享 `W.Time` 状态。

时区 Select 内部可显示：

```text
✓ UTC+08:00 · Asia/Shanghai
```

`✓` 与当前时区必须属于同一个 control，不形成独立块。

## 10. About Surface

About 不再拆成 Version / Build / qB / API / GitHub / License 多张小卡。

使用一个完整 Surface，内部用 section/divider 建立层级：

```text
WeiG qB WebUI
  Wei.G / WeiG Share
  Version / Build SHA
  GitHub / Website / GPL-3.0

qBittorrent upstream
  qBittorrent version
  WebAPI version
  upstream project / copyright / license attribution
```

必须清楚区分本项目与 upstream，避免作者归属歧义。

## 11. AmbientMark 2.0

复用现有 `W.AmbientMark`，不新造第二套 Logo animation。

模块接口覆盖：

```text
hover
  tilt / orbit / shine

click
  rotate-360 / flip-x / flip-y

idle-random
  spark / orbit / shine / breathe / combinations

accessibility
  prefers-reduced-motion
  document.hidden pause
```

Idle 动效低频随机触发，不持续闪烁。目标是可将 JS/CSS 模块直接迁移到其它 WeiG 网站。

## 12. Desktop Transfer Capsule

桌面底部原独立 DL / UL 状态合并成一个 Transfer Capsule：

```text
↓ 8.4 MiB/s   ↑ 1.2 MiB/s
```

点击打开统一限速控制：

```text
Mode   NORMAL / ALT
Download  value + unit
Upload    value + unit
Unlimited
Apply
```

显示单位可选：

```text
B/s / KiB/s / MiB/s / GiB/s
```

内部统一转换为 qB WebAPI 的真实单位。

ALT 模式必须通过背景/边框 tone 与 `ALT` 文本共同识别，不只改变一个小字。

## 13. Control Height

所有紧凑 control 使用统一高度级别：

```text
compact  30px
standard 34px
touch    38px+
```

Button / Select / label container 不得因各自 padding/line-height 形成底部空白或垂直错位。

## 14. Motion

页面打开：

```text
opacity + small translateY + subtle depth
180–280ms
```

静止：低频随机微光/边缘 shimmer。

Hover：最多 1–2px elevation / subtle border enhancement。

不允许 Settings 每行持续 3D 摇摆、强 glow、持续粒子动画。

`prefers-reduced-motion: reduce` 必须关闭非必要 motion。

## 15. 验收 Gate

新增/更新自动 contract 至少覆盖：

```text
Select content-fit and no mandatory chevron
single shared TorrentFieldRegistry
mobile torrent <= 2 visual lines
mobile command bar <= 1 visual line
field sort/visibility persistence
Settings section-row structure
short-value controls are not full-width
shared dismiss policy
Settings-only timezone entry
single About surface with upstream/project attribution
AmbientMark reduced-motion
Transfer Capsule NORMAL/ALT states
```

真实手机和桌面浏览器仍需要 live visual validation；fixture PASS 不替代真实环境验收。
