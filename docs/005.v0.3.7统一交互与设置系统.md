# 005. v0.3.7 统一交互与设置系统

Status: **Responsive UI System 3.2 contract**

本文件记录 v0.3.7 的统一 UI 契约。目标是减少局部补丁，把桌面与手机收拢到一套共享模型、一套 canonical component system 和明确的 viewport/scroll ownership。

## 1. 设计来源与原则

参考 `VoltAgent/awesome-design-md` 的方法论，不复制单一产品外观。

```text
Linear      深色 surface ladder、hairline、克制 accent、少而精的卡片
IBM Carbon  表单/设置行结构、信息密度、明确分组
Raycast     紧凑 command、popover、keyboard-first interaction
Apple       动效节奏、空间关系、减少视觉噪声
WeiG        蓝紫/cyan 品牌色、星空、低频随机 AmbientMark
```

核心目标：

```text
结构优先于装饰
信息密度优先于空卡片
可读性优先于硬塞
共享模型优先于桌面/手机复制
随机动效必须低频、克制、可关闭
一个语义只允许一个 canonical owner
```

## 2. 一套应用，两种响应式呈现

当前继续坚持共享 `app.js` / QBClient / application state，不拆成 desktop/mobile 两套业务 JS。

```text
Shared Model
├── TorrentFieldRegistry
├── SortModel
├── SelectionModel
├── DialogModel
├── SettingsSchema
├── TransferLimitModel
└── ResponsiveShell

Presentation
├── Desktop DataGrid
└── Mobile two-line Torrent Row
```

允许手机端有 adaptive layer，但该层只负责 layout、density、touch interaction 和 presentation，不复制 API/业务规则。

## 3. Intrinsic Select 2.0

所有 Select 使用同一 primitive。

### 3.1 宽度

默认由当前内容决定：

```text
50            -> 紧凑宽度
选择          -> 紧凑宽度
下载 ↓        -> 紧凑宽度
Asia/Shanghai -> 根据文字自然变宽
```

禁止给短值统一分配 180/220/330px 之类固定宽度。

### 3.2 视觉识别

Select 不依赖 `▾` 才能被识别。默认隐藏 chevron，通过以下状态区分：

```text
subtle tinted surface
hairline / accent edge
hover elevation
focus ring
open state
```

只有在无障碍或特定复杂控件确有需要时才允许显式展开图标。

### 3.3 弹出层

menu 根据最长合理选项与 viewport 决定宽度，可比 trigger 宽；所有浮层继续使用 body-level FloatingLayer，并执行 flip/shift/collision。

## 4. Dismiss Policy

所有 Dialog / Popover / Context Menu 统一声明类型，由公共控制器管理关闭行为。

```text
popover / context menu
  outside click -> close
  Escape        -> close
  opening other -> close previous

normal dialog
  backdrop double-click -> close
  Escape                -> close
  explicit close        -> close

destructive / irreversible dialog
  backdrop action -> no implicit close
  explicit cancel / close required
```

关闭后应恢复合理 focus。手机 long-press、桌面 contextmenu、Toolbar More 进入同一 TorrentActionController。

## 5. TorrentFieldRegistry

当前桌面列和手机 `mobileFields` 不应继续长期维护两份定义。建立一个共享 registry，每个字段至少描述：

```text
key
label
compactLabel
sortKey
formatter
desktop capability
mobile capability
default priority
min display policy
```

首批字段：

```text
Name
Size
Progress
Download
Upload
ETA
Status
Ratio
Tracker
Category
Tags
Seeds
Peers
Save path
Added time
Completion time
Priority
```

仅当当前 qB WebAPI/capability 提供可靠数据时才显示。

## 6. Mobile Torrent Row：严格两行

手机每个种子最多两行：

```text
☐ Torrent name........................  Downloading  ⋯
   72% · 6.2GiB · ↓8.4M · ↑1.2M · 22m · +2
```

第一行固定：

```text
Checkbox | Name | Status | More
```

第二行是用户可配置 Metric Rail。

空间不足的顺序：

```text
1. compact formatter
2. reduce gap within readable range
3. keep higher-priority selected fields
4. collapse remaining fields to +N
```

禁止继续把字号压到 6–7px 来保证所有字段物理显示。

`+N` 打开统一 detail/popover/bottom sheet 显示被折叠字段。

## 7. Mobile command bar：严格一行

手机 Torrent 工具条目标：

```text
[选择] [50] [列 6] [下载 ↓]                         [⤢]
```

更窄屏幕允许 compact label，但不允许换成两行。

`列 N` 使用 Bottom Sheet 管理字段；排序和字段显隐统一读取 TorrentFieldRegistry。

## 8. Settings：Section Rows + SettingsViewportLayout

禁止继续“一项设置 = 一张大卡”。所有设置页共享同一个 `SettingsViewportLayout`：

```text
SettingsPageShell
├── SettingsHeader
└── SettingsLayout
    ├── SettingsSidebar
    └── SettingsContentViewport  <- 唯一主滚动区
```

`Downloads / Connection / Speed / BitTorrent / Web UI / Advanced / WeiG WebUI / About` 不允许各自重新定义滚动行为。

硬规则：

```text
settings-view          height: bounded by app workspace
settings-layout        min-height: 0
settings-content       overflow-y: auto
settings-content       must reach the final visible setting row
body/document          must not become a competing second Settings scroll owner
```

### 8.1 Desktop Form Rail

普通 preference row 使用一个居中的 Form Rail，而不是横跨整个宽屏：

```text
                label column      control column
                left aligned      left aligned

                添加 Tracker      [             ]
                启用备用 Web UI    [ switch      ]
                备用 Web UI 路径   [/config/...  ]
```

当前几何 contract：

```text
whole rail      <= 820px
label column    ~290px
column gap      32px
control column  ~340px
```

两列整体居中；左侧文字全部左对齐，右侧 control 也从同一左轴开始。短数字、Switch、Select 不强制拉成与路径输入框相同宽度。

### 8.2 Mobile Settings

手机保持紧凑自适应，不把桌面 820px Form Rail 硬缩小。设置项仍属于同一个 Section Surface，并维持可读 touch target；主内容始终由 `settings-content` 单独滚动。

## 9. Display Time Zone

显示时区是浏览器 presentation setting，不修改 qB daemon、Docker 或宿主机时间。

唯一配置入口：

```text
Settings -> WeiG WebUI -> Display Time Zone
```

底部 desktop StatusDock 不再出现重复 timezone Select。Logs 等消费者只读取共享 `W.Time` 状态。

时区 Select 内部可显示：

```text
✓ UTC+08:00 · Asia/Shanghai
```

`✓` 与当前时区必须属于同一个 control，不形成独立块。

## 10. AboutFactsPanel

About 是只读 metadata surface，不是 preference page。

因此 About **不得出现语言、主题或其它可编辑 preference control**。语言继续自动跟随浏览器/运行时 i18n 策略，不在 About 放一个“语言”设置项。

结构：

```text
WeiG qB WebUI identity
qBittorrent upstream attribution

Facts
  Version        0.3.7
  Git SHA        <exact SHA>
  qBittorrent    v5.2.0
  WebAPI         2.15.1
  GitHub         weigefenxiang/WeiG-qB-WebUI
  Blog           WeiG Share
  License        GNU GPL-3.0
```

视觉 contract：

```text
Desktop  -> one surface + compact 2-column facts grid
Mobile   -> one surface + compact 1-column facts grid
FactRow  -> label + value + optional action stay on the same visual row
```

Label、value 和外链按钮由同一个 `FactRow` grid 管理；不能再退回“标题一行、值下一行”的大空白样式。

项目作者/品牌与 qBittorrent upstream attribution 必须分离，避免归属歧义。

## 11. AmbientMark 2.0

复用现有 `W.AmbientMark`，不新造第二套 Logo animation。

模块接口覆盖：

```text
hover
  tilt / orbit / shine

click
  rotate-360 / flip-x / flip-y

idle-random
  spark / orbit / shine / breathe / combinations

accessibility
  prefers-reduced-motion
  document.hidden pause
```

Idle 动效低频随机触发，不持续闪烁。

## 12. StatusDock + TransferRateEditor

Desktop StatusDock 分成明确的视觉职责：

```text
left          center runtime cluster                      right
Torrent N     Storage | TransferCapsule | Connection      reserved/status
```

`Storage + Transfer + Connection` 的联合视觉中心必须接近 StatusDock 中心，不允许全部堆在右侧。

### 12.1 Transfer Capsule

下载/上传速率是一个整体按钮：

```text
[ ↓ 8.4 MiB/s   ↑ 1.2 MiB/s ]
```

Hover / Focus / ALT mode 都作用于整个 capsule，不再保留两个 legacy speed button，也不允许一次点击弹出两个限速框。

### 12.2 TransferRateEditorDialog

桌面统一限速编辑器使用大尺寸 surface：

```text
canonical width     720px
viewport cap        calc(100vw - 48px)
header/body/actions horizontal inset 24px
mobile width        calc(100vw - 24px)
```

结构：

```text
Global speed limits
ModeSegmentedControl
├── Normal
└── Alternative rate limits

RateFieldCard: download
RateFieldCard: upload
DialogActionBar
```

RateFieldCard 复用：

```text
RateInput
RateUnitSelect
NumberScrubber
```

显示单位支持 B/s / KiB/s / MiB/s / GiB/s，内部仍转换为 qB WebAPI 的真实单位。

备用模式使用 qB 官方语义：

```text
备用速度限制
备用下载速度限制
备用上传速度限制
```

进入备用模式时整个 editor 的 border / surface / focus tone 一起 retint，不能只改变一个小 `ALT` 标签。

## 13. Control Height

所有紧凑 control 使用统一高度级别：

```text
compact  30px
standard 34px
touch    38px+
```

Button / Select / label container 不得因各自 padding/line-height 形成底部空白或垂直错位。

## 14. Motion

页面打开使用 opacity + small translate；静止状态只允许低频随机微光/边缘 shimmer。Hover 最多 1–2px elevation / subtle border enhancement。

不允许 Settings 每行持续 3D 摇摆、强 glow、持续粒子动画。`prefers-reduced-motion: reduce` 必须关闭非必要 motion。

## 15. 验收 Gate

自动 contract 至少覆盖：

```text
Select content-fit and no mandatory chevron
single shared TorrentFieldRegistry
mobile torrent <= 2 visual lines
mobile command bar <= 1 visual line
Settings section-row structure
SettingsContentViewport can scroll to final row
desktop centered/left-aligned Form Rail
About contains metadata only
About label/value remain on one visual row
desktop About 2-column / mobile About 1-column
Status runtime cluster is visually centered
single Transfer Capsule without nested legacy buttons
Transfer editor >= 680px effective desktop width
Transfer editor keeps >= 20px internal edge breathing room
Alternative mode retints the complete editor
Torrent ActionSheet semantic tones
Tooltip and ConnectionIndicator ownership
Reduced Motion
```

真实手机和桌面浏览器仍需要 live visual validation；fixture PASS 不替代真实环境验收。
