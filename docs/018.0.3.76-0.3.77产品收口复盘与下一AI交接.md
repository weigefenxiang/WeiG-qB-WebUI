## 4. 0.3.77 已完成什么

### 4.1 Transfer presentation

`transfer/info` poll owner没有变化，`W.TransferRuntime` 仍是唯一 bounded history owner。

完整 Transfer dialog删除图表上方重复 summary strip，只保留 chart-bottom 一组语义：

```text
left:  ↓ <realtime download> | 下载 <session downloaded>
right: 上传 <session uploaded> | ↑ <realtime upload>
```

Display-only smoothing：

```text

```

不增加 poll、timer 或 unbounded history。

### 4.2 返回原生 WebUI 的语言/root handoff

唯一 persisted language truth 仍是：

```text
qB app/preferences.locale
```

关闭 Alternative WebUI 时，`W.SessionController` 可执行 bounded temporary-locale -> root switch -> final-locale transaction，使 built-in WebUI 在新 root 下重新加载正确 translator。最终 persisted value仍只有用户目标 locale；没有 `previousLocale`、退出恢复或第二语言 owner。

### 4.3 Tracker 详情 exact URL

qB upstream `torrents/trackers` 对普通 Tracker 返回 exact `tracker.url`。Torrent Details 现在直接显示/编辑 API 原始 URL，不再把详情 URL送进 `normalizeTracker()`。

```text

[DHT] / [PeX] / [LSD]                 -> 保持 upstream 特殊项
```

长 URL 使用 variable-height/wrap，不为了固定行高破坏 source truth。

```text

```

```text

```
