## 4. Root-cause families

### R1 — Native group / compound layout fidelity

目标：source-native fieldset/row/legend/control/content层级在正式UI保持可理解关系。需要时新增通用family/layout primitive，例如：

- `stacked compound`：长标题/说明独占一行，control cluster另起一行；
- `inline compound`：多个短控件按source顺序成组；
- `time range`：from HH:MM -> to HH:MM + day selector；
- `group/table`：watch-folder等多子项保持同一group；
- `credential`：username/password + related gates。

这些名字是设计方向，不是要求固定API。最终owner必须仍是同一Control Graph / SettingsSchema / SettingsRenderer。

### R2 — Canonical Select / editability / overlay

同一个 `W.Components.selectControl()` 同时负责：真实pointer/keyboard交互、selected value、draft callback、focus/a11y与floating menu。A4不能建立Settings专用第二Select。

检查链：

~~~text
exact source options
-> compact option facts
-> Preference descriptor/projection
-> current runtime key / write gate
-> graph control semantic
-> canonical Select
-> draft mutation
-> setPreferences
-> verified reread
~~~

Overlay必须viewport-aware；长option需完整可辨识，可采用shared max-width / wrap / vertical scroll策略，但不能用单项CSS patch。

### R3 — Compound control semantics

Source存在多个controls并不自动形成正确UI family。A4需证明time range、credential、watch-folder等组合关系来自source structure；若当前compact contract缺少必要relation，扩充generic metadata并由全部版本source admission约束。

WebUI Password仍遵守write-only安全规则：不预填、不缓存旧secret、非空才POST、保存后清空，不伪造GET reread；但真实Options中必须出现source-proven输入。

### R4 — Exact qB-owned locale closure

所有qB-owned section/control/option/note只由exact `{source,context}` + exact-release official translation解析。Source ref已存在时，A4优先查 runtime registry/locale resolution，不建立WeiG手写中文数据库。

## 9. P0-23A runtime-owner 实施记录

首批正式 A4 产品变化使用 Product VERSION **0.3.131**，范围严格限定为已由 exact source / current graph 证明的 generic owner：

## 11. P0-23C compound span correction
