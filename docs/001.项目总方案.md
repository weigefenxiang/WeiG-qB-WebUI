# 001. WeiG qB WebUI 项目总方案

Status: **v0.3.6 Final Candidate**  
Repository: `weigefenxiang/WeiG-qB-WebUI`  
Compatibility floor: **qBittorrent 4.1.9.1 / WebAPI 2.2.1**  
Current product version: **0.3.6**

## 1. 产品目标

WeiG qB WebUI 是一套长期维护的 Alternate WebUI，不以“给当前截图补 CSS”为开发方式。工程目标是：

```text
统一组件
稳定交互
高信息密度
手机优先适配
老版本 qB 可用
新版本能力渐进增强
浏览器缓存身份可验证
真实服务器可快速回滚测试
```

设计参考可以来自 `VoltAgent/awesome-design-md` 收集的优秀体系，但只借鉴 token、component、responsive、interaction state 等方法论，不复制单个产品外观。

## 4. v0.3.6 六个长期基础系统

### 4.1 Canonical Primitive

一种语义只有一个实现：

```text
Button / IconButton
Input / Search
Select / Listbox
Switch / CheckControl
FilterChip
StatusPill
Card / Panel
Dialog / Drawer
FloatingLayer / Popover / Tooltip
DataGrid / Pagination / VirtualList
AmbientMark
```

### 4.2 FloatingLayer

所有会悬浮到业务内容上方的 Select、Dropdown、Menu、Popover、Tooltip、Timezone picker 进入 body-level portal，通过统一 flip/shift/collision contract 避免父容器 `overflow:hidden` 裁切。

### 4.3 TimeFormatter

显示时区属于浏览器：

```text
qB timestamp → normalized epoch → IANA timezone → visible text
```

底部状态栏是唯一全局入口。Logs 等 feature 消费同一状态，不再拥有第二个时区选择器。

### 4.4 Mobile Adaptive Layout

手机端由 App Shell 分配：

```text
Topbar
Workspace remaining track
Statusbar
Bottom navigation / safe area
```

页面只消费自己的剩余 track。Torrent/Search/RSS/Logs 禁止固定 viewport-minus-pixels 高度。

### 4.5 Advanced Unit Schema

数值 Preference 只有在 qB 官方源码/API 单位经过确认后才增加单位、转换或特殊值说明。所有转换必须 round-trip 到精确 WebAPI 表示。

### 4.6 Compatibility Matrix

兼容性按 WebAPI/capability 边界选择代表版本，不按 major 号粗暴判断。Canonical matrix 在 `tests/fixtures/qb-compat-matrix.json`。

## 5. Mobile UX 硬规则

### MOBILE-001

主页面优先使用剩余可用空间；不得在 Pager 与底部状态/导航之间留下人为大空白。

### MOBILE-CARD-001

Torrent 次要数据优先单行：

```text
↓0B/s  ↑0B/s  ETA  29.8MiB
```

适配顺序：压缩无意义空格/零 → gap → font/tracking → 最后才考虑 fallback。

### STATUS-SEMANTIC-001

```text
Downloading       cyan/blue
Seeding           green
Stalled download  amber
Stalled seeding   purple
Stopped/Paused    gray family
Queued            indigo
Checking/Moving   amber
Error             red
```

颜色与状态文字共同表达语义。

### TOOL-PAGE-001

手机 Search/RSS/Logs 只占一个 workspace viewport。空结果不得制造巨大固定空白框；有结果时数据区自动吃满剩余空间。

## 6. STORAGE-001

底部状态栏可展示 qB 默认保存路径所在文件系统的剩余空间，唯一数据源：

```text
sync/maindata
→ server_state.free_space_on_disk
```

它不等于“VPS 根目录剩余空间”。Docker bind mount 时可能对应宿主机上的数据盘/目录所在文件系统。

单位自动使用 IEC：

```text
B / KiB / MiB / GiB / TiB
```

精度按人类阅读习惯自适应，不强制固定有效数字。首次获取后使用 incremental RID；刷新低频运行；partial update 没有该字段时保留上一有效值；无数据不伪造。

## 7. TIME-002

状态栏标准形式包含 UTC offset 与 IANA zone。必须正确处理 `UTC+00:00`、`UTC+08:00`、`UTC+05:30`、`UTC+05:45` 和 DST。显示时区不修改 qB daemon、Docker 或宿主机时间。

## 8. SETTING-UNIT-001

已确认的示例：

```text
slow torrent timer                  s
slow torrent rate threshold         KiB/s
send buffer watermark               KiB
socket recv/send buffer             API B ⇄ display KiB
torrent file size limit             API B ⇄ display MiB
disk queue size                     API B ⇄ display KiB
memory working set                  MiB
checking memory                     MiB
hostname cache TTL                  s
refresh interval                    ms
save resume interval                min
```

特殊 `0` 语义如 System default / Disabled / Permanent lease 必须明确说明。枚举使用 canonical Select。

## 10. 缓存与部署

```text
HTML                   no-store bootstrap
CSS/JS                 ?v=<deployment Git SHA>
VERSION                 产品版本
GIT_SHA                 代码身份
weigg-install.json      部署元数据
```

Linux/Windows installer 与 release payload 都必须保留该身份链。部署 URL、Host path、qB-visible path、容器名和凭据属于运行环境输入/metadata，不属于源码常量。

## 12. LIVE Gate

发布前仍要求两个代际的真实 qB 实例：

```text
qB 4.1.9.1 / WebAPI 2.2.1
qB 5.2.x   / WebAPI 2.15.x
```

但仓库只定义**版本/能力要求**，不定义任何具体服务器域名、IP、凭据、容器名或宿主机安装目录。真实环境由维护者/使用者在运行测试时显式提供。

`tests/live-v036.sh` 使用：

```sh
sh tests/live-v036.sh \
  --sha <40-char-sha> \
  --target <installed-webui-dir> \
  --target <another-installed-webui-dir>
```

它只原子替换指定 Alternate WebUI 目录，生成备份与回滚提示，不要求重启 Docker/qB。qB 进程内 `alternative_webui_path` 也不由脚本猜测；已有安装 metadata 负责记录真实部署边界。

## 13. 结论

v0.3.6 的长期方向：

> **版本兼容由 Capability 决定；数字设置由 verified schema 决定；浮动 UI 由 FloatingLayer 决定；移动页面由 remaining-space layout 决定；时间显示由 TimeFormatter 决定；磁盘空间只展示 qB 实际提供的 filesystem telemetry；部署目标永远由运行环境提供。**
