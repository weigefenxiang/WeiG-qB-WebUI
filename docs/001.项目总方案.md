# 001. WeiG qB WebUI 项目总方案

Status: **v0.3.5 canonical UI + deterministic cache baseline**  
Repository: `weigefenxiang/WeiG-qB-WebUI`  
Compatibility floor: **qBittorrent 4.1.9**  
Compatibility target: **4.1.x → current 5.x**  
Current version: **0.3.5**


## 1. 产品目标

WeiG qB WebUI 是 qBittorrent Alternate WebUI，目标同时满足：

- qBittorrent 4.1.9 强兼容；
- 通过 Capability 延伸到当前 5.x；
- 高级、克制、立体的 Nebula Spatial Console；
- English canonical + 简体中文完整维护；
- 大型 Torrent 库分页 + VirtualList；
- Desktop DataGrid 与 Mobile Torrent Card；
- qB 核心 Torrent/Transfer/Settings/Search/RSS/Logs 能力；
- 新版功能在旧版能由已有数据可靠推导时，允许 WeiG JS Enhancement 回补；
- 后端不存在的数据/写接口绝不伪造；
- 用户交互状态在轮询中保持稳定；
- 安装、备份、回滚安全；
- HTML 与静态资源缓存行为确定、可追踪；
- 不依赖运行时大型前端框架或 CDN。

功能完整度可以参考 VueTorrent、官方 WebUI 等，但不能牺牲 4.1.9 下限，也不能复制其它产品视觉身份。

## 2. 核心硬规则

### COMPAT-001 — API 差异只能进入兼容层

```text
qB API
  ↓
QBClient + Capability + normalization
  ↓
稳定语义
  ↓
WeiG Enhancement
  ↓
Feature / UI
```

Feature/UI 禁止散落 qB 主版本判断。应使用 capability 或实际 Preferences 字段。

### COMPAT-002 — 四类能力

```text
Native       qB 当前版本原生提供
Compatible   QBClient 翻译新旧 API 语义/格式
Enhanced     浏览器基于已有数据补充交互能力
Unavailable  后端缺失且无法可靠推导，不伪造
```

典型：

```text
resume/pause ↔ start/stop      Compatible
paused ↔ stopped filter       Compatible
legacy/ms log timestamp       Compatible normalization
log search / severity filter  Enhanced
4.x Private/PT tracker rules  Enhanced
5.x exact Private flag        Native
old 4.x Torrent Creator       Unavailable
```

### UI-001 — One semantic primitive, one component

同一种语义只允许一套 canonical visual implementation：

```text
Settings        → SettingCard / settings-control
Torrent data    → DataGrid / VirtualList
Logs            → DataPage / DataPanel / VirtualList
Dialogs         → dialog + surface--modal
Status          → status-pill / Status Dock
```

Feature/version runtime 可以拥有行为，但不能重复造 Card/Grid/Modal。v0.3.5 以 Alternative WebUI 为基准修复：保留路径校验、确认和 self-disable 行为，视觉统一复用 SettingCard。

### CACHE-001 — HTML fresh, assets SHA-addressed

```text
HTML            → no-store bootstrap
build identity  → exact Git commit SHA
CSS/JS URL      → ?v=<Git SHA>
product VERSION → release/product version, not asset cache key
```

源文件使用 `__WEIGG_GIT_SHA__` 占位符，安装器/Release 打包时注入精确 SHA。Lazy runtime 必须读取同一个 HTML build SHA，不允许自己维护 `?v=0.x.y`。

### NAV-001 — No Dead-End Navigation

非首页必须有 Back；Fatal/Error 保留 Back / Home / Reload。

### PERF-001 — Data count != DOM count

```text
全库数据量
≠ 当前页 API 数据量
≠ 当前挂载 DOM 数量
```

20/50/100/200 只控制服务端分页；VirtualList 只挂载 viewport + overscan。

### SCROLL-001 — 用户滚动位置属于状态

自动轮询、Transfer 更新、Torrent 字段变化不得把用户从中部/底部弹回顶部。

允许主动重置：筛选、Facet、分页、页大小、搜索语境发生变化，或用户明确要求回顶部。

### PRIVACY-001 — Tracker credential 不进入 UI

显示、筛选、缓存 key 必须剥离 query / fragment。真正修改 Tracker API 时才可使用原值。

### I18N-001 — English canonical

English 是源语言；简体中文是正式维护翻译。缺失 locale 回退 English，不显示 raw translation key。qB 专有术语优先沿用官方翻译。

### STATE-001 — 一个业务状态源

Spatial/UX/runtime 可以重排、增强交互和订阅事件，但不得建立第二套 Torrent 业务状态。

## 3. 兼容基础

### 3.1 Stable Torrent semantics

```text
4.x              5.x
resume            start
pause             stop
paused filter     stopped filter
legacy log ms     modern log seconds
```

`QBClient` 负责 endpoint selection/fallback/normalization；UI 只理解稳定语义。Version 比较按点分整数，不准 `parseFloat('2.11')`。

### 3.2 Alternative WebUI Preferences

不按 qB 主版本猜测，读取实际：

```text
alternative_webui_enabled
alternative_webui_path
```

字段存在即显示；缺失即 Unsupported。

Docker 路径必须区分：

```text
Host/VPS path
/root/qbittorrent3/config/weigg-qb-webui
        ↓ /config mount
qB-visible path
/config/weigg-qb-webui
```

Host path 来自 installer metadata，不由 WebAPI/浏览器猜测。

## 4. Stable Virtual UI

VirtualList 必须：

- 自动 poll/manual refresh 保留 viewport；
- deliberate context change reset；
- 替换实例时清除旧 scroll handler；
- 不让 teardown 产生的 scrollTop=0 覆盖用户位置；
- 大型数据只挂载 viewport + overscan。

所有零结果 Torrent 视图使用紧凑 Empty State，不保留巨大空 DataGrid。

## 5. Transfer Control Dock

Desktop 底部是可交互状态/操作 Dock：

```text
↓ 当前下载
↑ 当前上传
ALT
连接状态
Torrent 数量
Transfer / Session
```

全局限速和 ALT 使用长期稳定 Transfer API。Transfer Graph 复用现有 transfer stream，不新增第二个高频 poller；最大 900 samples，Canvas 原生绘制。

## 6. Logs + Canonical DataPanel

在支持范围内：

```text
qB >= 4.1.0 → logs=true
```

timestamp：

```text
>= 1e12 → milliseconds / 1000
<  1e12 → seconds unchanged
```

Logs runtime：

```text
first last_known_id=-1
then current max id
own VirtualList
search
severity filter
Follow latest
max 5000 rows
route-local timer
```

布局：

```text
Auto     fill remaining workspace
Compact  intentionally smaller
Max      maximize data area
```

主数据区禁止回到 `max-height:62vh` + 大片无效空白的旧模式。

## 7. Settings canonical contract

卡片统一：

```text
Title
Description
Control / readonly value
```

qB preference：`W.Components.preferenceField()`  
安装/部署只读信息：`W.Components.readonlySettingField()`  
WeiG interface setting：`settings-control`

Responsive：

```text
mobile        1 column
desktop       2 columns
wide desktop  3-card visual grid
```

Alternative WebUI 的自定义 `alt-webui-v034__*` visual layer 和 `settings-v034.css` 在 v0.3.5 删除。

## 8. Build / Cache contract

部署目录必须包含：

```text
VERSION
GIT_SHA
private/weigg-install.json
```

metadata 示例：

```json
{
  "version": "0.3.5",
  "gitSha": "<40-character SHA>",
  "container": "qbittorrent3",
  "qbPath": "/config/weigg-qb-webui",
  "hostPath": "/root/qbittorrent3/config/weigg-qb-webui",
  "installedAt": "...",
  "installer": "linux"
}
```

`private/index.html` / `public/login.html` 声明 no-store/no-cache meta；本地 CSS/JS 用 Git SHA query。Linux/Windows installer 负责 SHA 注入；Release workflow 使用 `${GITHUB_SHA}` 固化 artifact。

真实域名仍必须检查最终 HTTP Header，避免 Cloudflare/Nginx 覆盖 HTML no-store。

## 9. 版本兼容矩阵

### Tier A — Legacy floor

```text
qBittorrent 4.1.9.x
Lab target: 4.1.9.1 / WebAPI 2.2.1
```

支持 Torrent 基础操作、Files、Tracker、Category、Global limit、ALT、Transfer stats、实际返回 Settings、分页/VirtualList、Logs、Alternative WebUI preference（字段存在时）。不伪造 Tags、exact Private flag、现代 Creator/Cookie API。

### Tier B — Mature 4.x

```text
4.2.x → 4.6.x
Browser fixture: 4.6.7 / WebAPI 2.8.3
```

按 capability 开启 Tags 等能力；Logs/Alternative WebUI 延续稳定 contract。

### Tier C — Modern 5.x

```text
5.0.x → current 5.x
Release-blocking target: 5.2.0 / WebAPI 2.15.1
```

Start/Stop、Stopped filter、Private flag、现代 Tags/Preferences 等按实际 WebAPI gate 开启。

## 11. Mobile

- Torrent Card，不压缩 Desktop DataGrid；
- Logs message + time/level 两行响应式 row；
- Bottom Navigation；
- Filter Popover/Sheet；
- Action Sheet；
- Settings 一列；
- 关键触控目标约 ≥44px。

## 12. 安装器

Linux / Windows installer 要求：

- 安装前备份；
- 原子替换目的 WebUI；
- 校验 `public/login.html` + `private/index.html` + `VERSION` + `GIT_SHA`；
- 多 qB Docker 实例时拒绝猜测；
- `--config-root` / `--container` 可明确目标；
- 普通 install/update 不修改 qB 用户名/密码；
- rollback 恢复上一份 WebUI/安全配置；
- main/Release payload 都必须有可追踪的 exact Git SHA。
