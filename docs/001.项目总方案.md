# 001. WeiG qB WebUI 项目总方案

Status: **v0.2.2 integrated baseline**  
Repository: `weigefenxiang/WeiG-qB-WebUI`  
Compatibility floor: **qBittorrent 4.1.9**  
Current version: **0.2.2**

## 0. 开发启动顺序

任何新 AI / 新开发者 / 新会话，修改前至少：

```text
1. 读 docs/001.项目总方案.md
2. UI/视觉/布局/i18n/Settings 任务读根目录 DESIGN.md
3. 读 docs/003.项目架构.md
4. 查 README.md / VERSION / main HEAD / CI
5. 搜索已有 Component / Client / Capability / VirtualList / i18n / SettingsSchema / Spatial layer
6. 明确 4.1.9、5.x、Desktop、Mobile、语言、性能和回归影响
7. Reuse → Extend → New
8. 修改后跑 CI，并同步 README / DESIGN / docs
```

## 1. 产品目标

WeiG qB WebUI 是 qBittorrent Alternate WebUI，目标同时满足：

- 4.1.9 强兼容并延伸到当前 5.x；
- 原生 qB 核心管理能力完整；
- Capability-based progressive enhancement；
- English canonical + 简体中文完整维护；
- Nebula Spatial Console 高级暗色视觉；
- Desktop 高信息密度、Mobile 一等交互；
- 20 / 50 / 100 / 200 服务端分页；
- 大量 Torrent / Files / Peers / Logs 使用 Virtual Window；
- Tracker/Announce 隐私脱敏；
- Metadata-driven Settings；
- GitHub 安装、备份、更新和回滚；
- 所有非首页页面都有返回路径。

## 3. 核心硬规则

### COMPAT-001
4.1.9 核心功能回归失败禁止发布。

### COMPAT-002
Feature/UI 不直接判断 qB 主版本；版本/WebAPI 信息只用于生成 Capability Profile。

### UI-001
视觉、布局、导航、i18n、Settings UX 以 `DESIGN.md` 为唯一权威。

### ARCH-001
模块职责以 `docs/003.项目架构.md` 为权威。UI 不直接访问 `/api/v2/*`。

### I18N-001
English 是 canonical source language；简体中文为正式维护翻译。缺失词条必须 English fallback。

### I18N-002
语言解析：用户手选 → 浏览器语言 → English。

### TYPO-001
所有字体使用 Semantic Typography Role；整体偏小时统一增加 2–3px，不逐组件修补。

### IA-001
Topbar 管应用导航；Desktop Sidebar 只保留低基数 Torrent 状态筛选。

### SIDEBAR-001
普通 Desktop 高度尽量不允许 Sidebar 自己出现滚动条。

### FILTER-001
Tracker / Save Path / Category / Tags 等高基数筛选使用 Filter Shelf + searchable Popover。

### SETTINGS-001
Settings 通过 metadata/schema 显示 human-readable title / description / control，不把 raw API key 当主标签。

### SETTING-001
Setting Card 固定：**标题 → 描述 → 控件**。

### NAV-001
非首页必须有 Back；错误状态保留 Back/Home/Reload。

### MOBILE-001
Mobile 不是 Desktop Table 缩小版。

### PERF-001
Torrent API 默认 50，允许 20 / 50 / 100 / 200。

### PERF-002
`Data Count != DOM Count`。

### PERF-003
Torrent、Files、Peers、Trackers、Logs、Search Results 等大型列表使用 Virtual Window + overscan。

### PRIVACY-001
Tracker/Announce 显示、筛选 key、本地 UI 状态必须先移除 query/fragment credential/passkey/token。

### DEPLOY-001
安装/升级必须可备份、验证和回滚；多 qB Docker 实例不得猜目标。

## 7. Nebula Spatial Console

Surface 顺序：

```text
Void
Base
Panel
Card
Raised
Floating
```

层级差异由 background luminance + thin edge + top highlight + black shadow + weak blue/violet ambient glow 共同完成。

Search/Input 在默认状态就必须和背景有区别：

```text
Default → Raised control surface
Hover   → blue cool edge + slight lift
Focus   → stronger blue border + soft focus ring
```

高级感来源是材质与层次，不是满屏 Neon。

## 8. i18n

正式维护语言：

```text
English
简体中文
```

运行时：

```text
English canonical dictionary
↓
Locale overlay
↓ missing
English fallback
```

qBittorrent 术语优先参考官方 `src/webui/www/translations/`；WeiG 独有词条由项目维护。

关键模块：

```text
webui/private/scripts/i18n.js
webui/private/scripts/settings-schema.js
webui/private/scripts/settings-translations.js
```

其他 Locale 可以存在，但缺词时必须安全回退 English。

## 9. Pagination / LargeList

用户页大小：

```text
20
50 default
100
200
```

普通列表使用 qB `limit + offset`。

```text
API page/cache
↓
Virtual Window
↓
Viewport + overscan DOM
```

目标：

```text
Desktop Torrent DOM normally ~20–60, prefer <100
Mobile prefer <=50
```

全库 Tracker / SavePath / PT 索引按有限批次构建，只缓存数据，不制造隐藏 DOM。

## 10. DataGrid

支持：

```text
column resize
sort
show/hide
order
persist width/order
reset
```

默认列：Name / Size / Progress / Download / Upload / ETA / Status。

手机使用 Torrent Card，不提供桌面列宽拖动。

## 11. Tracker Privacy

```text
https://tracker.m-team.cc/announce?credential=SECRET
→
https://tracker.m-team.cc/announce
```

5.x 有 private flag 时精确识别 Private；旧版用明确标注的 PT tracker-domain heuristic。

## 12. Settings v0.2.2

数据流：

```text
/app/preferences
↓
actual returned keys/types
↓
SettingsSchema
↓
English canonical metadata
↓
zh-CN translation / English fallback
↓
Canonical Setting Card
```

Setting Card：

```text
Title       one primary line
Description middle area
Control     bottom
```

Desktop 默认两列；Tablet / Mobile 单列。

Canonical controls：Boolean→Switch，Text/Path→Input，Enum→Select，Number→number input/control。

只显示当前 qB 实际支持/返回的 Preference。

## 14. Search / RSS / Logs

Capability-aware：不支持时隐藏入口，不显示死按钮。

Contextual Search 必须隔离：Settings 搜索不能触发 Torrent 后台搜索。

## 15. Installer

Linux：

```text
--list-containers
--container=NAME
--config-root=/host/config/root
--dir=/container/path
```
