## 1. 产品目标

WeiG qB WebUI 是 qBittorrent Alternate WebUI，目标同时满足：

- qBittorrent 4.1.9 强兼容；
- 通过 Capability 延伸到当前 5.x；
- 新版功能在旧版能够由现有数据安全推导时，使用 JS Enhancement 回补；
- 后端不存在的数据/写接口绝不伪造；
- 高级、克制、立体的 Nebula Spatial Console；
- 大型 Torrent/Logs 数据使用 VirtualList；
- Desktop/Mobile 响应式；
- 轮询不破坏用户位置与选择；
- 安装、备份、回滚安全。

## 2. Compatibility Bridge

### COMPAT-001 — API 差异只进入兼容边界

```text
qB API
  ↓
QBClient + Capability + normalization
  ↓
stable semantics
  ↓
WeiG Enhancement
  ↓
Feature / UI
```

UI 禁止散落主版本判断。

### COMPAT-002 — 四类能力

```text
Native       qB 当前版本原生提供
Compatible   QBClient 翻译新旧 API 语义/格式
Enhanced     浏览器基于已有数据补充交互能力
Unavailable  后端缺失且无法可靠推导，不伪造
```

典型例子：

```text
resume/pause ↔ start/stop      Compatible
paused ↔ stopped filter       Compatible
legacy/ms log timestamp       Compatible normalization
log search / level filter     Enhanced
4.x Private/PT tracker rules  Enhanced
5.x exact Private flag        Native
Torrent Creator on old 4.x    Unavailable
```

## 3. v0.3.2 Logs 兼容修复

旧实现错误使用：

```text
logs = WebAPI >= 2.3.0
```

导致 release floor `4.1.9.1 / WebAPI 2.2.1` 的 Logs 被 WeiG 自己隐藏。

v0.3.2 改为 qB **4.1.0+** 范围内开启 Logs，并保持未来版本 capability 语义。

### 时间戳归一化

旧 qB 日志可能返回毫秒，新 qB 返回秒。Feature/UI 不分支；`QBClient.logs()` / `peerLogs()` 统一输出秒：

```text
>= 1e12 → milliseconds / 1000
<  1e12 → seconds unchanged
```

### 增量日志

首次：

```text
last_known_id = -1
```

之后：

```text
last_known_id = current max id
```

只获取新增行。浏览器日志缓存上限 5000 条。

## 4. Canonical DataPanel

所有数据密集页逐步统一：

```text
Page Header
Toolbar
DataPanel
  Header
  VirtualList
  Empty/Error
  Status
```

Logs v0.3.2 首先落实：

- Auto：占满剩余 workspace；
- Compact：用户主动缩小；
- Max：最大化数据区域；
- 不再使用普通 `max-height: 62vh` 小框；
- 搜索、级别过滤、Follow latest；
- Mobile 两行布局。

后续 Search/RSS/Files/Peers/Trackers 可沿相同模板迁移。

## 5. 用户状态与性能硬规则

```text
Data count != DOM count
Poll update != scroll reset
Hidden route != high-frequency polling
```

自动轮询保持用户位置。筛选、分页、页大小、搜索语境改变属于 deliberate reset。

## 6. 版本兼容矩阵

### Tier A — 4.1.9.x

必须支持：Torrent 基础操作、Files、Tracker、Category、全局限速、ALT、Transfer stats、实际返回的 Settings、分页/VirtualList、**Logs**。

不伪造：Tags、exact Private flag、Creator/Cookie modern API。

### Tier B — Mature 4.x

按 WebAPI capability 增加 Tags、Stalled filter、rename 等，同时 Logs 继续原生可用。

### Tier C — Modern 5.x

使用 start/stop、stopped filter、exact Private flag、现代 Tags/Preferences，并按实际 WebAPI gate 开启 Creator/Cookie foundation。

## 7. 关键兼容桥

