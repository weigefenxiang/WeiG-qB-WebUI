# 001. WeiG qB WebUI 项目总方案

Status: **v0.3.7 / Responsive UI System 3.3**  
Target revision: **Clean Settings + Verified Session 3.4**  
Repository: `weigefenxiang/WeiG-qB-WebUI`  
Compatibility floor: **qBittorrent 4.1.9.1 / WebAPI 2.2.1**  
Current product version: **0.3.7**

## 1. 产品定位

WeiG qB WebUI 是长期维护的 qBittorrent Alternate WebUI。目标不是针对截图持续补丁，而是建立可复用、可测试、可迁移的 UI / interaction / compatibility system。

长期原则：

```text
一个业务模型
一套组件语义
一个语义一个 owner
当前运行文件使用稳定语义名，不用版本号当文件 ownership
Git 历史保存旧实现，运行目录不叠旧版本层
Settings 源渲染一次正确，不做旧 DOM 兼容修补
桌面 / 手机响应式呈现
高信息密度但不牺牲可读性
qB 老版本可用，新能力渐进增强
真正的 Session logout，而不是只跳登录页
精确 Git SHA 身份
Release 作为稳定分发事实源
真实环境可验证、可回滚
```

设计方法参考 `VoltAgent/awesome-design-md` 的 DESIGN.md 体系：Visual Theme & Atmosphere、Color Palette & Roles、Typography Rules、Component Styling、Layout Principles、Depth & Elevation、Do/Don't、Responsive Behavior 与 Agent implementation guide 都必须写进根 `DESIGN.md`。参考方法，不复制其它品牌界面。


## 4. 运行资产命名：稳定语义名，不按版本叠文件

新的硬规则：当前第一方运行资产只按职责命名。

目标结构示例：

```text
webui/private/css/app.css
webui/private/css/ui.css
webui/private/css/layout.css
webui/private/css/settings.css
webui/private/css/brand.css
webui/private/css/logs.css

webui/private/scripts/core.js
webui/private/scripts/components.js
webui/private/scripts/i18n.js
webui/private/scripts/ui.js
webui/private/scripts/layout.js
webui/private/scripts/settings.js
webui/private/scripts/brand.js
webui/private/scripts/header.js
webui/private/scripts/session.js
webui/private/scripts/logs.js
webui/private/scripts/app.js
webui/private/scripts/bootstrap.js
```

禁止：

```text
settings-brand-v037.css
ui-system-v037.css
v037.css
feature-v038.js
旧文件 + 新文件同时加载
旧文件名 alias/shim/import-only 兼容层
```

也不把 `settings-brand-v037.css` 简单改成长期的 `settings-brand.css`：这个文件本身混合 Settings / Brand 职责。最终应拆成 `settings.css` 与 `brand.css`，Header/Session 行为进入各自稳定 JS owner。

版本信息只存在于：

```text
VERSION        产品版本
Git SHA        代码与缓存身份
tag / Release  分发版本
```

CSS/JS 缓存通过 exact Git SHA 失效，不通过文件名版本号。Git 历史就是历史档案，运行目录不保留旧代第一方文件。

## 5. Settings 3.4：Clean Cut，不兼容旧展示层

这次截图已经证明继续“兼容旧 Settings DOM”会让旧系统永久干扰新系统。因此 3.4 采用 clean cut：

```text
app/qB/WeiG state
      ↓
PreferenceSchema
      ↓
ControlRegistry
      ↓
SettingRow factory
      ↓
SettingsGrid
      ↓
SettingsSectionPanel
```

源 renderer 一次生成最终 DOM。迁移完成后，Settings 范围内不再保留：

```text
.settings-control
.settings-row--canonical
.setting-row-grid
.settings-section--rows
.settings-grid-canonical
SETTINGS-FORM-RAIL-*
patchFactories()
normalizeSettings()/normalizeSection()
consolidateWeiGGrid()
Settings MutationObserver 搬行
语言卡片 observer 注入
时区卡片 observer 注入
靠 CSS 顺序压过旧 Settings CSS
```

这里的“不兼容”只针对旧 UI/DOM/CSS presentation。qBittorrent 4.1.9.1 的 WebAPI 兼容继续由 QBClient 保留。

## 6. Settings 视觉设计细节

所有页面统一：

```text
WeiG WebUI
下载
连接
速度
BitTorrent
Web UI
高级
```

宽桌面：两列。窄屏：一列。每个普通 SettingRow 内部固定：

```text
cell 左边缘                                  cell 右边缘
标题                                      [控件]
描述
```

明确几何：

```text
content max width          1240px
section header inset       16px
SettingRow inset           16px
row min-height             ~64px
inner columns              minmax(0,1fr) auto
SettingCopy                width:100%; justify-self:start; text-align:left
SettingControlSlot         justify-self:end
outer wide grid            repeat(2,minmax(0,1fr))
outer narrow grid          minmax(0,1fr)
```

Section 标题、每个 SettingCopy 的标题/描述必须共享同一左轴。任何普通 row 不允许水平居中。纵向居中控件可以，文字水平位置不可以居中。

普通字段默认 `span=1`。路径、URL、host、username、password 都不能因为字段名自动占整行。只有 multiline/composite/list/table 等真正宽编辑器允许 schema 显式 `span=full`。

奇数个普通 row 时，最后一项留左 cell，不拉满。

## 10. Verified Logout 3.4

真正 Logout 的验收不是“按钮点了、跳到 login”。标准流程：

```text
Logout action
→ SessionController.logout()
→ QBClient.logout()
→ POST /api/v2/auth/logout
→ QBClient.probeSession() 访问受保护 API
→ 必须确认旧 session 已不可用
```

确认 invalid 后才执行：

```text
停止 polling / 新认证请求
清空 torrents/settings 等内存私有数据
设置 sessionStorage logout guard
先锁住/隐藏 private shell
location.replace(public root)
```

Theme/Language/Timezone 等纯显示偏好可保留。

## 11. Back / BFCache SessionGate

浏览器后退不能恢复登出前的私有页面快照。

```text
logout guard 或 pageshow.persisted
→ private shell 不可重新显示
→ reload/probe server
→ session 无效时由 qB 返回 public login page
```

登录成功后清除 logout guard。

## 12. qB Authentication Bypass

qB 4.1.9.1 与当前版本都有同一类行为：如果当前客户端被配置成 localhost 免认证或 subnet whitelist 免认证，Session 结束后下一个请求会自动创建新 session。

所以：

```text
logout POST 成功
但 protected probe 仍成功
→ 不是“登出成功”
→ 识别为 auth bypass / durable logout impossible
→ 明确提示必须修改 qB Web UI 认证策略
```

前端不能伪造“真正登出”。

## 13. 本轮暴露的系统性问题

```text
1. 同一个 Setting 有多种 DOM shape。
2. 旧 FormRail 和新 SettingsGrid 同时拥有 layout。
3. ui-system / v037 / ui-polish / settings-brand 多代 CSS 都能碰同一 row。
4. 版本号文件命名鼓励“再叠一层”，而不是替换旧 owner。
5. 源 renderer 仍生成旧 DOM，再由 observer 二次修。
6. Language 与 Time zone 分别由历史 observer 后插入。
7. browser gate 只看两列，没锁绝对左轴，所以“外层两列、内层居中”也能 PASS。
8. migration bridge 被当成长期架构。
9. settings-brand-v037.js 同时承担 Settings / Brand / Header / Session，职责过重。
10. Logout 把 request resolved + redirect 误当成 session invalidation。
11. Back/BFCache 不在 Session contract 内。
12. qB auth bypass 没被识别，导致“刚登出又自动有 session”。
```

## 14. 硬性规则

```text
ASSET-NAMING-001
当前第一方运行资产只用稳定语义名；禁止 *-vNNN.* / vNNN.* 作为 active runtime ownership。
旧功能迁走后直接删除旧版本文件，不留 shim/alias/双加载。

SETTINGS-CLEAN-CUT-003
迁移完成后删除旧 Settings DOM/CSS/observer，不保留兼容分支。

SETTINGS-STRUCTURE-002
所有普通 editable setting 只允许一种最终 DOM。

SETTINGS-ALIGN-002
文字绝对左轴；控件绝对右轴；禁止普通 Settings 水平居中。

SETTINGS-GRID-002
宽桌面默认两列；普通 row 默认一个 cell。

SETTINGS-SPAN-002
full-span 只能 schema 明确声明。

SETTINGS-OWNER-002
一个 Settings geometry owner；不得靠 !important 互相覆盖。

AUTH-SESSION-002
Logout 必须通过 server-side protected probe 验证失效。

AUTH-BFCACHE-001
Back/BFCache 不得恢复 private shell。

AUTH-BYPASS-001
认证 bypass 下不得谎报 logout success。

SETTINGS-BUSINESS-001
presentation clean cut 不改变 qB preference key、unit conversion、save semantics 或 4.1.9.1 API compatibility。
```

## 15. 模块 ownership

```text
QBClient                 API / qB compatibility / logout endpoint / session probe
Application state        torrents / prefs / drafts / polling lifecycle
PreferenceSchema         label / description / type / enum / span / capability
ControlRegistry          semantic control selection
SettingsRenderer         source-rendered Section/Grid/Row/Fact composition
SettingsGrid             responsive geometry only
SettingRow               editable row structure only
SettingControlSlot       right-edge control placement
SessionController        logout state machine
SessionGate              private-shell re-entry / BFCache protection
HeaderUtilityAction      topbar utility presentation
BrandMark/AmbientMark    brand graphic and motion
AboutPanel/FactRow       read-only identity metadata
```

稳定文件名按 owner 拆分，禁止一个 `settings-brand.*` 长期同时承载 Settings / Brand / Header / Session。

## 17. Release 边界
