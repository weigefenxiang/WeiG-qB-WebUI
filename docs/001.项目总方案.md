# 001. 项目总方案

Status: **current project authority / stable project overview**

WeiG qB WebUI 是 qBittorrent Alternative WebUI。`webui/**` 是唯一正式产品，并且从 0.3.99 起本身就是可直接复制运行的 self-contained runtime；tools、source catalog、Virtual qB、CI 与 Pages 只负责发现、生成、审计、验证与发布证据，不能反向成为浏览器运行依赖。

本文件只维护长期目标、正式边界、authority 与当前高层状态。**Git history 是版本历史档案**；docs 不再按 WeiG 版本号新增复盘/下一 AI 交接文件。当前计划状态、未完成事项与 next-AI handoff 只维护在 `docs/014.AI协作与分支纪律.md`。

## 1. 长期目标与兼容原则

```text
qBittorrent 4.1.0 official stable
-> all admitted official stable releases
-> current latest official stable
-> future official stable / future major
```

未知能力不得靠版本号猜；危险 write 必须在 HTTP 前 fail closed。一个 semantic purpose 只有一个 Current Owner；禁止 old/new 双 active、MutationObserver repair、monkey patch、post-render repair、第二 polling/state/layout/language owner。

qB-owned surface 的正式 ownership 统一为：

```text
存在性 / 顺序 / UI 语义    exact qB upstream source
当前业务值                 qB WebAPI
文案身份                   exact {source, context}
目标语言                   exact release official qB translation
WeiG                       presentation / interaction / approved extensions
```

WeiG-owned surface 使用 WeiG 自己的 schema/i18n/UI，不能伪装成 qB-native；qB-owned surface 也不能再由 WeiG 手写一套版本真相。

## 3. 当前正式架构

```text
qB WebAPI
   ↓
W.QBClient
   ↓
W.CapabilityRegistry
   ← capabilities.json                 # control plane / release identity / compatFiles
   ← torrent-compat.json               # Torrent source facts
   ← detail-compat.json                # Torrent Detail source facts
   ← settings-compat.json              # current Settings compact facts
   ← rss-compat.json                   # RSS Downloader native surface facts
   ← source-actions.json               # action/parameter provenance
   ↓
canonical semantic owners
   ↓
WeiG UI

qB official source / admitted Frozen catalog
   ↓
tools / CI source extraction + independent coverage audit
   ↓
compact domain contracts / qB-owned copy evidence
   ↓
browser lazy-loads only the active compact domains it needs
```

Browser runtime 已退休旧 release-profile owner、`private/data/qb-releases.json` 与 `private/data/qb-release-profiles/`。65-release full catalog 继续作为离线 source/CI/simulator evidence，不进入正式浏览器 runtime。

当前 A 阶段新建的 Preferences native compact IR 还是 source/admission evidence，不能在正式切换前与现有 `W.SettingsSchema` 形成第二 active Settings owner。正式 cutover 必须同一 coherent change 完成新 source-driven projection、callers/tests 切换和旧手工 runtime truth 退休。

## 4. A–F 当前总方案

```text
A Options / Preferences
  exact source tabs/sections/order/control/copy/dependency
  ∩ runtime app/preferences
  -> native Options projection

B Torrent Status / Sidebar facets
  exact native status/filter/facet inventory/order/semantics
  -> generic qB-native projection
  -> append WeiG Path last

C qB-owned copy
  exact {source, context} + exact-release official translation
  -> W.I18n
  -> upstream English only when the official target translation is unavailable

D RSS
  exact native RSS/Downloader/rule source facts + source-actions
  -> generic source-driven rule projection

E Torrent Detail
  retain and finish the existing torrentDetailUi/detail-compat generic chain
  -> no second Detail system

F Source admission / compact runtime
  Frozen exact-source catalog
  -> independent inventory/census
  -> compact domain contracts with common release-set identity
  -> browser lazy loading
```

每个阶段内部优先 focused/change-point validation；阶段完整收口后最多一次 admitted-stable 65-release offline/Virtual full matrix。A–F 全部集成完成并冻结 final dev SHA 后，才进入 `docs/011` 定义的昂贵 real-qB Full Frozen Matrix。阶段离线 65 不等于真实 qB 65/65。

## 5. Universal Portable

raw `webui/` 与 materialized distribution 都必须自包含：正常运行不依赖 Node、tools、simulator、CI、GitHub 或在线翻译服务。Distribution 只负责 exact `GIT_SHA`、ZIP/checksum、manifest/installer 等发布身份，不再为 dev 生成 per-release browser profiles。
