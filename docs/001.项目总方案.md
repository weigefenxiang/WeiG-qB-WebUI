# 001. WeiG qB WebUI 项目总方案

Status: **v0.3.6 canonical interaction + ambient brand baseline**  
Repository: `weigefenxiang/WeiG-qB-WebUI`  
Compatibility floor: **qBittorrent 4.1.9**  
Compatibility target: **4.1.x → current 5.x**  
Current version: **0.3.6-dev**

## 0. 开发启动顺序

每轮开发遵循：

```text
1. 从长期 dev 开始
2. 先读 DESIGN.md + docs/001-004
3. 识别 canonical owner
4. 先修改 model/component boundary，再改 feature
5. 静态测试
6. Chromium fixture
7. 真实 qB 4.1.9.1 / 5.2.0 实机
8. dev → PR → main
```

长期分支只保留：

```text
main  稳定发布
 dev  持续开发
```

不把每个小功能长期保留为 `fix-*` / `v0.x-*` 分支。

## 1. 项目定位

WeiG qB WebUI 是 qBittorrent Alternative WebUI，不替代 qB 后台，也不伪造不存在的 qB API。

目标：

```text
跨 qB 4.1.x → 5.x
统一、现代、可复用 UI system
大量 Torrent 下稳定
轮询不破坏用户位置
暗色/亮色一致
桌面信息密度高
移动端 touch-first
部署可回滚、可识别精确 Git SHA
```

## 2. 兼容原则

### COMPAT-001 — Capability first

功能是否显示优先看：

```text
实际 qB/WebAPI capability
实际 preference field
```

而不是散落：

```text
if qB major === 4
if qB major === 5
```

版本判断集中在 QBClient/capability boundary。

### COMPAT-002 — 不伪造 backend ability

旧 qB 缺少的 native 数据/API 不伪造为“官方支持”。WeiG 可以提供安全的前端增强，但必须明确数据来源和限制。

### COMPAT-003 — 4.1.9 是真实 floor

关键功能必须至少在 fixture 中覆盖：

```text
4.1.9.1 / WebAPI 2.2.1
```

并在发布前做真实实例验证。

## 3. UI 架构总原则

### UI-001 — 一个语义，一个 canonical component

```text
Button
IconButton
Input
Search
Select/Listbox
Switch
CheckControl
FilterChip
Tooltip
Card
Panel
Badge/Status
Popover
Modal
Tabs
DataGrid
VirtualList
Settings Card
AmbientMark
```

任何 feature/version runtime 不得重新发明同一种视觉组件。

### UI-002 — Feature 负责业务，不负责第二套视觉

允许：

```text
layout
columns
feature-specific data state
validation
confirmation
API semantics
```

禁止：

```text
feature-local button system
feature-local select system
feature-local chip system
feature-local card system
feature-local modal system
```

### UI-003 — 所有交互控件统一状态

```text
Default
Hover
Focus-visible
Active/Selected
Disabled
```

Dark/Light 使用同一 token architecture。

## 4. v0.3.6 Canonical Select

系统 `<select>` popup 在 Windows/Chrome 等环境可能绕过页面配色。v0.3.6 起：

```text
Native select
   ↓ compatibility/data bridge
Canonical Select Trigger
   ↓
Floating Listbox
```

要求：

```text
暗色/亮色统一
Arrow Up/Down
Home/End
Enter/Space
Escape
ARIA listbox/option
Searchable long lists
mobile-safe presentation
```

所有页面的可见 dropdown 最终向该 primitive 收敛。

## 5. Ambient Brand

### BRAND-001

Logo 使用 reusable `AmbientMark`，不是 qB 页面一次性 CSS。

```text
Mark
Orbit
Spark
Shine
Scheduler
```

### BRAND-002

默认安静，随机短事件：

```text
8–28 秒随机检查
允许跳过
单次约 1–2 秒
```

效果：orbit / spark / tilt / shine / breathe。

### BRAND-003

```text
Reduced Motion → 停止非必要动画
page hidden    → scheduler stop
random source  → 可注入用于 deterministic test
```

禁止 permanent neon / permanent 3D spin / per-frame JS animation。

## 6. Logs

### LOGS-001 — Newest first

v0.3.6 默认：

```text
最新
↓
较旧
↓
最旧
```

排序优先 ID descending；fallback timestamp descending。

### LOGS-002 — Incremental cursor

显示倒序不改变 qB API contract：

```text
initial: last_known_id=-1
next:    last_known_id=max ID
```

### LOGS-003 — bounded

浏览器只保留最新 **5000** 条。

### LOGS-004 — Follow latest

Newest-first 后 Follow latest = 保持 top。

用户手动向下查看历史时 Follow 解除；新行插入顶部时补偿 scrollTop，不能把用户阅读位置推走。

### LOGS-005 — Canonical controls

Logs 组合：

```text
Search
FilterChip
CheckControl
Select
Button
StatusPill
DataPanel
VirtualList
```

不得自己实现下拉框/Chip/Follow control 视觉。

## 7. Client Time Zone

时区属于 display layer：

```text
qB timestamp
→ QBClient unit normalization
→ W.Time
→ Intl.DateTimeFormat
→ selected IANA timeZone
```

首项：System / Browser。

浏览器支持时使用：

```js
Intl.supportedValuesOf('timeZone')
```

选项保存在：

```text
localStorage: weigg.timeZone
```

不写 qB Preferences，不修改服务器时区。

## 8. Torrent Detail Back

### NAV-001

Detail tab strip：

```text
[ ← 返回种子列表 ] [ 概览 ] [ 文件 ] [ Trackers ] [ Peers ] ...
```

### NAV-002

返回必须恢复用户来源：

```text
Page 2 + scroll N
→ Detail
→ Back / Esc
→ Page 2 + scroll N
```

### NAV-003

直接 URL 进入 Detail、无内部 list context 时 fallback 到 Torrent home，不盲目跳站外 history。

### KEYBOARD-001

Esc priority：

```text
Select/Popover
→ Dialog
→ editable input 不抢
→ Torrent Detail Back
→ Torrent list existing behavior
```

用户状态包括：


后台 polling 只更新数据，不重置这些状态。

## 10. Data / performance

### LARGE-001

```text
Data count != DOM count
```

高 cardinality 内容必须 VirtualList/windowed。

### LARGE-002

Torrent / Files / Peers / Trackers / Logs 等不能因为几千条数据就挂几千个隐藏 DOM node。

### MOTION-001

不要用持续动画解决层级问题；不在每行挂 backdrop-filter；隐藏图表停止视觉计算。

## 11. Settings

所有 Settings：

```text
Title
Description
Control
```

qB Preference → `preferenceField()`  
WeiG readonly deployment → `readonlySettingField()`  
WeiG UI preference → `settings-control`

Alternative WebUI 特殊 save/confirm/path guard 只属于行为层，视觉仍是 canonical SettingCard。

## 12. Internationalization

```text
Canonical source: English
Maintained: English + 简体中文
Fallback: English
```

Feature runtime 不直接 `if zh`；使用 semantic translation key/overlay。

## 13. Cache / deployment identity

HTML：

```text
no-store / no-cache / must-revalidate
```

CSS/JS：

```text
?v=<deployment Git SHA>
```

Lazy runtime 一律通过：

```text
buildAssetUrl()
```

安装目录：

```text
VERSION
GIT_SHA
private/weigg-install.json
```

产品版本和代码身份严格分离。

## 14. Installer safety

安装器必须：

```text
识别 Docker /config mapping
host path 与 qB path 分离
多容器不猜目标
安装前备份
原子替换/rollback
不修改用户名密码
记录 version/gitSha/hostPath/qbPath
```

## 15. 自动 Gate

静态：

```text
smoke
compat
logs compatibility
settings contract
cache contract
v0.3.6 UI contract
JS syntax
installer syntax
```

Chromium：

```text
Logs: qB4.1.9.1 + qB5.2.0 × 3 viewport
Settings: qB4.1.9.1 / 4.6.7 / 5.2.0 × 3 viewport
UI v0.3.6: qB4.1.9.1 / 4.6.7 / 5.2.0 × 3 viewport
```

重点阻塞条件：

```text
visible native white Select popup risk
horizontal overflow
browser console/page error
newest-first wrong order
timezone changes source timestamp
Follow OFF loses historical viewport
Detail Back loses page/scroll
Reduced Motion still runs AmbientMark
```

## 16. 发布流程

```text
dev implementation
→ dev CI green
→ real qB 4.1.9.1 + 5.2.0 test
→ docs status update
→ PR dev → main
→ main CI green
```

Fixture PASS 不代表实机 PASS。

## 17. 当前 v0.3.6 目标完成定义

完成意味着：

1. Logo AmbientMark 随机且克制，可复用；
2. Logs/全站 Select 不再出现独立 OS 白色视觉；
3. Button/Select/Chip/Check/Card/Status 等 canonical ownership 明确；
4. Logs 最新在顶部；
5. 时区可以在浏览器选择；
6. Page 2 → Detail → Back/Esc 能回 Page 2 + 原 viewport；
7. qB 4.1.9.1 / 4.6.7 / 5.2.0 fixtures 通过；
8. 真机验证完成后才允许进入 main。
