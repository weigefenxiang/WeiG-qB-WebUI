## 1. 长期目标

同一份 `webui/**` 应覆盖：

```text
qB 4.1.0
-> all verified 4.x official stable
-> all verified 5.x official stable
-> current latest official stable
-> future stable / qB6.x / qB7.x / future x.x.x
```

兼容解析优先级：

```text
NATIVE
-> NORMALIZED / ADAPTER
-> reliable old-API composition
-> reliable DERIVED
-> READ_ONLY when applicable
-> UNAVAILABLE
```

future `UNKNOWN` 只关闭无法证明的具体 capability，尤其危险写操作；不能因为 major/version 变大就整体拒绝，也不能因为版本更高就自动继承 current latest semantics。

禁止：

```text
fake data
N items -> N compatibility requests
high-cost compatibility polling
presentation self-probe
second business state / duplicate owner
runtime bridge / monkey patch repair
manual compatibility mode
```

## 8. “65/65 compatible”的正式产品解释

**同一份 `weig-qb-webui/webui` 可以面向已验证 qB 4.1.0 -> 5.2.3 official stable 自动适配；但这不等于所有版本拥有全部后期功能。**

```text
该版本有 capability     -> 正常开放
该版本没有 capability   -> 正确隐藏/禁用/降级
future/unknown 未证明    -> UNKNOWN
危险 write UNKNOWN      -> HTTP 前 fail closed
```

代表性边界：

```text
Settings preferences/setPreferences endpoint    qB 4.1.0+
RSS core                                        qB 4.1.0+
Logs main/peers                                 qB 4.1.0+
Properties/Files/Trackers/Peers/WebSeeds        qB 4.1.0+
filePrio/addTrackers                            qB 4.1.0+
Search core                                     qB 4.1.4+
remove/edit Tracker                             qB 4.1.5+
Peer Ban                                        qB 4.2.0+
Tags capability                                 qB 4.2.0+ source truth
Torrent Creator                                 qB 5.0.0+
```

Settings endpoint 可用也不代表每个 Preference 都 writable；仍逐 Preference 按 setter/type provenance 决定。

## 12. Git / proof discipline

```text
fresh-read dev exact HEAD
-> staging/candidate only parent = fresh HEAD
-> exact compare expected paths
-> validate candidate
-> fresh-read dev immediately before ref update
-> if moved: candidate invalid, rebuild
-> force:false safe fast-forward only
```

Repo-wide ownership/absence/uniqueness 只认 target exact SHA + complete tree/blob/file。Search/snippet 只能 discovery；working-tree CRLF-transformed bytes 不能证明 Git blob identity。
