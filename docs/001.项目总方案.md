# 001. 项目总方案

Status: **current product plan / AI handoff entry**

WeiG qB WebUI 是 qBittorrent Alternative WebUI。**`webui/**` 是唯一正式产品；核心目标是从 qBittorrent 4.1.0 起覆盖全部 official stable，并优先保证当前 stable 与未来 stable/new major 自动适配。** Simulator、source catalog、WebAPI evolution ledger、Endpoint/Transport Contract 都是辅助发现与验证工具，不是产品本身。

详细产品兼容路线见 [`010.真实qB产品兼容路线.md`](./010.真实qB产品兼容路线.md)；当前兼容事实见 [`002.兼容与实现状态.md`](./002.兼容与实现状态.md)；发布/CI 分层见 [`006.发布与晋级流程.md`](./006.发布与晋级流程.md)。

## 1. 产品目标

同一份：

```text
webui/**
```

应能够：

```text
qB 4.1.0
-> all 4.x official stable
-> all 5.x official stable
-> current latest stable
-> future stable / qB6.x / qB7.x / future x.x.x
```

自动识别真实 release/WebAPI/source capability，自动选择 native / normalized / derived 实现；用户不需要手工选择 qB4/qB5/qB6 专用包，也不维护 patch-specific 配置。

兼容优先级：

```text
native equivalent API
-> adapter / request-response normalization
-> reliable old-API composition
-> reliable local derivation from canonical data
-> read-only when applicable
-> truly unavailable only then hide/disable
```

禁止伪造真实 qB 无法提供的数据，也禁止为了兼容制造不可控的 N->N 网络放大。

## 2. 当前正式范围

正式 support floor：

```text
qBittorrent 4.1.0
```

当前 source/product matrix 已验证：

```text
qB 4.1.0 -> 5.2.3
65 official stable profiles
50 qB 4.x + 15 qB 5.x
```

qB4.0.x / WebAPI v1 当前状态固定为：

```text
FUTURE OPTIONAL
```

不实现、不进当前 CI、不进 full-stable matrix、不占当前 Phase。未来如果明确要求支持，只通过集中 Legacy WebAPI v1 Adapter 映射到同一 canonical WeiG semantics；禁止把 v1/v2 判断散落到 UI caller。

## 4. Identity / VERSION

```text
Product version  -> VERSION / webui/VERSION / package.json.version / package-lock root version
Code identity     -> exact Git SHA
Distribution      -> Git tag / GitHub Release
```

只有正式 `webui/**` 产品内容变化才 bump 产品 VERSION。Simulator/tests/tools/workflow/docs/installer/CI-only 改动保持 VERSION；但任何 commit 都产生新的 exact SHA。

## 5. 产品兼容主链

```text
qB upstream official stable source
        |
        v
Source Extractors / exact qb-releases.json
        |
        v
W.ReleaseProfile
        |
        +-> W.CapabilityRegistry
        +-> W.TorrentSemantics
        +-> W.SettingsSchema
        +-> W.QBClient
        |
        v
canonical WeiG semantics
        |
        v
UI / presentation
```

UI/presentation 不维护 qB patch 版本表。

业务层禁止散落：

```text
if major >= 5
if qbVersion === ...
startsWith('5.')
```

优先判断 source action / field / filter / parameter 是否存在，以及是否能可靠 derived。

## 6. 当前已完成的核心能力

Phase A 已建立 source-derived facts：

```text
stable tags
WebAPI version / source SHA
API actions + parameters
Torrent info fields / states / filters
Properties / Tracker / File / WebSeed fields
Preference getter/setter/type provenance
release-to-release evolution
```

Phase B 已完成关键产品兼容：

```text
native/normalized/derived filters
Category / Tags read 与 write 分离
Category/Tags facet fallback
Reannounce / Remove Tracker exact action gate
unsupported dangerous actions fail closed before HTTP
```

Phase C 已建立 formal all-stable product matrix：

```text
65 / 65 official stable profiles PASS
```

逐 stable 执行正式 product owners，而不是只比 JSON 或只测代表版本。

## 7. Phase D — 下一步

下一阶段直接服务当前和未来 stable：

```text
new official stable discovered
-> source extract / exact profile
-> upstream diff
-> Full Stable Product Compatibility Matrix
-> product gap => CI fail
-> compatible => green
```

重点：

- 不预写 qB6/qB7 version table；
- 新 stable/new major 自动进入验证；
- 输出 upstream added/removed capability diff；
- 新增 architecture guard，阻止业务层重新出现 scattered qB version-if；
- 未知危险写操作继续 fail closed。

qB4.0.x 不进入 Phase D。

## 8. Validation 分层

普通 dev push：

```text
smoke / npm test / syntax
```

产品 candidate：

```text
exact all-stable catalog
-> all-stable source audit
-> Full Stable PRODUCT Compatibility Matrix
-> Linux/Windows browser
-> exact-SHA candidate package
```

重型 `Full qB stable WebAPI evolution audit` 只在 qB source/evolution 相关输入变化或手动触发时运行；`docs/**` 不触发它。具体规则见 `006.发布与晋级流程.md`。

Virtual qB / browser fixtures 是强辅助证据，但不单独等价于真实 qB binary PASS。

## 9. Git discipline

- 正式开发分支 `dev`；未经用户明确授权不动 `main`；
- 写前/ref update 前 fresh-read exact `dev`；
- ref 更新只允许 `force:false` fast-forward；
- product truth 与 stale test 冲突时先确认 upstream/real runtime truth；
- 不为了测试变绿回退正确产品行为。
