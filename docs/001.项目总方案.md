## 1. 产品目标

WeiG qB WebUI 是 qBittorrent Alternate WebUI，目标同时满足：

- qBittorrent 4.1.9 强兼容；
- 通过 Capability 延伸到当前 5.x；
- 高级、克制、立体的 Nebula Spatial Console；
- English canonical + 简体中文完整维护；
- 大型 Torrent 库分页 + VirtualList；
- Desktop DataGrid 与 Mobile Torrent Card；
- qB 核心 Torrent/Transfer/Settings/Search/RSS/Logs 能力；
- 用户交互状态在轮询中保持稳定；
- 安装、备份、回滚安全；
- 不依赖运行时大型前端框架或 CDN。

功能完整度可以参考 VueTorrent、官方 WebUI 等，但不能牺牲 4.1.9 下限，也不能复制其它产品视觉身份。

## 2. 核心硬规则

### COMPAT-001 — API 差异只能进入兼容层

```text
qB API
  ↓
QBClient + Capability
  ↓
稳定语义
  ↓
Feature / UI
```

Feature/UI 禁止散落：

```js
if (qbVersion >= 5) ...
```

应使用：

```js
if (capabilities.privateFlag) ...
if (capabilities.cookies) ...
```

### NAV-001 — No Dead-End Navigation

非首页必须有 Back；Fatal/Error 保留 Back / Home / Reload。

### PERF-001 — Data count != DOM count

```text
全库数据量
≠ 当前页 API 数据量
≠ 当前挂载 DOM 数量
```

20/50/100/200 只控制服务端分页；VirtualList 只挂载 viewport + overscan。

### SCROLL-001 — 用户滚动位置属于状态

自动轮询、Transfer 更新、Torrent 字段变化不得把用户从中部/底部弹回顶部。

允许主动重置：筛选、Facet、分页、页大小、搜索语境发生变化，或用户明确要求回顶部。

### PRIVACY-001 — Tracker credential 不进入 UI

显示、筛选、缓存 key 必须剥离 query / fragment。真正修改 Tracker API 时才可使用原值。

### I18N-001 — English canonical

English 是源语言；简体中文是正式维护翻译。缺失 locale 回退 English，不显示 raw translation key。qB 专有术语优先沿用官方翻译。

### STATE-001 — 一个业务状态源

Spatial/UX/v0.3 Runtime 可以重排、增强交互和订阅事件，但不得建立第二套 Torrent 业务状态。

## 3. v0.3.0 集成重点

### 3.1 Stable Virtual UI

旧实现每轮 `renderList()` 都重建 VirtualList，并可能把 `scrollTop` 重置为 0。

v0.3：

- VirtualList container 记录稳定滚动位置；
- 新实例替换旧实例时移除旧 scroll handler，防止事件监听累积；
- `setItems()` 默认保留滚动位置并夹到合法最大值；
- deliberate context change 主动 reset；
- 自动 poll/manual refresh 保留 viewport。

最终目标仍是进一步让主 Torrent VirtualList 长期复用，但在现有 Controller 拆分完成前，任何实现都必须满足 SCROLL-001。

### 3.2 Compact Empty State

所有 `total === 0` 的 Torrent 结果共用一个紧凑状态：

```text
Private/PT
Error
Downloading
Seeding
Completed
Paused
Active
Stalled
Tracker / Save Path / Category / Tag
Torrent search
```

0 条时：

- 隐藏空 DataGrid body；
- 隐藏无意义 Pager；
- Empty Card 约 180–240px；
- 保留 Filter Shelf 和全局 Transfer/Network 状态；
- Mobile 同样不使用满屏空白。

### 3.3 Transfer Control Dock

Desktop 底部状态栏升级为居中可交互 Dock：

```text
↓ 当前下载
↑ 当前上传
ALT
连接状态
Torrent 数量
刷新时间
Transfer
```

点击 ↓/↑ 修改**全局**下载/上传限速；ALT 切换备用限速；Connection 打开 qB/WebAPI/Compatibility；Transfer 打开 Session + Graph。

跨版本使用长期稳定 Transfer API：

```text
GET  transfer/downloadLimit
POST transfer/setDownloadLimit
GET  transfer/uploadLimit
POST transfer/setUploadLimit
GET  transfer/speedLimitsMode
POST transfer/toggleSpeedLimitsMode
```

这些能力在 4.1.9 compatibility floor 即可使用。

### 3.4 Session Stats + Transfer Graph

Transfer Graph 不新增第二套高频轮询：订阅现有 `getTransferInfo()` 数据流。

记录：

```text
timestamp
dl_speed
up_speed
```

最大 900 samples，内存 ring buffer；窗口 1 / 5 / 15 min。

Session surface 展示：

- 本次会话下载/上传；
- 当前 Global DL/UL limit；
- DHT / Peer Connections；
- `sync/maindata` 可用时的 free space；
- Download / Upload speed graph。

Canvas 原生绘制，不引入 Chart runtime。

### 3.5 Multi-select

保留：

```text
Ctrl/Cmd+A
Escape
Delete
```

增加当前渲染窗口中的 Ctrl/Cmd-click / Shift-click。不能通过挂载隐藏 Torrent 行来实现跨 Virtual Window 选择。

## 4. VueTorrent 功能差距策略

VueTorrent 当前项目基线面向 qB 4.4+，WeiG 不得直接复制其 API 假设。

本轮已补：

```text
Session statistics
Transfer graph
Global speed limits
Alternative speed mode
更丰富 rendered-row multi-select
```

已建立 QBClient foundation、但本轮不冒充完整产品页：

```text
Torrent Creator
Cookie Manager
```

Capability 原则：

- Cookie API 只在相应 WebAPI capability 出现时可用；
- Torrent Creator 只在现代 qB capability 下可用；
- 4.1.9 不出现已知不可用按钮；
- 后续完整页面必须再增加 UI、i18n、validation 和真实 5.x 回归。

后续候选优先级：

```text
RSS Rule Editor
Search Plugin Manager
Torrent Creator UI
Cookie Manager UI
Configurable Dashboard
PWA / Magnet Handler
```

## 5. 版本兼容矩阵

### Tier A — Legacy floor

```text
qBittorrent 4.1.9.x
Lab target: 4.1.9.1 / WebAPI 2.2.1
```

必须支持：Torrent 基础操作、Files、Tracker、Category、全局限速、ALT、Transfer stats、Settings 中实际返回项、分页/VirtualList。

不伪造：Tags、exact Private flag、现代 Creator/Cookie API。

### Tier B — Mature 4.x

```text
4.2.x → 4.6.x
```

随着 WebAPI capability 开启 Tags、Stalled Filter、rename folder/file 等能力，但 exact Private flag 仍不能因为“看起来像 5.x”而假设存在。

### Tier C — Modern 5.x

```text
5.0.x → current 5.x
Release-blocking target: 5.2.0
```

Start/Stop、Stopped filter、Private flag、现代 Tags/Preferences、Creator/Cookie 等能力按实际 WebAPI gate 开启。

## 6. 关键兼容桥

```text
4.x              5.x
resume            start
pause             stop
paused filter     stopped filter
```

`QBClient` 负责 endpoint selection/fallback；UI 只理解“开始/停止/暂停”语义。

Version 比较必须按点分整数，不准 `parseFloat('2.11')`。

## 8. 性能与轮询

主页面默认刷新约 2 秒，后台 tab 放慢。大型库采用：

```text
server pagination
+
bounded whole-library catalog batches
+
Virtual Window
```

Transfer Graph 复用同一 Transfer stream，不创建独立持续 polling storm。

禁止：

- 每行 backdrop-filter；
- 每个功能自己起 1 秒 timer；
- 每轮刷新清空用户选择/scroll；
- 数据量与隐藏 DOM 线性绑定。

## 9. Mobile

- Torrent Card，不压缩 Desktop DataGrid；
- Bottom Navigation；
- Filter Popover/Sheet；
- Action Sheet；
- Settings 一列；
- Desktop Transfer Dock 可在 Mobile 隐藏，由触控友好入口替代；
- 关键触控目标约 ≥44px。

## 10. 安装器

Linux / Windows installer 要求：

- 安装前备份；
- 原子替换目的 WebUI；
- 校验 `public/login.html` + `private/index.html`；
- 多 qB Docker 实例时拒绝猜测；
- `--config-root` / `--container` 可明确目标；
- 普通 install/update 不修改 qB 用户名/密码；
- rollback 恢复上一份 WebUI/安全配置。
