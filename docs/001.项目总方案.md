## 1. 长期目标与兼容原则

```text
qBittorrent 4.1.0 official stable
-> all admitted official stable releases
-> current latest official stable
-> future official stable / future major
```

未知能力不得靠版本号猜；危险 write 必须在 HTTP 前 fail closed。一个 semantic purpose 只有一个 Current Owner；禁止 old/new 双 active、MutationObserver repair、monkey patch、post-render repair、第二 polling/state/layout/language owner。

qB-owned surface 的正式 ownership 统一为：

```text
存在性 / 顺序 / UI 语义    exact qB upstream source
当前业务值                 qB WebAPI
文案身份                   exact {source, context}
目标语言                   exact release official qB translation
WeiG                       presentation / interaction / approved extensions
```

WeiG-owned surface 使用 WeiG 自己的 schema/i18n/UI，不能伪装成 qB-native；qB-owned surface 也不能再由 WeiG 手写一套版本真相。

### 1.1 Product-first 执行原则

`webui/** is the product` 不只是目录定义，也是开发优先级。默认执行顺序必须是：

```text
明确当前正式产品 blocker
-> 优先修改/切换 webui/** canonical owner
-> 只在解除该 blocker 所必需时补 tools/tests/source parser
-> focused validation
-> 阶段完整后再做阶段级 full evidence
```

当 source/admission/census/provenance foundation 已足以支撑当前产品切换时，应停止主动扩充 tests/tools，转入正式 `webui/**` cutover。任何新增 `tools/**`、`tests/**`、simulator 或 CI 工作，都应该能回答至少一个问题：它正在解除哪个具体 product blocker、证明哪个具体 product contract，或防止哪个已知产品回归。回答不出来时，优先不做。

当前阶段可把约 70–80% 精力放在正式产品实现、20–30% 放在必要 tests/tools 作为工作启发；这不是永久配额，也不是 commit 计数规则，真正标准仍是“是否直接推动 formal product owner 收口”。

```text

  -> generic qB-native facet state/projection
  -> append WeiG Path extension last

  exact {source, context} + exact-release official translation
  -> W.I18n
  -> upstream English only when official target translation is unavailable

D RSS
  exact native RSS feeds/Downloader/rule source facts + source-actions
  -> generic source-driven rule/surface projection

  retain and finish existing torrentDetailUi/detail-compat generic chain
  -> fill only real inventory/copy/action gaps
```

每个阶段内部优先 product implementation + focused/change-point validation；只有出现具体 source/provenance blocker时才回补 tooling。阶段完整收口后最多一次 admitted-stable offline/Virtual full matrix。A–F全部集成完成并冻结 final dev SHA后，才进入 `docs/011` 定义的昂贵 real-qB Full Frozen Matrix。阶段离线 65 不等于真实 qB 65/65。
