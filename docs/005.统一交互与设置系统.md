# 005. 统一交互与设置系统

Status: **current implementation authority**  
Current product version is defined by `VERSION` / `webui/VERSION`.

> 本文件只描述当前实现。历史 WeiG 版本由 Git history / tags / Releases 保存，不在 runtime/tests/deploy 文件中保留兼容副本。

## 1. Release boundary

### EXACT-HEAD-001
所有 CI/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 改动都会生成新 candidate；真实 qB4/qB5 LIVE 全过并得到 maintainer 明确授权前，`main` 不晋级、不 tag、不 Release。

## 2. Current-only / owner rules

### OWNER-RETIRE-001
New canonical owner 上线时 old caller/shim/state/event/CSS/test expectation 同批退出。

### CONTROL-SKIN-001
Settings Select 只由 `W.Components.selectControl()` 创建；shared Select/Dialog skin 只属于 `css/ui.css`。

### DIALOG-SCROLL-001
Outer dialog shell 不承担通用 scrolling；真实溢出区域内部滚动。

### NATIVE-THEME-001
Native Select/options 跟随 resolved Light/Dark theme。

### SELECT-SCROLL-001
Searchable floating Select 的 `.ui-select__options` 自己拥有 scroll position；内部 wheel/touch scroll 不触发菜单 anchor re-placement。页面/窗口/visualViewport 滚动才允许重新定位。

### HEADER-SEARCH-001
Torrent Search 只有一个 `#search-input` / `app.search`。Desktop 只改变 presentation：约 320px -> 240px -> 40px icon；icon focus 临时展开同一 input。Mobile 继续复用现有 mobile Search trigger。

### STATUS-SIGNAL-001
Connection 只有一个 explicit dot；Connected 只动画该 dot，不允许第二个可辨识圆环/光点。

## 5. Display time zone

`timezoneRow()` remains a searchable canonical Select backed by `W.Time.zones()` and `W.Time.setZone()`.

```text
canonical Select -> W.Time.setZone -> localStorage -> weigg:timezonechange
```

No timezone-specific dropdown, native fallback, wheel handler, MutationObserver or CSS patch. Long option lists scroll only inside `.ui-select__options`; the search field stays fixed. Selection must update both `W.Time.getZone()` and the visible trigger on Desktop and Mobile, in Dark and Light themes.

## 6. Desktop Torrent Header / Statusbar

Topbar:

```text
wide     WeiG qB | Nav | [Search ~320] | + Add | Theme | utilities
medium   WeiG qB | Nav | [Search ~240] | + Add | Theme | utilities
narrow   W | Nav | [Search icon 40] | + Add | Theme | utilities
```

Focused icon mode expands the same search control temporarily; blur collapses presentation without losing input/filter state. Topbar stays one row and does not overflow.

Statusbar remains `"torrent storage transfer connection message"`. Connection state mapping:

```text
connected     success   Connected / 已连接       one breathing dot
firewalled    warning   Network limited / 网络受限  one static dot
disconnected  danger    Disconnected / 未连接    one static dot
error         danger    Unavailable / 异常       one static dot
```

Reduced Motion makes the same Connected dot static.

## 7. Mobile

Mobile reuses the same search input, time-zone Select, semantic lifecycle and Settings owner. Mobile Summary remains; Desktop Statusbar remains hidden; no second business state/polling path.

## 8. Existing transfer/data contracts

Transfer history includes **12 h** with bounded raw/minute storage. Canonical rate = B/s; ALT preference is normalized at QBClient boundary. `ALT Apply` writes through canonical methods.

Progressive paging uses pageSize+1, spinner before total, exact total later, `!` on aggregate failure, never `?`.
