# 005. 统一交互与设置系统

Status: **current implementation authority**  
Current product version is defined by `VERSION` / `webui/VERSION` / `package.json`.

> 本文件只描述当前实现。历史 WeiG 版本由 Git history / tags / Releases 保存。

## 1. Release boundary

### EXACT-HEAD-001
所有 CI/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 改动生成新 candidate；真实 qB4/qB5 LIVE 全过并得到 maintainer 明确授权前，`main` 不晋级、不 tag、不 Release。

## 2. Current-only / owner rules

### OWNER-RETIRE-001
New canonical owner 上线时 old caller/shim/state/event/CSS/test expectation 同批退出。

### CONTROL-SKIN-001
Settings Select 只由 `W.Components.selectControl()` 创建；shared Select/Dialog primitive skin 属于 `css/ui.css`。

### DIALOG-SCROLL-001
Outer dialog shell 不承担通用 scrolling；真实溢出区域内部滚动。

### NATIVE-THEME-001
Native Select/options 跟随 resolved Light/Dark theme。

### SELECT-SCROLL-001
Searchable floating Select 的 `.ui-select__options` 自己拥有 scroll position；内部 wheel/touch scroll 不触发 anchor re-placement。

### HEADER-SEARCH-001
Torrent Search 只有一个 `#search-input` / `app.search`。Desktop 只改变 presentation：约 320px -> 240px -> 40px icon；Mobile 复用同一 input/state。

### HEADER-END-ANCHOR-001
Desktop Add/Theme/GitHub/WeiG Share/Logout 是一个右端 action rail；Search 先收缩，actions 不漂移到中间。

### RENDERED-SIGNAL-001
Connection 验收看最终渲染，不只数 DOM。禁止 pseudo dot / ring / halo 制造第二个视觉 marker。

### STATUS-EXPLAIN-001
Connection Tooltip/Dialog 只读取现有状态，不新增 API/polling/port scan。

### CAPABILITY-RANGE-001
User-facing capability 使用 semantic ranges 和 declarative exceptions，不靠精确 patch 枚举。

### FEEDBACK-OWNER
Transient feedback 只有 `W.Feedback / scripts/feedback.js` 一个 runtime owner，业务入口只有 `W.toast(message, kind, options)`。

### FEEDBACK-TRUTH
Processing 必须来自真实业务 Promise，并用 `duration:0` 持久显示；只有真实结果能把同一 card 更新为 success/warning/error。Timer 只决定完成后的展示寿命。

### FEEDBACK-NOISE
Routine background success silent；background polling 不生成“刷新成功”。用户触发动作和 actionable failure 才进入 Feedback Stack。

### FEEDBACK-RETIRE
旧 `core.js` Toast owner、旧 `.toast-region/.toast` CSS、旧 `danger` Toast caller 与对应测试假设必须和新 owner 同批退出；不保留 compatibility alias、wrapper 或第二通知 API。

## 6. Display time zone

`timezoneRow()` remains a searchable canonical Select backed by `W.Time.zones()` and `W.Time.setZone()`.

```text
canonical Select -> W.Time.setZone -> localStorage -> weigg:timezonechange
```

No timezone-specific dropdown, wheel handler, MutationObserver or CSS patch。Long list scroll 保留当前 scrollTop，selection 更新 `W.Time.getZone()` 和 visible trigger。

## 8. Floating Feedback Stack

Public API：

```js
const notice = W.toast(message, 'info', {title, duration: 0});
notice.update(nextMessage, 'success', {title: nextTitle});
notice.dismiss();
```

Canonical kinds only：`info / success / warning / error`。不保留 `danger -> error` compatibility alias。

Business migration：

```text
Add Torrent
missing source -> warning
submit -> info duration:0
API accepted -> same card success
API failed -> same card error

Settings
no draft -> info
setPreferences -> info duration:0
write + getPreferences readback -> success
write succeeded but readback failed -> warning
write failed -> error

RSS
addFeed -> info duration:0
add + refreshed list -> success
add succeeded but reload failed -> warning
add failed -> error

Selection
qB command request accepted -> info "Command sent / 命令已发送"
request failed -> error
```

`Command sent` 不等于长任务最终完成，不增加 polling 去等待最终状态。

Stack 最多 4 条。有限时长自动退出严格 FIFO；`duration:0` processing 不阻塞后续 finite notifications。Timeout、manual close、capacity eviction 全部通过同一个 right-exit lifecycle，离场后剩余 DOM 原地 reflow。

Desktop 右下角；Mobile/Android top safe-area。Light/Dark 复用同一 semantic tokens。Reduced Motion 关闭位移/缩放/进度动画，但 lifecycle/timer/dismiss 不变。

## 9. About / product version ownership

About 不再硬编码 `0.3.x`。Installer/deploy 由 canonical `VERSION` 生成 `weigg-install.json.version`；Settings About 读取该 metadata。这样 product version 不再维护第四份手写字符串。

`VERSION`、`webui/VERSION`、`package.json.version` 必须一致。

## 10. Mobile

Mobile reuses same Search, Capability Registry, Settings/Select, Feedback queue and semantic lifecycle. No second business state or polling path。

## 11. Existing transfer/data contracts

Transfer history includes **12 h** with bounded storage. Canonical rate = B/s; ALT preference normalized at QBClient boundary. `ALT Apply` writes through canonical methods。

Progressive paging uses pageSize+1 and bounded aggregate state。
