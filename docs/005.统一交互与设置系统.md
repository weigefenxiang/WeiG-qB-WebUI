# 005. 统一交互与设置系统

Status: **current implementation authority**  
Current product version is defined by `VERSION` / `webui/VERSION`.

> 本文件只描述当前实现。历史 WeiG 版本由 Git history / tags / Releases 保存。

## 1. Release boundary

### EXACT-HEAD-001
所有 CI/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 改动生成新 candidate；真实 qB4/qB5 LIVE 全过并得到 maintainer 明确授权前，`main` 不晋级、不 tag、不 Release。

## 2. Current-only / owner rules

### OWNER-RETIRE-001
New canonical owner 上线时 old caller/shim/state/event/CSS/test expectation 同批退出。

### CONTROL-SKIN-001
Settings Select 只由 `W.Components.selectControl()` 创建；shared Select/Dialog primitive skin 属于 `css/ui.css`。

### DIALOG-SCROLL-001
Outer dialog shell 不承担通用 scrolling；真实溢出区域内部滚动。

### NATIVE-THEME-001
Native Select/options 跟随 resolved Light/Dark theme。

### SELECT-SCROLL-001
Searchable floating Select 的 `.ui-select__options` 自己拥有 scroll position；内部 wheel/touch scroll 不触发 anchor re-placement。

### HEADER-SEARCH-001
Torrent Search 只有一个 `#search-input` / `app.search`。Desktop 只改变 presentation：约 320px -> 240px -> 40px icon；Mobile 复用同一 input/state。

### HEADER-END-ANCHOR-001
Desktop Add/Theme/GitHub/WeiG Share/Logout 是一个右端 action rail；Search 先收缩，actions 不漂移到中间。

### RENDERED-SIGNAL-001
Connection 验收看最终渲染，不只数 DOM。禁止 pseudo dot / ring / halo 制造第二个视觉 marker。

### STATUS-EXPLAIN-001
Connection Tooltip/Dialog 只读取现有状态，不新增 API/polling/port scan。

### CAPABILITY-RANGE-001
User-facing capability 使用 semantic ranges 和 declarative exceptions，不靠精确 patch 枚举。

## 3. qB capability facts

```text
qBittorrent compatibility floor: 4.1.9.1
Private/PT exact metadata: qBittorrent 5.0.0+
Tags capability: WebAPI 2.3.0+
Known qB-facing Tags milestone: 4.2+
```

因此 **此功能需要 qBittorrent 5.0.0+** 和 WebAPI 2.3.0+ 都是当前 capability facts。

qB4 Private click -> `5+` shared Capability Dialog -> filter unchanged -> 0 tracker requests。Unsupported Tags -> `4.2+` badge -> same Dialog -> no state/request mutation。

## 4. Capability template

```text
QBClient.detect
→ qbVersion + webApiVersion
→ W.CapabilityRegistry
→ data/capabilities.json
→ support state
→ badge / disabled / tooltip / shared dialog
```

范围支持：`eq / gt / gte / lt / lte / all / any / not`。任意 patch 版本按范围计算；synthetic `4.9.2 / 4.9.3` 用于边界测试，不是 upstream release claim。

Unsupported 默认 visible + `aria-disabled`，不再静默隐藏。WebAPI requirement 的主列表 badge 优先显示已知 qB-facing version；Dialog 同时显示 qB 与 WebAPI technical detail。

## 6. Display time zone

`timezoneRow()` remains a searchable canonical Select backed by `W.Time.zones()` and `W.Time.setZone()`.

```text
canonical Select -> W.Time.setZone -> localStorage -> weigg:timezonechange
```

No timezone-specific dropdown, wheel handler, MutationObserver or CSS patch。Long list scroll 保留当前 scrollTop，selection 更新 `W.Time.getZone()` 和 visible trigger。

## 7. Desktop Header / Statusbar

Topbar：

```text
wide     WeiG qB | Nav | Search ~320 | flexible gap | Add Theme GitHub Blog Logout
medium   WeiG qB | Nav | Search ~240 | flexible gap | Add Theme GitHub Blog Logout
narrow   W | Nav | Search icon 40    | flexible gap | Add Theme GitHub Blog Logout
```

Actions 始终右对齐。Focused icon mode 展开同一 Search；blur 后收回且 search/filter state 不丢。

Statusbar Connection：

```text
connected     one green gentle breathing dot
firewalled    one amber slower breathing dot
disconnected  one red static dot
error         one red static dot
```

Hover -> 简短原因；Click -> canonical Connection troubleshooting Dialog。Dialog 显示现有 qBittorrent/WebAPI/DHT/Peers 信息和排查顺序，不新增请求。Reduced Motion -> same marker static。

## 8. Mobile

Mobile reuses same Search, Capability Registry, Settings/Select and semantic lifecycle. No second business state or polling path。

## 9. Existing transfer/data contracts

Transfer history includes **12 h** with bounded storage. Canonical rate = B/s; ALT preference normalized at QBClient boundary. `ALT Apply` writes through canonical methods。

Progressive paging uses pageSize+1 and bounded aggregate state。
