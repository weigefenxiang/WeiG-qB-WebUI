## 2. A2 full-fidelity Options graph / interaction

A1证明“Preference不应长期flatten成单行”；A2进一步证明“control/helper被表示”也不足以等价于真实Options。正式graph必须同时覆盖 **可见source内容、交互dependency、copy identity与presentation grouping**。

### 2.1 Source node vocabulary

至少表达：

- fieldset / nested fieldset；
- row / cluster / source order；
- Preference与auxiliary control；
- source helper/action，包含已admit的 `<button>` 与 `<input type=button>`；
- local label / Select option / adornment；
- `note / help / list / hint` 等非Preference source-copy node；
- textarea/multiline control的source identity。

Run external program的Supported parameters是代表性note/list，不允许因为没有Preference key而silent drop。

### 2.2 Behavior predicates与gate projection

允许的小型可审计predicate：

```text
truthy / falsy
equals / notEquals
allOf / anyOf
```

允许的source-proven UI gate/projection至少包括boolean gate、numeric sentinel gate、empty-string/presence gate与nested fieldset gate。

Proxy代表性链为Type、SOCKS4限制、BitTorrent proxy、peer connection、Authentication的组合条件；这些必须由source编译成predicate graph，renderer不得维护Proxy key表。

Downloads的 `export_dir/export_dir_fin`代表presence projection：source保存逻辑证明checkbox off -> empty string；checkbox on -> editable string。该语义属于通用projection family，不属于Downloads专用代码。

### 2.3 Predicate completeness is acceptance

旧structural census允许behavior assignment已被表示但predicate仍unknown，这会导致runtime `unknown -> disabled`并产生假绿。A2要求：

```text
source behavior nodes == represented/reviewed behavior nodes
runtime-relevant unknown predicates == 0
unaccounted source content/actions == 0
duplicate structural ownership == 0
```

无法证明的行为可以fail closed，但不能同时把该release/阶段报告为full-fidelity complete。

### 2.4 Typed receiver proof

Getter read type必须来自exact source/declaration。除已有session/pref/local member外，类似 `app()->isFileLoggerEnabled()` 应解析receiver并从exact upstream interface/header declaration证明 `bool`；setter `.toBool()` 再与其形成EXACT agreement。禁止 `if(key==='file_log_enabled')` 型类型白名单。

### 2.5 qB-owned copy closure

所有runtime显示的graph `{source,context}` refs都必须进入现有 `qb-settings-native` native/bridge dependency closure，包括tab、fieldset、control、option、helper、adornment、local-label、note/list。官方zh_CN存在翻译时应解析官方值，例如 `Behavior -> 行为`；只有exact release官方目标翻译不存在时才fallback upstream English。

A2只扩大现有Settings copy closure，不提前建立C阶段第二copy owner。

### 2.6 Generic compact layout

Desktop presentation允许generic row-packer利用两列/同一视觉行：

- short controls/checkbox+value/helper可成对；
- Listening Port+Random可与UPnP sibling合理利用左右空间；
- Connection Limits可按短row成对；
- I2P Host+Port+Mixed mode可保持source cluster同时紧凑显示。

禁止按Preference key决定左右位置。Textarea、note/list、structured/table、长copy保持full-width；Mobile使用同一graph自然stack。

### 2.7 Expandable multiline editor

Source textarea统一使用canonical multiline presentation。Compact editor可以点击/通过展开按钮打开shared Dialog的大型编辑区；Dialog只编辑同一个Settings draft，确认后回写draft，取消不改变draft，最终仍由Settings Save统一setPreferences + reread。不得新增textarea专用持久store或单独立即保存路径。

### 2.8 Product identity remains single-owner

About/Product Identity沿A1已经完成的 `tools/product-identity.mjs -> product-identity.json -> Settings About` 路径；A2不得恢复 `weigg-install.json` version authority。

## 3. Native Options identity

## 4. Preferences independent census

字段级 `tabs / preferences / bindings` census继续有效，但A2将结构级accounting升级为full-fidelity census：

```text
raw Preferences source
├─ preference/API inventory
├─ structural controls/fieldsets/rows
├─ source actions
├─ adornments/options/local labels
├─ note/help/list/hint copy nodes
└─ behavior assignments/predicates

=> semantic graph + explicit reviewed exclusions
=> unaccounted = 0
=> overlap/escaped/duplicate = 0
=> runtime-relevant unknown predicate = 0
```

A1的 `sourceControls == representedControls` 等断言保留，但不再足以单独声明complete。Source action parser必须account `input type=button` 等admitted action形式；纯copy节点不能因为无control id而逃出census。

Mapping ratio仍不能代替字段或full-fidelity census。

## 8. Shared interaction
