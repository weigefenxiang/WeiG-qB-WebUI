# 005. 统一交互与设置系统

Status: **current implementation authority**  
Current product version is defined by `VERSION` / `webui/VERSION` / `package.json.version` / `package-lock.json` root version.

> 本文件只描述当前实现。历史 WeiG 版本由 Git history / tags / Releases 保存。

## 1. Release boundary

### EXACT-HEAD
所有 CI/Pages/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 改动都产生新的 exact validation identity；旧 SHA 的证据不继承。只有准备晋级 `main` / Release 时，该 exact final dev SHA 才进入 candidate 语义。真实 qB4/qB5 LIVE 全过并得到 maintainer 明确授权前，`main` 不晋级、不 tag、不 Release。

## 2. Current-only / owner rules

### OWNER-RETIRE
New canonical owner 上线时 old caller/shim/state/event/CSS/test expectation 同批退出。

### CONTROL-SKIN
Settings Select 只由 `W.Components.selectControl()` 创建；shared Select/Dialog primitive skin 属于 `css/ui.css`。

### DIALOG-SCROLL
Outer dialog shell 不承担通用 scrolling；真实溢出区域内部滚动。

### NATIVE-THEME
Native Select/options 跟随 resolved Light/Dark theme。

### SELECT-SCROLL
Searchable floating Select 的 `.ui-select__options` 自己拥有 scroll position；内部 wheel/touch scroll 不触发 anchor re-placement。Mobile 长列表允许占用更大的 safe visual viewport，并在必要时 above/below flip；所有 option 必须可通过内部滚动触达，不得被 Drawer 裁切。

### HEADER-SEARCH
Header Search 只有一个 `#search-input` DOM owner。Desktop 只改变 presentation：约 320px -> 240px -> 40px icon；Mobile 复用同一 input。Semantic state 按 route 分派：Torrent -> `app.search / W.LibraryController`；RSS -> `W.RSS`；Logs -> `W.Logs`。RSS/Logs 不再渲染 feature-local Search icon/input/state。

### HEADER-END-ANCHOR
Desktop Add/Theme/GitHub/WeiG Share/Logout 是一个右端 action rail；Search 先收缩，actions 不漂移到中间。

### RENDERED-SIGNAL
Connection 验收看最终渲染，不只数 DOM。禁止 pseudo dot / ring / halo 制造第二个视觉 marker。

### STATUS-EXPLAIN
Connection Tooltip/Dialog 只读取现有状态，不新增 API/polling/port scan。

### CAPABILITY-RANGE
User-facing capability 使用 semantic ranges 和 declarative exceptions，不靠精确 patch 枚举。

### SEMANTIC-NAMING
Current architecture identifier 使用稳定职责名，不维护 `-001/-002/...` revision suffix。Git history/tags 是 revision archive；qB/WebAPI/Playwright 版本号属于当前 upstream/dependency facts，可按职责保留。

### FEEDBACK-OWNER
Transient feedback 只有 `W.Feedback / scripts/feedback.js` 一个 runtime owner，业务入口只有 `W.toast(message, kind, options)`。

### FEEDBACK-TRUTH
Processing 必须来自真实业务 Promise，并用 `duration:0` 持久显示；只有真实结果能把同一 card 更新为 success/warning/error。Timer 只决定完成后的展示寿命。

### FEEDBACK-ACTIVITY
`duration:0` 使用 indeterminate activity rail，只表示请求仍在进行，不表达百分比；真实结果落定后同一卡片把 rail 切为 finite lifetime。

### FEEDBACK-NOISE
Routine background success silent；background polling 不生成“刷新成功”。用户触发动作和 actionable failure 才进入 Feedback Stack。

### FEEDBACK-RETIRE
旧 `core.js` Toast owner、旧 `.toast-region/.toast` CSS、旧 `danger` Toast caller 与对应测试假设必须和新 owner 同批退出；不保留 compatibility alias、wrapper 或第二通知 API。

### TORRENT-PROGRESS-OWNER
Torrent progress 的语义投影与 DOM 由 `W.Components.progressVisual/progressTrack` 统一输出，`css/progress.css` 负责状态视觉；Mobile 复用同一个 rail，不维护第二份映射。

### TORRENT-PROGRESS-TRUTH
进度宽度只来自真实 `torrent.progress`；流光/高光只在已填充区域内运动，禁止用 timer 或 CSS width animation 假造下载完成。

### TORRENT-PROGRESS-STATE
Torrent 当前 state 本地投影为 download/seed/complete/paused/checking/queued/stalled/error/idle，不增加 API、polling 或 DOM 推断。

### TORRENT-PROGRESS-MOTION
只有真实 active download/seed/checking 播放轻量 flow/sheen；completed/paused/queued/stalled/error 静止。System/WeiG Reduced Motion 都关闭装饰动画而不改变真实 width/state。

## 8. Floating Feedback Stack

Public API：

```js
const notice = W.toast(message, 'info', {title, duration: 0});
notice.update(nextMessage, 'success', {title: nextTitle});
notice.dismiss();
```

Canonical kinds only：`info / success / warning / error`。不保留 `danger -> error` compatibility alias。

Business migration：

```text
Add Torrent
missing source -> warning
submit -> info duration:0 + activity rail
API accepted -> same card success + lifetime rail
API failed -> same card error + lifetime rail

Settings
no draft -> info
setPreferences -> info duration:0 + activity rail
write + getPreferences readback -> success + lifetime rail
write succeeded but readback failed -> warning + lifetime rail
write failed -> error + lifetime rail

RSS
addFeed -> info duration:0 + activity rail
add + refreshed list -> success + lifetime rail
add succeeded but reload failed -> warning + lifetime rail
add failed -> error + lifetime rail

Selection
qB command request accepted -> info "Command sent / 命令已发送"
request failed -> error
```

Activity rail 不等于业务百分比；`Command sent` 也不等于长任务最终完成，不增加 polling 去等待最终状态。

Stack 最多 4 条。有限时长自动退出严格 FIFO；`duration:0` processing 不阻塞后续 finite notifications。Timeout、manual close、capacity eviction 全部通过同一个 right-exit lifecycle，离场后剩余 DOM 原地 reflow。

Desktop 右下角；Mobile/Android top safe-area。Light/Dark 复用同一 semantic tokens。Reduced Motion 关闭位移/缩放/rail 动画，但 lifecycle/timer/dismiss 不变。

## 10. About / product version ownership

About 不再硬编码 `0.3.x`。Installer/deploy 由 canonical `VERSION` 生成 `weigg-install.json.version`；Settings About 读取该 metadata。这样 product version 不再维护额外手写字符串。

产品 VERSION 只在 `webui/**` 产品内容发生正式变化时递增 patch。仅修改 tests、workflow、docs、DESIGN、installer 或 gate 时保持当前产品 VERSION；但新 commit 仍产生新的 exact SHA，旧 SHA 验证证据失效。

发生 `webui/**` 产品变化时，`VERSION`、`webui/VERSION`、`package.json.version`、`package-lock.json` root version 必须在同一正式状态中同步一致。

## 11. Mobile / route tools

Mobile reuses same Header Search DOM, Capability Registry, Settings/Select, Theme, Feedback queue, Torrent progress projection and semantic lifecycle. No second business state or polling path。

Route tools 继续复用同一 Header Search surface：

```text
Torrent -> app.search / W.LibraryController
RSS     -> W.RSS
Logs    -> W.Logs
```

RSS Header Search 是唯一 RSS query entry；RSS 本地 Search icon/input 已退休。RSS Header 负责 Add Feed / Refresh 等 route actions，RSS 本身仍由 `W.RSS` 处理 semantic state。

Logs Header Search 是唯一 Logs query entry；Logs 本地 Search icon/input 已退休。Mobile Logs toolbar 保持单行：`普通 / 信息 / 警告 / 严重` 作为一个连续等级列表，随后是 `最新`、canonical size Select（例如 `自动 ▼`）与 Refresh。Refresh 在窄屏先退化为 icon-only，仍不够时整条 toolbar 使用 nowrap + horizontal scrolling；不允许重新变成两行。Canonical Select 只有一个可见 trigger border，不允许 feature wrapper 再画第二个框。

## 12. Existing transfer/data contracts

Transfer history includes **12 h** with bounded storage。Canonical rate = B/s; ALT preference normalized at QBClient boundary。`ALT Apply` writes through canonical methods。

Transfer windows remain `1m/5m/15m/30m/1h/3h/6h/12h`，默认 selected window = **5m**。Mobile Drawer mini chart 与完整 realtime upload/download dialog 共享同一个 selected window state；切换一次，两处同步，不建立第二状态或 polling。

Download speed text / download curve / download legend 使用同一 canonical download accent；Upload speed text / upload curve / upload legend 使用同一 canonical upload accent。Desktop、Mobile mini chart 与完整 dialog 不得各自选择不同颜色。

Progressive paging uses pageSize+1 and bounded aggregate state。

## 15. Theme mode / Settings ownership

### THEME-OWNER
`W.Theme / scripts/theme.js` owns mode validation, resolved visual theme, System media listener, Smart Auto boundary timer, theme metadata and lifecycle event。`W.Config` is persistence only; Header and Settings are presentation callers。

### THEME-MODE
Canonical saved values: `system / time / light / dark`。Header 与 Settings 都通过同一个 `W.Theme.setMode()`；不维护第二 enum 或 toggle state。

### THEME-RESOLUTION
Preference 与 resolved theme 分离。CSS 只看 resolved `html[data-theme=light|dark]`；`system/time` 不直接进入 CSS policy。

### THEME-SYSTEM
System mode 使用一个 `prefers-color-scheme` listener；系统主题变化实时同步，无 reload/API/polling。

### THEME-TIME
Smart Auto 使用浏览器设备当地时间：20:00–08:00 Dark，08:00–20:00 Light。仅保留下一 boundary timeout，并在 visibility/pageshow 校准。

### THEME-SURFACE
Light 以白色为 canvas/surface 基底，蓝/紫为品牌 accent/elevation；Dialog、Select、Topbar、Statusbar、Settings、Input、Button、Transfer、Logs 与 Mobile state overlay 都通过各自 canonical semantic token owner 适配，不新增 CSS repair layer。

### THEME-DARK-STABILITY
Dark palette 不在本轮重设计；Dark semantic values 保持视觉基线。

### THEME-MOTION
System/WeiG Reduced Motion 下 Theme truth、mode sync、System listener 与 Smart Auto 生命周期保持一致；装饰 motion 不作为状态表达。

### THEME-RETIRE
旧 `core.js` theme resolution、`app.js::toggleTheme()`、`#theme-btn.onclick`、重复 enum/state 与旧 Light `!important` correction patch 同批退出。
