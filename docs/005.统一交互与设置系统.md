# 005. 统一交互与设置系统

> 当前 Settings / Locale / qB-owned copy / shared interaction contract。Current Owner 最终以 `DESIGN.md` 为准；qB 原生翻译历史边界与 source-derived 证据见 `docs/012.qB原生翻译与国际化复盘.md`。

## 1. Canonical controls

Settings 复用统一组件：

```text
W.Components.selectControl()
switch-control
field-input setting-input
canonical Dialog / Feedback
shared section/grid/row layout
```

不为 qB4/qB5、Desktop/Mobile 或某个 tab 建第二套控件系统。

## 2. 六个 qB Settings surfaces

Canonical surfaces：

```text
Downloads
Connection
Speed
BitTorrent
Web UI
Advanced
```

Preference routing 由 `W.SettingsSchema` 唯一负责：

```text
exact schema
-> semantic family
-> canonical surface
-> Advanced / Upstream fallback
```

## 3. Exact Preference provenance

每个 admitted official stable profile从 qB upstream getter/setter source生成 descriptor：

```text
getter/read type/kind/confidence
setter/write type/kind/confidence
getter/setter agreement
writable
enum fallback provenance
```

Setter-only key不得逃出 `app/preferences` surface。未知/无法证明的写操作必须 fail closed。

Preference UI source解析除 `<label for=...>` 外，还必须支持 qB使用的 `aria-labelledby` 控件关系；否则 file log age/max size等设置会错误退回 humanized English。

## 4. Locale：单一 persisted owner

唯一持久语言真值：

```text
qB app/preferences.locale
```

启动链：

```text
QBClient.detect()
-> ReleaseProfile / capabilities ready
-> QBClient.getPreferences()
-> W.AppState.preferences / W.SettingsState.prefs
-> W.I18n.applyLocale(prefs.locale)
-> W.I18n.ready()
-> normal render
```

WeiG不保存第二份 `weigg-language`，也不通过 `languagechange`反向写 qB。

两个显示入口：

```text
WeiG WebUI -> Interface -> Language
qB Settings -> Advanced -> Locale
```

共享同一个 `SettingsState.draft.locale`、exact-release locale options、`SettingsSchema` writable provenance、`QBClient.setPreferences()` transaction与 verification reread。

## 5. Locale 保存必须 verification-first

普通 locale save：

```text
user edits locale
-> SettingsState.draft.locale
-> SettingsSchema writable check
-> QBClient.setPreferences(pending)
-> QBClient.getPreferences() verification reread
-> shared prefs snapshot updated
-> W.I18n.applyLocale(verified prefs.locale)
-> rerender existing shared DOM
```

write失败时不切视觉语言。write已成功但 verification reread失败时，明确反馈“已写入但无法确认”，仍不能把未确认 draft提升为 rendered truth。

### 5.1 返回 qB 原生 WebUI 的 locale/root handoff

当同一次 verified Settings transaction把 `alternative_webui_enabled`从 true切为 false时，qB built-in WebUI与 Alternative WebUI translator root会切换。bounded handoff继续由 `W.SessionController`拥有：

```text
Settings pending draft
-> planNativeWebUiReturn(current prefs,pending)
-> prepareNativeWebUiReturn()
   -> if needed: temporary locale
   -> setPreferences({locale:temporary}) + verified reread while Alternative root is active
-> setPreferences(rootPending without final locale)
   -> alternative_webui_enabled=false
-> completeNativeWebUiReturn()
   -> setPreferences({locale:final target}) after built-in root is active
   -> verified reread
-> normal Settings verification reread
```

约束：

```text
最终 persisted truth 仍只有 app/preferences.locale
不保存 previousLocale
不做 exit restore
用户本次 save 显式选择的 locale 必须保持 final target
temporary locale 只是 transaction 中间值
任一阶段失败都不能把未验证 draft 提升为最终 rendered truth
```

## 6. Locale options 的 source truth

真实 qB：

```text
private/views/preferences.html
-> qB WebApplication replaces ${LANGUAGE_OPTIONS}
-> current runtime locale code + localized language name
```

Virtual qB / historical exact profile：

```text
source-SHA-bound frozen locale facts
-> W.ReleaseProfile exact webuiLocales
```

当前 admitted latest qB 5.2.3 source facts为61项；旧 release使用自己的历史 code/subset。历史 alias/identity只在 canonical locale normalization/source layer处理，禁止在 Settings caller中写 patch-version分支。

## 7. qB-owned copy：统一 official source/context pipeline

### 7.1 source-derived semantic refs

qB-owned文案不限于 Preference title/description。source parser还从 exact upstream WebUI markup证明并绑定 Settings tabs、Transfer rate modes、Torrent status filters等 semantic refs。

这些 semantic key只是 WeiG内部稳定引用，译文 owner仍是 qB official source/context + official translation facts。

历史 qB filter名称不同，例如旧版本使用 `Resumed/Paused`、新版本使用 `Running/Stopped`。产品 canonical state仍由 `W.TorrentSemantics`统一，显示文案通过 exact upstream source回到正确 wording，不能在 UI caller自己猜版本。

`Private / PT`是 WeiG-specific filter，没有 qB upstream source/context，因此明确保持 WeiG-owned/English-only边界，不能伪装成 qB官方翻译。

### 7.2 native-first + exact official-TS bridge

正式 source/data链：

```text
exact qB Preferences/toolbar/filters source
-> QBT_TR source/context refs
-> exact sourceSha translator behavior family
-> official qB TS facts
-> enriched Settings translation overlay
-> native registry / minimal official QM
-> exact bridge shard only where required
```

Native registry `private/data/qb-settings-native.txt` 同时包含：

```text
@@WEIGG_PROFILE
@@WEIGG_UI
@@WEIGG_TEXT
```

`tools/qb-settings-native-bundle.mjs`把 Settings refs与 qB-owned UI refs放进同一个 translator-family routing与 canonical minimal QM union；没有第二套翻译数据库。

`4.5.0 -> 4.6.4` 的 Alternative WebUI不执行 document translation，所以 exact sourceSha bridge `private/data/qb-settings/<sourceSha>.json` 继续允许携带同一批 source-proven official-TS facts。这个 JSON是窄 transport，不是翻译 owner。

### 7.3 Current runtime owner

Canonical resolver由：

```text
webui/private/scripts/i18n.js
```

统一负责：

```text
parse @@WEIGG_UI from existing native registry
reuse same exact native / bridge routing as Settings copy
W.I18n.qbText()
W.I18n.loadQbOwnedText()
```

Presentation模块只做 caller，不得再通过 post-render repair补官方文案。

## 8. `qb-releases.json` 与翻译解耦

`qb-releases.json` 的长期职责是 compatibility/source facts：

```text
qB/WebAPI version
source SHA
actions / parameters
Torrent fields / filters
Torrent Detail source facts
Preference provenance
translator behavior / routing facts
other source-derived capability facts
```

它不是 translation database。

禁止再次把 all-release Settings/qB-owned UI translation bodies或 all-locale translation sets塞回 runtime `qb-releases.json`。Build-only translation facts必须在构建阶段用于 routing/artifact生成后从 runtime profile移除；exact bridge shard只保留 source-proven gap所需内容。

## 9. WeiG-owned 文案边界

qB upstream没有对应语义的内容仍由 WeiG自己拥有，例如：

```text
WeiG Interface / Theme / Starfield / Motion
WeiG diagnostics / compatibility notices
WeiG-specific layout/help/feedback
About / Brand / project identity
Private / PT
```

反过来，如果显示语义在 qB upstream已有明确 source/context，优先复用 qB owner，不再手写一份“看起来一样”的翻译。

## 10. Shared column interaction contract

Main Torrent DataGrid 与 Torrent Detail shared tables共用设计语言，但 owner不同：

```text
Main source schema/user projection -> W.TorrentFieldRegistry
Main header geometry/resize/reorder -> W.DataGrid
Detail exact source columns         -> W.ReleaseProfile.torrentDetailUi / detail projection
Detail user visibility/order/width  -> W.SharedColumns
Detail pointer/touch lifecycle      -> W.ColumnInteraction
```

Detail Columns dialog必须 live-apply到同一 shared owner：

```text
checkbox change
-> W.SharedColumns.commit(...)
-> ctx.apply(true)
-> applyDetailColumns(ctx,true)
```

不能出现“canonical state已写入、DOM等 MutationObserver/第二 owner再修”的路径。

Resize/reorder纪律：

```text
resize handle -> resize only
pointermove -> live width + grid-template only
pointerup -> commit/persist once
header pointer drag -> reorder
touch scroll -> 不得误触 reorder
long-press -> 才进入 mobile reorder
```

Detail resize handle必须完整位于当前 header cell 的可命中区域；不能把 hitbox放到 `overflow:hidden`会裁掉的位置。

## 11. Editability

Exact stable profile只有同时满足以下条件才可编辑：

```text
setPreferences action proven
setter exists
write type understood
getter/setter type agrees
descriptor writable == true
```

否则可见但 read-only，或按 capability policy隐藏。Locale也不得绕过这一 contract。

## 12. Unknown / future Preferences

未来 stable新 key不静默丢失：

```text
exact schema
-> semantic family
-> canonical surface
-> Advanced / Upstream fallback
```

未知 scalar在没有 exact setter provenance时只读；未知 array/object可见但只读。禁止猜 unit / enum / range / startup default，也禁止 blind write。

## 13. 与 simulator Endpoint/Transport Contract 的边界

```text
W.SettingsSchema + Preference descriptors
-> key/type/getter/setter/editability

simulator Endpoint Contract
-> historical request/response/status/mutation semantics

simulator Transport Contract
-> auth/header/proxy transport semantics
```

Pages/Virtual qB使用 validation-only server-translation emulation；fixture不得进入正式 product runtime，也不得为 upstream明确禁用 Alternative WebUI QBT_TR的版本伪造 native capability。

## 14. Mobile / acceptance

Mobile使用同一 Settings DOM/state/controls/save flow，不建立第二套语言状态。

当前 product/contract至少覆盖：

```text
qB Locale save -> verified reread -> WeiG UI locale applies
WeiG Language and Advanced Locale share draft/value/options
exact release locale set is used
no weigg-language persistent state
no duplicate setPreferences after ordinary locale save
native WebUI return uses bounded temporary-locale/root/final-locale handoff
native WebUI return final truth remains qB preferences.locale
Desktop/Mobile consume same active locale
QBT_TR source/context provenance
translator behavior across admitted release families
official QM provisioning where required
qB-owned bridge rejects mismatched qbVersion/sourceSha
Virtual qB does not leak unresolved QBT_TR markers
qB-owned Settings + shared UI refs share one source/translator pipeline
qB-owned shared copy APIs are owned only by W.I18n
presentation callers do not keep post-render repair owners
Torrent Detail Columns live-apply uses canonical SharedColumns owner
ordinary mobile detail touch scroll does not reorder
mobile detail long-press reorder persists through canonical owner
```

## 15. 发布证据纪律

Candidate deployment acceptance、Current Stable Locale Matrix与 Real qB Full Frozen Matrix职责互补。正式 promotion/release必须消费同一 final SHA的 release-grade evidence；普通 push的 skipped job、旧 SHA aggregate或 Fast utility不能代替。

Full Frozen Matrix只在 final SHA最终验证/准备发布阶段手工运行，不用于日常 Settings/i18n开发反馈。

未经用户明确批准不得手动触发 Candidate/Locale/Full Frozen；未经明确授权不得移动 main、tag或发布 GitHub Release。

## 16. Dev materialized distribution / installer classifier

Windows/Linux Dev installer只消费 Pages `downloads/dev` materialized payload，不允许 raw-source fallback。

Pages Source使用 canonical materialization relevance matcher覆盖正式 public payload/build inputs。对 dev还会在必要时比较：

```text
published downloads/dev/GIT_SHA
-> current dev SHA
```

只有 workflow能证明整段 newer history全是 Pages-irrelevant变化时，旧 materialized payload才可代表 current dev产品bytes；否则必须 exact-ref materialize。unknown/truncated/读取失败必须 fail closed。
