# 005. 统一交互与设置系统

Status: **current implementation authority**  
Current product version is defined by `VERSION` / `webui/VERSION`.

> 本文件记录当前实现、回归链与 LIVE 验收。历史 WeiG 版本只存在于 Git history / tags / Releases，不在当前文件名、runtime、tests 或 deploy scripts 中保留兼容副本。

## 1. Release boundary

### EXACT-HEAD-001

所有 CI/LIVE/Release 结论绑定 exact 40-char Git SHA。任何 code/test/docs 变化产生新 candidate，旧 SHA 证据不自动继承。

真实 qB4/qB5 LIVE 全过且 maintainer 明确授权前：`main` 不晋级、不 tag、不 Release。

## 2. Repository current-only policy

### FILE-NAMING-001

文件名描述稳定职责，不描述 WeiG release version，也不以某个 qB 版本命名测试职责。

```text

```

### CURRENT-ONLY-001

`dev` 只保存当前架构和当前测试。旧 WeiG runtime、old contracts、old deploy scripts、compat alias 不保留；Git history 是 archive。

### VERSION-FACT-001

以下属于当前产品能力，必须明确保留：

```text
qBittorrent compatibility floor: 4.1.9.1
Private/PT capability: qBittorrent 5.0.0+
Tags capability: WebAPI 2.3.0+
fixture / upstream qB and WebAPI versions
VERSION / exact Git SHA / tag / Release identity
```

所以 **此功能需要 qBittorrent 5.0.0+** 这类提示禁止因仓库去版本化而删除。

## 8. Transfer / telemetry

Transfer history：raw max 900；minute buckets max 720；windows through 12h；长窗口不增加 polling。

Rate canonical unit = B/s；NORMAL endpoint B/s；ALT preference KiB/s；QBClient read ×1024 / write ÷1024。

DHT/Peers single writer：

```text
sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer
```

formatted value unchanged -> zero DOM write。
