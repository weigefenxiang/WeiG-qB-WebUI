## 2. A5 structural / ownership / projection contract

### 2.1 Structural owner是第一事实

每个native Settings control必须有boundary-safe owner path：

~~~text
tab -> fieldset/group -> row -> control
~~~

label/options/unit/helper/content/dependency只能挂到可证明owner。Label evidence优先explicit label-for / aria-labelledby，其次same-row structural relation，再次source-proven compound relation。禁止regex跨label/row/fieldset/tab猜“相邻”文案；fieldset legend不能自动冒充control label。

### 2.2 Unified evidence resolver

Preference read/write relation、controlId、label sourceRef、structural path必须由一个resolver统一仲裁。旧extractor有结果不等于正确；多个evidence冲突必须AMBIGUOUS/fail，不得静默选择第一个。

### 2.3 Canonical projection dialect

Modern DOM与legacy MooTools只允许作为source syntax adapter，最终必须归一为identity/scale/enum-map/sentinel/presence/structured/write-only/unproven等canonical projection。

Legacy至少覆盖 setProperty/getProperty/getSelected/getChildren(option)[index]/setAttribute(selected) 与switch/index mapping。禁止qbVersion分支或Preference-key safeWrite补丁。

### 2.4 Writable round-trip

对source/API证明原生可写的Preference，必须证明完整合法domain的raw->UI->raw与UI->raw->UI互逆。Select/enum遍历全部source options；numeric验证inverse；structured验证parse/serialize；write-only继续遵守P0-11B。

Runtime缺证明时仍fail closed，但A5 acceptance同时报告为FAIL，直到parser/projection被证明或有exact-source reviewed exclusion。

### 2.5 Canonical Select / compound / locale仍保持A4成果

所有Settings enum/select继续只复用 W.Components.selectControl()；compound/structured/time/credential/shared overlay继续使用A4 generic family，不回退。qB-owned copy仍只走exact {source,context}+official translation。A5修的是事实归属和历史projection，不允许破坏5.2.3已验证行为。

## 3. Native Options identity

## 8. Shared interaction

Settings/Detail继续复用canonical `W.Components` 与 shared Input/Button/Dialog/Select；Desktop/Mobile只是同一semantic state的adaptive presentation。

A2新增两条shared interaction contract：

1. **Canonical Select real interaction**：Settings Select必须通过shared `W.Components.selectControl()`完成真实用户option选择并回写同一draft；synthetic value/change不能代替此验收。
2. **Settings row intrinsic layout**：由row shape/semantic/content length/width class决定wrap与packing；长label/description必须增长行高，禁止key/string特判。
3. **Expandable textarea**：inline textarea与expanded Dialog必须共享同一个draft value；Dialog不是第二editor owner、第二save path或第二persistent state。
4. **Time composite formatting**：时/分等显示由generic formatter负责，presentation zero-padding不改变raw value。
5. **Dynamic/write-only controls**：option inventory与current value分离；source control存在性与API是否返回current value分离。

Torrent/Detail现有VirtualList/scroll contract不变。

A5必须先在source阶段复现4.4.5 ownership错误与4.6.7 legacy projection缺口，再修canonical source/compiler owner；禁止先让browser“看起来正确”。

Required validation分层：

全admitted Settings browser matrix必须动态遍历exact native tabs与全部graph controls，不靠key allowlist；writable controls按semantic自动生成安全pointer/keyboard -> draft -> POST -> reread交互。4.4.5/4.6.7/5.2.3只是regression seeds。

第六轮真实复核PASS以前不得进入A full validation；A full validation必须包含ownership census、writeability/projection census、compact round-trip与全admitted browser aggregate。全部PASS才A VERIFIED DONE。


## 10. Source-proven write-only 与 presentation（长期 contract）

Settings 允许一种严格受限的 setter-only/write-only 控件：只有 exact source 同时证明 Options 控件、`setPreferencesAction` 写键/类型、direct write 与 `omitEmpty` 语义时，才可在当前 key 不出现在 `GET /app/preferences` 的情况下进入同一 Settings draft/save owner。此类值永不预填、永不缓存旧值；保存后立即清空，只验证请求成功与普通 preferences 可继续回读，不把“读不到 secret”误判为失败。

显示值与 raw preference 分离：若 exact Options source 明确通过纯 presentation helper（例如单字符前补 `0`）显示数值，Control Graph 应携带通用 `displayFormat`；renderer 只格式化显示，不改变 raw value / projection / write safety。RSS Downloader 的禁用提示同样必须来自 exact source/context copy，不能在 WeiG 里另写一份 qB 文案。
