## 2. A4 compound / Select / locale fidelity contract

### 2.1 Native group / compound layout

Source-native fieldset、row、legend gate、control label、note/help之间的关系必须由 Control Graph 保留到正式 DOM。Renderer不得一律把所有结构压成“左copy + 右control”的固定两列行。以下 family 需要 generic layout primitive，而不是 key-specific CSS：

- section-title + toggle + text/path input；
- time range（from HH:MM -> to HH:MM + day selector）；
- credential pair（username/password + related gates）；
- watch-folder / grouped sub-options；
- inline-multi-control / helper/action；
- long label / note / description。

若 section title 与 control label文本等价，presentation应避免无意义重复，但不能删除 source-owned identity；应由结构/role决定哪个层级显示。

### 2.2 Canonical Select：editability + overlay

所有 Settings enum/select继续只复用 `W.Components.selectControl()`。A4 必须同时证明 source option inventory、real-qB writable gate、真实 pointer/keyboard交互、same draft、Save/reread，以及 menu在viewport内完整可读。

当前 shared CSS 的 option采用单行 ellipsis；第四轮人工证据已证明这对长选项不满足 Settings可读性，因此 A4 应在 shared Select overlay owner系统解决，不能给单个菜单加补丁。

### 2.3 Time / credential / grouped family

Scheduler raw hour/minute值与显示文本分离，正式呈现应组成 source语义的 `08:00 -> 20:00` 与 day selector，不重复同一标题。Web UI credential应保持 source control visibility 与分组；write-only Password不预填旧secret但必须存在可编辑输入。watch-folder等 grouped options应保留 native group关系，可用 table/grid/stacked family实现，但 owner仍是同一 Settings graph/renderer。

### 2.4 Exact locale/context closure

qB-owned文案只按 exact `{source,context}` + exact-release official translation解析。第四轮 I2P 标题仍英文，而 source evidence已经包含对应 OptionsDialog ref；A4 必须审计 runtime copy registry / locale tag / resolvedRefs lookup，不能手工写中文。官方确无翻译时才回退 upstream English。

## 3. Native Options identity

固定八 native-tab whitelist已从 compact tooling退休；当前按 exact `qbOwnedUi` 的 `settings.tab.*` source facts动态提取 native tab集合/顺序。历史已知 change point只作为 evidence，不应再变成固定 allowlist或未来版本 if/else。

## 8. Shared interaction

Settings/Detail继续复用canonical `W.Components` 与 shared Input/Button/Dialog/Select；Desktop/Mobile只是同一semantic state的adaptive presentation。

A2新增两条shared interaction contract：

1. **Canonical Select real interaction**：Settings Select必须通过shared `W.Components.selectControl()`完成真实用户option选择并回写同一draft；synthetic value/change不能代替此验收。
2. **Settings row intrinsic layout**：由row shape/semantic/content length/width class决定wrap与packing；长label/description必须增长行高，禁止key/string特判。
3. **Expandable textarea**：inline textarea与expanded Dialog必须共享同一个draft value；Dialog不是第二editor owner、第二save path或第二persistent state。
4. **Time composite formatting**：时/分等显示由generic formatter负责，presentation zero-padding不改变raw value。
5. **Dynamic/write-only controls**：option inventory与current value分离；source control存在性与API是否返回current value分离。

Torrent/Detail现有VirtualList/scroll contract不变。

## 9. A4 Validation

A4 必须先让 browser acceptance能够复现**第四轮真实 qB**的 failure family，再改产品；旧 A3 fixture PASS不能覆盖真实人工 FAIL。

Required focused coverage至少包括：

- external-program / IP Filtering：不出现逐字竖排；section/control标题层级清晰；toggle + path/input布局完整；
- Scheduler：单一标题，明确 from/to，显示 `08:00` / `20:00`，day selector可见，raw save type不变；
- Downloads content-layout / stop-condition 与 BitTorrent encryption：真实 pointer可选择、draft改变、Save/reread正确；
- watch-folder grouped options：source-native子项集合/顺序/分组正确，不错误摊平成无关行；
- Web UI credentials：username + write-only Password source control均存在，Password非空可POST、保存后清空、GET不伪造secret；
- I2P：exact source/context官方 zh_CN route正确，若官方无翻译才显示 upstream English；
- shared Select menu：长选项完整可辨识、合理换行/扩宽、不得越出viewport；
- no obvious browser/page errors，desktop/mobile与Light/Dark保持同一semantic owner。

自动 PASS 后必须做第五轮真实 qB 人工复核；用户明确PASS后才运行 required admitted-version A full validation。该 validation也PASS后 A才 VERIFIED DONE，之后默认 B -> C -> D -> E -> F。

## 10. Source-proven write-only 与 presentation（长期 contract）

Settings 允许一种严格受限的 setter-only/write-only 控件：只有 exact source 同时证明 Options 控件、`setPreferencesAction` 写键/类型、direct write 与 `omitEmpty` 语义时，才可在当前 key 不出现在 `GET /app/preferences` 的情况下进入同一 Settings draft/save owner。此类值永不预填、永不缓存旧值；保存后立即清空，只验证请求成功与普通 preferences 可继续回读，不把“读不到 secret”误判为失败。

显示值与 raw preference 分离：若 exact Options source 明确通过纯 presentation helper（例如单字符前补 `0`）显示数值，Control Graph 应携带通用 `displayFormat`；renderer 只格式化显示，不改变 raw value / projection / write safety。RSS Downloader 的禁用提示同样必须来自 exact source/context copy，不能在 WeiG 里另写一份 qB 文案。
