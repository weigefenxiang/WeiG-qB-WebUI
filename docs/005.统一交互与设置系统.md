## 2. Settings structural projection / Control Graph

人工复核已经否定“source没有compound proof时长期退化成每个Preference单独一行就是可接受最终行为”。对qB-owned Options，**exact source本身就是composition/behavior proof**；A1必须把这部分结构抽出来，而不是手写旧compound owner。

### 2.1 Source-owned structure

至少需要表达：

- fieldset / nested fieldset；
- same-row control cluster；
- local labels，例如 `From:` / `To:` / `When:`；
- Preference control与source-owned helper button/action；
- checkbox/sentinel pair；
- source notes / adornments；
- source order与parent/child关系。

Examples only — not key-specific implementation rules:

- Listening Port：port input + source-owned Random button；
- Connection Limits：enable checkbox + numeric value，backend `-1`不应作为最终UI语义裸露；
- I2P：fieldset enable + Host/Port + Mixed mode；
- Scheduler：enable + From `HH:MM` + To `HH:MM` + When；
- Proxy：Type/Host/Port + nested Authentication + BitTorrent/peer/RSS/general-purpose controls。

### 2.2 Behavior predicates

旧 `gates.every(preferenceKey is truthy)` 不足。A1 source IR只允许小型可审计predicate，不执行arbitrary upstream JS：

```text
truthy / falsy
equals / notEquals
allOf / anyOf
```

例如Proxy source可表达 `type != None`、`type != SOCKS4`、`proxy_bittorrent=true`、`auth=true`等组合。无法source-prove的条件禁用/read-only，不猜。

### 2.3 Display adornment != value projection

单位/后缀来自source presentation，raw↔display转换来自value projection，两者必须拆开。`KiB/%/MiB/ms/sec/min`可以被source证明应显示，但不能仅凭文本推断 `*1024`、`/1024`或其它write inverse。

### 2.4 Generic templates only

`W.SettingsRenderer`仍是唯一presentation owner。允许的template family是结构型的，例如single row、inline cluster、control+button、gated value、nested fieldset、time range、adornment；template由Control Graph shape选择。

禁止：

- `if (key === 'listen_port')`；
- scheduler/Proxy/I2P manual key list；
- qB patch-version layout switch；
- 恢复旧Listening/Schedule手工owner；
- 第二Settings renderer/state；
- MutationObserver/post-render repair。

移动端仍只是同一graph的adaptive presentation，不改变source semantics。

### 2.5 A1-0 Product Identity / About

A1-0已切换为 `tools/product-identity.mjs` 生成 `webui/private/product-identity.json`；About只读取这一路径，source-direct与materialized/install runtime因此共享canonical product version。`weigg-install.json`继续只记录部署metadata，其历史stale version不再能污染About；build阶段会拒绝Product Identity与VERSION不一致。

## 3. Native Options identity

WeiG外层不应把 qB native Preferences surface重新命名成一套独立“Settings”产品语义。qB-owned native surface identity必须来自对应 exact release upstream source；例如 toolbar/title/source里是 `Options` 时，显示文本由 official qB translation解析。

固定八 native-tab whitelist已从 compact tooling退休；当前按 exact `qbOwnedUi` 的 `settings.tab.*` source facts动态提取 native tab集合/顺序。历史已知 change point只作为 evidence，不应再变成固定 allowlist或未来版本 if/else。

## 4. Preferences independent census

A source layer现在有独立于 semantic extractor 的 census：

```text
raw Preferences source
-> independent tab inventory
-> independent read/write app/preferences references
-> independent source-bound control bindings
-> account against semantic manifest + explicit reviewed exclusions
```

Full-stable Preferences source contract要求每个 admitted release的 `tabs / preferences / bindings` census均 complete；出现 `unaccounted / overlap / escaped / duplicate` 直接 FAIL。Raw helper/client-only controls可以保留为 diagnostics，但不能假装成 app/preferences completeness blocker。

字段级Preferences census仍有效，但A1必须新增独立structural accounting：source-owned helper/adornment/cluster/nested-fieldset/behavior node必须全部进入Control Graph或有reviewed exclusion。当前blocker是**A1 structural projection implementation**，不是继续等待旧A人工复核。Mapping ratio不能代替字段census或structural accounting。

## 5. Locale / qB-owned copy

唯一 persisted language truth是 `qB app/preferences.locale`。qB-owned wording不维护第二手写翻译表，统一走 `W.I18n`：exact `{source, context}` + exact-release official translation facts；只有 source-proven Alternative WebUI hard gap才使用 compact official-TS bridge。官方目标 locale缺失时允许回退 **upstream English source**，不允许回退 WeiG手写“官方中文”。

当前 runtime仍使用 Settings-focused `qb-settings-native.txt` + minimal official QM。C阶段若把它泛化为 domain-neutral qB-owned copy artifact，必须一次切换 generator、runtime loader、callers、tests、distribution contract并删除旧 artifact；不得保留 `qb-settings-native.txt` 和新文件两套 active registry。

`4.5.0 -> 4.6.4` document-translation hard gap继续保留。完整 TS/recovery/source evidence只在 tools/CI，最终 runtime只携带实际引用的 compact registry与 minimal QM。

Locale bootstrap正确链路：

```text
browser/session locale intent
-> canonical bootstrap decision
-> qB app/preferences.locale persisted truth
-> reread/observed locale
-> W.I18n presentation
```

`W.I18n` 只负责 presentation，不得偷偷成为第二 persisted language owner。出现 `zh-CN browser -> qB locale en` 时，不能用前端强制中文显示掩盖；必须检查 bootstrap初始化顺序、session/reset、simulator Preferences truth与真实 qB write/reread contract。
