Status: **current Torrent workspace authority**


## 3. Desktop Header

## 4. Desktop Workspace

Workspace has no four-card Stats dashboard; TorrentPanel flex-fills. Action order remains `Start -> Pause -> More -> Delete -> Expand`. Sidebar keeps Private/PT and Tracker/Path/Category/Tags canonical Selects.

## 5. qB capability

Private/PT unsupported instances keep `5+`. **此功能需要 qBittorrent 5.0.0+** remains a current capability fact. Tags threshold remains **WebAPI 2.3.0+**; unsupported -> visible canonical control -> shared dialog -> no state/request mutation.

## 6. Transfer / DHT / Peers

`sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer`. Same formatted DHT/Peers value -> zero DOM mutation. Transfer history is bounded and includes 12 h without extra polling.

## 7. Connection

```text
getTransferInfo connection_status
-> app emits weigg:status-state
-> W.MobileAdaptive semantic presentation
-> css/layout.css single visual signal
```

Desktop areas: `"torrent storage transfer connection message"`.

```text
connected     success   Connected / 已连接       one animated dot
firewalled    warning   Network limited / 网络受限  one static dot
disconnected  danger    Disconnected / 未连接    one static dot
error         danger    Unavailable / 异常       one static dot
```

There is exactly one `.connection-indicator__dot`. Connected has no second ring/glow circle. Reduced Motion disables its pulse.

## 8. Mobile

Same Facet DOM, Selection toolbar, Search input, Settings Selects and semantic state. Mobile Summary stays visible; Desktop Statusbar hidden; touch target >=44×44; no second qB client/polling/business state.

## 9. Current hard rules

```text
FACET-OWNER-001
PRESENTATION-STATE-001
TELEMETRY-PAINT-001
STATUS-NOISE-001
STATUS-DEDUP-001
STATUS-PLACEMENT-001
ADAPTIVE-STATUS-001
LIVE-INDICATOR-001
STATUS-SIGNAL-001
MOTION-STATUS-001
HEADER-UTILITY-001
HEADER-SEARCH-001
SELECT-SCROLL-001
OWNER-RETIRE-001
FILE-NAMING-001
CURRENT-ONLY-001
```

- `FACET-OWNER-001`: Facet state/composition/control/skin each has one canonical owner.
- `PRESENTATION-STATE-001`: UI nodes are not business-state databases.
- `TELEMETRY-PAINT-001`: one telemetry input, idempotent paint.
- `STATUS-NOISE-001`: routine polling success is silent.
- `STATUS-DEDUP-001`: one durable status is not repeated in one viewport.
- `STATUS-PLACEMENT-001`: durable status uses the lowest-cost surface instead of consuming primary workspace height.
- `ADAPTIVE-STATUS-001`: Desktop/Mobile placement does not create second state or polling.
- `LIVE-INDICATOR-001`: online indicator consumes existing connection state only.
- `STATUS-SIGNAL-001`: one Connection semantic state renders one distinguishable dot only.
- `MOTION-STATUS-001`: online motion respects Reduced Motion.
- `HEADER-UTILITY-001`: passive identity and manual refresh do not occupy permanent Topbar space.
- `HEADER-SEARCH-001`: same Search DOM/state adapts Full -> Compact -> Icon; no duplicate filter owner.
- `SELECT-SCROLL-001`: floating Select internal option scroll cannot trigger anchor re-placement.
- `OWNER-RETIRE-001`: old caller/CSS/test leaves with replaced owner.

## 10. Systemic failure summary

Forbidden regressions include adding a **new UI wrapper** while the old owner remains, replacing a **shared component** with a feature-local copy, spending **primary workspace height** on duplicate telemetry, restoring a permanent **manual refresh**, treating Select internal scroll as page scroll, creating a second Search input for responsive layout, or rendering one Connection state as two visible circles.

## 11. Validation

Browser regression performs real interaction: time-zone option list wheel-scroll must retain non-zero scroll position without menu jump; selecting Asia/Singapore/System updates `W.Time` and trigger text; Desktop Search shrinks to icon on narrow desktop, focus expands the same input and filter state, Mobile reuses the same search input; Connection contains one animated dot and no second glow signal. Dark and Light variants are both exercised.
