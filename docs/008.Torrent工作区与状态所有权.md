# 008. Torrent 工作区与状态所有权

Status: **v0.3.7 canonical contract**

本文定义 Torrent 首页的最终 Desktop/Mobile 信息层级、Current Owner、状态刷新、能力降级与验收规则。设计方法参考 `awesome-design-md`：先定义 semantic tokens、组件职责、responsive behavior、状态契约和失败模式，再由实现消费这些契约；WeiG 保持自己的 Nebula Spatial Console 视觉语言，不复制第三方产品配色或截图。

## 1. 最终信息架构

Desktop Torrent 首页不是仪表盘，而是数据工作台：

```text
Topbar       身份、导航、搜索、Add、Theme、全局 utilities
Sidebar      Torrent 状态筛选 + canonical Facet controls
Workspace    Torrent DataGrid
Statusbar    Torrent 数量 + Free space + Transfer + Connection + actionable message
```

Mobile 是同一应用的 adaptive presentation：

```text
Topbar
Mobile command + Facets
Mobile Summary  Download / Upload / Network / Torrent count
Torrent list
Mobile bottom nav
```

Desktop 不再用四张 Stats Card 消耗 primary workspace height。Mobile Summary 继续保留，不创建第二套 business state。

## 2. Desktop Topbar contract

Desktop Topbar 永远单行：

```text
WeiG qB | Torrents Search RSS Logs Settings | flexible Search | + Add | Theme | utilities
```

Search 是主要 flex-shrink 区，Nav/Actions 不换行。

永久删除：

```text
qB qBittorrent passive product marker
manual refresh button
```

qB 版本/WebAPI 仍在 Sidebar connection metadata 中可见；后台自动 polling 保留，因此 manual refresh 不再占用永久 Header 空间。

### HEADER-UTILITY-001

Permanent Topbar space is reserved for identity, navigation, primary search and actionable global utilities. Passive duplicate product identity and redundant manual refresh do not remain in first-party runtime.

删除 Header 功能必须同时删除 source DOM、caller、专用 CSS、breakpoint rule、过时 test expectation；不得用 `display:none` 留 zombie owner。

## 3. Torrent Sidebar / Facets

Facet 不再显示重复的外部 `Tracker / Save path / Category / Tags` label。

### FACET-OWNER-001

Facet business state belongs to `W.AppState / W.LibraryController`. Facet presentation belongs to `W.SpatialRuntime`. Every visible Facet uses `W.Components.selectControl()` and the shared `css/ui.css` skin.

Retired `filter-shelf`, `facet-trigger`, `facet-popover`, `facet-search`, hidden tracker/path/category/tag nav trees and shelf summary must not remain in runtime.

## 4. Capability degradation

qB4 Private/PT：

```text
entry visible + 5+
click -> shared capability dialog
0 filter mutation
0 legacy Private tracker scan
0 per-torrent fallback
```

Tags 始终可见。`QBClient.capabilities.tags` 的真实边界是 **WebAPI >= 2.3.0**：unsupported 时 Select 的 canonical `onOpen` guard 打开共享 capability dialog，不请求 unsupported Tags endpoint、不改变 tag state。

Compatibility 不允许默认 `N items -> N requests`。

## 5. Desktop workspace geometry

Desktop：

```text

└─ TorrentPanel flex:1
   ├─ GridToolbar
   │  ├─ page size / columns
   │  ├─ Start / Pause / More / Delete
   │  └─ Expand
```


Desktop `.stats-grid` 不是隐藏的第二个 desktop owner，而被正式定义为 **Mobile Summary only**。Desktop 断点不为它保留高度、margin 或布局 slot。

## 6. Mobile adaptive contract

Mobile 消费相同的：

```text
W.AppState / W.LibraryController
W.Selection / ActionRegistry
W.Components.selectControl()
W.SpatialRuntime Facets
W.TransferRuntime telemetry
weigg:status-state connection semantic lifecycle
```

同一个 Facet host 与 Selection toolbar 在显式 Desktop/Mobile slot 之间移动，不 clone 第二业务树。Touch target >=44×44 CSS px。

### PRESENTATION-STATE-001

DOM copy is not application state. Mobile/Selection consume semantic controllers/events, not hidden presentation text.

### ADAPTIVE-STATUS-001

Desktop and Mobile may place one semantic status differently, but they must not create independent state owners or polling paths. Connection has one semantic lifecycle; Desktop renders it in Statusbar and Mobile renders it in Network Summary.

## 7. Transfer telemetry

`W.TransferRuntime` owns transfer samples and metadata：

```text
existing getTransferInfo stream -> speed samples
sync/maindata -> DHT / Peers / Free space
```

DHT / Peers：

```text
sync/maindata
→ W.TransferRuntime
→ weigg:maindata
→ app.js Network metadata renderer
```

### TELEMETRY-PAINT-001

One telemetry field has one authoritative presentation input. Repeated formatted DHT/Peers values perform zero DOM write. Do not add timer, debounce polling, MutationObserver or CSS flash workaround.

Desktop 删除 Network Card 不删除 DHT/Peers semantics；Mobile Network Summary 与 Transfer realtime dialog 仍可使用 canonical telemetry snapshot。

## 8. Connection semantic state

Connection 不增加 API 请求。现有 `loadTransfer()` / `getTransferInfo()` 已取得：

```text
connection_status
```

它只发布：

```text
weigg:status-state
```

`W.MobileAdaptive` 是 adaptive Connection presentation owner，并从同一 semantic event 更新 Desktop Statusbar 与 Mobile Network Summary。

状态：

```text
connected     green     Connected / 已连接
firewalled    warning   Network limited / 网络受限
disconnected  danger    Disconnected / 未连接
error         danger    Unavailable / 异常
```

### LIVE-INDICATOR-001

Online animation is presentation only. It consumes existing semantic connection state and must not create timers, qB clients or network requests.

Connected 使用 `--success` 的柔和绿色 core + halo；firewalled 使用 `--warning`；disconnected/error 使用 `--danger`。Light/Dark 都消费同一 semantic token，只调整已有 surface/contrast 行为。

### MOTION-STATUS-001

The connected glow must respect both `prefers-reduced-motion: reduce` and `html[data-motion="reduced"]`. Reduced Motion uses a static semantic glow, never a JS animation timer.

## 9. Desktop Statusbar

Named areas：

```text
"torrent storage transfer connection message"
```

Persistent desktop state：

```text
Torrent count | Free space | Transfer capsule | Connection
```

`status-message` 只承载 actionable/transient error。Transfer capsule 仍是 `W.Transfer` 的 canonical presentation；Connection 紧跟 Transfer 右侧并垂直居中。

### STATUS-NOISE-001

Background refresh success is silent. `Refreshed / 已刷新`、refresh timestamp 或 polling heartbeat 永远不占持久 UI。

### STATUS-DEDUP-001

A durable state must not appear on multiple permanent surfaces in the **same viewport** without a distinct purpose. Desktop Connection belongs to Statusbar; Mobile Connection belongs to Mobile Network Summary. Both consume the same semantic lifecycle and neither owns polling.

### STATUS-PLACEMENT-001

Persistent global status belongs to the lowest-cost persistent surface. Duplicate global telemetry must not consume primary workspace height when an existing Statusbar can express it.

## 11. Owner retirement

### OWNER-RETIRE-001

Canonical replacement and old owner retirement happen in one change. Git history is the archive.

本轮正式退休：

```text
Desktop Stats presentation / reserved geometry
Desktop Network-card-only connection presentation
qB product marker DOM / CSS / Header caller / breakpoint rules
manual refresh DOM / app caller / obsolete tests

```

前一轮已退休并继续保持删除：

```text

filter-shelf custom Facet system
hidden Facet nav source trees
DHT/Peers transfer-info second writer
Refreshed / last-refresh persistent owner
```

## 12. Systemic failure patterns

1. A new UI wrapper is added while the old owner remains underneath it.
2. A shared component exists but a feature builds a second control system.
3. One telemetry field is painted by multiple streams.
4. Presentation DOM is treated as another presentation's state database.
5. Routine polling success becomes permanent visual noise.
6. Durable global telemetry is repeated in multiple fixed surfaces.
7. Desktop dashboard cards consume primary workspace height even though the same durable state fits a cheaper Statusbar surface.
8. Passive duplicate product identity and manual refresh occupy permanent Header width although neither is required for the primary workflow.

Review must search the whole problem chain, not only the originally reported screenshot element.
