# 008. Torrent 工作区与状态所有权

Status: **v0.3.7 canonical contract**

本文件定义 Torrent 首页在桌面/移动端的最终布局、Current Owner、能力降级、状态刷新与验收规则。它是 `DESIGN.md` 单一所有权原则在 Torrent 工作区的页面级落地；实现不得通过旧 DOM、CSS 覆盖、Observer、版本化并行脚本或兼容壳长期叠加。

## 1. 设计方法

页面设计遵循 `awesome-design-md` 所强调的工程化设计纪律：先定义 semantic tokens、组件职责、布局规则、responsive behavior 和已知失败模式，再由实现消费这些契约。WeiG 保持自己的 Nebula Spatial Console 视觉语言，不复制第三方产品配色或截图。

桌面 Torrent 首页只有四层长期信息：

```text
Topbar       全局导航、搜索、添加、产品入口与全局工具
Sidebar      Torrent 状态筛选 + canonical facet controls
Workspace    统计卡 + DataGrid + 选中项操作
Statusbar    Torrent 数量 + 可用空间 + Transfer
```

持久 UI 不重复表达同一状态。`Network` 卡拥有连接状态；Statusbar 不再重复 `Connected / 已连接`。后台正常刷新成功保持静默，不显示 `Refreshed / 已刷新` 或刷新时间。

## 2. Desktop Topbar contract

Topbar 始终单行：

```text
WeiG qB | Torrents Search RSS Logs Settings | Search | + Add | qBittorrent | Refresh | Theme | utilities
```

搜索框是主要弹性区域：导航与动作保持 `flex:0 0 auto`，搜索区域保持 `flex:1 1 auto` 并允许收窄。空间不足时先缩短 Search，不让 Add、qBittorrent、Refresh 或 Theme 换到第二行。

顶部添加按钮使用短文案 `Add / 添加`；Add Torrent dialog 继续使用完整 `Add Torrent / 添加种子`。短文案是独立 semantic copy，不覆盖全局 `library.add`。

qBittorrent 产品标记紧跟 Add，属于 Header presentation，不属于 Facet/Spatial summary。

## 3. Torrent Sidebar and Facets

Sidebar 状态筛选保留：

```text
All
Downloading
Seeding
Completed
Paused
Active
Stalled
Error
Private / PT [5+ when unsupported]

[All Trackers]
[All Paths]
[All Categories]
[All Tags]
```

Facet 不再显示重复的外部标题 `Tracker / Save path / Category / Tags`。当前 Select value 已承担语义提示。

### FACET-OWNER-001

Torrent facet business state belongs to `W.AppState` and the `W.LibraryController` facade. Visible facet presentation belongs to `W.SpatialRuntime`. Every visible facet control is created with `W.Components.selectControl()` and consumes the shared `css/ui.css` skin.

The retired `filter-shelf`, `facet-trigger`, `facet-popover`, `facet-search`, hidden source nav trees and `filter-shelf__summary` must not remain in first-party runtime.

Tracker and Save Path may enable canonical Select search when the option set becomes large. This is a mode of the shared Select, not a feature-local dropdown.

## 4. Capability degradation

Private/PT on qB 4.x remains visible with the existing `5+` marker. Clicking it opens the shared capability dialog, does not change filter state and does not issue per-torrent tracker scans.

Tags remains visible even when the current WebAPI does not support it. The canonical Tags Select intercepts opening and shows the same shared capability dialog. The capability source is `QBClient.capabilities.tags` (`WebAPI >= 2.3.0`); it must not be falsely described as a qB 5-only feature.

Capability dialogs share one shell and accept feature-specific title/requirement/current-version content. They keep the canonical Dialog scroll policy and do not create feature-local modal skins.

## 5. Torrent workspace geometry

The obsolete Library title block is removed from runtime. The Torrent route begins with Stats and then the DataGrid:

```text
ListView
├─ MobileCommandSlot      mobile only
├─ MobileFacetSlot        mobile only
├─ StatsGrid              intrinsic
└─ TorrentPanel           flex:1
   ├─ GridToolbar
   │  ├─ Selection / page / columns
   │  └─ Start Pause More Delete Expand
   ├─ ColumnHeader
   ├─ TorrentList         primary internal scroll
   └─ Pager
```

Desktop action order is fixed:

```text
Start -> Pause -> More -> Delete -> Expand
```

`W.Selection` and its `ActionRegistry` remain the only action semantics owner. Responsive code may move the same toolbar between declared layout slots; it must not clone action buttons or bind a second action controller.

## 6. Mobile adaptive contract

Mobile is adaptive presentation, not a second application. It consumes the same:

```text
W.AppState / W.LibraryController
W.Selection / ActionRegistry
W.Components.selectControl()
W.SpatialRuntime facet instances
W.TransferRuntime telemetry
```

`W.MobileAdaptive` may move canonical nodes between explicit desktop/mobile slots and adapt density/row height. Touch targets remain at least 44×44 CSS px.

### PRESENTATION-STATE-001

Visible or hidden DOM copy is not application state. Mobile/adaptive UI reads semantic state/events or a semantic controller; it must not copy `page-title`, `library-count-copy`, active hidden facet nav text or another presentation node as an authoritative state source.

Selection-wide query operations likewise consume `LibraryController.state()` rather than retired facet DOM.

## 7. Telemetry and paint discipline

### TELEMETRY-PAINT-001

A telemetry field has one authoritative presentation input. DHT / Peers belongs to `W.TransferRuntime` metadata snapshot sourced from `sync/maindata`.

```text
sync/maindata
  -> W.TransferRuntime snapshot
  -> weigg:maindata
  -> Network metadata renderer
```

`loadTransfer()` owns live Download/Upload speed and connection status only. It must not write DHT/Peers.

The Network metadata renderer is idempotent: if the formatted value is unchanged, it performs no DOM write. Do not add a second timer, debounce-poll loop, MutationObserver or CSS flashing workaround.

## 8. Statusbar contract

Durable Statusbar information is limited to:

```text
Torrent count | Free space | Transfer capsule
```

`Connected / 已连接` is removed because Network card already owns connection status. `Refreshed / 已刷新` and refresh timestamps are removed because routine polling success carries no user decision value.

### STATUS-NOISE-001

Routine background success is silent. Persistent status surfaces are reserved for durable information or actionable warnings/errors. Explicit operation success may use a bounded Toast when useful.

### STATUS-DEDUP-001

A durable state must not occupy multiple permanent surfaces unless each surface has a distinct user purpose. Connection state belongs to the Network card; Statusbar does not duplicate it.

## 9. Owner retirement

### OWNER-RETIRE-001

When this contract becomes canonical, all replaced callers leave runtime in the same change. Git history is the archive.

Retired in this migration:

```text
Library title/count presentation state
filter-shelf and custom facet dropdown system
tracker/savepath/category/tag hidden source nav trees
facet summary qBittorrent marker
Selection reads from retired facet DOM
DHT/Peers transfer-info presentation writer
persistent Refreshed status and last-refresh DOM
persistent Statusbar connection/Connected owner
```

No versioned replacement assets, alias wrappers, Observer repairs or permanent CSS correction layers are allowed.

## 10. Repeated systemic failure patterns

1. A new UI wrapper is added but the old owner remains underneath it.
2. A shared component exists but a feature invents a second control/dropdown system.
3. One telemetry value is painted from more than one data stream.
4. One UI node is treated as another UI's state database.
5. Background success polling creates permanent visual noise or redundant repaint.
6. The same durable state is repeated across multiple fixed surfaces.

Code review must search for these patterns across the complete problem chain, not only the originally reported element.

## 11. Validation contract

Static contracts must verify:

- no retired Library/facet/status DOM IDs or custom facet runtime tokens;
- canonical facet controls and explicit desktop/mobile slots exist;
- Selection reads `LibraryController` state;
- Tags unsupported path uses shared capability dialog and canonical Select open guard;
- DHT/Peers has one writer and idempotent paint;
- Statusbar has no persistent connection or refresh-success owner;
- desktop statusbar geometry is `torrent / storage / transfer / message` only;
- Topbar has a flexible Search region and one-line no-wrap geometry.

Browser interaction gates must execute real user actions: select facet values, qB4 Private capability click, unsupported Tags click, action-toolbar ordering, route transitions and dark/light Select behavior.

Release validation remains exact-HEAD. Any code change invalidates prior candidate SHA. `main` remains release-only until qB 4.1.9.1 and qB 5.2.x LIVE validation passes and the maintainer explicitly authorizes promotion.
