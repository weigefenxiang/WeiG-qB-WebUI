```text

```

## 8. Mobile

Same Facet DOM、Selection toolbar、semantic state。Mobile Summary stays visible；Desktop Statusbar hidden；touch target >=44×44；no second qB client/polling/business state。

## 9. Current hard rules

```text
FACET-OWNER-001
PRESENTATION-STATE-001
TELEMETRY-PAINT-001
STATUS-NOISE-001
STATUS-DEDUP-001
STATUS-PLACEMENT-001
ADAPTIVE-STATUS-001
LIVE-INDICATOR-001
MOTION-STATUS-001
HEADER-UTILITY-001
OWNER-RETIRE-001
FILE-NAMING-001
CURRENT-ONLY-001
```

- `FACET-OWNER-001`: Facet state/composition/control/skin each has one canonical owner.
- `PRESENTATION-STATE-001`: UI nodes are not business-state databases.
- `TELEMETRY-PAINT-001`: one telemetry input, idempotent paint.
- `STATUS-NOISE-001`: routine polling success is silent.
- `STATUS-DEDUP-001`: one durable status is not repeated in one viewport.
- `STATUS-PLACEMENT-001`: durable status uses the lowest-cost surface instead of consuming primary workspace height.
- `ADAPTIVE-STATUS-001`: Desktop/Mobile placement does not create second state or polling.
- `LIVE-INDICATOR-001`: online indicator consumes existing connection state only.
- `MOTION-STATUS-001`: online motion respects Reduced Motion.
- `HEADER-UTILITY-001`: passive identity and manual refresh do not occupy permanent Topbar space.
- `OWNER-RETIRE-001`: old caller/CSS/test leaves with replaced owner.

## 10. Systemic failure summary

Forbidden regressions include adding a **new UI wrapper** while the old owner remains, replacing a **shared component** with a feature-local copy, spending **primary workspace height** on duplicate telemetry, or restoring a permanent **manual refresh** control beside automatic polling.

## 11. Repository boundary

Current repository files use stable responsibility names. Old WeiG release-specific tests/scripts are deleted, not aliased. This cleanup does not remove qB/WebAPI version capability facts.
