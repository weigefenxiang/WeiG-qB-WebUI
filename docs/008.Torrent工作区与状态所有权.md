# 008. Torrent 工作区与状态所有权

Status: **current Torrent workspace authority**

## 1. Information architecture

```text
Topbar    -> identity / navigation / search / primary global actions
Sidebar   -> Torrent state filters + canonical facets
Workspace -> Torrent DataGrid
Statusbar -> Torrent count + storage + Transfer + Connection + actionable message
```

Mobile keeps compact Download / Upload / Network / Torrent Summary and hides Desktop Statusbar.

## 3. Desktop

Topbar：`WeiG qB | Nav | flexible Search | + Add | Theme | utilities`。No passive qB product badge；no manual Refresh；automatic polling remains。

Workspace 无四卡 Stats dashboard；TorrentPanel flex-fill。Action order：`Start -> Pause -> More -> Delete -> Expand`。

Sidebar 保持 Private/PT 和 Tracker/Path/Category/Tags canonical Selects。

## 4. qB capability

Private/PT 在 unsupported qB 上保持 `5+`。**此功能需要 qBittorrent 5.0.0+** 是当前 capability fact，必须保留。

Tags threshold = **WebAPI 2.3.0+**；unsupported -> visible control -> shared dialog -> no state/request mutation。

## 6. Transfer / DHT / Peers

`sync/maindata -> W.TransferRuntime -> weigg:maindata -> app renderer`。DHT/Peers same formatted value -> zero DOM mutation。

Transfer history bounded：raw max 900；minute buckets max 720；windows through 12h；no extra polling。

## 7. Connection

```text
getTransferInfo connection_status
→ app emits weigg:status-state
→ W.MobileAdaptive presentation
```

Desktop areas：`"torrent storage transfer connection message"`。

```text
connected     success   Connected / 已连接
firewalled    warning   Network limited / 网络受限
disconnected  danger    Disconnected / 未连接
error         danger    Unavailable / 异常
```

Connected pulse is CSS-only；Reduced Motion -> static glow。

## 8. Mobile

Same Facet DOM、Selection toolbar、semantic state。Mobile Summary stays visible；Desktop Statusbar hidden；touch target >=44×44；no second qB client/polling/business state。

## 9. Status noise

Routine polling success silent。`Refreshed / 已刷新` / last-refresh timestamp stay retired。

## 10. Repository boundary

Current repository files use stable responsibility names. Old WeiG release-specific tests/scripts are deleted, not aliased. This repository cleanup does not remove qB/WebAPI version capability facts.
