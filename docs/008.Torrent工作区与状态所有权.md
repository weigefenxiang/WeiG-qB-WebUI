# 008. Torrent 工作区与状态所有权

Status: **current Torrent main/detail ownership authority**

本文件维护 Torrent workspace 的当前 semantic ownership、source provenance 与交互边界，不记录按 WeiG VERSION 切片的开发历史。当前尚未完成的产品事项统一放在 `docs/014`。

## 1. Product owner chain

```text
qB stable source facts
-> W.ReleaseProfile
-> W.TorrentSemantics / W.TorrentFieldRegistry / W.QbUiEvidence
-> W.TorrentFilterView / W.LibraryController / W.Selection / W.SharedColumns
-> generic Detail runtime / W.CapabilityRegistry
-> W.QBClient HTTP boundary
-> canonical presentation
```

### TORRENT-FILTER-OWNER

`W.TorrentSemantics` 是 status/filter evaluation 的唯一 owner；`app.js` 与 `selection.js` 不得维护自己的 state regex/version table。

### TORRENT-COLUMN-LAYOUT

对 exact/certified qB release：`W.ReleaseProfile.torrentTableColumns -> W.TorrentFieldRegistry -> W.DataGrid -> row/card presentation`。Source schema拥有 native key/order/defaultVisible/defaultWidth/dataProperties；用户 visibility/order/width只是 override。

Resize hitbox只负责 resize；header drag threshold负责 reorder；ordinary header click负责 sort。Pointermove只做 live width/grid-template paint，pointerup进行一次 canonical save/reconciliation。用户 resize floor 为 24 px。禁止 MutationObserver、post-render repair、第二 layout state或第二 persisted column owner。

## 2. Main VirtualList / horizontal scroll

`#torrent-list` native scroll container + `W.VirtualList` 是主表唯一 virtual/scroll projection owner。

```text
horizontal motion does not trigger row render
horizontal motion期间 polling仍继续
new polling items只保留 latest pending snapshot
while horizontally active -> no main-list repaint
continued horizontal motion -> restart same bounded idle timer
140 ms idle -> flush latest snapshot once
other VirtualLists -> immediate setItems behavior
```

禁止第二 app-level scroll state、scrollLeft transform同步 header/body、停止全部后台 polling、MutationObserver/post-render scroll repair，或每次 poll 重建 scroll owner。

## 3. Torrent Detail source manifest

Detail source facts链：

```text
exact qB properties markup + detail scripts + menu markup + controller actions
-> Detail source parsers
-> W.ReleaseProfile.torrentDetailUi + actionDescriptor
-> W.QbUiEvidence / canonical detail projection
```

Source surface包括 tabs/translation refs、property groups/fields/dataProperties、Files/Trackers/Peers/Web Seeds columns、file-priority controls/options、context-menu order/labels/availability、sourceAction + endpoint relation、action required/optional parameters/options。UI key 不自动等于 API field；未知 upstream shape必须 fail closed。

## 4. Detail generic runtime / shared columns

Runtime dispatch：

```text
source-generated tabOrder/tabs
-> General uses source propertyLayout
-> table tab resolves from torrentDetailUi.tables
-> generic renderDetailTable(surface)
```

Files / Trackers / Peers / Web Seeds 不再拥有各自 renderer/action registry。固定 `detailActions`、固定五-tab assumption、per-surface renderer与第二 General fallback都属于 retired architecture。

Shared columns：

```text
W.ReleaseProfile.torrentDetailUi.tables
-> W.QbUiEvidence.detailColumns(surface)
-> W.SharedColumns user visibility/order/width
-> W.ColumnInteraction pointer/touch lifecycle
-> shared detail table DOM
```

`.shared-table__viewport` 是唯一 horizontal scroll owner。Detail header/body消费同一个 resolved column definition/grid template/order/width。Header 使用不透明 semantic surface，滚动 row 不得透过 sticky header 显示。Columns checkbox必须 live-apply同一 canonical state；pointermove只 paint，pointerup再 persist。普通 mobile touch scroll不得误触 reorder；intentional long-press才可 capture。

## 5. Detail identity / toolbar / context ownership

0.3.88 的 canonical Detail presentation：

```text
identity row: Detail eyebrow + torrent state
next row: torrent title
progress: existing truthful torrent progress owner
```

状态不再占用独立大块纵向空间。

每个 shared table surface只有一个 first toolbar rail，顺序固定为：

```text
source-proven zero-selection actions
-> Columns
-> count / explanatory note
```

Count/note 属于该 toolbar，不再单独占一行。Columns不能被推到最右侧形成第二视觉 owner。

右键交互：

```text
blank table area -> selectionCount=0 -> exact zero-selection source actions
row -> row context + selectionCount=1 -> exact row/source actions
```

Blank-area 与 row context menu 只是 presentation caller，不能各自维护 action truth。空白区没有 source-proven action时保持无操作。

## 6. Tracker source provenance / exact URL / actions

Tracker row source relation必须 source-prove，例如 `peers -> num_peers`、`seeds -> num_seeds`、`leeches -> num_leeches`、`downloaded -> num_downloaded`、`message -> msg`。

Torrent Detail Tracker URL 的 business truth 是 `torrents/trackers` 返回的 exact `url`。Display/edit/action row-address不得通过 `normalizeTracker()` 丢失 hostname/path/query。UI presentation可 single-line ellipsis，并把完整 exact value放入 title/tooltip。

Tracker Edit/remove/reannounce/add等 transport action分别由 source-generated context menu + exact action descriptor证明；不能用粗粒度 writable boolean或 endpoint-name分支代替。

Source-proven Tracker Copy 是本地 presentation action：复制 exact row URL 到浏览器 clipboard，不发明 WebAPI write endpoint。

## 7. Peer provenance / flags / actions

Peers table普通数据字段与 mutation actions分层：

```text
peer data / source relation -> exact upstream/profile
row/cell rendering          -> shared detail projection
country flag                -> source-pinned local qB flag asset + deterministic ISO fallback
peer mutation action        -> exact source menu/action + capability + QBClient
```

Peer永久 inline `×` action已退休；supported peer actions进入 row context menu。Source-proven Peer Copy 使用本地 browser clipboard executor，不进入 QBClient transport。

`country_code` 的图形资源由 materialization owner从 pinned qB source生成本地 `images/flags/<iso>.svg` + `css/qb-peer-flags.css`；raw/unmaterialized source只显示 ISO code fallback，不依赖外部 CDN runtime truth。

## 8. Content / Files provenance

Files/Content table继续消费 exact source-derived columns和 `filePriority` control/options。

0.3.88 增加的 native-like row actions必须满足：

```text
Rename -> exact current release proves torrentscontroller.h:renameFileAction
       -> oldPath binds exact source-proven file name/path
       -> newPath is prompted through generic parameter contract
Priority -> values/labels come from source-derived filePriority control/options
         -> write only when exact filePrioAction provenance is present
```

不能因为 UI 中存在文件名或 priority 列就推断 write support。不存在 exact provenance时 action不显示/不发送 HTTP。

当前 proven derived relation仍包括：

```text
checked   -> priority
remaining -> size + progress + priority
priority == 0 -> checked=false, remaining=0
else remaining = size * (1 - progress)
```

## 9. Properties / General provenance

General只执行一次 `torrents/properties` read，然后把 response交给 source-generated `propertyLayout + dataProperties + certified profile`。Group/field labels走 qB-owned translation refs，值复用 canonical formatter/helpers。

桌面 General 按 source order 使用 native-like 三组 label/value pairs 排列；这是 presentation of the same source layout，不是第二 field registry。移动端可以降为单列，但 source order/provenance不变。

`#detail-content` 不拥有第二滚动；`.general-detail` 在 General surface 自己承担 vertical scroll。没有 propertyLayout或 binding无法 exact证明时 fail closed / omission。禁止恢复手写 General field list或假值 fallback。

## 10. Generic Detail action contract

Toolbar、blank-area context menu与row context action共享同一 source action chain：

```text
contextMenus / exact local source action
-> source availability + selection context
-> ReleaseProfile.actionDescriptor(sourceAction) when transport is required
-> endpoint agreement
-> required/optional parameters + parameterOptions
-> generic parameter binding
-> W.QBClient.request() for transport actions
```

Generic binder可绑定 torrent hash、Tracker exact URL、Peer address、Content exact path、source-proven option/new-value参数。不能绑定 required parameter、endpoint/sourceAction不一致或 provenance未知时，在 HTTP 前 fail closed。

Copy 一类 source-proven local action只使用浏览器能力（当前 clipboard），不得为了统一 executor而伪造 qB endpoint。

禁止为 `editTracker/removeTrackers/banPeers/renameFile` 等当前 endpoint重新建立 feature-local业务 owner。

## 11. Filter / selection parity

qB historical/current upstream filter名称差异由 `W.ReleaseProfile + W.TorrentSemantics` canonicalize；caller不维护 patch-version判断。Completed与Seeding必须区分；`progress >= 1`只证明完成，不单独证明正在做种。

`Private / PT` 属于 capability-gated Tracker facet，不属于 status filter。其可见性必须由 `W.CapabilityRegistry.supports('privateFilter')` 判定；Page rendering与 `W.Selection.selectAllMatching()/invertAllMatching()` 必须消费同一个 `LibraryController.matchesTorrent()` matcher，保证页面与选择语义一致。

## 12. Transfer ownership

Existing app transfer cycle仍是 `transfer/info` poll publisher；`W.TransferRuntime` 是唯一 bounded realtime history owner。Desktop/Mobile只做 adaptive presentation，不增加第二 request/timer/history owner。
