# 008. Torrent 工作区与状态所有权

Status: **current Torrent main/detail ownership authority**

本文件维护 Torrent workspace 的当前 semantic ownership、source provenance 与交互边界，不记录按 WeiG VERSION 切片的开发历史。当前尚未完成的产品事项统一放在 `docs/014`。

## 1. Product owner chain

```text
qB stable source facts
-> W.ReleaseProfile
-> W.TorrentSemantics / W.TorrentFieldRegistry / W.QbUiEvidence
-> W.TorrentFilterView / W.LibraryController / W.Selection / W.SharedColumns
-> generic Detail runtime / W.CapabilityRegistry
-> W.QBClient HTTP boundary
-> canonical presentation
```

### TORRENT-FILTER-OWNER

`W.TorrentSemantics` 是 status/filter evaluation 的唯一 owner；`app.js` 与 `selection.js` 不得维护自己的 state regex/version table。

### TORRENT-COLUMN-LAYOUT

对 exact/certified qB release：

```text
W.ReleaseProfile.torrentTableColumns
-> W.TorrentFieldRegistry
-> W.DataGrid
-> row/card presentation
```

`torrentTableColumns` 提供 native key、source order、defaultVisible/defaultWidth与 `dataProperties`；用户 visibility/order/width只是 override。Saved preference与 current effective availability分离；暂时缺失的列不得破坏性删除用户设置。

Main Columns dialog仍由 `app.js -> openColumns()` 进入同一 persisted owner；Desktop header resize/reorder由 `W.DataGrid`负责。约束：

```text
resize hitbox -> resize only
header drag threshold -> reorder
ordinary header click -> sort
pointermove -> live width/grid-template only
pointerup -> one canonical save/reconciliation
user resize floor -> 24 px
```

列存在本身不证明 server sort；未知 source-only column不能发明 sort semantics。

禁止 MutationObserver、post-render repair、第二 layout state或第二 persisted column owner。

## 2. Main VirtualList / horizontal scroll

`#torrent-list` native scroll container + `W.VirtualList` 是主表唯一 virtual/scroll projection owner。

当前 polling/scroll contract：

```text
horizontal motion does not trigger row render
horizontal motion期间 polling仍继续
new polling items只保留 latest pending snapshot
while horizontally active -> no main-list repaint
continued horizontal motion -> restart same bounded idle timer
140 ms idle -> flush latest snapshot once
other VirtualLists -> immediate setItems behavior
```

这条优化不允许被改造成：

```text
第二 app-level scroll state
scrollLeft transform同步header/body
停止所有后台 polling
MutationObserver/post-render scroll repair
每次poll重建新的 scroll owner
```

Main row/header的横向位置由浏览器 native scrollLeft直接驱动；轮询/重建不得无故把用户位置重置为0。

## 3. Torrent Detail source manifest

Detail source facts链：

```text
exact qB properties markup + detail scripts + menu markup + controller actions
-> Detail source parsers
-> W.ReleaseProfile.torrentDetailUi + actionDescriptor
-> W.QbUiEvidence / canonical detail projection
```

Source surface当前包括：

```text
detail tabs + official translation refs
property groups / property fields / dataProperties
Files / Trackers / Peers / Web Seeds columns
column source order/caption/source-context/defaults
response/derived source relation
file-priority controls/options
Tracker/Peer context-menu order/labels/availability
sourceAction + endpoint relation
action required/optional parameters + source-proven options
```

UI key不自动等于 API field；每个 relation必须 exact-source proven。Unknown source shape必须 fail closed。

## 4. Detail generic runtime / shared columns

Runtime dispatch：

```text
source-generated tabOrder/tabs
-> General uses source propertyLayout
-> table tab resolves from torrentDetailUi.tables
-> generic renderDetailTable(surface)
```

Files / Trackers / Peers / Web Seeds 不再拥有各自 renderer/action registry。固定 `detailActions`、固定五-tab assumption、per-surface table renderer与第二 General fallback都属于 retired architecture。

Shared columns：

```text
W.ReleaseProfile.torrentDetailUi.tables
-> W.QbUiEvidence.detailColumns(surface)
-> W.SharedColumns user visibility/order/width
-> W.ColumnInteraction pointer/touch lifecycle
-> shared detail table DOM
```

Owner边界：

```text
source schema/default/provenance -> W.ReleaseProfile.torrentDetailUi
source row/value projection      -> W.QbUiEvidence
user visibility/order/width     -> W.SharedColumns
resize/reorder lifecycle        -> W.ColumnInteraction
horizontal scroll               -> .shared-table__viewport
```

Detail Columns checkbox必须 live-apply同一个 canonical state。Resize lifecycle必须 pointerId-filtered；pointermove只 paint，pointerup再 persist。普通 mobile touch scroll不得误触 reorder；long-press才进入 intentional reorder。

Columns entry加入该 surface 已存在的 first toolbar row；zero-selection source actions也走同一 toolbar rail。Header与body必须消费同一 column definition、grid template、order/width/padding/alignment projection。`.shared-table__viewport`是唯一 horizontal scroll owner；禁止为了“修表头位置”增加第二段同步 JS、transform或 MutationObserver。

## 5. Tracker source provenance / exact URL / actions

Tracker row source relation当前必须 source-prove：

```text
peers      -> num_peers
seeds      -> num_seeds
leeches    -> num_leeches
downloaded -> num_downloaded
message    -> msg
```

Parser覆盖 legacy indexed assignment、`row=[...]`、source-proven bare local/helper dependency、modern `rows.push({...})` 与 nested `tracker.endpoints` dependency；未知 upstream形态继续 fail closed。

Torrent Detail Tracker URL的 business truth是 `torrents/trackers` 返回的 exact `url`。Display/edit/action row-address不得通过 `normalizeTracker()` 丢失 hostname/path/query。UI presentation可做 single-line ellipsis并把完整 exact value放入 title/tooltip，但不得改变业务值。

主 Torrent 列表 Tracker facet的 normalization属于另一个合法语义 owner，Detail URL contract不得用全文件正则误伤它。

Tracker Edit/remove/reannounce/add等 action分别由 source-generated context menu + exact action descriptor证明；不能用粗粒度 `trackerWritable` boolean或 endpoint-name分支替代。

## 6. Peer provenance / flags / actions

Peers table普通数据字段与 mutation actions分层：

```text
peer data / source relation -> exact upstream/profile
row/cell rendering          -> shared detail projection
country flag                -> shared U.countryFlag(country_code)
peer mutation action        -> exact source menu/action + capability + QBClient
```

Country/region icon复用 shared ISO alpha-2 code renderer，不维护手写 country-name -> flag mapping。

Peer永久 inline `×` action已退休；supported peer actions进入 row context menu。Context menu只是 presentation caller，真实 action support、required parameter与 transport仍由 canonical source/capability/QBClient owner决定。

## 7. Properties / General provenance

Properties source surface不能只扫描 `KEY_PROP_*`。qB部分版本的 `propertiesAction()` 还会使用 shared serializer中的 `KEY_TORRENT_*`；因此允许字段来自：

```text
propertiesAction() actual assignments
+ shared serializer key definitions
```

General当前执行一次 `torrents/properties` read，然后把 response交给 source-generated `propertyLayout + dataProperties + certified profile`渲染。Group/field labels走 qB-owned translation refs，值复用已有 formatter/helpers。

不同版本没有的字段按 source/API能力安全缺省；没有 propertyLayout或某 binding无法 exact证明时 fail closed / omission。禁止恢复手写 General field list或假值 fallback。

## 8. Generic Detail action contract

Toolbar与row action共享同一 source action chain：

```text
contextMenus
-> source availability
-> ReleaseProfile.actionDescriptor(sourceAction)
-> endpoint agreement
-> required/optional parameters + parameterOptions
-> generic parameter binding
-> W.QBClient.request()
```

通用 binder可以绑定 canonical context能可靠证明的数据：torrent hash、Tracker exact URL、Peer address、source-proven option/new-value参数。不能绑定 required parameter、endpoint/sourceAction不一致或 provenance未知时，在 HTTP 前 fail closed。

禁止为 `editTracker/removeTrackers/banPeers` 等当前 endpoint再建立专用业务分支；未来 source新增 action应优先由 generator/manifest + generic runtime自动接入，而不是修改 UI owner表。

## 9. qB 5.2 Content derived facts

当前 proven relation：

```text
checked   -> priority
remaining -> size + progress + priority
```

正式语义：

```text
priority == 0 -> checked=false, remaining=0
else remaining = size * (1 - progress)
```

Browser fixture可以消费 current exact-source overlay，但不能因此私自晋级 Frozen LKG。

## 10. Filter / selection parity

qB historical/current upstream filter名称差异由 `W.ReleaseProfile + W.TorrentSemantics` canonicalize；caller不维护 patch-version判断。

Completed与Seeding必须区分；`progress >= 1`只证明完成，不单独证明正在做种。

`Private / PT` 属于 capability-gated Tracker facet，不属于 status filter。其可见性必须由 `W.CapabilityRegistry.supports('privateFilter')` 判定；Page rendering与 `W.Selection.selectAllMatching()/invertAllMatching()` 必须消费同一个 `LibraryController.matchesTorrent()` matcher，保证页面与选择语义一致。

## 11. Transfer ownership

Existing app transfer cycle仍是 `transfer/info` poll publisher；`W.TransferRuntime` 是唯一 bounded realtime history owner。Desktop/Mobile只做 adaptive presentation，不增加第二 request/timer/history owner。

## 12. QBClient / simulator boundary

`W.QBClient`负责真实 transport，不拥有 patch-version compatibility policy；Source profile/capability owner决定 endpoint/action/parameter是否合法。

Virtual qB 位于 QBClient后方，用于验证 historical request/response/status/mutation semantics；Simulator/Pages PASS不能反向定义正式 Torrent product truth。
