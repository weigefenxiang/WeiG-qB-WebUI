## 1. Product owner chain

```text
compact source facts -> W.CapabilityRegistry
-> W.TorrentSemantics / W.TorrentFieldRegistry / W.QbUiEvidence
-> W.LibraryController / W.Selection / W.SharedColumns
-> generic Detail runtime
-> W.QBClient HTTP boundary
-> canonical presentation
```

`W.VirtualList` 是主 Torrent list以及适用 Detail virtual surface 的唯一 virtual/scroll projection owner。Polling 可以在原生横向/纵向滚动或 scrollbar drag 期间继续取得新数据，但不得在用户交互期间用新 snapshot 替换当前 DOM；只保留 latest pending snapshot，bounded idle 后一次提交。禁止第二 scroll/poll/state owner、scroll repair loop、MutationObserver 同步或每个 wheel/scroll frame rebuild。

## 2. B — Status / native Sidebar facets

Status/filter semantics由 `W.CapabilityRegistry + W.TorrentSemantics` canonicalize；caller不写 patch-version分支。B 的最终链固定为：

```text
exact upstream Status/filter/facet inventory + order
-> torrent compact source facts
-> W.CapabilityRegistry / W.TorrentSemantics
-> generic Library facet state/value providers
-> generic Sidebar projection
-> append WeiG Path extension last
```

qB-native facets的存在、顺序、filter parameter/value语义、source/context copy都必须由 exact source admission证明。Category/Tags 的实时值来自 qB；Tracker business value保持 exact URL；WeiG Path不是 qB-native，始终最后。

`All Categories / All Tags / All Trackers / All Paths` 只是 no-filter/default option；facet trigger的持久 dimension label应分别是原生 `Categories / Tags / Trackers` 与 WeiG `Path`，不能把 `All` 误做成额外 facet标题。

当前 `spatial.js` 仍固定声明 `category/tag/tracker/savePath`，LibraryController 也仍有固定 facet state/setter，因此 **B 尚未完成**。正式切换时必须把 qB-native facet部分原子替换成 generic manifest consumer并删除被替代的固定 qB facet owner；不能在旁边再加第二套 generic renderer。

未来 upstream 增加同类 native facet时，应由 source inventory/admission进入 compact manifest；不得再靠手改 `defs` 增加第 N 个 qB-native facet。WeiG Path 保持明确 extension，不参与 upstream inventory。

## 3. Main columns / filters / actions

Exact certified column/source facts由 `W.CapabilityRegistry.torrentFieldFacts()` 投影给 `W.TorrentFieldRegistry`；用户 visibility/order/width只是 override。Torrent More/right-click只有一个 ActionRegistry；Category/Tags truth实时来自 qB；checked tag remove必须 exact `removeTagsAction`；Copy browser-local，其余 mutation/export走 QBClient。

主列表 VirtualList 必须保持持久实例；polling 只更新 canonical data/snapshot，不得因为 refresh 重建第二个 virtual-list owner。滚动交互结束后只提交 latest pending snapshot，避免 scrollbar thumb drag期间 DOM replacement造成拖动位置跳跃或卡顿。

## 4. E — Torrent Detail

```text
W.CapabilityRegistry.torrentDetailUi()
-> W.QbUiEvidence
-> generic Detail runtime
-> W.SharedColumns / W.ColumnInteraction / existing viewport / W.VirtualList where applicable
-> W.CapabilityRegistry.actionDescriptor()
-> W.QBClient
```

Tabs/General/tables/context menus都消费同一 compact source manifest。General/Properties使用同一 properties response/cache owner，不为了 hero 与 Properties surface建立第二请求/cache。Files/Trackers/Peers/Web Seeds不建立 per-surface renderer/action owner。Header/body同 column definition；`.shared-table__viewport`是唯一 table scroll owner。

E 已经是 A–F 中最成熟的 source-driven surface。本轮只做 inventory/copy/action completeness audit和真实缺口修补；禁止因为其它 domain 重构而另建 `DetailV2`、legacy/new renderer或第二 state/polling/column owner。

Detail hero 的状态与 progress 是同一 torrent semantic state 的两个 presentation区域：状态位于上一行，真实 progress rail + truthful percentage位于下一行；禁止 margin/DOM repair hack，也不得引入第二份 progress state。

## 5. Files provenance / expand-collapse anchor / local copy

qB files response order与 exact source file index必须保持。Synthetic folder只是 presentation，绝不是 qB source file。Folder aggregation只读；folder/file context共用 canonical owner但 folder不继承 file-only Priority。

File Rename只在 exact `renameFileAction` provenance存在时发送；Folder Rename独立要求 `renameFolderAction`。两者不能互相推断。

展开/收起 folder 时，viewport anchor固定为**用户实际点击的 folder row 的 viewport Y**。异步更新/重算后，只有用户没有主动滚动时才尝试把同一 folder row 恢复到原 viewport Y；如果该 row 无法稳定恢复，只允许 bounded fallback。不得再恢复 stale child anchor、已消失 child row、旧 selection 或其它与用户点击无关的 anchor。

真实 file row 的 browser-local context actions可以包含：

```text
复制文件路径
复制所在文件夹路径
```

路径必须来自 qB 返回的 host path semantics；Windows/Unix separator不能从运行浏览器的 OS 猜。Synthetic folder 不是 qB file，不能伪装成 file-level source action target。

Sticky parent与 hierarchy继续使用同一 viewport，无 MutationObserver/scroll sync/第二 data owner。

## 6. Tracker / Peer / General

Tracker business value保持 exact `torrents/trackers.url`；presentation ellipsis不得改变 write/copy地址。Peer flags使用 source-pinned local qB assets + deterministic ISO fallback，无第三方 CDN truth。General layout来自 source-generated property layout；没有 proof即 omission/fail closed，不恢复手写 fallback。

## 7. Write boundary

Generic mutation链固定为 source availability -> CapabilityRegistry action descriptor -> endpoint agreement -> required/optional parameter binding -> QBClient。无法证明 required binding、source action或endpoint时必须在 HTTP 前阻断。桌面客户端 Open/Open containing folder等无 WebAPI provenance能力不得伪造。

## 8. Validation notes

B 阶段内部优先 source/change-point + focused browser tests，完整 B 收口后最多一次 65-release offline/Virtual Sidebar/Torrent matrix；应证明 source inventory = mapped native facets/statuses + explicit exclusions，unaccounted=0。

Torrent/Detail browser tests必须执行真实滚动、drag、expand/collapse、context action并断言最终 semantic/visible state。只检查 DOM 节点存在不能证明 scroll ownership或 anchor稳定。

若 browser test在 Settings/Torrent/Detail等待旧 selector超时，先核对 current semantic owner和 renderer DOM；不能因为旧测试路径失效就恢复已退休结构。同样，若真实 UI确实未渲染/不可交互，也不能把它简单改成 test skip。
